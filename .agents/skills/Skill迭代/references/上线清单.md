# v1.0 资产 Skill 上线清单

一个能正式上线的 Skill，8 条全勾：

- [ ] `name` 名称字段清楚、不和别的 Skill 冲突
- [ ] `description` 触发说明字段写清输入、意图、输出、边界（五要素齐全）
- [ ] 有触发和不触发场景（含用户真实口语说法）
- [ ] 有最低输入要求，不足会追问
- [ ] 工作流程有顺序、关键处有检查点
- [ ] 输出格式可验收
- [ ] 禁止伪造、高风险动作（D/E 级）必须确认
- [ ] 有测试记录、有迭代记录

草稿 Skill：能解决一次问题，但结构可能不完整。
资产 Skill：可重复使用、可测试、可迭代、可维护。

9. 推荐执行通道已标注，可自动化环节未退化为手工浏览器流程（机器通道优先）。
