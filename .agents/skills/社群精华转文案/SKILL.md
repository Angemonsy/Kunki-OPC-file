# 社群精华转文案

> 社群里的每一次碰撞，都是一座素材富矿

## 🎯 功能概述

这是一个**编排器 skill**，专门处理"社群讨论→公众号文章"的转化链路。

社群讨论相比其他素材来源的独特优势：
1. **多视角碰撞**：不是一个人的想法，是一群人的真实反馈和争论
2. **案例密集**：群友会自发分享自己的经历、数据、踩坑
3. **争议天然**：讨论中的分歧点，就是最好的聊观点素材
4. **需求真实**：群里反复出现的问题，说明是真痛点

```
社群内容输入 → 内容清洗 → 选题提炼 → 类型判断 → 素材池构建 → 文案生成 → 下游流水线
```

与其他入口 skill 的区别：

| Skill | 素材来源 | 核心动作 |
|-------|---------|---------|
| 灵感碎片转文案 | 脑子里的想法 | 从碎片出发，AI判断类型→文案 |
| 录音稿转文案 | 录音稿/课程笔记 | 从学习素材出发，整理→选题→文案 |
| 用户提问转文案 | 粉丝问题/私信 | 问题即选题，回答即正文 |
| **社群精华转文案** | **社群讨论/聊天记录** | **从多人碰撞中提炼洞察→文案** |

## 📥 输入参数

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `社群内容` | ✅ 是 | 聊天记录、讨论截图文字、精华总结、或@引用社群总结文件 | - |
| `执行模式` | ❌ 否 | 自动模式/交互模式 | 询问用户选择 |
| `是否已整理` | ❌ 否 | 内容是否已经过整理（如已有社群总结文档） | AI自动判断 |
| `目标平台` | ❌ 否 | 公众号/小红书/视频号 | 公众号 |

支持的输入形式：
- 直接粘贴聊天记录原文（含昵称、时间戳等杂乱格式）
- 粘贴已整理的讨论精华
- @引用社群总结文件（如 `社群总结（持续更新）.md`）
- 粘贴某个具体话题的讨论片段

## ⚡ 双模式说明

### 模式一：🚀 自动模式（推荐）

全程自动执行，只在两个关键节点暂停：

```
智能判断是否已整理 → (需要则清洗) → 自动提炼选题 → 自动选TOP1
→ 自动判断类型 → 自动构建素材池 → 自动生成文案
→ ⏸️ 用户确认文案 → 自动下游流水线 → ⏸️ 用户确认最终成品
```

自动模式的默认行为：
- 整理判断：AI自动判断是否需要清洗
- 选题选择：自动选择爆款概率最高的TOP 1选题
- 类型判断：AI自动判断
- 素材来源：优先从社群讨论原文提取素材

检查点只有 2 个：
| 检查点 | 位置 | 等什么 |
|--------|------|--------|
| ⏸️ 1 | 完整文案生成后 | 用户确认文案内容 |
| ⏸️ 2 | 最终成品（排版后）| 用户确认发布 |

每步暂停，用户全程参与决策：

```
→ 下游流水线 → ⏸️ 确认发布
```

检查点 5 个：
| 检查点 | 位置 | 等什么 |

## 🔄 完整工作流程

### Step 1：内容清洗 + 智能判断

#### 1.1 判断是否需要清洗

AI自动判断输入内容的状态：

```
已整理（跳过清洗）的特征：
- 有清晰的主题分类和层级结构
- 已去除聊天噪音（表情、无关闲聊）
- 如：直接@引用了社群总结文件

未整理（需要清洗）的特征：
- 原始聊天记录格式（昵称:内容）
- 包含大量表情、接龙、无关闲聊
- 话题跳跃，没有结构
```

#### 1.2 内容清洗（如需要）

对原始聊天记录执行：

```
Step 1: 去噪 — 删除表情包、接龙、无关闲聊、重复内容
Step 2: 话题分割 — 识别讨论中的不同话题线程
Step 3: 观点归类 — 按话题将不同人的观点归类
Step 4: 关键信息提取 — 提取每个话题下的：
  - 💡 核心观点（谁说了什么有价值的话）
  - 📊 数据/案例（群友分享的真实数据和经历）
  - ⚡ 争议点（大家意见不一致的地方）
  - 🔥 金句（特别精彩的表达）
  - ❓ 未解决的问题（讨论到最后没有定论的）
```

#### 1.3 交叉参考社群总结

读取 `社群总结（持续更新）.md`，检查：
- 本次讨论是否涉及已沉淀的话题（可以深化/更新）
- 是否出现了全新的话题（值得新增到社群总结）

**模式分流：**
- 🚀 自动模式：自动清洗，继续执行
- 🔧 交互模式：⏸️ 展示清洗结果和关键信息提取，等用户确认

### Step 2：选题提炼

#### 2.1 从清洗后的内容中提炼选题

每个话题线程都可能产出选题，按以下角度挖掘：

| 挖掘角度 | 说明 | 示例 |
|---------|------|------|
| 争议点 → 聊观点 | 群里吵起来的话题 | "社群里吵翻了：AI做自媒体到底算不算作弊？" |
| 共识点 → 教知识 | 大家都认同的方法论 | "10个群友验证过的起号方法，第3个最意外" |
| 真实案例 → 讲故事 | 某个群友的精彩经历 | "群里一个宝妈，用AI三个月做到月入2万" |
| 高频问题 → 教知识 | 反复被问的问题 | "社群里被问了50遍的问题，今天统一回答" |
| 反常识发现 → 聊观点 | 颠覆认知的讨论结果 | "我们在群里做了个实验，结果颠覆了所有人的认知" |
| 实战数据 → 晒过程 | 群友分享的真实数据 | "群里5个人同时测试，数据差异让人震惊" |

#### 2.2 选题评分

对每个候选选题，基于13大爆款元素评分：

| 维度 | 权重 | 说明 |
|------|------|------|
| 爆款元素匹配 | 30% | 命中13大爆款元素的数量 |
| 素材丰富度 | 25% | 社群讨论中有多少可用素材 |
| 普遍性 | 20% | 话题是否能引起圈外人共鸣 |
| 争议性 | 15% | 是否能引发评论区讨论 |
| 时效性 | 10% | 是否与当下热点相关 |

输出 TOP 3-5 选题，未使用的选题自动存入灵感点子表。

**模式分流：**
- 🚀 自动模式：自动选择TOP 1，继续执行
- 🔧 交互模式：⏸️ 展示所有选题，等用户选择

### Step 3：类型判断 + 路由

根据选定的选题，判断内容类型：

```
选题核心是争议/立场？
  ├─ 是 → 「聊观点」→ 调用「聊观点文案」skill
  └─ 否 → 继续判断
选题核心是可复制的方法/步骤？
  ├─ 是 → 「教知识」→ 调用「教知识文案」skill
  └─ 否 → 继续判断
选题核心是某个人的完整经历？
  ├─ 是 → 「讲故事」→ 调用「讲故事文案」skill
  └─ 否 → 「晒过程」→ 调用「公众号爆款生产」skill
```

**模式分流：**
- 🚀 自动模式：AI自动判断，继续执行
- 🔧 交互模式：⏸️ 展示判断结果和理由，等用户确认

### Step 4：文案生成

#### 4.1 并行读取知识库

先读取直播口语风格萃取（⚠️风格底座，口语节奏打底），再读取公众号文案风格萃取（⚠️必读），然后读取AI创作规范、个人自传、对应开篇模板库、引流钩子模板。

#### 4.2 构建素材池（核心差异点）

社群讨论的素材池构建逻辑与其他skill不同——**多人视角是最大的资产**：

```
素材优先级：
① 社群讨论原文素材（群友的观点、案例、数据、金句）→ 最高优先级
② 社群总结沉淀（已有的方法论和洞察）→ 补充深度
③ 个人自传（你自己的经历和观点）→ 补充权威性
④ 合理推理（延伸和总结）→ 兜底
```

素材分类打标：

| 素材类型 | 来源 | 用途 |
|---------|------|------|
| 🗣️ 群友观点 | 讨论原文 | 正文论据、多角度呈现 |
| 📊 群友数据 | 群友分享的真实数据 | 数据支撑、案例佐证 |
| 📖 群友案例 | 群友的真实经历 | 故事素材、案例拆解 |
| 💬 群友金句 | 讨论中的精彩表达 | 直接引用、增加真实感 |
| ⚡ 争议观点 | 意见分歧 | 聊观点的正反论据 |
| ❓ 未解问题 | 讨论未定论 | 结尾互动引导 |

#### 4.3 开篇策略（核心差异点）

社群类文章有独特的开篇优势——**群体讨论天然有画面感和真实感**：

**推荐开篇模式（按优先级）：**

```
模式A（最推荐）：社群场景还原
"昨天社群里聊了一个话题，直接炸了——{话题}"
"群里有人丢了一个问题，结果引发了一场大讨论：{问题}"

模式B：争议引入
"社群里最近吵了一架，起因是{争议点}。两边都有道理，但我站{立场}。"

模式C：数据/案例引入
"群里有个学员分享了一组数据，看完我沉默了——{数据}"

模式D：共识总结
"最近在社群里做了个小调查，{N}个人的回答出奇一致：{共识}"

模式E：反常识发现
"我们在群里做了个实验，结果颠覆了所有人的认知——{发现}"
```

#### 4.4 调用对应文案skill

将以下信息传递给对应的文案skill：
- 选题方向（已包装）
- 素材池（已构建，含群友观点/数据/案例/金句）
- 开篇方式（已选定）
- 社群讨论原文（作为核心素材参考）

#### 4.5 文案质量自检

生成后自检：
- [ ] 是否充分利用了社群讨论中的素材（而不是抛开讨论自己写）？
- [ ] 群友的观点/案例是否自然融入正文？
- [ ] 是否保留了讨论的多角度特征（而不是只呈现一个观点）？
- [ ] 群友隐私是否已脱敏（不暴露真实昵称和身份）？
- [ ] 结尾是否引导了更多讨论（"你怎么看？""欢迎来群里继续聊"）？
- [ ] 口吻是否符合你的风格（调用公众号文案风格萃取）？

#### 4.6 署名测试（不可替代性检查）

> **核心问题：把署名换成别人，这篇文案还能成立吗？**

逐项检查：
- [ ] 文中是否有**只有你才有的经历**？（个人实战、真实案例、踩过的坑）
- [ ] 文中是否有**独家数据或独家判断**？（不是公开信息的二次搬运）
- [ ] 去掉所有个人印记后，和通用AI生成的内容**区别在哪**？（必须能说清）

**判定：**
- ✅ 至少2项有明确答案 → 通过，继续下游流水线
- ❌ 少于2项 → **必须补入个人素材**（从 `02.领域/0.内容创作系统/🔧06.我的档案/我的个人上下文` 或 `思想力武器库` 中调取），重新过一遍自检

**模式分流：**
- 🚀 自动模式：自动生成，⏸️ 输出完整文案等用户确认
- 🔧 交互模式：⏸️ 输出完整文案 + 质量自检报告，等用户确认

#### 5.2 事实核查
- 调用「事实核查」skill
- 重点核查群友分享的数据和案例的合理性

#### 5.3 敏感词检测
- 调用「敏感词检测」skill

#### 5.4 公众号排版
- 调用「公众号排版」skill

#### 5.5 用户确认 + 发布

展示最终成品，用户确认后：
- 调用「微信公众号发布」skill 发布到草稿箱
- 或导出为其他平台格式

**模式分流：**
- 🚀 自动模式：全部自动执行，⏸️ 最终成品等用户确认发布

## ⚠️ 核心原则

### 素材优先级

```
社群讨论原文素材 > 社群总结沉淀 > 个人自传 > 合理推理
```

社群讨论本身就是最好的素材来源——里面有真实的多角度观点、案例、数据。文案生成时必须优先使用讨论中的素材，而不是抛开讨论从个人自传里找。

### 多角度保留

社群讨论的最大价值是多人视角碰撞。文案中要保留这种多角度特征：
- 不要只呈现一个观点，要展示不同声音
- 用"有人说...也有人说...我的看法是..."的结构
- 让读者感受到这是一群真实的人在讨论

### 隐私脱敏

- 群友昵称统一替换为"有个学员"、"群里一个朋友"、"一位做XX的群友"
- 不暴露具体的群名、群规模等信息
- 涉及收入等敏感数据，可以模糊处理（"月入五位数"代替具体金额）

### 社群引流闭环

社群类文章的结尾，天然适合做社群引流：
- "想参与这样的讨论？欢迎加入我们的社群"
- "这个话题在群里还在继续，感兴趣的可以来聊"
- 调用引流钩子模板，选择社群导流话术
