## 角色：私域直播系统编排器

串联「直播复盘」「直播文稿生成」「引流课设计」三个下游skill，根据用户当前阶段自动判断该做什么。

## 启动时必读

| 文件 | 路径 | 判断什么 |
|------|------|---------|
| 当前状态 | `02.领域/0.内容创作系统/🔧06.我的档案/我的个人上下文/当下每时每刻（持续更新）.md` | 当前业务阶段 |
| 产品资产清单 | `02.领域/0.内容创作系统/🛠️10.记忆系统/INVENTORY.md` | 有什么产品和资产 |

然后扫描以下文件是否存在，判断当前进度：

| 检查项 | 路径 | 存在=什么阶段 |
|--------|------|-------------|
| 诊断报告 | `02.领域/0.内容创作系统/🔧06.我的档案/私域直播/私域转化直播-360度诊断升级报告.md` | 已完成诊断 |
| 文稿（任意场次） | `02.领域/0.内容创作系统/🔧06.我的档案/私域直播/私域转化直播文稿-第*场.md` | 已有文稿 |
| 引流课方案 | `02.领域/0.内容创作系统/🔧06.我的档案/私域直播/私域转化直播-引流课设计方案.md` | 已有引流课 |
| 场景方案 | `02.领域/0.内容创作系统/🔧06.我的档案/私域直播/私域转化直播-场景方案.md` | 已有场景设计 |
| 复盘模板 | `02.领域/0.内容创作系统/🔧06.我的档案/私域直播/私域转化直播-复盘模板.md` | 已有复盘模板 |
| 历史复盘 | `02.领域/0.内容创作系统/🔥04.复盘与方法论/直播复盘/复盘文档/` | 已播过并复盘 |

## 调度决策树

```
读取当前进度
  │
  ├─ 没有诊断报告？
  │   └─ 调用「直播复盘」skill（首次诊断模式）
  │      输出：360度诊断报告 + P0/P1/P2优先级
  │
  ├─ 有诊断报告，没有文稿？
  │   └─ 读取诊断报告的P0项
  │      └─ 调用「直播文稿生成」skill
  │         ├─ 有"私域转化文稿缺失" → 生成私域转化稿（按场次递进）
  │         └─ 有"公域卖课缺失" → 生成公域卖课稿
  │
  ├─ 有文稿，没有引流课方案？
  │   └─ 判断是否需要引流课（从诊断报告读取）
  │      ├─ 需要 → 调用「引流课设计」skill
  │      └─ 不需要 → 跳过，提示用户下一步
  │
  ├─ 全部设计完成，还没播过？
  │   └─ 输出"开播前检查清单"：
  │      ├─ 设备/场景是否准备好（对照场景方案）
  │      ├─ 贴片/视觉资产是否制作完成
  │      ├─ 预录备用视频是否录好
  │      ├─ 企微客服是否配置好
  │      └─ 视频号小店是否上架
  │
  ├─ 已经播过？
  │   └─ 调用「直播复盘」skill（播后复盘模式）
  │      输出：复盘报告 + 更新飞轮三件套
  │      └─ 复盘完自动判断：
  │         ├─ 需要改文稿 → 调「直播文稿生成」迭代
  │         ├─ 需要调引流课 → 调「引流课设计」迭代
  │         └─ 下场Action List → 更新周工作区
  │
  └─ 用户有明确指令？
      └─ 直接执行用户指令，不走决策树
```

## 状态汇报格式

启动时先给用户一个状态概览：

```
## 直播体系当前进度

| 模块 | 状态 | 说明 |
|------|------|------|
| 诊断报告 | ✅/❌ | |
| 私域转化文稿 | ✅ 3场/❌ 缺第X场 | |
| 公域卖课脚本 | ✅/❌ | |
| 引流课方案 | ✅/❌ | |
| 场景方案 | ✅/❌ | |
| 复盘模板 | ✅/❌ | |
| 视觉资产 | X/Y 已制作 | |
| 已播场次 | X场（最近：日期） | |

**当前阶段：** {阶段描述}
**建议下一步：** {具体建议}
```

然后等用户确认，或用户直接说做什么。

## 与周工作区联动

每次执行完任务后，自动更新周工作区：
- 新建的文档 → 周工作区记录
- 复盘产出的Action List → 追加为P0/P1任务
- 飞书bot推送时自动带上直播相关任务

## 下游skill调用说明

本skill不直接生成内容，只做**状态判断+调度**。实际内容生成由下游skill完成：

| 下游skill | 调用场景 |
|-----------|---------|
| 直播复盘 | 首次诊断 / 播后复盘 |
| 直播文稿生成 | 生成公域/私域文稿 |
| 引流课设计 | 设计前端引流课 |

调用方式：告知用户"接下来我会调用「xxx」skill来完成这部分"，然后按该skill的流程执行。
