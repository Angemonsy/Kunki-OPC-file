# 用户提问转文案

> 粉丝的每一个问题，都是一篇爆款的种子

## 🎯 功能概述

这是一个**编排器 skill**，专门处理"用户提问→公众号文章"的转化链路。

核心优势：用户问题天然具备三个爆款要素——
1. **真实痛点**：问题来自真人，说明这个需求是真实存在的
2. **天然钩子**："有粉丝问我..."是最强的开篇钩子之一
3. **高互动性**：回答问题的文章，评论区天然会有更多讨论

```
用户问题输入 → 问题解析 → 选题包装 → 类型判断 → 文案生成 → 下游流水线
```

与其他入口 skill 的区别：

| Skill | 素材来源 | 核心动作 |
|-------|---------|---------|
| 公众号爆款生产 | 外部热点链接 | 从热点出发，选题→文案 |
| 灵感碎片转文案 | 脑子里的想法 | 从碎片出发，AI判断类型→文案 |
| 录音稿转文案 | 录音稿/课程笔记 | 从学习素材出发，整理→选题→文案 |
| 爆款拆解改写 | 别人的爆款文案 | 拆骨架→换血肉 |
| **用户提问转文案** | **粉丝问题/评论/私信** | **问题即选题，回答即正文** |

## 📥 输入参数

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `问题内容` | ✅ 是 | 粉丝提问原文、评论截图文字、私信内容、社群提问 | - |
| `问题来源` | ❌ 否 | 评论区/私信/社群/面对面/其他 | AI自动判断 |
| `执行模式` | ❌ 否 | 自动模式/交互模式 | 询问用户选择 |
| `目标平台` | ❌ 否 | 公众号/小红书/视频号 | 公众号 |

支持的输入形式：
- 直接粘贴问题文字
- 粘贴多个问题（自动识别最有爆款潜力的）
- 截图中的文字（用户自行提取后粘贴）
- @引用包含问题的笔记文件

## ⚡ 双模式说明

### 模式一：🚀 自动模式（推荐）

全程自动执行，只在两个关键节点暂停：

```
问题解析 → 自动选题包装 → 自动判断类型 → 自动生成文案
→ ⏸️ 用户确认文案 → 自动下游流水线 → ⏸️ 用户确认最终成品
```

自动模式的默认行为：
- 多个问题时：自动选择爆款概率最高的问题
- 类型判断：AI自动判断
- 开篇方式：默认使用"有粉丝问我..."钩子开篇
- 素材来源：优先从问题本身+个人经验中提取

检查点只有 2 个：
| 检查点 | 位置 | 等什么 |
|--------|------|--------|
| ⏸️ 1 | 完整文案生成后 | 用户确认文案内容 |
| ⏸️ 2 | 最终成品（排版后）| 用户确认发布 |

### 模式二：🔧 交互模式

每步暂停，用户全程参与决策：

```
问题解析 → ⏸️ 确认选题方向 → 类型判断 → ⏸️ 确认类型
→ 文案生成 → ⏸️ 确认文案 → 下游流水线 → ⏸️ 确认发布
```

检查点 4 个：
| 检查点 | 位置 | 等什么 |
|--------|------|--------|
| ⏸️ 1 | 问题解析+选题包装后 | 确认选题方向和角度 |
| ⏸️ 2 | 类型判断后 | 确认内容类型 |
| ⏸️ 3 | 完整文案生成后 | 确认文案内容 |
| ⏸️ 4 | 最终成品（排版后）| 确认发布 |

## 🔄 完整工作流程

### Step 1：问题解析 + 爆款评估

#### 1.1 问题深度解析

从用户提供的问题中提取：

```
- 核心问题：用一句话概括粉丝到底在问什么
- 问题背后的痛点：为什么会问这个问题？（焦虑/困惑/好奇/求证）
- 问题的普遍性：这是个别问题还是很多人都有的问题？
- 问题的层次：表面问题 vs 深层问题（往往深层问题更有价值）
- 隐含假设：问题背后有没有错误假设？（纠正假设本身就是好内容）
```

#### 1.2 多问题筛选（如果输入了多个问题）

当用户一次性提供多个问题时，按以下维度打分，选出最优：

| 维度 | 权重 | 说明 |
|------|------|------|
| 普遍性 | 30% | 多少人可能有同样的问题 |
| 爆款元素匹配 | 25% | 命中13大爆款元素的数量 |
| 回答深度 | 20% | 你能给出多有价值的回答 |
| 争议性 | 15% | 是否能引发讨论 |
| 时效性 | 10% | 是否与当下热点相关 |

#### 1.3 选题包装

把原始问题包装成爆款选题：

```
原始问题："老师，我想做自媒体但不知道从哪开始"
                    ↓ 包装
选题方向A（教知识）："新手做自媒体的第一步，不是注册账号"
选题方向B（聊观点）："为什么我劝你别急着做自媒体"
选题方向C（讲故事）："一个学员问我怎么开始做自媒体，我的回答让他沉默了"
```

输出至少 2-3 个选题方向，标注推荐的内容类型。

**模式分流：**
- 🚀 自动模式：自动选择爆款概率最高的选题方向，继续执行
- 🔧 交互模式：⏸️ 展示所有选题方向，等用户选择

### Step 2：类型判断 + 路由

根据选定的选题方向，判断内容类型：

```
问题涉及可复制的方法/步骤？
  ├─ 是 → 「教知识」→ 调用「教知识文案」skill
  └─ 否 → 继续判断
问题涉及明确立场/判断/争议？
  ├─ 是 → 「聊观点」→ 调用「聊观点文案」skill
  └─ 否 → 继续判断
问题可以用一个故事来回答？
  ├─ 是 → 「讲故事」→ 调用「讲故事文案」skill
  └─ 否 → 「晒过程」→ 调用「公众号爆款生产」skill
```

**模式分流：**
- 🚀 自动模式：AI自动判断类型，继续执行
- 🔧 交互模式：⏸️ 展示判断结果和理由，等用户确认

### Step 3：文案生成

#### 3.1 并行读取知识库

先读取直播口语风格萃取（⚠️风格底座，口语节奏打底），再读取公众号文案风格萃取（⚠️必读），然后读取AI创作规范、个人自传、社群总结、对应开篇模板库、引流钩子模板。

#### 3.2 构建素材池

素材优先级：
```
① 问题本身（天然钩子 + 痛点描述）
② 个人真实经历（从个人自传中匹配相关经历）
③ 社群讨论沉淀（从社群总结中提取相关观点）
④ 专业知识储备（合理推理和延伸）
```

#### 3.3 开篇策略（核心差异点）

用户提问类文章有独特的开篇优势——**问题本身就是最好的钩子**：

**推荐开篇模式（按优先级）：**

```
模式A（最推荐）：直接引用问题
"昨天有个粉丝私信问我：{问题原文}"
"评论区有人问了一个很好的问题：{问题原文}"

模式B：问题+共鸣放大
"最近收到好几个类似的问题：{问题}。说实话，这个问题我自己也踩过坑。"

模式C：问题+反转
"有人问我{问题}，我的回答可能会让你意外——"

模式D：问题+数据
"后台收到了20多条类似的私信，都在问{问题}。今天统一回答一下。"
```

#### 3.4 调用对应文案skill

将以下信息传递给对应的文案skill：
- 选题方向（已包装）
- 素材池（已构建）
- 开篇方式（已选定）
- 问题原文（作为核心素材）
- 问题来源（用于开篇话术）

#### 3.5 文案质量自检

生成后自检：
- [ ] 开篇是否自然引入了用户问题？
- [ ] 回答是否真正解决了问题（而不是泛泛而谈）？
- [ ] 是否有具体的案例/数据/经历支撑？
- [ ] 结尾是否引导了更多互动（"你们觉得呢？""你遇到过类似的问题吗？"）
- [ ] 口吻是否符合用户风格（调用公众号文案风格萃取）？

#### 3.6 署名测试（不可替代性检查）

> **核心问题：把署名换成别人，这篇文案还能成立吗？**

逐项检查：
- [ ] 文中是否有**只有用户才有的经历**？（个人实战、真实案例、踩过的坑）
- [ ] 文中是否有**独家数据或独家判断**？（不是公开信息的二次搬运）
- [ ] 去掉所有个人印记后，和通用AI生成的内容**区别在哪**？（必须能说清）

**判定：**
- ✅ 至少2项有明确答案 → 通过，继续下游流水线
- ❌ 少于2项 → **必须补入个人素材**（从 `04.我的上下文` 或 `思想力武器库` 中调取），重新过一遍自检

**模式分流：**
- 🚀 自动模式：自动生成，⏸️ 输出完整文案等用户确认
- 🔧 交互模式：⏸️ 输出完整文案 + 质量自检报告，等用户确认

- 调用「公众号排版」skill

展示最终成品，用户确认后：
- 调用「微信公众号发布」skill 发布到草稿箱
- 或导出为其他平台格式

**模式分流：**
- 🚀 自动模式：全部自动执行，⏸️ 最终成品等用户确认发布
- 🔧 交互模式：⏸️ 最终成品等用户确认发布

#### 4.6 存档 + 反馈闭环

**存档规范**：文案保存到 `05.内容创作系统/🔥02.发布文案/2026年/` 目录，文件名格式 `YYYY年M月D日-标题关键词.md`。frontmatter 必须遵循 `05.内容创作系统/🛠️11.系统配置/frontmatter规范.md` 中的统一规范，必填字段：title、type、status（初始为"草稿"）、created、tags、source_type。

## ⚠️ 核心原则

### 问题即钩子

用户问题是天然的开篇钩子，不要浪费。开篇必须让读者感受到"这个问题我也有"。

### 回答要有增量

不能只是回答问题本身，要给出超出提问者预期的增量价值：
- 纠正问题背后的错误假设
- 给出提问者没想到的角度
- 提供可直接复制的方法/步骤

### 互动闭环

用户提问类文章的结尾，必须引导更多互动：
- "你们遇到过类似的问题吗？评论区聊聊"
- "还有什么问题，私信我，下次继续写"
- 这样形成"提问→文章→更多提问→更多文章"的飞轮

### 隐私保护

- 不暴露提问者的真实身份信息
- 用"有粉丝"、"有学员"、"有朋友"等模糊称呼
- 如果问题涉及敏感信息，脱敏处理
