# 微信公众号标题抓取器

这个 skill 帮助你抓取指定微信公众号的所有历史文章标题，并支持导出为 Markdown 或 Excel 格式，方便后续分析。

## 触发场景

当用户需要以下任务时自动调用：
- 抓取公众号文章标题
- 对标账号研究
- 分析竞品内容策略
- 批量获取选题灵感
- 研究爆款标题规律

## 关键词

公众号抓取、抓取标题、公众号分析、对标账号、文章标题、批量抓取、公众号研究

## 快速启动

用户只需提供公众号名称或链接，即可立即启动抓取。

## 使用说明

### 输入要求

用户需要提供以下信息之一：
1. **公众号名称**（如："人民日报"）
2. **公众号文章链接**（从链接中提取公众号 ID）
3. **公众号 biz 参数**（高级用户）

### 输出格式

抓取完成后，会生成以下内容：
1. **Markdown 文件** - 保存在 vault 中，格式化展示
2. **数据统计** - 文章总数、发布频率、标题特征分析
3. **可选 Excel 导出** - 导出到 ~/Desktop 供进一步分析

## 工作流程

### 第一步：获取公众号信息

1. **接收用户输入**
   - 如果是公众号名称：提示用户需要提供文章链接（因为名称无法直接定位）
   - 如果是文章链接：解析出 `__biz` 参数
   - 如果是 biz 参数：直接使用

2. **验证公众号有效性**
   - 尝试访问公众号主页
   - 确认可以获取文章列表

### 第二步：抓取文章列表

**方法选择（按优先级）：**

#### 方法 1：使用搜狗微信搜索（推荐）
- 访问 `https://weixin.sogou.com/`
- 搜索公众号名称
- 进入公众号主页
- 抓取文章列表（最近10篇）
- **优点**：无需登录，稳定性高
- **缺点**：只能获取最近文章

#### 方法 2：使用第三方 API
- 新榜、清博等数据平台
- 需要 API key
- **优点**：数据完整，包含阅读量等
- **缺点**：需要付费

#### 方法 3：手动导出 + 解析
- 用户使用浏览器插件导出
- 上传 HTML/JSON 文件
- Claude 解析提取标题
- **优点**：最可靠，数据最全
- **缺点**：需要用户手动操作


### 第三步：数据解析和清洗

1. **提取标题信息**
   - 文章标题
   - 发布时间
   - 文章链接（可选）
   - 阅读量（如果有）

2. **数据清洗**
   - 去除 HTML 标签
   - 统一时间格式
   - 去重（避免重复抓取）

3. **数据验证**
   - 检查标题完整性
   - 验证时间格式
   - 确认数据量合理

### 第四步：数据分析

自动进行基础分析：

1. **统计分析**
   - 文章总数
   - 发布频率（日均/周均/月均）
   - 最早和最新文章时间

2. **标题特征分析**
   - 平均字数
   - 常用词汇（词云）
   - 标题模式识别（如：数字、问号、感叹号使用频率）
   - 表情符号使用情况

3. **趋势分析**
   - 发布时间分布
   - 标题长度趋势
   - 高频关键词变化


### 第五步：生成报告并导出

#### 1. Markdown 报告（保存在 vault）

生成格式化的 Markdown 文件，包含：

```markdown
---
公众号: [公众号名称]
抓取时间: YYYY-MM-DD HH:mm:ss
文章总数: XXX
时间范围: YYYY-MM-DD 至 YYYY-MM-DD
---

## 📊 基础数据

- 文章总数: XXX 篇
- 发布频率: 平均 X.X 篇/周
- 时间跨度: XXX 天
- 平均标题字数: XX 字

## 📝 文章列表

### 2024年1月
1. [标题1](链接) - 2024-01-15
2. [标题2](链接) - 2024-01-14
...

## 🔍 标题特征分析

### 高频词汇 Top 10
1. 关键词1 - XX次
2. 关键词2 - XX次
...

### 标题模式
- 包含数字: XX%
- 包含问号: XX%
- 包含表情符号: XX%
- 平均标题长度: XX字

## 💡 选题洞察

[基于数据的选题建议]
```

保存路径: `03.资源/竞品分析/[公众号名称]_标题分析_YYYYMMDD.md`

#### 2. Excel 导出（可选）

如果用户需要进一步分析，可导出表格数据。

## 技术实现方案

### 推荐方案：搜狗微信搜索 + 手动辅助

由于微信公众号的反爬机制，完全自动化抓取较困难。推荐混合方案：

**步骤 1：用户提供数据源**
- 方式A：提供公众号文章链接，Claude 使用 WebFetch 尝试抓取
- 方式B：用户手动复制公众号文章列表页面，粘贴给 Claude
- 方式C：用户使用浏览器插件导出 HTML，上传给 Claude

**步骤 2：Claude 解析数据**
- 使用正则表达式提取标题
- 解析发布时间
- 清洗和格式化数据

**步骤 3：生成分析报告**
- 统计分析
- 生成 Markdown 报告
- 可选导出 Excel

### 工具依赖

- `WebFetch`: 尝试抓取公众号页面
- `Bash`: 数据处理（jq, grep, sed）
- `Write`: 生成 Markdown 报告
- `Read`: 读取用户上传的文件

## 注意事项

### ⚠️ 重要限制

1. **微信反爬机制**
   - 微信公众号有严格的反爬虫机制
   - 频繁请求可能导致 IP 被封
   - 建议使用手动辅助方式

2. **数据完整性**
   - 搜狗微信只能获取最近文章
   - 历史数据需要第三方平台或手动导出
   - 部分公众号可能无法访问

3. **隐私和合规**
   - 仅用于学习和研究目的
   - 不要用于商业用途
   - 尊重原创作者版权

### ✅ 最佳实践

1. **首选方式**：用户手动导出数据，Claude 负责分析
2. **备选方式**：使用第三方数据平台（新榜、清博等）
3. **避免**：频繁自动化请求微信服务器

## 常见问题

**Q1: 能抓取多少篇文章？**
A: 取决于数据来源。搜狗微信约10-20篇，手动导出可以全部。

**Q2: 需要登录微信吗？**
A: 推荐方案不需要。但如果使用高级方案，可能需要。

**Q3: 能获取阅读量吗？**
A: 搜狗微信可以获取部分阅读量，但不完整。建议使用第三方平台。

**Q4: 支持批量抓取多个公众号吗？**
A: 支持。用户提供多个公众号信息即可。

**Q5: 生成的报告保存在哪里？**
A: 默认保存在 `03.资源/竞品分析/` 文件夹。
