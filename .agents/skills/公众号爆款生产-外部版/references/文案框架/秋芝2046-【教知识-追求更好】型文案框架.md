## 二、开篇设计

### 优先钩子手法（按数据表现排序）

第一优先：AI效果演示直接轰炸（S1/S4/S7/S8 + A级5条验证）

句式模板：

「[AI演示指令1]，[AI演示指令2]，[AI演示指令3]。
朋友们，[产品名]这次真的[震撼评价]。」

可替换变量示例：

- AI演示指令：让这两个人笑起来 / 把这张照片上色 / 用图一的风格做海报
- 震撼评价：太实用了老少皆宜 / 太狠了 / 到了设计师都可用的地步了

> 原理：先让观众"眼见为实"看到效果，再用评价锚定价值。3秒内完成"效果冲击→价值定义"。

第二优先：全民覆盖式喊话（S1验证，33.8万赞最高爆款）

句式模板：

「准备好一起[动作]吧。今天不管你是[人群1]、[人群2]、[人群3]还是[人群4]，
这回是[价值承诺]了。」

可替换变量：

- 人群枚举：创作者 / 设计师 / 打工人 / 博主 / 学生 / 自媒体
- 价值承诺：送到家的神器 / 必备的技能 / 轻松成为XX的日子

> 原理：枚举多人群实现"总有一个是你"的覆盖，再用价值承诺锁定注意力。

第三优先：新功能/升级宣告（A级4条验证）

句式模板：

「[产品]这次升级太狠了，我[素材]就可以玩成[效果1]、[效果2]、[效果3]。」

或

「朋友们，[领域]进入[新阶段]了。最近[概念]火遍全网了，
那今天我们就来用最简单的方式上手[核心内容]。」

## 三、论证过程设计

### 推荐论证结构："定位→分类展示→意义升华"三段式（S+A级共11条中9条采用）

|段落|功能|占比|内容模式|
|---|---|---|---|
|段1-极致定位|用一个标签锚定产品地位|10%-15%|"登顶/王/神/最强更新/人均XX"|
|段2-海量玩法分类展示|按功能/场景分类逐一演示|70%-80%|从基础到高级递进|
|段3-意义升华或风险提醒|从工具回到人的层面|10%-15%|金句收尾/安全警示|

段2的内部组织原则（核心区）：

1. 按人群分类：创作者能做什么→设计师能做什么→普通人能做什么（S1验证）
2. 按难度递进：基础玩法→进阶玩法→创意恶搞（S7验证）
3. 按功能模块：功能A演示→功能B演示→功能C演示（A级多条验证）

论据组合原则：

- 每个玩法必须有"指令→效果"的完整展示（不能只说不演）
- 玩法数量≥10个（S1有20+，S7有究极玩法集）
- 必须在中间插入1-2个"惊喜效果"（"没想到效果这么好"/"这要不是我自己生的，我真以为是真图"）
