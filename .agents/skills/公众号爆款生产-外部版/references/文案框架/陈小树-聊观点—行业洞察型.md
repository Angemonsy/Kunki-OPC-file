## 一、核心选题公式
选题 = 人群/现象 + 反直觉判断 + 隐含身份归属

变量1——人群/现象标签： 精神世界丰富的人 / 内向的人 / 有痛苦经历的人 / 不敢露脸的人 / 想做IP的人 ……

变量2——反直觉判断（3种模型）：

|模型|公式|示例|
|---|---|---|
|不适合A适合B|「【人群】不适合做【A】，适合做【B】」|精神世界丰富的人不适合当网红|
|负面变正面|「【负面事物】是【领域】最佳的【正面价值】」|痛苦是自媒体的最佳素材|
|本质提炼|「做【X】的本质就是【简单A】+【简单B】」|做自媒体的本质就是露脸+重复|

变量3——底层情绪驱动力：

- 身份认同：「这说的不就是我吗？」
- 认知颠覆：「原来是这样？」
- 希望感：「原来我也可以」
- 争议性：「我不同意/太对了」→ 驱动评论

## 二、开篇设计

优先句式排序：反直觉观点式 > 借势名人式 > 极简总结式

### 句式A：反直觉观点直抛式（最高频）

我觉得【特征】越【程度词】的人，
越不要做【大众选择A】，应该做【推荐选择B】。
大部分人对【概念1】、【概念2】、【概念3】的概念非常模糊。

关键： 第一句必须制造认知冲突，第二句给出「为什么大家搞错了」的铺垫

### 句式B：借势名人观点式

我前两天看到【名人】教大家【事情】。
里面有个东西我非常认同。
作为【身份背书（含数字）】，今天聊聊【主题】。

### 句式C：极简本质总结式

我觉得【时间】，想做【事情】，
其实就【N】个点：【核心点1】、【核心点2】。
别想太复杂。

## 三、论证过程设计

推荐结构（按数据排序）：

### 结构1：二元对比贯穿式（S级首选）

概念A vs 概念B的定义对比
→ A的路径和局限
→ B的路径和优势
→ 目标人群该选B的理由
→ B的正确做法

- 全文围绕一组对比展开，不跑偏
- 适用： 概念辨析型观点（博主vs IP、日更vs爆款）

### 结构2：递进论证式

观点阐述（为什么这么说）
→ 成功案例/故事印证
→ 普通人可复制的路径
→ 情感升华

- 适用： 励志型/价值观型观点

### 结构3：分论点展开式

核心观点（就N个点）
→ 点1展开（为什么 + 怎么做）
→ 点2展开
→ 点3展开（可选）
→ 收尾重申

- 适用： 方法论精简型观点

高频论据方向（至少选2种）：

|论据方向|说明|使用频率|
|---|---|---|
|概念辨析|拆解大家混淆的概念|★★★★|
|个人低谷/真实故事|自己的失败经历建立信任|★★★★（3条全用）|
|心理洞察|揭示人性弱点（拧巴/羞耻/懒惰）|★★★|
|成功IP案例|他人逆袭故事做论据|★★|
|信任逻辑推导|没有脸→没有信任→没有变现|★★|

论据组合原则：

- 必选： 个人真实经历/故事（3条爆款全部包含）
- 观点类文案的论据不求多求深，每个论据展开要充分
- 避免堆砌：全文论据不超过3种类型

## 四、结尾强化

### 策略1：价值翻转式金句（最推荐）

不要去浪费你【看似负面的东西】。
你的一切【经历/特质】都可以成为你的【正面资产】。

示例：

- 「不要浪费你糟糕的人生。你的一切经历都可以成为账号资产。」

### 策略2：方法论收尾（无金句但有指导性）

【角色/身份】必须做【前提条件】。
但也是有选择性的展示，要把【真实内容】梳理成【适合传播的形式】。

### 策略3：自我追问式

每天问自己【核心判断标准】？
对，坚持。不对，调整方法。
