# 公众号爆款生产流水线（独立版）

> 从热点链接到完整公众号文章的一站式解决方案
> 本skill为独立打包版本，所有引用文档均内置于 references/ 目录，无需外部知识库。

## ⚠️ 首次使用必读

**使用前请先完成个人配置**：
1. 打开 `references/用户配置/我的用户画像.md`，填写你的个人信息、目标用户、优势素材
2. 填写完成后，AI会根据你的配置定制文案内容

## 🎯 功能概述

这是一个**端到端的自动化内容生产流水线**：

```
热点链接 → 选题推荐（含历史案例参考） → 用户选择 → 热点深度分析 → 智能框架匹配 → 用户确认结构 → 文案生成（含个人素材注入） → 事实核查 → 标题生成 + 排版优化 + 敏感词检测（并行） → 用户确认 → 存档
```

## 📥 输入参数

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `热点链接` | ✅ 是 | 热点新闻链接，支持各大媒体平台 | - |
| `内容类型` | ❌ 否 | 教知识/聊观点/讲故事/晒过程 | 智能判断 |
| `执行模式` | ❌ 否 | 自动模式/交互模式 | 询问用户选择 |

## ⚡ 双模式说明

### 模式一：🚀 自动模式（推荐）

全程自动执行，只在两个关键节点暂停：

```
自动抓取热点 → 自动选题包装（选TOP1） → 自动判断类型
→ 自动匹配框架+开篇 → 自动生成文案
→ ⏸️ 用户确认文案 → 自动下游流水线（标题→核查→敏感词→排版）
→ ⏸️ 用户确认最终成品
```

| 检查点 | 位置 | 等什么 |
|--------|------|--------|
| ⏸️ 1 | 完整文案生成后 | 用户确认文案内容 |
| ⏸️ 2 | 最终成品（排版后）| 用户确认发布 |

### 模式二：🔧 交互模式

每步暂停，用户全程参与决策：

| 检查点 | 位置 | 等什么 |
|--------|------|--------|
| ⏸️ 1 | 选题包装后 | 用户选择选题方向 |
| ⏸️ 2 | 框架+开篇匹配后 | 用户确认结构和开篇 |
| ⏸️ 3 | 完整文案生成后 | 用户审核文案 |
| ⏸️ 4 | 最终成品（排版后）| 用户确认 |

## 🔄 完整工作流程

### ⚡ Phase 1: 热点解析 + 选题推荐（连续执行，不可中断）

> **重要**：Step 1 和 Step 2 必须在**同一个回复**中完成。

**执行步骤**：
1. 使用 WebFetch 或 WebSearch 工具抓取热点链接内容
2. 同时读取以下知识库（并行执行）：
   - `references/方法论/13大爆款元素.md`
   - `references/用户配置/我的用户画像.md`
   - `references/方法论/数字生命卡兹克-选题特点萃取.md` ⚠️ 必读
   - （案例库和选题模板需用户自行积累，初次使用时跳过此步）
3. 提取热点核心信息
4. **数据可验证等级标注**：

   | 等级 | 来源类型 | 文案处理方式 |
   |------|---------|------------|
   | A级 | 权威媒体报道/官方公告/论文 | 可直接引用具体数字 |
   | B级 | 行业媒体/知名分析师 | 可引用但建议标注来源 |
   | C级 | 社交媒体/未经验证的转发 | 必须模糊化处理（如"据报道"） |

5. 匹配13大爆款元素，结合卡兹克选题特点萃取中的12种切入角度，参考选题模板库中验证过的公式，生成5个选题并打分
6. **选题排除检查**：根据常见失败模式排除风险选题（如选题过于宽泛、缺乏具体痛点、同质化严重等）
7. **一次性输出**：热点摘要 + 5个爆款选题

**输出格式**：
```markdown
## 📍 热点事件
{事件标题}
📝 核心描述：{100字描述}
🏷️ 关键词：{关键词1}、{关键词2}、{关键词3}
📊 关键数据：{数据1}、{数据2}

---

## 📋 爆款选题推荐（按潜力排序）

### 选题1 ⭐评分：{分数}分

**选题名称**：{标题}
**文案类型**：教知识/聊观点/讲故事/晒过程
**命中爆款元素**：{元素1}、{元素2}、{元素3}
**推荐理由**：{50-100字理由}
**目标用户痛点**：{痛点描述}
**关键词**：{关键词1}、{关键词2}
**卡兹克选题参考**：{参考选题类型}

---
（选题2-5同格式）
```

### Step 3: 热点深度分析

**目标**：全网搜集信息，生成深度分析报告

**执行方式**：
1. 使用 WebSearch 工具，围绕选题关键词进行多轮搜索（至少3轮不同角度）
2. 搜索维度：
   - 事件全貌：时间线、关键人物、最新进展
   - 数据支撑：官方数据、行业报告、第三方统计
   - 各方观点：支持方、反对方、中立分析
   - 社交舆论：微博/知乎/小红书上的热议观点
   - 历史对比：类似事件的前车之鉴
3. 整理为结构化素材报告

**输出**：
```markdown
## 🔍 深度分析报告

### 事件全貌
{时间线 + 关键节点}

### 核心数据
{可引用的数据，标注来源和可信度等级}

### 各方观点
- 支持方：{观点}
- 反对方：{观点}
- 中立分析：{观点}

### 可用素材
{金句、案例、数据、类比}
```

### Step 5: 生成完整文案

**目标**：生成符合个人风格的完整文案

**⏱️ 推荐目标字数**

> ⚠️ **必读**：`references/方法论/数字生命卡兹克-文案规律萃取.md`

根据选题类型，按语速230字/分钟计算：

| 选题类型 | 推荐时长 | 推荐字数 |
|---------|---------|---------|
| 时效热点型（快讯） | 3-5分钟 | 700-1150字 |
| 产品首发实测型 | 6-8分钟 | 1380-1840字 |
| 反认知/观点颠覆型 | 6-9分钟 | 1380-2070字 |
| 行业趋势预判型 | 7-10分钟 | 1610-2300字 |
| 警示危机型 | 6-8分钟 | 1380-1840字 |
| 干货教程型（方法论） | 8-12分钟 | 1840-2760字 |
| 成本效益型 | 5-7分钟 | 1150-1610字 |
| 情感共鸣型 | 5-7分钟 | 1150-1610字 |
| 批评吐槽型 | 5-7分钟 | 1150-1610字 |
| 人物故事型（专访） | 8-12分钟 | 1840-2760字 |
| 数据洞察型 | 7-9分钟 | 1610-2070字 |
| 娱乐猎奇型 | 4-6分钟 | 920-1380字 |

**最佳甜蜜点：1200-2000字（5-9分钟）**

**⚠️ 必读知识库**：
1. `references/方法论/AI创作规范.md`（去AI味规范）
2. `references/用户配置/我的用户画像.md`（个人风格和素材）

**执行方式**：
1. 读取「我的用户画像」中的写作风格偏好和个人素材
2. 读取「AI创作规范」学习去AI味规则
3. 按照以下原则生成：
   - 去AI味：不用"综上所述/建议您/首先其次最后/值得注意的是"
   - 注入个人风格：根据用户画像中的语气、口头禅生成
   - 注入个人素材：如用户画像中有相关经历，自然融入文案
4. 使用用户画像中的常用口语词增加真实感

**风格检查清单**：
- [ ] 开篇是否使用了选中的开篇模板？
- [ ] 是否使用了用户画像中的常用口头禅？
- [ ] 是否避免了所有AI味词汇？
- [ ] 结尾是否有行动号召？
- [ ] 读起来像真人说的话吗？
- [ ] 是否注入了个人真实经历或独家观点？

### 署名测试（不可替代性检查）

> **核心问题：把署名换成别人，这篇文案还能成立吗？**

- [ ] 文中是否有**只有作者才有的经历**？
- [ ] 文中是否有**独家数据或独家判断**？
- [ ] 去掉所有个人印记后，和通用AI生成的内容**区别在哪**？

**判定：**
- ✅ 至少2项有明确答案 → 通过
- ❌ 少于2项 → **必须补入个人素材**（从用户画像中调取）

**输出要求**：
- 字数：根据选题类型匹配，允许浮动±10%
- 段落：短段落（每段不超过3-4行），遵循「短-短-短-展」节奏
- 金句：每400-500字至少1句可传播金句
- 结尾：引导行动
- 标注：文案末尾标注「📝 本文约XXX字，预计朗读X分钟」

### Step 6: 事实核查

**目标**：核查文案中引用的数据、案例、事件的真实性

**执行方式**：
1. 逐条提取文案中的关键事实声明（数据、引言、时间、事件描述）
2. 使用 WebSearch 逐条验证
3. 核查重点：
   - 引言是否真实存在？是否原话？
   - 数据来源是否可靠？数字是否准确？
   - 事件时间线是否正确？
   - 案例描述是否与事实相符？
4. 标注核查结果：
   - ✅ 已验证：来源可靠
   - ⚠️ 部分偏差：需要修正
   - ❌ 无法验证：建议删除或模糊化处理
5. 根据核查结果修正文案，输出修正后的完整文案

**核查后处理**：
- ✅ 核查通过：继续下一步
- ⚠️ 发现问题：修正文案后再继续
- ❌ 严重失实：告知用户，等待确认

### Step 7/8/9: 下游流水线（并行执行）

#### 任务A：生成20个爆款标题

**⚠️ 必读**：
1. `references/方法论/数字生命卡兹克-标题公式萃取.md`（9大标题公式）
2. `references/方法论/13大爆款元素.md`（情绪方向）

**执行方式**：
1. 读取「标题公式萃取」和「13大爆款元素」
2. 从9大公式中选3-4个，各生成4-5个标题
3. 覆盖不同情绪方向：
   - 好奇/悬念型（4个）
   - 震撼/冲击型（4个）
   - 共鸣/情感型（4个）
   - 实用/干货型（4个）
   - 戏剧/故事型（4个）
4. 必须使用S级高频词汇（刚刚/神级/天花板/封神/居然）
5. 必须排除禁用句式（简单聊聊/聊聊X/来了等）

**标题质量自检**：
- 字数：15-25字为最佳
- 是否包含数字/具体细节？
- 是否制造了信息差/好奇心？
- 是否避免了标题党嫌疑？

---

#### 任务B：公众号排版优化

**排版规范**：

1. **段落处理**：
   - 每段不超过3-4行（手机屏幕适配）
   - 段间空一行
   - 重要观点单独成段

2. **二级标题**：
   - 保留原文标题，不另起炉灶
   - 如原文无标题，从内容中提炼
   - 标题要口语化，禁止"一、二、三"编号

3. **视觉标记**：
   - 每小节2-3处加粗重点
   - 金句用 `>` 引用块突出
   - 列表用 `-` 而非 `1.2.3.`

4. **开篇处理**：
   - 前3行必须抓人（这是决定用户是否继续读的关键）
   - 不加标题，直接进入正文

5. **结尾处理**：
   - 行动号召明确
   - 可加引导关注/转发的话术

#### 任务C：敏感词检测

**检测规则**（覆盖小红书/抖音/视频号/公众号）：

**8大敏感词分类**：

| 分类 | 高频敏感词示例 | 替换方案 |
|------|-------------|---------|
| 极限用词 | 最好/第一/唯一/100% | 非常好/领先/极少数/接近100% |
| 广告导流 | 免费领取/扫码/点击链接/私信 | 可以获取/了解更多/评论区见 |
| 医疗健康 | 治疗/药效/根治/特效 | 调理/改善/缓解/辅助 |
| 金融诈骗 | 暴富/躺赚/稳赚不赔/日入过万 | 增长/收益提升/有不错的回报 |
| 引战争议 | 对立性别词/地域歧视/政治敏感 | 直接删除或改写 |
| 色情低俗 | 各类擦边词汇 | 直接删除 |
| 平台违规 | 引导站外/竞品名称/举报类 | 根据平台规则处理 |
| 政治敏感 | 涉及领导人/政策批评/敏感事件 | 中性表述或删除 |

**检测流程**：
1. 逐句扫描文案
2. 标注风险词及风险等级（高/中/低）
3. 给出替换建议
4. 输出完整修改版
