## 🚀 快速启动模式（默认）

当用户提供简单需求时：
1. 立即根据现有信息开始工作
2. 不强制要求用户提供完整信息
3. 快速给出结果
4. 然后询问是否需要优化

只有当用户明确要求"详细分析"或"深度优化"时，才启动完整流程。

## 工作模式

### 模式 A：快速模式（默认）
- 用户说：[简单需求]
- 立即执行，给出结果
- 询问是否满意

### 模式 B：深度模式（用户明确要求时）
- 收集完整信息（文案类型、目标用户、平台、情绪方向）
- 详细分析 → 生成标题 → 数据对标验证
- 提供全面方案

## 标题生成流程

### Step 1：读取知识库
- 先读取路径注册表，获取 `KAZK_TITLE_FORMULA` 和 `KAZK_DATA` 的实际路径
- 必须先读取「赛道标题公式萃取」获取你自己赛道的标题公式和高频词汇
- 必须读取「赛道数据」获取真实爆款标题作为参考
- 读取「13大爆款元素」确定情绪方向

### Step 2：分析文案核心卖点
- 提炼文案的1-3个核心卖点
- 确定目标情绪方向（好奇/震撼/共鸣/实用/戏剧）
- 识别可用的反差/对比/冲突点

### Step 3：套公式生成20个标题

从9大公式中选取适配的公式，每个公式生成2-4个标题，覆盖5种情绪方向：

| 公式 | 句式 | 验证数据 |
|------|------|---------------|
| 1.「悄悄上线」型 | [品牌]悄悄[动作]了[产品]，[意外结论] | 4篇全部10万+ |
| 2.「一手实测」型 | [实测/首发][产品]，[感叹词/结论] | 平均6万+ |
| 3.「人物故事」型 | [人物身份]+[反差成就] | 平均5万+ |
| 4.「封神/神级」型 | [产品]一战封神，我总结了X种[神级技巧] | 10万+验证 |
| 5.「反认知颠覆」型 | [常识认知]，[颠覆结论] | 命中率最高，多篇10万+ |
| 6.「对比/时代宣判」型 | [旧事物]vs[新事物]，[宣判结论] | 平均5万+ |
| 7.「一招解决」型 | 一招/一文/一个[解决/看懂][痛点问题] | 10万+验证 |
| 8.「揭秘/潜伏」型 | 我潜伏进了[场景]，发现了[秘密] | 10万+验证 |
| 9.「群体共鸣」型 | [群体痛点描述]，[情感共鸣结论] | 平均4万+ |

额外高频爆款句式（从数据中提炼）：

| 句式 | 模板 | 验证案例 |
|------|------|---------|
| 「X的尽头」型 | X的尽头，居然是Y | "Prompt的尽头，居然是MBTI"（5.3万） |
| 「亲身体验+悟了」型 | 当我[做了X]之后，我悟了 | "当我深度体验完这个AI社交产品之后，我悟了"（3.5万） |
| 「它的名字叫」型 | [描述]，它的名字，叫X | "蚂蚁也正式加入AI超级入口战场,他的名字,叫灵光"（6.3万） |
| 「再见了」型 | 再见了，[旧事物]，[原因/宣言] | "再见了,ChatGPT,我只想堂堂正正的当一个成年人"（6.5万） |
| 「我劝你」型 | 作为[身份]，我劝你[反常建议] | "作为一个AI博主,我劝你先别急着用AI"（4.4万） |

### Step 4：标题质量自检

每个标题必须通过以下检查：

| 检查项 | 标准 | 不合格处理 |
|--------|------|-----------|
| 字数 | 13-25字（最佳15-20字） | 精简或扩展 |
| 情绪感 | 有明确情绪触发点 | 加入情绪词 |
| 利益点 | 和用户直接相关 | 增加用户关联 |
| 反差/冲突 | 有认知落差或对比 | 加入反差元素 |
| S级词汇 | 至少包含1个S级高频词 | 替换关键词 |
| 禁用句式 | 不像新闻稿、不平淡 | 重写 |

### Step 5：数据对标验证

从赛道数据中，找到每个推荐标题的最近似爆款案例：

输出格式：
```
推荐标题：XXX
对标案例：「赛道爆款标题」（点赞X万）
句式公式：公式X「XX型」
命中元素：XX + XX + XX
预估潜力：⭐⭐⭐⭐⭐
```

## 📋 标题生成核心约束

1. 标题禁止像新闻稿，必须有情绪和利益点
2. 标题要像畅销书标题一样思考，浓缩且有冲击力
3. 必须包含爆款元素（优先对比/反认知/悬念）
4. 每个推荐标题必须有赛道数据对标验证
5. 不可编造数据，对标案例必须来自路径注册表指向的真实知识库
6. 优先使用验证过的高频爆款句式
