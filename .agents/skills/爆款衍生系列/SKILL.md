# 爆款衍生系列

> 一篇爆款的价值，远不止一篇文章

## 🎯 功能概述

这是一个**编排器 skill**，专门处理"自己的爆款→衍生更多内容"的生产链路。

核心逻辑：一篇爆款已经被市场验证了选题方向、内容类型、用户需求。围绕它做衍生，相当于站在"已验证"的基础上再出发，爆款概率远高于从零开始。

```
自己的爆款 → 复盘分析（为什么爆） → 衍生策略选择 → 文案生成 → 下游流水线
```

与其他入口 skill 的区别：

| Skill | 素材来源 | 核心动作 |
|-------|---------|---------|
| 公众号爆款生产 | 外部热点链接 | 从热点出发，选题→文案 |
| 爆款拆解改写 | 别人的爆款文案 | 拆别人的骨架→换自己的血肉 |
| **爆款衍生系列** | **自己的爆款内容** | **分析自己爆的原因→围绕它生成更多内容** |

关键区别：「爆款拆解改写」是拆**别人的**爆款，「爆款衍生系列」是围绕**自己的**爆款做延伸。

## 📥 输入参数

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `爆款内容` | ✅ 是 | 自己的爆款文案全文，或@引用已发布文案文件 | - |
| `数据表现` | ✅ 是 | 点赞/收藏/转发/评论/阅读量等数据 | - |
| `执行模式` | ❌ 否 | 自动模式/交互模式 | 询问用户选择 |
| `衍生策略` | ❌ 否 | A/B/C/D/E 五种策略 | 自动模式推荐TOP1，交互模式用户选 |
| `目标平台` | ❌ 否 | 公众号/小红书/视频号 | 与原文同平台 |

支持的输入形式：
- 直接粘贴爆款文案全文 + 数据
- @引用 `07.发布文案/` 下的已发布文案文件 + 数据
- 提供爆款案例库中已有的案例编号

## ⚡ 双模式说明

### 模式一：🚀 自动模式（推荐）

全程自动执行，只在两个关键节点暂停：

```
自动复盘分析 → 自动推荐衍生策略TOP1 → 自动生成文案
→ ⏸️ 用户确认文案 → 自动下游流水线 → ⏸️ 用户确认最终成品
```

自动模式的默认行为：
- 复盘分析：自动调用爆款复盘分析skill
- 策略选择：自动推荐投入产出比最高的衍生策略
- 文案生成：保留原文的核心爆款元素，按策略生成衍生内容

检查点只有 2 个：
| 检查点 | 位置 | 等什么 |
|--------|------|--------|
| ⏸️ 1 | 完整文案生成后 | 用户确认文案内容 |
| ⏸️ 2 | 最终成品（排版后）| 用户确认发布 |

### 模式二：🔧 交互模式

每步暂停，用户全程参与决策：

```
复盘分析 → ⏸️ 确认分析结果 → 衍生策略 → ⏸️ 选择策略
→ 文案生成 → ⏸️ 确认文案 → 下游流水线 → ⏸️ 确认发布
```

检查点 4 个：
| 检查点 | 位置 | 等什么 |
|--------|------|--------|
| ⏸️ 1 | 复盘分析后 | 确认爆款原因分析 |
| ⏸️ 2 | 衍生策略推荐后 | 选择衍生策略 |
| ⏸️ 3 | 完整文案生成后 | 确认文案内容 |
| ⏸️ 4 | 最终成品（排版后）| 确认发布 |

## 🔄 完整工作流程

### Step 1：爆款复盘分析

#### 1.1 调用「爆款复盘分析」skill

将用户提供的爆款内容和数据传入，获取完整的复盘报告：
- 数据层分析（基础指标、核心指标）
- 元素层分析（命中了哪些爆款元素、元素组合公式）
- 结构层分析（文案框架、开篇方式、主体结构、结尾方式）
- 模板层提取（可复用的选题/开篇/结构模板）

#### 1.2 提取"爆的核心原因"

从复盘报告中提炼 3 个关键成功因素，按重要性排序：

```
示例：
爆款：「我的AI写文案没有AI味」
核心原因：
1. 选题精准命中痛点（AI味是所有AI用户的焦虑）
2. 反认知钩子（"没有AI味"颠覆预期）
3. 实操价值高（给了具体方法，收藏率64.7%）
```

#### 1.3 交叉参考历史数据

- 读取爆款案例复盘库，看同类型爆款的衍生规律
- 读取失败案例复盘库，看哪些衍生方向容易扑
- 读取可复用模板库，看有没有已验证的衍生公式

**模式分流：**
- 🚀 自动模式：自动完成分析，继续执行
- 🔧 交互模式：⏸️ 展示复盘报告和核心原因，等用户确认

### Step 2：衍生策略推荐

基于复盘结果，推荐 5 种衍生策略：

#### 策略A：续集深化（最常用）

```
原文讲了3个方法 → 续集讲"进阶版5个方法"
原文讲了入门 → 续集讲"高阶玩法"
原文讲了问题 → 续集讲"解决方案"
```

核心原则：
- 保留原文的选题方向和爆款元素组合
- 深度加倍，给出更多/更深的内容
- 标题明确标注"续集"或"进阶版"，吃原文的长尾流量
- 开篇可以引用原文数据："上一篇{标题}，{数据}人收藏了..."

适用场景：原文是教知识类，内容还没讲完

#### 策略B：换角度重写

```
原文从"方法论"角度讲 → 换成"踩坑避雷"角度
原文从"个人经验"角度讲 → 换成"行业观察"角度
原文从"正面论证"角度讲 → 换成"反面警示"角度
```

核心原则：
- 同一个选题，完全不同的切入角度
- 保留核心爆款元素（痛点不变），换表达方式
- 可以换内容类型（教知识→聊观点，讲故事→教知识）

适用场景：原文的选题方向被验证了，但还有其他角度没挖

#### 策略C：换平台适配

```
公众号长文 → 小红书图文（精简为5-7张图+文字）
公众号长文 → 视频号口播脚本（改为口语化+节奏感）
公众号长文 → 社群分享素材（提炼核心观点+讨论问题）
```

核心原则：
- 内容核心不变，形态完全重构
- 适配目标平台的内容规范和用户习惯
- 小红书：短段落+emoji+图文结合
- 视频号：口语化+前3秒钩子+节奏紧凑

适用场景：原文在一个平台爆了，想在其他平台也发

#### 策略D：用户反馈衍生

```
评论区高频问题 → 写一篇专门回答的文章
评论区争议观点 → 写一篇聊观点的文章
评论区"求教程" → 写一篇详细教程
```

核心原则：
- 从原文的评论区/私信中挖掘衍生方向
- 用户已经告诉你他们还想看什么了
- 开篇可以引用："上篇文章发出后，评论区最多的问题是..."

适用场景：原文评论区有大量有价值的反馈

#### 策略E：系列化IP

```
单篇爆款 → 打造成系列栏目
「AI写文案没有AI味」→ 「AI系列」：AI做PPT/AI做视频/AI做设计...
「小红书月入12万」→ 「变现系列」：公众号变现/视频号变现/知识付费...
```

核心原则：
- 把爆款的选题公式抽象化，变成可批量复制的系列
- 每篇都用相同的选题公式+框架，换不同的具体话题
- 形成品牌栏目，培养用户期待

适用场景：原文的选题公式有通用性，可以套用到多个话题

#### 策略推荐逻辑

AI根据以下维度自动推荐最优策略：

| 维度 | 权重 | 说明 |
|------|------|------|
| 原文内容完整度 | 25% | 内容讲完了→换角度/换平台；没讲完→续集 |
| 评论区反馈 | 25% | 有大量追问→用户反馈衍生；无明显追问→其他策略 |
| 选题公式通用性 | 20% | 公式可套用→系列化IP；公式特殊→续集/换角度 |
| 多平台需求 | 15% | 用户做多平台→换平台适配；单平台→其他策略 |
| 历史衍生效果 | 15% | 参考可复用模板库中的衍生成功率 |

**模式分流：**
- 🚀 自动模式：自动推荐TOP 1策略，继续执行
- 🔧 交互模式：⏸️ 展示5种策略的分析和推荐排序，等用户选择

### Step 3：文案生成

#### 3.1 并行读取知识库

先读取「直播口语风格萃取」用口语节奏打底，再读取「公众号文案风格萃取」做书面化微调（⚠️必读）、AI创作规范、个人自传、社群总结、开篇模板库(精选版)、对应类型开篇库、框架使用说明书、框架效果数据、卡兹克文案规律萃取、引流钩子模板。

#### 3.2 构建素材池

```
素材优先级：
① 原文的核心素材（已验证有效的案例/数据/观点）→ 可部分复用
② 原文评论区的用户反馈（真实声音）→ 天然素材
③ 个人自传中的相关经历（补充新素材）
④ 社群总结中的相关讨论（补充多角度）
⑤ 合理推理和延伸（兜底）
```

#### 3.3 衍生内容的核心约束

无论选哪种策略，衍生内容必须遵守：

```
✅ 必须保留的（原文验证过的）：
- 核心爆款元素组合（选题公式不变）
- 目标用户群体（痛点方向不变）
- 内容价值类型（实用/共鸣/争议）

❌ 必须改变的（避免重复）：
- 具体案例和数据（换新的）
- 开篇方式（不能和原文一样）
- 主体结构的具体内容（换新的知识点/观点/故事）

⚠️ 可选改变的：
- 内容类型（教知识→聊观点，看策略需要）
- 文案框架（可以换不同框架）
- 目标平台（策略C专用）
```

#### 3.4 路由到对应文案skill

根据衍生内容的类型，路由到对应skill：

```
教知识 → 调用「教知识文案」skill
聊观点 → 调用「聊观点文案」skill
讲故事 → 调用「讲故事文案」skill
晒过程 → 调用「公众号爆款生产」skill
```

传递信息：
- 衍生选题（已包装）
- 素材池（已构建）
- 原文的核心爆款元素（必须保留）
- 衍生策略的具体约束
- 原文链接/标题（用于开篇引用）

#### 3.5 文案质量自检

生成后自检：
- [ ] 是否保留了原文的核心爆款元素组合？
- [ ] 是否和原文有足够的差异化（不是换皮）？
- [ ] 是否有新的增量价值（不是炒冷饭）？
- [ ] 开篇是否自然引用了原文的成功（"上篇...很多人问..."）？
- [ ] 结尾是否引导了系列化期待（"下一篇我们聊..."）？
- [ ] 口吻是否符合你的风格？

#### 3.7 署名测试（不可替代性检查）

> **核心问题：把署名换成别人，这篇文案还能成立吗？**

逐项检查：
- [ ] 文中是否有**只有你才有的经历**？（个人实战、真实案例、踩过的坑）
- [ ] 文中是否有**独家数据或独家判断**？（不是公开信息的二次搬运）
- [ ] 去掉所有个人印记后，和通用AI生成的内容**区别在哪**？（必须能说清）

**判定：**
- ✅ 至少2项有明确答案 → 通过，继续下游流水线
- ❌ 少于2项 → **必须补入个人素材**（从 `02.领域/0.内容创作系统/🔧06.我的档案/我的个人上下文` 或 `思想力武器库` 中调取），重新过一遍自检

**模式分流：**
- 🚀 自动模式：自动生成，⏸️ 输出完整文案等用户确认
- 🔧 交互模式：⏸️ 输出完整文案 + 质量自检报告，等用户确认

### Step 4：下游流水线

#### 4.1 标题生成
- 读取「卡兹克标题公式萃取」
- 生成 20 个候选标题

## ⚠️ 核心原则

### 衍生不是炒冷饭

衍生内容必须有新的增量价值。读者看完原文再看衍生，应该觉得"又学到了"而不是"这不是说过了吗"。

### 保留验证过的元素

原文爆了，说明选题公式+爆款元素组合是对的。衍生时保留这些"已验证"的部分，改变"未验证"的部分（具体内容、角度、形态）。

### 系列化思维

不要只想"衍生一篇"，要想"这个方向能不能做成系列"。一个爆款方向如果能衍生3-5篇，就是一个内容栏目。

### 数据驱动迭代

衍生内容发布后，对比原文数据：
- 衍生 > 原文：说明衍生方向对了，继续深挖
- 衍生 ≈ 原文：说明选题公式稳定，可以系列化
- 衍生 < 原文：分析差在哪里，调整策略
