# LeonG 调研：完整时间线

## 时间线

### 2023年初
- 开始在抖音发布内容
- 最初定位：情感搭讪教学

### 2023年6月
- 粉丝量突破1万
- 完成初期积累

### 2023下半年 - 2024年初
- **定位重大转型**：从单纯搭讪教学转变为「男性成长/男性觉醒」赛道
- 创立自有品牌 **RST情感**
- 启动商业化：推出《开撩蓝图》，开设3000元/45分钟私教咨询

### 2024年
- 完善内容体系：推出《Alpha通识课》（1.0-7.0共12集）、《觉醒商业课》
- 再次明确转型定位："不做流量，要做情感IP"
- 发生争议事件"直播间泪洒事件"，引发广泛讨论

### 2025年3月
- 主号公开数据：粉丝13.4万，作品83个，获赞190.8万
- 开始布局**矩阵号战略**：主号+多个矩阵号同时运营，团队化操作

### 2025年 - 2026年初
- 矩阵号持续扩张，全网粉丝累计**超过100万**
- 业务拓展：从单一线上课程发展到「线上课程+线下活动」完整闭环
- 用户已经报名**2026年7月杭州线下课**，说明品牌影响力持续扩大

### 2026年5月（当前）
- 状态：持续稳定更新内容、直播问答
- 业务：线上课程（Alpha通识、觉醒商业课）+ 私教咨询 + 线下课 = 完整产品矩阵
- 定位：抖音男性成长垂直领域有影响力的博主，主打"男人要卓越"的男性觉醒理念

## 关键趋势

1. **持续进化**：从搭讪教学 → 男性成长IP → 线上+线下完整闭环，每一步都踩对节奏
2. **矩阵化运营**：多账号矩阵，团队作业，全网粉丝百万+，规模效应显现
3. **高客单价策略**：坚持3000元私教定价，筛选高意愿用户，不做低价内卷
4. **线下落地**：从纯线上走向线下，2026年已经能开付费线下课，证明社群和用户信任建立成功
