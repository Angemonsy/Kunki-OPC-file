### 维度七：文案策略分析

## 数据提取要点

从账号主页抓取时，重点关注：

**必提取数据：**
- 基础数据：粉丝数、获赞数、收藏数
- 笔记列表：标题、封面、互动数据
- 账号简介：定位、标签
- 更新频率：发布时间规律

**深度挖掘：**
- 评论区高频问题
- 置顶笔记特征
- 合集/专辑规划
- 互动话术套路

## 分析质量标准

✅ 优秀的分析报告应该：
1. 数据准确：基于真实抓取或用户提供的数据
2. 分析全面：覆盖12个维度
3. 洞察深刻：不只是数据罗列，要有分析结论
4. 建议实用：对标建议具体可执行
5. 排版专业：PDF美观易读
6. 来源透明：清楚标注数据来源（自动抓取/用户提供/行业推算）

✅ 当无法自动抓取时：
1. 基于用户提供的数据进行分析
2. 结合行业经验进行合理推断
3. 在报告中明确标注数据来源和推算依据
4. 聚焦于可分析的维度，不强求完整性
5. 提供基于现有信息的最佳洞察

❌ 避免：
1. 数据不准确或过时
2. 分析浅显，流于表面
3. 建议空泛，不可执行
4. 格式混乱，难以阅读
5. 因数据不足而拒绝分析（应灵活调整）

【建议提供（可选，但能让分析更准确）】
5. 账号主页截图

**如果用户提供截图：**
- 从图片中提取可见信息

- 标注分析基于用户提供的数据

**如果数据不足：**
- 说明当前可获取的数据情况
- 基于现有数据进行分析
- 标注哪些维度因数据不足而采用行业平均值推算
- 建议用户补充哪些信息可以让分析更准确

**如果账号是新号：**
- 调整分析框架，重点分析内容策略
- 减少对历史数据的依赖
- 提供新号冷启动建议
