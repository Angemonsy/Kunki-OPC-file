# 产品推广文案

> 把真实素材变成让人想下单的推广文案，不靠硬卖，靠真实感和前后对比打动人

## 🎯 功能概述

这是一个**产品推广文案生产 skill**，专门解决：
1. 有产品/课程要推广，但不知道怎么写才能让人下单
2. 有直播稿、学员反馈等素材，但不知道怎么组织成文案

```
产品信息 + 真实素材 → 经纬晒过程框架 + ABCD模型 → 高转化推广文案 → 串联下游流水线
```

## 🔄 完整工作流程

### Step 1：素材解析 + 产品梳理

接收用户输入后，执行以下分析：

**1.1 产品信息提取**

从用户提供的信息中提取：
- 产品名称和定价（原价/现价）
- 交付清单（课程/工具/模板/社群/更新等）
- 目标用户画像（谁需要这个产品）
- 核心卖点（解决什么问题）
- 差异化优势（和市面上其他方案有什么不同）

**1.2 素材盘点**

从用户提供的素材（直播稿/学员反馈/实战数据等）中提取：
- 可用于「困境段」的素材：用户/作者以前遇到的痛点、挣扎
- 可用于「转折段」的素材：发现了什么、想明白了什么
- 可用于「变化段」的素材：前后对比数据、具体效果
- 可用于「社会证明」的素材：学员案例、客户反馈、直播观众评价
- 可用于「真实感」的素材：口语化表达、具体场景、情绪流露

**1.3 爆款元素匹配**

读取`13大爆款元素`，从素材中识别可放大的爆款元素：
- 成本对比（以前XX小时 → 现在XX分钟）
- 数据冲击（具体数字、具体案例）
- 对比/对立（旧方法 vs 新方法）
- 场景共鸣（目标用户熟悉的痛苦场景）

**1.4 输出解析结果**

```markdown
## 📦 产品梳理
- 产品：{名称}
- 定价：{原价} → {现价}
- 交付：{清单}
- 目标用户：{画像}
- 核心卖点：{卖点}

## 📋 素材盘点
- 困境素材：{X}条可用
- 转折素材：{X}条可用
- 变化素材：{X}条可用
- 社会证明：{X}条可用
- 素材缺口：{缺什么}

## 🔥 爆款元素
- 主打：{元素1}
- 辅助：{元素2}、{元素3}
```

---

### 🛑 检查点1：用户确认

**交互模式**：暂停，展示解析结果，等待用户确认或补充。

**自动模式**：展示解析结果，不暂停，直接进入 Step 2。如素材严重不足（困境/转折/变化任一为0），强制暂停要求补充。

### Step 2：文案生成（核心）

读取所有知识库，按经纬「晒过程·客户见证/产品推广型」框架 + ABCD模型生成文案。

#### 框架结构（ABCD + 晒过程融合）

```
A→B 危机预警开头（占全文约15%）
│  目标：让不感兴趣的人开始感兴趣
│  方法：描述目标用户正在经历的痛苦循环，制造"这说的不就是我吗"的共鸣
│  要求：具体场景 + 情绪词 + 短句节奏
│
B→C 论点1：困境（占全文约25%）
│  目标：让感兴趣的人想了解更多
│  方法：讲"我以前也一样"，用自己的真实经历佐证困境的普遍性
│  要求：真实感是命脉，要有犹豫、有情绪波动
│  框架规则：让客户/作者用自己的话说出问题，不要第三方总结
│
B→C 论点2：转折（占全文约30%）
│  目标：让想了解的人开始心动
│  方法：讲"直到我想明白一件事"，展示转折点和方法
│  框架规则：⚠️ 方法论只点到不讲透（制造"我也想学"的欲望）
│  要求：恍然大悟的感觉 + 具体场景展示（不是抽象概念）
│  关键：展示结果和过程，不解释原理
│
C→D 论点3：变化+引流转化（占全文约30%）
│  目标：让心动的人准备下单
│  方法：前后对比 + 社会证明 + 产品介绍 + 行动指令
│  框架规则：必须有具体的"前后对比"（之前XX → 现在XX）
│  要求：
│    - 变化段要有数据（时间对比、效率对比）
│    - 社会证明要有具体案例（身份+场景+结果，3个左右）
│    - 产品介绍要简短（3-5行，交付清单放配图）
│    - 结尾要情感先行，行动指令自然跟上
```

#### 写作约束（必须遵守）

1. **真实感是命脉**：所有内容必须基于用户提供的真实素材，不编造数据和案例
2. **方法只点不展开**：转折段展示"发现了什么"和"结果如何"，不解释具体方法论
3. **必须有前后对比**：至少一组明确的"以前XX → 现在XX"
4. **口语化表达**：像跟朋友聊天，不像新闻稿
5. **产品介绍要克制**：不超过全文15%，交付清单用配图代替文字罗列
6. **社会证明要具体**：身份+场景+结果，不要泛泛的"学员都说好"
7. **结尾情感先行**：先唤起"我也想要这种感觉"，再给行动指令
8. **读取AI创作规范**：按70%+30%原则检查，去AI味
9. **绝对化描述降温**：不用"没有任何区别""100%""完全一样"，换成"很接近""基本上""差不多"——留余地反而更可信
10. **产品定性准确**：区分作者自用的"系统"和学员实际拿到的"工具包/课程"，不把交付物往大了包装
11. **未发生的不写**：课程未开不编学员见证，功能未上线不写进卖点，数据未核实不引用——宁可少写，不可失实
12. **标题不放陌生术语**：读者不认识的专业名词（OpenClaw、RAG、Agent等）不进标题和开篇，卖痛点和结果，不卖方案名

#### 配图标记（文案生成后必做）

通读全文，在关键位置插入配图标记：

| 类型 | 格式 | 适用场景 |
|------|------|---------|
| 📐 设计制作图 | `【配图①：图片类型，具体描述内容】` | 对比图、交付清单图 |
| 🖥️ 本地截图 | `【本地截图①：截图内容描述】` | 展示系统界面、工具、知识库 |

标记规则：
- 中等文案（1000-2000字）2-3张，长文案（>2000字）3-5张
- 当文章提到自己的系统/工具/知识库时，优先使用「本地截图」
- 交付清单优先做成设计图而非文字罗列

### Step 3：用户视角审稿

文案生成完成后，在进入下游流水线之前，必须以**目标用户的第一视角**通读一遍，逐一检查以下4项：

**3.1 数字一致性**
- 课程周数/天数全文是否统一（如"3周"和"21天"不能混用）
- 技能模板数量是否与实际交付物一致
- 所有数据（播放量、成功率、名额等）是否已核实或有来源

**3.2 术语门槛**
- 目标读者不认识的专业词（OpenClaw、RAG、飞书Bot等）有没有图片或一句话解释托底
- 如果没有解释，读者会不会在这里分心或产生恐惧感

**3.3 CTA转化力**
- 结尾有没有给出"现在就行动"的理由（限时/限额/专属价格等）
- 还是让读者感觉"先收藏，改天再看"

**3.4 情绪一致性**
- 结尾情感升华有没有飘离前文语境
- 前文在说省时间/找客户，结尾突然升华到"人生意义"，会造成断裂感

**输出格式：**
```
【用户视角审稿】

✅ 数字一致性：通过 / ⚠️ 发现问题：{描述}
✅ 术语门槛：通过 / ⚠️ 发现问题：{描述}
✅ CTA转化力：通过 / ⚠️ 发现问题：{描述}
✅ 情绪一致性：通过 / ⚠️ 发现问题：{描述}
```

发现问题时，直接给出修改建议，等用户确认后再改。

---

### Step 4：串联下游流水线

审稿确认无问题后，按顺序串联：

1. **标题生成**：调用「标题生成」skill，传入完整文案，生成20个标题候选
2. **排版优化**：调用「公众号排版」skill
3. **敏感词检测**：调用「事实核查」skill 或「敏感词检测」
4. **存档**：更新文案 frontmatter 状态

每个环节按对应 skill 的规则执行。

## ⚠️ 重要规则

### 必须遵守

1. **框架不可跳过**：必须按 A→B→C→D + 困境→转折→变化→引流转化 的结构写
2. **素材不可编造**：所有数据、案例、场景必须来自用户提供的真实素材
3. **方法只点不展开**：这是经纬框架的核心规则，违反会破坏转化效果
4. **前后对比必须有**：至少一组，最好两组以上
5. **知识库必读**：Step 2 的所有知识库不可跳过
6. **下游不可省略**：标题、排版、敏感词必须执行

### 禁止行为

1. ❌ 禁止在转折段详细讲解方法论原理
2. ❌ 禁止编造学员案例和数据
3. ❌ 禁止产品介绍超过全文15%
4. ❌ 禁止用"很多人说好"代替具体案例
5. ❌ 禁止用AI腔写文案（读AI创作规范）
6. ❌ 禁止跳过配图标记
7. ❌ 禁止用绝对化词汇描述效果（"没有任何区别""完全替代""100%"）
8. ❌ 禁止把交付物包装成比实际更大的概念（工具包不叫系统，模板不叫平台）
9. ❌ 禁止写入未发生的社会证明（课程未开=无学员见证，功能未上线=不进卖点）
10. ❌ 禁止在标题和开篇使用目标读者不认识的专业术语
