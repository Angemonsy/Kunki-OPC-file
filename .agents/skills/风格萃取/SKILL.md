# 文案风格萃取

从用户提供的文案样本中深度提取写作风格特征，输出结构化JSON风格定义，用于后续基于该风格生成其他主题的文案。

## 触发条件
- 用户说"帮我提取风格""风格萃取""分析一下这个文案风格""提取写作风格"
- 交付场景：为客户做风格萃取时调用

## 输入要求
用户提供5-10篇文案样本（任何平台都行）。可以是：
- 直接粘贴文案内容
- 提供文件路径让AI读取

## 执行流程

### 第1步：收集样本
确认用户提供的文案样本数量。少于3篇时提醒"样本越多，风格提取越准，建议5-10篇"。

### 第2步：逐篇分析
通读所有样本，从以下9个维度分析文本风格特征：

1. **语言特征**：句式、用词、修辞
2. **结构特征**：段落、过渡、层次
3. **叙事特征**：视角、距离、时序
4. **情感特征**：浓淡、方式、基调
5. **思维特征**：逻辑、深度、节奏
6. **个性标记**：独特表达、意象系统
7. **文化底蕴**：典故、知识领域
8. **韵律节奏**：音节、停顿、节奏
9. **禁忌特征**：作者明显不会用的表达方式

### 第3步：输出风格定义

以JSON代码块格式输出：

```json
{
    "style_summary": "风格一句话概括",
    "language": {
        "sentence_pattern": ["主要句式特征", "次要句式特征"],
        "word_choice": {
            "formality_level": "正式度 1-5",
            "preferred_words": ["高频特征词1", "特征词2"],
            "avoided_words": ["规避词类1", "规避词类2"]
        },
        "rhetoric": ["主要修辞手法1", "修辞手法2"]
    },
    "structure": {
        "paragraph_length": "段落平均字数",
        "transition_style": "过渡特征",
        "hierarchy_pattern": "层次展开方式"
    },
    "narrative": {
        "perspective": "叙事视角",
        "time_sequence": "时间处理方式",
        "narrator_attitude": "叙事态度"
    },
    "emotion": {
        "intensity": "情感强度 1-5",
        "expression_style": "表达方式",
        "tone": "情感基调"
    },
    "thinking": {
        "logic_pattern": "思维推进方式",
        "depth": "思维深度 1-5",
        "rhythm": "思维节奏特征"
    },
    "uniqueness": {
        "signature_phrases": ["标志性表达1", "表达2"],
        "imagery_system": ["核心意象1", "意象2"]
    },
    "cultural": {
        "allusions": ["典故类型", "使用频率"],

    },

        "syllable_pattern": "音节特征",
        "pause_pattern": "停顿规律",
        "tempo": "节奏特征"
    }
}
```

### 第4步：存档

将JSON风格定义写入指定路径。

- 如果是用户自己的：写入 `05-内容创作系统/🔧06.我的档案/我的个人上下文/风格萃取/`
- 如果是客户交付的：写入客户系统对应的个人上下文目录

## 注意事项

1. 文中提及的特殊要素不要提取，例如书名、作者姓名、特定地理位置等
2. 风格提取的目的在于基于该风格生成其他指定主题的文章，提取要素应当基于这一任务
3. 多篇样本之间如果风格有差异，取交集（稳定出现的特征），而非并集
4. 如果样本太少或风格差异太大，主动告知用户"这几篇风格差异较大，建议补充更多同类型样本"
