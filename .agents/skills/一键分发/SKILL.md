# 一键分发

> 文案定稿后，一键适配多平台，存入vault。你只负责最后点发布。

## 触发方式

用户说：`/分发`、`分发`、`发布到全平台`、`一键分发`、文案定稿后问"接下来怎么办"

## 分发范围

### 图文链路（本skill覆盖）

| 平台 | 操作 | 备注 |
|------|------|------|
| 微信公众号 | API推送到草稿箱 | 调用/微信公众号发布 skill |
| 小红书 | 生成标题+6-9张卡片文案+正文+话题标签 | 调用/小红书图文 skill |
| X/推特 | 生成中文Thread串（7-12条）+ 单条金句 | 调用/推特内容转换 skill |

### 视频链路（不在本skill范围）

视频号/抖音/B站/YouTube 需用 VideoForge 出片后手动上传，本skill不处理。

---

## 执行流程

```
收到「分发」指令
  → 确认当前文案文件（读取用户当前打开的文件，或请用户粘贴文案）
  → 询问：「要发哪些平台？默认公众号+小红书+X推特，还是全选/单选？」
  → 用户确认后，并行执行：
     ├→ 公众号：调用「微信公众号发布」skill → 推送草稿箱
     ├→ 小红书：调用「小红书图文」skill → 生成完整内容包
     └→ X推特：调用「推特内容转换」skill → 生成Thread串+金句推文
  → 将小红书版本和X推特版本追加到原文案文件底部（用分隔线）
  → 汇报完成状态
```

## 注意事项

1. **公众号发布前确认**：推到草稿箱后告知用户「已到草稿箱，请你登录后台确认封面图和摘要再发布」
2. **小红书需配图**：生成的是文案，图片由用户自行准备或用 Nano Banana 生成
3. **X推特发中文**：默认生成中文Thread，不做英文版，除非用户要求
4. **视频类平台跳过**：视频号/抖音/B站/YouTube 提醒用户走 VideoForge 流程
5. **分发记录**：分发完成后在周工作区记录「已分发：{文章标题}→{平台列表}」
