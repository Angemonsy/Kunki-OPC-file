# 公众号一键发布

当用户确认文章定稿、要发布到公众号时，引导用户操作。

## 操作步骤

告诉用户：

### 方式一：Copy Document as HTML（推荐，已安装）

1. 在Obsidian中打开要发布的文章
2. `Ctrl+P` 打开命令面板
3. 直接搜索 `Copy entire document to clipboard`，点击执行
4. 去公众号后台（mp.weixin.qq.com）→ 图文消息 → 新建
5. `Ctrl+V` 粘贴，标题和段落格式会自动保留
6. 手动插入图片（HTML方式不会自动带图片）
7. 预览确认后发布

### 方式二：Note to MP（已安装，支持图片）

1. 在Obsidian中打开要发布的文章
2. `Ctrl+P` 打开命令面板
3. 搜索 `note to mp`，选择对应命令
4. 插件会自动转换格式并处理图片
5. 去公众号后台粘贴发布

### 方式三：API发布到草稿箱

如果用户说"用API发布"或"自动发布"，则调用「微信公众号发布」skill。

## 定稿自动归档到待发布（必做）

当文章通过敏感词检测（用户确认不改或无敏感词），AI必须立即执行：

1. 将文章的 frontmatter `status` 改为 `待发布`
2. 将文件从 `草稿/` 移动到 `待发布/` 文件夹：
   - 源路径：`02.领域/0.内容创作系统/🔥02.发布文案/{年份}/草稿/{文件名}.md`
   - 目标路径：`02.领域/0.内容创作系统/🔥02.发布文案/{年份}/待发布/{文件名}.md`
3. 告知用户文章已移到待发布

触发时机：敏感词检测完成且用户确认后，不等用户提醒，自动执行。

## 发布前自动清理（必做）

在用户执行复制操作之前，AI必须先扫描文章，删除所有Obsidian图片别名行。

**问题**：Obsidian粘贴图片时会自动生成两行：
```
[[xxx_MD5.jpg|Open: 原始文件名.png]]   ← 别名行（多余，会被Copy as HTML当成文字输出）
![[xxx_MD5.jpg]]                        ← 图片嵌入（保留）
```

**清理规则**：删除所有匹配 `[[xxx|Open: xxx]]` 格式的行（没有 `!` 开头的图片引用），只保留 `![[xxx]]` 的图片嵌入行。

## 发布后自动归档（必做）

当用户确认已发布（说"发布了"、"发了"、"已发布"等），AI必须立即执行：

1. 将文章的 frontmatter `status` 改为 `已发布`
2. 将文件从 `待发布/` 移动到 `已发布/` 文件夹：
   - 源路径：`02.领域/0.内容创作系统/🔥02.发布文案/{年份}/待发布/{文件名}.md`
   - 目标路径：`02.领域/0.内容创作系统/🔥02.发布文案/{年份}/已发布/{文件名}.md`
3. 提醒用户可以调用「朋友圈文案生成」skill生成配套转发文案

## 注意事项

- 发布前提醒用户检查：标题是否OK、图片是否齐全、结尾钩子是否到位
- 发布前必须执行「自动清理别名行」，否则复制到公众号会出现多余文字
- 如果文章中有 `![[图片]]` 格式的本地图片，方式一需要手动上传，方式二会自动处理
- 发布后自动归档，不需要用户手动移动文件
