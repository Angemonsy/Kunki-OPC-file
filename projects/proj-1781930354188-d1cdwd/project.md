# 微信CLI 群聊内容提取分析项目

## 项目目标
使用本地 `wechat-cli` 工具，定期读取指定微信群聊记录，提取对用户有用的AI、商业、认知相关价值信息，整理为结构化洞察报告，存档到知识库。

## 操作流程
1. 用户提供目标群名称/线索 + 时间范围/要求
2. 通过 `wechat-cli` 搜索找到对应群聊
3. 读取聊天记录并保存到临时文件
4. 提取AI、商业、认知相关的有用洞察、方法论、链接、案例
5. 整理为结构化报告呈现给用户
6. 可选：存档完整聊天记录到知识库 `微信导出/` 目录

## 已完成示例
- **栋哥AI一人公司俱乐部（6/18-6/19）**：提取了陈厂长9条心法、地鼠80万案例、yangclaw蒸馏方法等核心价值
- **亚特兰蒂斯·新岛会员群（6/15-6/19）**：提取了全平台调研工作流、何锦成交引流品逻辑、Token真实指标论等内容

## 工具路径
- `wechat-cli`: `/Library/Frameworks/Python.framework/Versions/3.12/bin/wechat-cli`
- 配置: `~/.wechat-cli/config.json`
- 密钥: `~/.wechat-cli/all_keys.json`
