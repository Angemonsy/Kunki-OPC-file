# HTML PPT Skill

使用现代化HTML/CSS/JavaScript创建精美的PPT演示文稿。

## 功能特点

- 支持现代化美观设计
- 完全可控的布局和样式
- 支持动画和过渡效果
- 可在浏览器中直接演示
- 可导出为PDF或PPTX格式
- 基于reveal.js框架

## 使用方式

当用户需要制作PPT时：

1. 根据用户需求，基于reveal.js生成完整的HTML PPT文件
2. 使用现代化配色和布局，保证美观度
3. 输出可以直接在浏览器打开的HTML文件

## 导出方式

- 在浏览器中按 `Ctrl+P` 可以导出为PDF
- 可以使用wkhtmltopdf或在线工具转换为PPTX

## 示例模板

使用reveal.js CDN，无需本地安装依赖。
