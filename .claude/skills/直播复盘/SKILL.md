## 双模式：首次诊断 vs 播后复盘

本skill支持两种模式，启动时自动判断：

### 模式判断逻辑

```
用户说"复盘直播"/"诊断直播"
  │
  ├─ 用户提供了直播逐字稿+后台数据？ → 【播后复盘模式】
  │
  └─ 用户没有播过/想从零规划？ → 【首次诊断模式】
```

### 首次诊断模式（还没播过）

**输入**：用户口述当前直播现状、产品信息、目标

**必读文件**：

| 个人自传 | `02.领域/0.内容创作系统/🔧06.我的档案/我的个人上下文/个人自传（持续更新）.md` |

## 输入要求（播后复盘模式）

### ⛔ 硬性规则：数据不足时禁止开始分析

**必须同时满足「最低启动条件」才能开始复盘。缺任何一项，只输出缺失清单+获取方法，不做任何分析。**

### 最低启动条件（全部必须）

| # | 必须素材 | 具体要求 | 获取方法 |
|---|---------|---------|---------|
| 1 | **直播逐字稿** | 完整的直播文字稿（非片段摘要） | 视频号后台→直播回放→下载→用录音稿整理skill转文字 |
| 2 | **后台数据截图（至少5张）** | 见下方「数据截图清单」，至少覆盖5个必须页面 | 视频号后台→数据中心→直播数据→逐页截图 |
| 3 | **直播主题+产品信息** | 本场卖什么、价格多少、目标人群 | 用户口述即可 |

### 后台数据截图清单

> 用户提供截图后，逐项核对下表，缺哪张就告诉用户补哪张。

| # | 截图页面 | 必须/可选 | 需要从中提取的指标 |
|---|---------|---------|-----------------|
| 1 | **数据总览页** | 必须 | 直播时长、累计观看、最高在线、平均在线、人均观看时长 |
| 2 | **互动数据页** | 必须 | 评论次数、点赞次数、分享次数、新增粉丝、转粉率 |
| 3 | **成交/商品数据页** | 必须 | GMV、订单数、商品曝光率、曝光点击率、点击成交率 |
| 4 | **流量来源页** | 必须 | 推荐feed占比、关注页占比、分享占比、直播广场占比 |
| 5 | **在线人数曲线图** | 必须 | 在线人数随时间变化趋势（用于判断节奏效果和高成交时段） |
| 6 | **观众画像页** | 可选 | 性别、年龄、地域分布 |
| 7 | **粉丝团/加团数据** | 可选 | 加团人数、加团率 |
| 8 | **商品转化漏斗** | 可选 | 商品曝光→点击→下单→支付各环节转化率 |

### 可选但推荐的素材

| 素材 | 价值 | 缺失时影响 |
|------|------|---------|
| 直播脚本（原计划） | 对比脚本执行偏差 | 无法做「计划vs实际」分析，仅分析实际表现 |
| 直播间截图/录屏片段 | 分析场景搭建（贴片、构图、设备） | "场"的诊断部分评分为"待查" |
| 上场复盘文档 | 对比历史进步 | 无法做趋势对比 |

### 启动流程

1. 用户说"帮我复盘直播"
2. 向用户展示上方「最低启动条件」和「数据截图清单」
3. 用户提供素材
4. **逐项核对**：对照截图清单，确认5张必须截图是否齐全
5. 齐全 → 读取方法论 → 开始七维诊断
6. 不齐全 → 明确告知缺哪几张截图，给出获取路径，**等用户补齐后再开始**

## 七维诊断框架（按此顺序执行）

### 维度一："人"的诊断——主播素养

基于「主播素养篇」逐项检查：

**1.1 人设定位检查**
| 检查项 | 方法论标准 |
|--------|---------|
| 人设是否清晰 | 与产品高度匹配 |
| 人设是否有差异化 | 区别于同赛道主播 |
| 人设是否真实 | 不能虚构 |
| 自我介绍话术 | 包含：我是谁 + 背书 + 能帮你什么 + 引导关注 |

**1.2 三大角色合一**
- 老师（有知识可分享）
- 主持人（控场、随机应变）
- 销售员（讲课的同时要卖课）

**1.3 73855定律**
- 7% 说话内容
- 38% 声音（语气、语速、自信度）
- 55% 肢体语言（看镜头、表情、姿态）

**1.4 表达习惯分析**（基于逐字稿）
- 口头禅频次统计
- 自我贬低/不自信表达
- 句子完整度
- 卖课时语气是否坚定

### 维度二："货"的诊断——产品设计

基于「产品设计篇」+「进阶篇」检查：

| 检查项 | 方法论标准 |
|--------|---------|
| 产品类型定位 | 是引流课(1~99)/利润课(100~2000)/高端课(3000+)？ |
| 产品阶梯 | 是否有引流课→利润课→高端课的完整阶梯 |
| 课程包装三要素 | 主图、标题、详情页是否完整 |
| 无形包装 | 交付体系、答疑、社群 |
| 公域vs私域定价策略 | 公域应卖低价引流课，私域卖中高客单 |

### 维度三："场"的诊断——场景搭建

基于「场景搭建篇」检查：

| 检查项 | 方法论标准 |
|--------|---------|
| 直播间类型 | 口播/上课/连麦/实操演示/横屏——是否匹配内容 |
| 121构图公式 | 上1/4主题 + 中2/4主播 + 下1/4介绍营销 |
| 五要素 | 空间场地、画面布置(贴片)、设备配置、互动道具、营造氛围 |
| 贴片检查 | 主题贴片、人物介绍、营销贴图是否齐全 |
| 违规检查 | 有无微信号、第三方平台名等违规内容 |

### 维度四："播"的诊断——直播流程

基于「直播流程篇」+「主播素养篇」检查：

**4.1 直播前清单**：物料/设备/预热/私域承接/主播准备/开播设置

**4.2 直播中清单**：福袋/私域转发/脚本节奏/点讲解/氛围组/评论区管理

**4.3 直播后清单**：违规申诉/复盘/数据调阅

**4.4 节奏诊断（最核心）**
- 方法论标准：15分钟一轮循环 = 10min干货 + 5min卖课
- 对照逐字稿还原实际节奏时间线
- 计算干货→卖课循环次数
- 检查是否犯了"一直讲干货不卖课"的错误

### 维度五：成交诊断

基于「成交篇」逐步检查：

**成交四部曲：**
1. **激发需求**：向上制造向往 + 向下制造痛点 + 痛点场景代入
2. **需求能被解决**：降低学习门槛 + 学员案例 + 消除顾虑
3. **我最适合帮你解决**：个人权威性 + 外部权威借力 + 相似性
4. **你必须现在解决**：限时 + 限量 + 价格锚定 + 从众引导 + 互惠

**《影响力》四大技巧检查：**
- 权威性原理
- 稀缺性原理
- 社会认同原理
- 互惠原理

**成交六步流程检查：**
①聚人留人 → ②激发需求+圈人群 → ③塑品 → ④上品(3,2,1上链接) → ⑤说服 → ⑥逼单

### 维度六：数据诊断（复盘六大维度）

基于「复盘篇」的六大维度：

| 维度 | 核心指标 | 基准线 |
|------|---------|--------|
| GMV和订单 | 是否达到目标 | 用户自定 |
| 五维四率 | 曝光进入率/商品曝光率/曝光点击率/点击成交率 | 曝光进入率25% |
| 脚本执行 | 是否按脚本/节奏是否正确 | 对照脚本 |
| 脚本效果 | 干货拉在线→卖课出单 | 在线曲线锯齿状 |
| 高成交片段 | 出单时间点+前5分钟内容 | 提炼可复用话术 |
| 互动数据 | 加团率2%/转粉率4%/停留2min/互动率4% | 见基准线 |

### 维度七：商业模型诊断

基于「进阶篇」检查：

| 检查项 | 方法论推荐 |
|--------|---------|
| 公域直播卖什么 | 低价引流课(1~99元) |
| 私域承接 | 企业微信客服自动回复+打标签+拉群 |
| 闭门直播 | 每周1次私域闭门直播卖正价课 |
| 日常运营 | 社群早报+周日预热分享+群发提醒 |
| 产品阶梯 | 引流课→利润课→高端课 |

## 评分标准

每个检查项使用A~F评分：
- **A**：完全达标，可复用
- **B**：基本达标，有小瑕疵
- **C**：及格，有明显改进空间
- **D**：不及格，需要重点改进
- **F**：完全缺失或严重偏离

## 话术生成规则

对于每个评分为D或F的环节，**必须生成对应的标准话术**：
1. 从方法论中提取话术模板
2. 结合用户的具体产品/人设进行定制化改写
3. 标注使用场景（"每30分钟讲一次""每轮干货结束时用""逼单时用"）
