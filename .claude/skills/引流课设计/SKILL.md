## 引流课设计原则（从方法论提炼）

### 硬性规则

1. **与后端同类型、同用户群** — 引流课的用户必须是后端产品的目标用户
2. **定价1-99元** — 太低不珍惜，太高门槛高
3. **录播为主** — 降低交付成本，可无限复用
4. **必须有1-3节适合公域直播间演示的内容** — 这是卖课的核心素材
5. **有社群承接** — 买完课不是终点，加微信进群才是目的
6. **可复用已有内容** — 优先从已有录音稿、文章、课程中改编

### 设计公式

```
引流课 = 后端产品的"试吃装"
├── 让用户体验到后端产品的核心价值
├── 但只给方法论/框架，不给完整执行方案
├── 制造"想要更多"的渴望
└── 自然过渡到后端产品
```

- 标注哪些节适合公域直播演示
- 标注哪些内容可从已有素材复用（附来源）

### 板块3：课程包装三件套

| 素材 | 要求 |
|------|------|
| 主图 | 尺寸、核心信息、设计要点 |
| 标题 | 关键词+痛点+结果导向 |
| 详情页 | 痛点→方案→大纲→讲师介绍→学员评价→限时优惠 |

### 板块4：公域卖课脚本

- 基于15分钟循环设计
- 至少4轮不同干货演示
- 每轮：钩子→演示→卖课转化
- 含贴片设计+视觉资产标记
- **注**：此板块可调用「直播文稿生成」skill的公域模式

### 板块5：加微→私域承接SOP

完整链路设计：
```
下单 → 自动发货（课程链接）
     → 企微客服自动回复（关键词触发）
     → 加微信 → 打标签
     → 拉群 → 群公告+欢迎语
     → 日常运营（早报/答疑/预热）
     → 三场闭门直播预告
```

包含：
- 企微自动回复配置方案
- 标签体系设计
- 接待话术（4条）
- 群公告模板
- 日常运营时间表
- 三场直播预热时间轴

### 板块6：录制计划

- 素材复用策略（哪些从已有内容改编）
- 需要新录的内容
- 录制优先级排序
- 预计工时
