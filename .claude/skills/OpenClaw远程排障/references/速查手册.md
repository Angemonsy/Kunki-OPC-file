# OpenClaw 运维速查手册

> 精简版，覆盖最常见的操作和报错。复杂问题请读原文档。

---

## 一、诊断命令梯（按顺序执行）

```bash
openclaw status              # 基础状态
openclaw status --all         # 全量诊断报告（推荐一键排查）
openclaw status --deep        # 深度连通性测试（API是否通）
openclaw gateway status       # 网关状态
openclaw channels status --probe  # 通道连通性（飞书/Telegram各账户）
openclaw logs --follow        # 实时日志流
openclaw doctor               # 健康检查
openclaw doctor --fix          # 健康检查 + 自动修复
```

| 文件 | 路径 | 用途 |
|------|------|------|
| 主配置 | `~/.openclaw/openclaw.json` | agents、channels、bindings、tools |

| 飞书探针 | `~/.openclaw/extensions/feishu/src/probe.ts` | 飞书健康检查（可改源码加缓存） |

## 三、常见操作

### Gateway 重启
```bash
pkill -f openclaw-gateway && sleep 2
nohup openclaw gateway start > ~/.openclaw/gateway.log 2>&1 &
sleep 5
ps aux | grep openclaw | grep -v grep
```

### 清空会话缓存（换API后必做）
```bash
rm -rf ~/.openclaw/sessions/*
```

### 生成新Token（WebUI访问用）
```bash
openclaw doctor --generate-gateway-token
openclaw dashboard --no-open   # 输出带token的URL
```

### 切换API中转站（三处必须全改）
1. `openclaw.json` → channels 或 providers 里的 base_url
2. `models.json` → 模型名映射
3. `auth-profiles.json` → API key

改完 → 清 sessions → 重启 Gateway

### sessions_spawn 派活配置
```bash
# 1. 在 openclaw.json 的 agents.list 里给管家加 allowAgents
# （注意：不是放在 agents.defaults.subagents 或 tools.subagents 下！）
python3 -c "
import json
d = json.load(open('/root/.openclaw/openclaw.json'))
for a in d['agents']['list']:
    if a['id'] == 'steward':
        a['subagents'] = {'allowAgents': ['scout','writer','editor','distributor','data','growth','advisor','dm','sales','proposal','ta','supervisor','cases']}
d['agents']['defaults']['subagents'] = {'maxSpawnDepth': 2, 'maxChildrenPerAgent': 5, 'maxConcurrent': 8, 'runTimeoutSeconds': 900, 'archiveAfterMinutes': 60}
json.dump(d, open('/root/.openclaw/openclaw.json', 'w'), indent=2, ensure_ascii=False)
"

# 2. 改完 AGENTS.md 后必须清 session + 重启
rm -rf ~/.openclaw/agents/{agentId}/sessions/*
openclaw gateway start
```

### 备份配置
```bash
cp ~/.openclaw/openclaw.json ~/.openclaw/openclaw.json.backup-$(date +%Y%m%d%H%M)
```

## 四、常见报错 → 解法

| 报错/现象 | 原因 | 解法 |
|----------|------|------|
| bot不回复群消息 | 缺少 groupPolicy 或设为 open 耗光额度 | 设 `groupPolicy: "mention"` |
| "origin not allowed" | WebUI访问的origin不在白名单 | 检查 gateway 配置的 allowedOrigins |
| "pairing required" | DM策略要求配对 | `openclaw pairing approve <channel> <code>` 或改 `dmPolicy: "open"` |
| "gateway token missing" | Token过期或丢失 | `openclaw doctor --generate-gateway-token` |
| 所有bot都回复同一条消息 | mention检查有bug | 用 `requireMention: true` + 飞书平台层天然隔离 |
| API额度耗尽（飞书50K/月） | probe每60秒×14个bot | 改 probe.ts 加缓存（SUCCESS_CACHE_TTL=12h） |
| 端口占用 | 旧进程未释放18789 | `openclaw gateway start --force` |
| OOM崩溃 | 内存不足 | `journalctl -k \| grep "oom\|killed"` 确认，减少并发bot |
| heredoc中文乱码 | bash不支持中文heredoc | 用Python脚本写入文件 |
| 换API后bot还用旧配置 | sessions缓存 | 清空 sessions 文件夹 + 重启 |
| 群里@bot无反应 | Telegram需用英文用户名@，不能用中文昵称 | 用 `@XuGuangScoutBot` 而非 `@选题` |
| 新bot的@call不工作 | topics配置缺失 | 设 `"topics": []` 允许所有话题 |
| `sessions_spawn` 报 "agentId is not allowed (allowed: none)" | `allowAgents` 放错位置 | 在 `agents.list` 里给发起方 agent 加 `subagents.allowAgents`，不要放在 `agents.defaults` 或 `tools.subagents` 下 |
| 改了 AGENTS.md 但 agent 行为没变 | 旧 session 缓存了旧指令 | `rm -rf ~/.openclaw/agents/{agentId}/sessions/*` + 重启 Gateway |
| 子 agent 没有以自己 bot 身份发消息 | 设计限制，非 bug | 子 agent 结果只回到父 agent（管家），由管家转发。用标记（如"✅【写手完成】"）区分来源 |
| `tools.subagents` 里配了 allow 不生效 | 该字段只支持 deny | 用 `tools: { deny: ["gateway","cron"] }` 限制子 agent 工具，allowAgents 放在 `agents.list` 里 |

## 八、未知问题通用排查框架（速查表解决不了时用）

按顺序执行，逐步缩小问题范围：

1. **先看日志** → `openclaw logs --follow`，实时观察报错信息
2. **全量诊断** → `openclaw status --all` + `openclaw doctor`，获取完整状态报告
3. **对照踩坑记录** → 查两份部署手册（Telegram/飞书），看是否是已知坑
4. **查官方FAQ** → https://openclaw.cc/help/faq
5. **查官方排障文档** → https://docs.openclaw.ai/gateway/troubleshooting
6. **联网搜索报错信息** → 把具体报错关键词搜索，找社区解法
7. **实在解决不了** → 把完整日志+报错截图发给小林，一起分析
