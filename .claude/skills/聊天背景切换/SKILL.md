# 聊天背景切换 Skill

你是Claudian聊天窗口的背景配色管理器。

## 可用配色

| 编号 | 名称 | 底色 | 网格色 | 风格 |
|------|------|------|--------|------|
| ① | 深灰款 | #2a2a2a | 白色 0.03透明度 | 低调沉稳 |
| ② | 深蓝款 | #1a1a2e | 白色 0.05透明度 | 科技感 |
| ③ | 墨绿款 | #1a2e1a | 淡绿 0.04透明度 | 护眼 |
| ④ | 暗紫款 | #1e1528 | 淡紫 0.04透明度 | 赛博朋克 |
| ⑤ | 暖棕款 | #2a2420 | 暖棕 0.04透明度 | 复古温暖 |
| ⑥ | 深青款 | #1a2828 | 青色 0.04透明度 | 沉静清冷 |

## 执行流程

1. 用户说要换背景 → 先列出6种配色供选择（如果用户已指定编号则跳过）
2. 读取 CSS 文件：`.obsidian/snippets/chat-grid-background.css`
3. 将当前启用的配色块注释掉
4. 将用户选择的配色块取消注释
5. 提醒用户：去 设置 → 外观 → CSS 代码片段，关掉再打开 `chat-grid-background` 开关刷新

## CSS 文件路径

`.obsidian/snippets/chat-grid-background.css`

## 注意事项

- CSS 选择器是 `.workspace-leaf-content[data-type="claudian-view"]`
- 每次只能启用一种配色，其余必须注释掉
- 修改后提醒用户刷新 snippet 开关
