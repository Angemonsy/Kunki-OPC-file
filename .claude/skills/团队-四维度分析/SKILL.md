# 团队四维度分析 Skill

## 触发场景
- 用户说"分析一下我们团队"
- 用户说"团队缺什么"
- 用户问"下一个该招什么人"
- 要加新成员时，想了解团队能力缺口

## 执行步骤

### Step 1：读取团队数据
读取 `02.领域/1.团队管理/团队花名册.md`，提取所有在职成员的盖洛普TOP 10。

### Step 2：统计四域分布

对每个成员，统计其TOP 10才干分别属于哪个域：

| 域 | 对应才干 |
|---|--------|
| 执行力 | 成就、安排、信仰、一致、审慎、纪律、专注、责任、统筹 |
| 影响力 | 激励、沟通、竞争、完美、伯乐、关系、自信、统率、取悦、行动 |
| 关系建立 | 适应、联系、发展、体谅、和谐、包容、个别、积极、交往 |
| 战略思维 | 分析、前瞻、关联、理念、搜集、学习、战略、思维、回顾 |

输出团队四域汇总表：
```
| 成员 | 执行力 | 影响力 | 关系建立 | 战略思维 | 特别标注 |
|-----|-------|-------|--------|--------|--------|
| 你   | 4个  | 1个   | 1个    | 4个    | 沟通#34 |
```

### Step 3：绘制团队雷达图（文字版）

```
          战略思维
            ████████  ← X人/X个才干
           /        \
执行力 ████          ████ 影响力
           \        /
            ████  ← 关系建立
```

标注：
- **充足（≥3个才干）**：这个域有人覆盖
- **薄弱（1-2个才干）**：这个域依赖少数人，有单点故障风险
- **缺失（0个才干）**：这个域没有天赋覆盖，是盲区

### Step 4：对照业务清单做能力覆盖分析

读取 `02.领域/1.团队管理/业务工作清单.md`，将每类工作与对应的才干域匹配：

| 业务工作类型 | 需要的才干域 | 团队覆盖情况 | 风险等级 |
|-----------|----------|-----------|--------|
| 社群运营/答疑 | 影响力+关系建立 | | |
| 系统交付 | 执行力+战略思维 | | |
| 产品策略 | 战略思维 | | |
| 客户沟通 | 影响力+关系建立 | | |
| 内容创作 | 战略思维+影响力 | | |

### Step 5：输出建议

```
## 团队四维度分析报告

**当前团队**：X人
**分析日期**：YYYY-MM-DD

### 团队能力分布
（四维度表格）

### 集体强项
（最多才干的域）→ 擅长做什么

### 集体盲区
（最少/缺失的域）→ 容易出问题在哪

### 业务覆盖缺口
（哪些业务工作目前没有合适的人）

### 下一个该招什么人
基于盲区和缺口，给出：
- 需要的才干类型
- 盖洛普画像建议（哪些才干要在TOP 10）
- 不需要什么（避免重复堆积已有才干）

### 风险预警
（如：团队中没有人有"纪律"才干，执行SOP可能有漏洞）
```

## 注意事项
- 盖洛普四域分析是参考，实际能力也取决于经验和系统
- AI时代"系统兜底"可以弥补部分才干缺失
- 团队<5人时，不需要每个域都有人，优先覆盖主营业务
