# 实战复盘转内容

> 把你的AI实战过程，变成一篇有灵魂的教知识类爆款文章

## 🎯 功能概述

这是一个**从实战到内容的转化流水线**，将以下环节串联起来：

```
实战过程回溯 → 方法论提炼 → 选题包装（含爆款元素评分） → 用户选择 → 框架匹配 → 用户确认结构 → 文案生成（含实战翻译+个人素材注入） → 事实核查 → 标题生成 → 排版优化 → 敏感词检测 → 配图标注 → 用户确认 → 发布草稿 → 存档+反馈闭环
```

## 📥 输入参数

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `实战来源` | ✅ 是 | 指向本次实战产出的文件路径（如发布文案.md）、或口头描述实战过程 | - |
| `关联文件` | ❌ 否 | 本次实战过程中产出的中间文件（如选题列表、素材报告、框架匹配结果等） | 自动从vault搜索 |
| `内容类型` | ❌ 否 | 教知识/聊观点/讲故事/晒过程 | 默认「教知识」 |
| `目标平台` | ❌ 否 | 公众号/小红书/视频号 | 公众号 |
| `执行模式` | ❌ 否 | 自动模式/交互模式 | 询问用户选择 |

## ⚡ 双模式说明

### 模式一：🚀 自动模式（推荐）

全程自动执行，只在两个关键节点暂停：

```
自动回溯实战 → 自动提炼方法论 → 自动选题包装（选TOP1）
→ 自动匹配框架+开篇 → 自动生成文案
→ ⏸️ 用户确认文案 → 自动下游流水线 → ⏸️ 用户确认最终成品
```

自动模式的默认行为：
- 选题选择：自动选择爆款概率最高的TOP 1选题
- 框架匹配：自动选择适配度最高的框架
- 开篇方式：自动选择最优开篇
- 下游流水线：标题→核查→敏感词→排版，全部自动执行

检查点只有 2 个：
| 检查点 | 位置 | 等什么 |
|--------|------|--------|
| ⏸️ 1 | 完整文案生成后 | 用户确认文案内容 |
| ⏸️ 2 | 最终成品（排版后）| 用户确认发布 |

### 模式二：🔧 交互模式

每步暂停，用户全程参与决策：

```
实战回溯 → 方法论提炼 → 选题包装 → ⏸️ 用户选择选题
→ 框架匹配+开篇 → ⏸️ 用户确认结构 → 文案生成
→ ⏸️ 用户审核文案 → 下游流水线 → ⏸️ 用户确认发布
```

检查点 4 个：
| 检查点 | 位置 | 等什么 |
|--------|------|--------|
| ⏸️ 1 | 选题包装后 | 用户选择选题方向 |
| ⏸️ 2 | 框架+开篇匹配后 | 用户确认结构和开篇 |
| ⏸️ 3 | 完整文案生成后 | 用户审核文案 |
| ⏸️ 4 | 最终成品（排版后）| 用户确认发布 |

## 🔄 完整工作流程

### ⚡ Phase 1: 实战过程回溯（本 skill 独有）

> **核心任务**：从实战产出中提取「可教的方法论」，这是与「公众号爆款生产」最大的区别。

**Step 1：读取实战产出**

1. 读取用户指定的实战产出文件（如已发布的文案.md）
2. 如有关联文件（中间产物），一并读取
3. 如用户未指定关联文件，在 vault 中搜索同日期、同主题的相关文件

**Step 2：实战过程拆解**

从实战产出中提取以下信息：

1. **完整步骤链**：这次实战从头到尾经历了哪些步骤？（按时间顺序列出）
2. **关键决策点**：哪些环节需要人做决策？决策依据是什么？
3. **工具/系统使用**：用了哪些AI工具、知识库、系统？各自负责什么？
4. **中间产物**：每个步骤产出了什么？（选题列表、素材报告、文案初稿等）
5. **效率数据**：整个流程花了多长时间？对比之前效率提升了多少？
6. **核心洞察**：这次实战最值得分享的经验/方法论是什么？

**输出格式**：
```markdown
## 📋 实战过程拆解

### 步骤链（共X步）
1. {步骤1}：{做了什么} → 产出：{什么}
2. {步骤2}：{做了什么} → 产出：{什么}
...

### 关键决策点
- 决策1：{在哪个环节} → {做了什么决策} → {依据是什么}
- 决策2：...

### 工具/系统清单
| 工具/系统 | 负责环节 | 具体作用 |
|-----------|---------|---------|
| {工具1} | {环节} | {作用} |
...

### 效率数据
- 总耗时：{X分钟}
- 对比传统方式：{提升X倍}

### 核心洞察（可教的方法论）
1. {洞察1}
2. {洞察2}
3. {洞察3}
```

**Step 3：方法论提炼 + 实战翻译**

> **实战翻译**是本 skill 的核心能力：把技术操作翻译成读者能理解、能复制的大白话。

翻译规则：
| 技术语言 | 读者语言 | 示例 |
|---------|---------|------|
| skill/agent/workflow | AI员工/AI团队/工作流 | "调用热点分析skill" → "3号员工：热点分析师" |
| 知识库文件/prompt | 培训手册/操作SOP | "读取用户画像.md" → "它能调用我的用户画像" |
| API调用/自动化 | 一键操作/自动完成 | "调用WeChat API发布" → "一键推送到草稿箱" |
| 框架匹配算法 | 自动匹配最合适的 | "基于框架效果数据选择" → "从20多个框架中自动匹配最适合的" |
| YAML frontmatter | 文章档案/标签 | "写入frontmatter" → "自动存档并打标签" |

方法论提炼原则：
1. **可复制性**：读者看完能照着做，至少能做到简化版
2. **层次感**：从「我怎么做的」→「为什么这样做」→「你也可以这样做」
3. **具象化**：每个抽象概念都要有具体例子或类比
4. **差异化**：突出「知识库驱动」和「多步骤拆解」的核心差异，不是简单的"用AI写文章"

**输出格式**：
```markdown
## 🧠 方法论提炼

### 核心方法论（一句话）
{用一句话概括这个方法论的核心}

### 方法论骨架
1. {步骤1的读者版表达}
   - 原始操作：{技术描述}
   - 翻译后：{大白话}
   - 读者可复制版：{简化操作}
2. {步骤2}
...

### 关键差异点（为什么我的方法不一样）
1. {差异1}：{解释}
2. {差异2}：{解释}

### 读者行动指南（3步简化版）
1. {第一步}：{具体怎么做}
2. {第二步}：{具体怎么做}
3. {第三步}：{具体怎么做}
```

### ⚡ Phase 2: 选题包装（连续执行，不可中断）

> 基于 Phase 1 提炼的方法论，生成5个选题角度。

**执行步骤**：
1. 读取以下知识库（并行执行）：
   - `05.内容创作系统/🔥04.复盘与方法论/13大爆款元素.md`
   - `05.内容创作系统/🔧05.用户画像/我的用户画像.md`
   - `05.内容创作系统/🔥04.复盘与方法论/数字生命卡兹克-选题特点萃取.md` ⚠️ 必读
   - `05.内容创作系统/🔥01.选题决策/选题工具箱/选题模板库.md` ⚠️ 必读
   - `05.内容创作系统/🔥03.数据反馈/❌ 失败案例库.md` ⚠️ 必读
   - 按内容类型读取对应爆款案例库

2. 基于方法论骨架，从以下5个角度生成选题：
   - **效率对比角度**：突出时间/成本的巨大反差（如"从2小时到10分钟"）
   - **系统拆解角度**：突出完整方法论的可复制性（如"11个步骤完整拆解"）
   - **认知颠覆角度**：突出与主流做法的差异（如"不是用AI写，而是指挥AI团队"）
   - **身份转变角度**：突出角色变化的戏剧性（如"从一个人干五个人的活，到当老板"）
   - **底层逻辑角度**：突出方法论背后的核心原理（如"没有知识库的AI只是临时工"）

3. 匹配13大爆款元素评分
4. 对照失败案例库排除
5. 一次性输出：方法论摘要 + 5个爆款选题

**选题角度**：{效率对比/系统拆解/认知颠覆/身份转变/底层逻辑}

**命中爆款元素**：{元素1}、{元素2}、{元素3}

**推荐理由**：{50-100字理由}

**目标用户痛点**：{痛点描述}

**目标用户层级**：{意向用户/意识用户/潜在用户/大众用户 + 匹配理由}

**卡兹克选题参考**：{参考哪种选题类型}

**署名测试（不可替代性检查）**：

> **核心问题：把署名换成别人，这篇文案还能成立吗？**

- [ ] 去掉所有个人印记后，和通用AI生成的内容**区别在哪**？（必须能说清）

- ❌ 少于2项 → **必须补入个人素材**（从 `04.我的上下文` 或 `思想力武器库` 中调取），重新过一遍自检

- 段落：短段落（每段不超过3-4行）

## 💡 使用技巧

### 提高方法论质量
- 提供尽可能多的关联文件（中间产物越多，方法论越详细）
- 在 Phase 1 阶段主动补充AI没有捕捉到的决策细节
- 告诉AI你觉得最值得分享的点是什么

### 提升文案可读性
- 在检查点2选择开篇时，优先选「数据对比型」或「故事引入型」
- 实战翻译时，多用「X号员工」的拟人化表达
- 配图标注要具体，方便后续制图

### 形成内容飞轮
- 每次用「公众号爆款生产」写完文章后，都可以用本 skill 把过程变成第二篇文章
- 一次实战 → 两篇内容（实战产出 + 方法论拆解）
- 持续积累，形成「AI内容生产方法论」系列
