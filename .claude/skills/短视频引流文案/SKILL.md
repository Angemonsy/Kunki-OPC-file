# 短视频引流文案

> 一篇长文章，压成30秒短视频，引流到直播间或公众号

## 🎯 功能概述

将公众号文章（通常1500-3000字）压缩为**150-250字**的短视频口播脚本，适配视频号/抖音平台。

核心逻辑：**不是缩写，是重新提炼**——从长文中抽出一个最锋利的痛点 + 一个最直观的案例 + 一句金句 + 一个行动指令。

```
公众号长文 → 提炼核心钩子 → 30-60秒口播脚本 → 配图/配屏录标记 → 存档
```

## 📥 输入参数

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `源文案` | ✅ 是 | 公众号文章路径或全文 | - |
| `引流目标` | ❌ 否 | 引流到哪里：直播间/公众号/社群/课程 | 直播间 |
| `时长目标` | ❌ 否 | 30秒/45秒/60秒 | 45秒 |
| `平台` | ❌ 否 | 视频号/抖音/小红书 | 视频号 |

## 🔄 完整工作流程

### Step 1：素材提取

读取源文案，提取以下要素：

1. **痛点列表**：文章中提到的所有痛点（按扎心程度排序）
2. **案例列表**：文章中的具体案例（带数据的优先）
3. **金句列表**：文章中最有记忆点的句子
4. **方法论**：文章的核心方法（一句话能说清的）
5. **引流素材**：文章中已有的引流话术

从中选出：
- **1个最扎心的痛点**（开头用，3秒抓住注意力）
- **1个最直观的案例**（中间用，有数据有对比）
- **1句金句**（记忆锚点）
- **1个行动指令**（结尾引流）

### Step 2：脚本生成

按以下结构生成口播脚本：

```
【开头-痛点钩子】（3-5秒，30字以内）
直接戳痛点，用"大多数人..."/"你是不是也..."/"别再...了"开头

【中间-案例+方法】（15-30秒，80-120字）
一个具体案例 + 核心方法，要有对比感（之前vs之后，别人vs我）

【金句】（5秒，20字以内）
一句话总结，要有记忆点

【结尾-行动指令】（5-10秒，20-40字）
根据引流目标生成：
- 直播间："今晚X点直播，现场演示，想看的点预约"
- 公众号："完整教程在公众号，搜XXX"
- 社群："想进群的评论区扣1"
- 课程："链接在评论区/主页"
```

**字数控制**：
- 30秒 → 总字数 ≤ 150字
- 45秒 → 总字数 ≤ 200字
- 60秒 → 总字数 ≤ 250字

**语言规则**：
1. 全程口语化，像跟朋友聊天，不要书面语
2. 短句为主，每句不超过20字
3. 不用"首先其次最后"等连接词
4. 不用"大家好我是XXX"开头（浪费前3秒）
5. 先读取「直播口语风格萃取」打底口语节奏，再读取「公众号文案风格萃取」保留用户语言习惯
6. 可以用省略号表示停顿节奏

### Step 3：配图标记

在脚本关键位置插入配图/屏录标记：

- 短视频通常需要**1-3个画面切换点**
- 优先使用「本地截图」或「截图」类型（短视频配合画面切换更有冲击力）
- 标记插在对应文字后面，拍摄/剪辑时知道这里要切画面

### Step 4：存档

保存到 `02.领域/0.内容创作系统/07.发布文案/2026年/草稿/` 目录下。

文件名格式：`{日期}-{主题}短视频引流文案.md`

Frontmatter 格式：
```yaml
---
title: {主题}短视频引流文案（引流{目标}）
date: {日期}
platform: {平台}
type: 短视频引流
status: 草稿
source: {源文案标题或路径}
duration: {时长目标}秒
tags:
  - 短视频
  - 直播引流
  - {相关标签}
---
```

## ⚠️ 重要规则

1. **字数铁律**：严格控制在目标时长对应的字数范围内，宁短勿长
2. **一个核心**：整个脚本只讲一个点，不要试图把长文的所有内容塞进去
3. **口语化**：读出来要自然，不像在念稿
4. **前3秒定生死**：开头必须是痛点或悬念，不要寒暄
5. **结尾必须有行动指令**：短视频不引流就是浪费流量
