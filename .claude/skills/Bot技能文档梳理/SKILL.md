# Bot技能文档梳理

## 任务目标
- 本Skill用于：梳理OpenClaw 14个AI员工（飞书+Telegram）各自对应的Skills和知识文档
- 能力包含：全量扫描skills目录、提取每个skill的references文件和SKILL.md内引用的知识库文档、按角色归类输出
- 触发条件：用户提到"梳理bot"、"梳理agent"、"bot的skills"、"agent的文档"、"AI员工技能"、"bot文档配置"等意图

## 核心规则（铁律）

1. **零遗漏**：必须扫描全部skills目录和所有SKILL.md内引用的文档路径，禁止凭记忆输出
2. **路径强制**：所有输出必须使用以下两个根路径前缀
   - Skills文档：`/root/vault/.claude/skills/`
   - 知识库文档：`/root/vault/`
3. **文件名一一对应**：Skills名称必须与`.claude/skills/`下的实际文件夹名完全一致，禁止修改、翻译、缩写
4. **不用表格**：全部用文字格式输出，方便复制
5. **每个角色头部必带路径声明**

## 操作步骤

### Step 1：全量扫描skills目录

```
Glob: .claude/skills/*/SKILL.md
```

列出所有skill文件夹名，这是后续匹配的唯一来源。

### Step 2：扫描每个skill的references文件

```
Glob: .claude/skills/{skill名}/references/*
```

对每个skill逐一扫描，记录references目录下的所有文件。

### Step 3：扫描每个skill的SKILL.md内引用的知识库文档

```
Grep: pattern="02\.领域|03\.参考|04\.我的|05\.文案|06\.我的|07\.发布|08\.数据|09\.经验|00\.系统|01\.用户|01\.选题|03\.选题|04\.开篇"
path=".claude/skills"
glob="**/SKILL.md"
```

提取所有SKILL.md中引用的知识库文档路径，去重后归类到对应skill。

### Step 4：角色-Skill匹配

按以下对应关系，将skills分配到角色。如果发现新skill不在列表中，主动询问用户归属：

**🏠 管家**：无
**🔥 选题**：`热点追踪` / `选题生成` / `选题验证评分` / `选题匹配爆款模板` / `爆款内容选题策划师`
**✍️ 写手**：`教知识文案` / `讲故事文案` / `聊观点文案` / `热点文案生成` / `爆款拆解改写` / `爆款衍生系列` / `灵感碎片转文案` / `录音稿转文案` / `社群精华转文案` / `用户提问转文案` / `对话转文案` / `朋友圈文案` / `朋友圈文案生成`
**🔍 编辑**：`敏感词检测` / `爆款标题生成` / `标题生成` / `爆款复盘分析` / `结尾钩子生成`
**📢 分发**：`小红书图文` / `推特内容转换` / `公众号排版` / `标签生成` / `一键分发`
**📊 数据**：`爆款复盘分析` / `热点分析`
**📈 增长**：`营销转化专家` / `趋势分析`
**🧠 顾问**：无
**💬 私信**：`营销转化专家` / `朋友圈文案` / `朋友圈文案生成`
**💰 销售**：`营销转化专家` / `客户见证转化文案`
**📋 方案**：无
**👨‍🏫 助教**：`AI工具手把手教学专家`
**👁️ 督导**：`爆款复盘分析`
**📚 案例**：`爆款复盘分析` / `录音稿提炼选题专家`

> ⚠️ 同一个skill可以被多个角色共用（如`营销转化专家`被增长/私信/销售共用，`爆款复盘分析`被编辑/数据/督导/案例共用）

### Step 5：按格式输出

每个角色严格按以下格式输出：

```
**{emoji} {角色名}（{英文ID}）**
Skills文档：/root/vault/.claude/skills/
知识库文档：/root/vault/

Skills：`skill1` / `skill2` / ...
文档：
- `skill1/references/xxx.pdf`
- `skill2/references/xxx.md`
- `02.领域/0.内容创作系统/xxx/xxx.md`（`skill名`引用）
- ...

---
```

**格式规则**：
- references文件不带根路径前缀（相对于skills目录）
- 知识库文档带 `02.领域/` 或 `03.参考资料库/` 等相对路径（相对于vault根目录）
- 每个知识库文档后面用括号标注是哪个skill引用的
- Skills为"无"的角色，文档也写"无"
- 文档去重，同一个文件只列一次

### Step 6：变更检测（可选）

如果用户说"看看有没有新增"或"和上次比"，则：
1. 读取上次输出的清单（如果有存档）
2. 对比当前扫描结果
3. 标注新增/删除/变更的skill和文档

## 注意事项

- 扫描范围仅限与14个bot角色相关的skills，不包括纯工具类（如`自动安装助手`、`Windows性能优化`、`聊天背景切换`等）
- 如果扫描发现新的内容创作相关skill，主动问用户该归到哪个角色
- PDF文件也要列出，不能因为是PDF就跳过
- 遇到同一份文档在references和SKILL.md中都被引用的情况，只列一次
