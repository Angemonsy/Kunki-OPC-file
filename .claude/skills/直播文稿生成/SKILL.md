## 公域卖课稿生成规则

### 核心结构：15分钟循环

```
【每轮循环 = 15分钟】
├── 0:00-10:00 干货演示（让观众觉得牛逼、有用）
│   ├── 钩子开场（前30秒抓住注意力）
│   ├── 痛点引入（为什么你需要这个）
│   ├── 现场演示（核心演示内容）
│   └── 效果展示（演示结果/前后对比）
└── 10:00-15:00 卖课转化
    ├── ① 塑品（刚才演示的只是冰山一角…）
    ├── ② 开价（原价xxx → 现在只要xxx）
    ├── ③ 上链接（3、2、1上链接！）
    ├── ④ 逼单（限时/限量/赠品/从众）
    └── ⑤ 回收（没抢到的扣"已拍"）
```

### 循环设计要求

- **至少设计4轮不同的干货演示**，循环滚动（新观众随时进来）
- 每轮干货主题不同，但**卖课话术可复用同一套**
- 每轮开头都要有**独立钩子**（不依赖上文，新观众能直接听懂）
- 干货演示要**视觉化**（屏幕演示/对比图/实操），不能纯口播

### 贴片提示

每个环节标注需要切换的贴片/画面：
- `【贴片：主题贴片-xxx】`
- `【画面：切到屏幕演示】`
- `【画面：切回主播】`

## 私域转化稿生成规则

### 核心结构：三场递进

| 场次 | 主题定位 | 核心目标 | 时长 |
|------|---------|---------|------|
| 第1场 | 认知颠覆 | 打破旧认知，建立新框架 | 60-90min |
| 第2场 | 深度演示 | 展示完整能力，制造"我也想要" | 60-90min |
| 第3场 | 成交收割 | 产品发布+限时优惠+逼单 | 60-90min |

### 每场内部结构

```
├── 开场（5-10min）
│   ├── 破冰/回顾上场
│   ├── 本场预告（今天讲什么、能收获什么）
│   └── 互动暖场（扣1表示xxx）
├── 核心内容（40-60min）
│   ├── 模块1：认知/方法论
│   ├── 模块2：现场演示（王炸环节）
│   ├── 模块3：案例/学员故事
│   └── 【每个模块之间插互动】
├── 过渡→成交（10-15min）
│   ├── 痛点回顾（不解决会怎样）
│   ├── 方案呈现（我的产品如何解决）
│   └── 学员见证
└── 成交（10-20min）
    ├── 产品介绍+价格锚定
    ├── 限时优惠+赠品
    ├── 下单引导
    └── 逼单+答疑
```

### 递进关系检查

生成第2/3场时，必须读取前面场次的文稿，确保：
- 内容不重复（每场有新东西）
- 认知递进（第1场种草→第2场深化→第3场收割）
- 信任递增（每场加一层信任素材）
- 成交力度递增（第1场软植入→第2场明确介绍→第3场全力成交）

## 视觉资产标记（自动生成）

文稿生成完成后，**必须自动标记视觉资产**，无需用户额外要求：

### 标记类型

| 类型 | 格式 | 适用场景 |
|------|------|---------|
| 设计制作图 | `【配图①：图片类型，具体描述内容】` | 对比图、流程图、数据图 |
| 本地截图 | `【本地截图①：截图内容描述】` | 展示软件界面、系统结构 |
| 动画录屏 | `【动录①：录制内容描述，时长】` | 现场演示的预录备用视频 |
| 滚动录屏 | `【录屏①：录制内容描述，时长】` | 展示数量多的内容滚动 |

### 标记规则

1. **每个现场演示环节**必须配一个`【动录】`作为预录备用（防冷场/翻车）
2. **展示"数量多"的地方**用`【录屏】`替代静态截图
3. **对比/数据/流程**用`【配图】`
4. **展示自己系统/工具**优先用`【本地截图】`
5. 每个标记要具体到：内容描述 + 建议时长/尺寸

## 质量自检

文稿生成后自检：

| 检查项 | 标准 |
|--------|------|
| 每轮干货有独立钩子 | 新观众30秒内能被吸引 |
| 卖课环节完整 | 塑品→开价→上链接→逼单→回收 |
| 演示环节有备用视频 | 每个演示配【动录】标记 |
| 互动指令均匀分布 | 每10分钟至少1个互动点 |
| 不重复历史文稿 | 与已有文稿对比无重复 |
| 成交四部曲完整 | 激发需求→能被解决→我最适合→现在解决 |
| 贴片切换标注 | 每次画面变化都有标注 |
| 时间轴合理 | 干货:卖课 ≈ 2:1 |
