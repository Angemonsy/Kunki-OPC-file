# 领航计划 · AI 内容创作系统 — 系统配置
## 系统版本与目录优先级（最高规则）

- `02.内容创作系统/` 是领航计划当前最新版、最完整的内容创作系统，也是后续制作其他学员版、行业版安装包的唯一母版。
- 根目录 `AGENTS.md` 与 `CLAUDE.md` 分别是 Codex 与 Claude Code 的当前运行规则，必须与新版系统保持一致。
- 历史目录 `02-内容创作系统/` 已退出运行层并归档，不得作为默认读写路径，不得用其中旧模板、旧方法论或旧路径覆盖新版。
- `00-inbox` 是固定收件箱目录，**不得删除、不得改名、不得移动位置**，必须保留在根目录。
- `旧库迁入`、`历史`、`旧版参考资料` 目录只保存用户真实资产、案例和历史证据；使用时需结合日期与当前记忆判断，不自动视为最新方法。
- 构建其他版本时，应复制新版母版骨架，再注入对应用户档案、行业资料和必要 Skills；不要从旧知识库反向复制整体架构。
- 当前事实优先读取 `01-记忆系统/当前唯一真相.md`。


## 语言要求
- 所有回复使用中文简体
- 保持专业、清晰、简洁的表达
- 技术术语首次出现时给出中英文对照
- 代码注释用中文，代码本身用英文

## 回复风格
- 直接回答问题，不要过多寒暄
- 给出具体可操作的建议
- 如果不确定，明确说明

## 输出方式（AI 自由判断）

用户是在 Obsidian 里直接使用，所以输出方式不死板规定，**AI 根据内容类型自由判断**对话里输出多少、什么时候存档。

### 唯一硬规则：文案类必须存档 + 自动打开

凡是产出**可发布的文案**（公众号文章、短视频口播稿、朋友圈文、社群文等），生成后**立即执行**：

1. Write 存档到 `02.内容创作系统/🔥02.发布文案/2026年/草稿/`，文件名格式 `YYYY年M月D日-标题关键词.md`
2. 用 `obsidian://open?vault=xxx&file=...` 协议或直接在对话末尾插入 `[[草稿/YYYY年M月D日-标题]]` wiki 链接，**自动在 Obsidian 里打开该笔记**
3. 后续修改用 Edit 直接改这份草稿，不要重新生成

# 记忆系统

## 最高规则

根目录 [[01-记忆系统]] 是唯一有效的 AI 记忆系统。[[02.内容创作系统]] 只调用它，不再维护独立记忆。

## 强制启动协议（每次新对话的第一条回复前必须执行）

收到用户第一条消息时，先读取：

1. `01-记忆系统/当前唯一真相.md`
2. `01-记忆系统/当下每时每刻（持续更新）.md`
3. `01-记忆系统/长期记忆.md`
4. `01-记忆系统/AI协作偏好.md`

读取含义：

- `当前唯一真相.md`：最高优先级事实，判断身份、定位、战略、禁用旧表达。
- `当下每时每刻（持续更新）.md`：最新思考、动态、状态、近期任务，最高频更新。
- `长期记忆.md`：稳定用户画像、长期偏好、长期方法论。
- `AI协作偏好.md`：AI说话方式、协作边界、输出偏好。

`01-记忆系统/每日输入与复盘/` 只在需要查每日记录、复盘、灵感碎片、原始材料时读取。

## 记忆写入规则

1. 最新状态、最新思考、短期任务 → 写入 `01-记忆系统/当下每时每刻（持续更新）.md`
2. 稳定身份、业务、产品、目标用户、长期偏好、稳定方法论 → 写入 `01-记忆系统/长期记忆.md`
3. 重大身份、定位、战略、禁用旧表达变化 → 写入 `01-记忆系统/当前唯一真相.md`
4. 每日输入、每日复盘、原始材料 → 写入 `01-记忆系统/每日输入与复盘/`
5. AI协作人格或说话方式变化 → 写入 `01-记忆系统/AI协作偏好.md`，重要变更需用户确认
6. 通知格式：`[记忆] 文件名 操作：内容摘要`

禁止再向 `02.内容创作系统/🛠️10.记忆系统/` 写入运行记忆。

## 按需加载

- 内容创作：先读 `当前唯一真相.md`、`当下每时每刻（持续更新）.md`、`长期记忆.md`，再路由对应 Skill。
- 复盘/日报：读取 `每日输入与复盘/`。
- 目录治理：读取 `README.md` 和 `当前唯一真相.md`。

# 写作规则

## 基本原则
- 协助写作时遵循用户的语言风格，不强加AI风格
- 草稿阶段：AI可大幅参与（结构、内容、风格）
- 定稿后：只做校对级微调，不擅自改动已有作品
- 大幅修改前：告知用户，确认后再动

## ⚠️ 内容创作铁律（全局强制）

**文案正文生成后，第一件事是立即 Write 存档到草稿目录，不等标题确认，不等自检通过，不等定稿。**

原因：对话上下文有字数上限，对话结束后内容永久丢失。生成即存档是防止内容丢失的唯一保障。

- 存档路径：`02.内容创作系统/🔥02.发布文案/2026年/草稿/公众号/`
- 文件名格式：`YYYY年M月D日-标题关键词.md`
- 存档后所有修改用 Edit 直接改该文件，不重新生成

## 禁用符号
禁止在任何文案正文中使用破折号（——）。用逗号或句号代替，不要用任何形式的横杠连接语句。

# 配图标记规则

文案生成完成后，通读完整文案，找出适合配图的关键位置，插入配图标记：

| 类型 | 格式 | 适用场景 |
|------|------|---------|
| 📐 设计制作图 | `【配图①：图片类型，具体描述内容】` | 对比图、流程图、数据图、场景图 |
| 📷 网页截图 | `【截图①：URL，描述】` | 截取网页特定内容 |
| 📸 滚动录屏 | `【录屏①：URL，录制长页面滚动】` | 录制长页面滚动效果 |
| 🔴 动画录屏 | `【动录①：URL，录制页面动画】` | 录制页面动画或自动播放视频 |
| 🖥️ 本地截图 | `【本地截图①：截图内容描述】` | 展示本地软件界面 |

配图数量：短文案（<1000字）1-2张，中等（1000-2000字）2-3张，长文案（>2000字）3-5张。
五种类型可混合使用，当文章提到自己的系统、工具时优先使用「本地截图」。
