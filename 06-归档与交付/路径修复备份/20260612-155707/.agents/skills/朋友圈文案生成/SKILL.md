# 朋友圈文案生成

> 像你自己发的，不像AI写的

## 🎯 功能概述

朋友圈和公众号是两个完全不同的物种：

| 维度 | 公众号 | 朋友圈 |
|------|--------|--------|
| 长度 | 2000-4000字 | 50-350字 |
| 驱动 | 标题驱动 | 开头3行+配图驱动 |
| 关系 | 读者 vs 作者 | 朋友 vs 朋友 |
| 目标 | 阅读量、转发 | 点赞、评论、私聊 |
| 调性 | 专业、有深度 | 真实、有温度、像聊天 |

本 Skill 的核心价值：用你自己的说话方式，写出高互动的朋友圈文案。

## 📥 输入参数

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `素材` | ✅ 是 | 想发的内容/想法/经历/文章链接/截图描述 | - |
| `场景类型` | ❌ 否 | A干货分享/B个人故事/C日常生活/D热点借势/E产品推广 | AI自动判断 |
| `执行模式` | ❌ 否 | 自动模式/交互模式 | **询问用户选择** |
| `配图说明` | ❌ 否 | 描述要配什么图（截图/自拍/风景/产品图等） | AI建议 |
| `互动目标` | ❌ 否 | 点赞/评论/私聊咨询/转发 | 根据场景自动匹配 |

## 🎨 用户朋友圈风格规范（强制遵守）

### 语言风格

| 维度 | 规范 |
|------|------|
| 字数 | 50-350字，不超过400字 |
| 段落 | 超短段落，1-2句一段，呼吸感强 |
| 开头 | 直接进场景/进故事/进对话，零铺垫零废话 |
| 叙事 | 先故事/场景 → 再抽观点/感悟（禁止先说道理再举例） |
| 语气 | 像跟朋友聊天，口语化，自然使用"哈哈"、"吧"、"啊"等语气词 |
| 人称 | 第一人称"我"为主，真实感强 |
| 情绪 | 克制但有温度，不煽情不鸡汤，偶尔自嘲 |
| 金句 | 结尾必有一句点睛之笔 |

### 开头三行法则（生死线）

朋友圈折叠后只显示前3行（约45-60字），这3行决定用户是否点开"全文"。

**高效开头模式：**

| 模式 | 示例 | 适用场景 |
|------|------|---------|
| 场景切入 | "李小龙去世后，香港功夫片领域出现巨大空白" | 干货分享 |
| 时间锚点 | "马上就是从地产离职两整年了，还记得很清楚" | 个人故事 |
| 对话引入 | "朋友问，西西弗里是网红书店吗？" | 日常生活 |
| 数据冲击 | "昨天那条视频，3小时播放量破了10万" | 产品推广/干货 |
| 反常识 | "做了两年自媒体，我发现最没用的就是追热点" | 热点借势/干货 |

**禁止的开头：**
- ❌ "今天想和大家分享一下..."
- ❌ "最近有个感悟..."
- ❌ "关于XX，我有几点想法..."
- ❌ 任何以"我觉得"、"我认为"开头的

### 结尾三种收法

| 收法 | 示例 | 适用场景 |
|------|------|---------|
| 行动号召型 | "有启发的，点个赞吧。" | 干货分享 |
| 信念宣言型 | "我的目标里面只有信念，不再有具体数字。" | 个人故事 |
| 幽默收尾型 | "那些年，我们在AI面前废掉的武功，哈哈。" | 日常生活 |
| 开放提问型 | "你们觉得呢？" | 热点借势 |
| 轻推引导型 | "想了解的可以私聊我。" | 产品推广 |

### 绝对禁区

1. ❌ 禁用"——"（破折号）
2. ❌ 禁用"首先、其次、最后"
3. ❌ 禁用"综上所述"、"总而言之"
4. ❌ 禁用感叹号轰炸（最多1个）
5. ❌ 禁止说教语气
6. ❌ 禁止鸡汤金句堆砌
7. ❌ 禁止"建议您"、"希望大家"
8. ❌ 禁止emoji轰炸（最多3-4个，且只用在列表编号处如1️⃣2️⃣3️⃣）

## 📋 5种场景类型详解

### 场景A：干货分享型

**目的**：展示专业度，引发收藏/截图/点赞

**结构公式**：故事/案例引入 → 提炼观点/方法论（2-3条） → 行动号召

**核心技巧**：
- 用一个具体的故事或案例开头，不要直接抛观点
- 方法论用数字列表（1️⃣2️⃣3️⃣），方便截图传播
- 每条方法论一句话说完，不展开
- 结尾用"有启发的，点个赞吧"或类似轻推

**字数**：200-350字

**配图建议**：思维导图/要点截图/相关场景图

---

### 场景B：个人故事型

**目的**：人设建设，展示真实自我，引发共鸣和信任

**结构公式**：时间锚点/场景切入 → 故事展开（有细节有对话） → 感悟升华（不说教）

**核心技巧**：
- 必须有具体的时间、地点、人物、对话
- 对话要还原真实场景（"他一脸诧异，啊，你是要转行写代码吗？"）
- 情绪克制，用事实说话，不用形容词堆砌
- 感悟部分要自然流出，不要突然升华
- 可以适当自嘲（"领导虽然也像看白痴一样看我"）

**字数**：200-350字

**配图建议**：真实场景照片/老照片/工作环境

---

### 场景C：日常生活型

**目的**：拉近距离，展示真实生活状态，让人觉得你不只是个"做AI的"

**结构公式**：生活场景切入 → 自然延伸到专业/思考 → 幽默或感悟收尾

**核心技巧**：
- 从一个很小的生活细节切入（书店、吃饭、散步）
- 自然过渡到专业思考，不要硬转
- 展示多面性：设计背景、审美、生活态度
- 结尾轻松，可以用"哈哈"收

**字数**：100-250字

**配图建议**：生活照/风景/美食/书店/咖啡

---

### 场景D：热点借势型

**目的**：蹭热点表达独特观点，引发讨论和转发

**结构公式**：热点事件一句话概括 → 独特角度切入 → 关联到自己的领域 → 开放式结尾

**核心技巧**：
- 不复述热点，默认大家都知道了
- 找一个别人没说过的角度
- 必须关联到AI/自媒体/个人成长领域
- 结尾用提问引发讨论

**字数**：100-200字

**配图建议**：热点相关截图/新闻截图

---

### 场景E：产品/服务推广型

**目的**：转化，引导私聊咨询，但不能硬卖

**结构公式**：痛点场景/客户故事 → 解决方案（轻描淡写） → 成果展示 → 轻推引导

**核心技巧**：
- 绝对不能硬广，要像在分享一个故事
- 用客户的真实反馈/对话作为素材
- 成果用具体数据说话，不用形容词
- 引导语要轻："想了解的可以私聊我"，不要"快来报名"
- 制造稀缺感要自然："最近咨询的人有点多"

**字数**：150-300字

**配图建议**：客户反馈截图/成果数据截图/产品展示

## 🔄 完整工作流程

### Step 1：素材解析 + 场景判断

1. 读取用户画像（确认目标受众）
2. 分析用户输入的素材：
   - 素材类型：想法/经历/文章/截图/热点/产品
   - 核心信息提取
   - 情绪基调判断
3. 自动匹配最适合的场景类型（A-E）
4. 确定互动目标

**场景判断逻辑**：
```
素材包含方法论/经验总结 → A 干货分享
素材包含个人经历/时间节点/情感 → B 个人故事
素材包含生活场景/日常琐事 → C 日常生活
素材包含热点事件/新闻 → D 热点借势
素材包含产品/服务/客户反馈 → E 产品推广
素材是公众号文章 → 特殊模式：生成3条不同角度的转发文案
```

---

### Step 2：素材池构建

读取知识库，构建个人素材池：

1. 读取个人自传 → 提取可关联的真实经历片段
2. 读取社群总结 → 提取可引用的专业观点
3. 结合用户输入的素材，构建完整素材池

**素材优先级**：
```
① 用户直接提供的素材 → 最高优先级
② 个人自传中的真实经历 → 信任建设
③ 社群中的专业观点 → 深度补充
④ AI合理延伸 → 兜底（尽量少用）
```

### Step 2.5：结构选择（方法论驱动）

> ⚠️ 必读：`references/朋友圈结构框架（薛辉方法论）.md`
> 核心原则：**骨架用方法论的，语言用用户的。**

根据素材类型和场景，从方法论框架中选择最佳组合：

**① 选结构模式**（6选1）：

| 素材特征 | 推荐结构 |
|---------|---------|
| 有真实事件/经历 | 模式1：真实事件→情绪释放→规律提炼 |
| 有热点/现象 | 模式2：现象切入→拆解分析→反常识结论 |
| 有方法论/干货 | 模式3：知识框架型（编号列点） |
| 有数据/多案例 | 模式4：数据/案例堆叠→个人判断 |
| 日常生活素材 | 模式5：生活碎碎念→意外升华 |
| 有故事/他人经历 | 模式6：故事沉浸叙述→现实映射 |

**② 选开头钩子**（8选1）：

| 素材特征 | 推荐钩子 |
|---------|---------|
| 有反直觉观点 | 反常识标题式 |
| 有具体场景 | 事件现场还原 |
| 有真实对话 | 对话直接引入 |
| 有冲击性数字 | 数字冲击 |
| 有哲理性问题 | 自问自答 |
| 有时间线 | 时间锚点 |
| 有搞笑/荒诞元素 | 情绪爆发式 |
| 有多个要点 | 清单预告式 |

**③ 选收尾模式**（5选1）：

| 场景/目的 | 推荐收尾 |
|----------|---------|
| 输出强观点 | 强观点收尾 |
| 要金句传播 | 对仗金句 |
| 打破说教感 | 自嘲/幽默收尾 |
| 引导下一步 | 行动号召 |
| 制造回味 | 留白式 |

**④ 选核心技巧**（至少用1-2个）：
- 对话还原法：有真实对话时必用
- 身份降格+自我解构：输出强观点时必用
- 数字具象化：涉及数据时必用
- 括号旁白：需要幽默感时用
- 跨界类比：解释专业概念时用

**⑤ 金句句式**（收尾时参考）：
- "越是X的人越Y"
- "X不是X，而是Y"
- 四字对仗
- 否定+肯定："不要X，要Y"

### Step 3：生成3条文案

> ⚠️ 必读：`02.内容创作系统/🔧06.我的档案/我的个人上下文/风格萃取/朋友圈文案风格萃取.md`
> 核心原则：**Step 2.5选的是骨架，这一步穿的是用户的皮肤。结构可以学别人，语言必须是自己的。**

根据Step 2.5选定的结构组合，用用户的语言风格生成3条不同角度的文案。

**3条文案的差异化策略**：
| 文案 | 角度 | 风格 |
|------|------|------|
| 文案1 | 最直接的角度 | 标准风格 |
| 文案2 | 换一个切入点 | 更轻松/更深度 |
| 文案3 | 反向/意外角度 | 更有话题性 |

**生成时强制执行**：
- [ ] 开头3行是否能独立成立？（折叠测试）
- [ ] 是否直接进场景/故事？（零铺垫检查）
- [ ] 段落是否够短？（1-2句一段）
- [ ] 是否有语气词？（"哈哈"、"吧"、"啊"）
- [ ] 结尾是否有点睛之笔？
- [ ] 是否触犯禁区？（破折号、说教、鸡汤、emoji轰炸）
- [ ] 字数是否在场景要求范围内？
- [ ] 读起来像用户本人发的吗？

### 署名测试（不可替代性检查）

> **核心问题：把署名换成别人，这条朋友圈还能成立吗？**

逐项检查：
- [ ] 文中是否有**只有用户才有的经历**？（个人实战、真实案例、踩过的坑）
- [ ] 文中是否有**独家数据或独家判断**？（不是公开信息的二次搬运）
- [ ] 去掉所有个人印记后，和通用AI生成的内容**区别在哪**？（必须能说清）

**判定：**
- ✅ 至少2项有明确答案 → 通过，继续下游流水线
- ❌ 少于2项 → **必须补入个人素材**（从 `04.我的上下文` 或 `思想力武器库` 中调取），重新过一遍自检

### Step 4：配图策略

根据选定的文案，给出具体的配图建议：

| 场景 | 配图数量 | 配图类型 |
|------|---------|---------|
| A 干货分享 | 1-3张 | 要点截图/思维导图/相关场景 |
| B 个人故事 | 1-3张 | 真实照片/老照片/场景照 |
| C 日常生活 | 3-6张 | 生活照/风景/美食 |
| D 热点借势 | 1张 | 新闻截图/热点相关图 |
