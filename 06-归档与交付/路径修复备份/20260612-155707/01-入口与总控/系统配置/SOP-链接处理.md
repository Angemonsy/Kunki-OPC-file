# SOP：链接自动读取处理规范

## 触发规则

**只要用户发送URL链接，自动触发处理**，不需要等用户说"帮我读"。

## 判断链接类型

| 链接类型 | 用哪个Skill | 输出要求 |
|----------|------------|---------|
| 飞书文档链接 | 先用 `lark-cli` 导出，如果失败再试 `x-reader-url` | 完整正文+结构化整理 |
| 普通网页/公众号/知乎/小红书 | `x-reader-url` | 提取正文，去除广告导航，保留核心内容 |
| 视频链接（B站/YouTube等） | `x-reader-video` | 转文字 + 核心要点摘要 |
| 需要登录才能访问 | 告诉用户"需要登录，无法直接读取"，不硬试 |
| GitHub仓库 | WebFetch读取README，总结 |

## 处理流程

### Step 1：识别链接类型

用户发URL → 判断是什么类型，选对Skill。

### Step 2：调用Skill提取内容

- 网页文章 → `mcp__skill-handler__Skill(skill="x-reader-url", args="URL")`
- 视频 → `mcp__skill-handler__Skill(skill="x-reader-video", args="URL")`

### Step 3：结构化整理输出

提取完内容后，整理成：
1. **标题**：原文标题
2. **来源**：原链接
3. **核心要点**：分点列出关键信息（5-10点）
4. **全文**（如果不长）或者**摘要**（如果很长）

### Step 4：决定是否存档

- 如果是参考资料类内容 → 询问用户是否保存到 `03.参考资料库/`
- 如果是临时阅读 → 直接输出给用户即可
- 如果是用户要求同步的飞书文档 → 直接保存到对应本地文件夹

## 调用示例

### 普通网页链接
```
mcp__skill-handler__Skill(skill="x-reader-url", args="https://example.com/article")
```

### 视频链接
```
mcp__skill-handler__Skill(skill="x-reader-video", args="https://www.bilibili.com/video/xxx")
```

## 注意事项

1. **飞书链接特殊处理**：飞书文档优先用 `lark-cli` 导出，因为权限完整能拿到全部内容
2. **大图/二进制文件**：不自动读取，询问用户用途
3. **隐私内容**：用户发的隐私链接，处理完不存档，只给用户看
4. **超长内容**：大数据量用 `browser_save_file` 存本地文件，不全部输出到对话

## 结果存档位置

如果需要存档，按主题放：
- 用户相关 → `05.我的上下文/`
- 参考资料 → `03.参考资料库/`
- 产品相关 → `07.产品管理/`
- 商业变现 → `08.商业变现/`
