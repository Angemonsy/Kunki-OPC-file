# 录音稿转文案

> 从录音稿到公众号文章的一站式生产线

## 🎯 功能概述

这是一个**编排器 skill**，把现有的 3 个独立 skill 串成一条完整的流水线，补上中间缺失的路由环节：

```
录音稿/课程笔记/PDF → 整理 → 提炼选题 → 用户选择 → 类型判断 → 文案生成 → 下游流水线
```

与其他入口 skill 的区别：

| Skill | 素材来源 | 核心动作 |
|-------|---------|---------|
| 公众号爆款生产 | 外部热点链接 | 从热点出发，自己选题自己写 |
| 灵感碎片转文案 | 脑子里的想法 | 从碎片出发，AI判断类型再写 |
| 实战复盘转内容 | 自己的实战过程 | 从经历出发，提炼方法论再写 |
| 爆款拆解改写 | 别人的爆款文案 | 从别人的成品出发，拆骨架→换血肉 |
| **录音稿转文案** | **录音稿/课程笔记/PDF** | **从学习素材出发，整理→选题→文案** |

## 📥 输入参数

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `素材` | ✅ 是 | 录音稿文字、课程笔记、PDF文件路径、或已整理好的文档 | - |
| `执行模式` | ❌ 否 | 自动模式/交互模式 | 询问用户选择 |
| `是否已整理` | ❌ 否 | 素材是否已经过整理 | AI自动判断 |
| `目标平台` | ❌ 否 | 公众号/小红书/视频号 | 公众号 |

## ⚡ 双模式说明

接收到素材后，先询问用户选择执行模式（如果用户已指定则跳过）：

### 模式一：🚀 自动模式（推荐）

全程自动执行，只在两个关键节点暂停：

```
判断是否已整理 → (需要则整理) → 自动提炼选题 → 自动选TOP1
→ 自动判断类型 → 自动生成文案 → ⏸️ 用户确认文案
→ 自动下游流水线 → ⏸️ 用户确认最终成品 → 发布
```

自动模式的默认行为：
- 整理判断：AI自动判断素材是否已整理，已整理则跳过Phase 1
- 选题选择：自动选择爆款概率最高的TOP 1选题
- 类型判断：AI自动判断内容类型
- 素材来源：优先从录音稿原文提取素材，补充个人自传+社群总结
- 下游流水线：标题→核查→敏感词→排版，全部自动执行

检查点只有 2 个：
| 检查点 | 位置 | 等什么 |
|--------|------|--------|
| ⏸️ 1 | 完整文案生成后 | 用户确认文案内容 |
| ⏸️ 2 | 最终成品（排版后）| 用户确认发布 |

### 模式二：🔧 交互模式

每步暂停，用户全程参与决策：

```
判断是否已整理 → ⏸️ → (需要则整理) → ⏸️ 确认整理结果
→ 提炼选题 → ⏸️ 用户选择选题 → 确认类型 → ⏸️ 确认
→ 文案生成 → ⏸️ 确认 → 下游流水线 → ⏸️ 确认发布
```

检查点有 6 个：
| 检查点 | 位置 | 等什么 |
|--------|------|--------|
| ⏸️ 1 | Phase 1 整理完 | 确认整理结果（如跳过则无此检查点）|
| ⏸️ 2 | Phase 2 选题列表输出后 | 用户从TOP 5中选择选题 |
| ⏸️ 3 | Phase 3 类型判断后 | 确认内容类型 |
| ⏸️ 4 | Phase 4 完整文案输出后 | 确认文案内容 |
| ⏸️ 5 | Phase 5 自检报告输出后 | 确认质量 |
| ⏸️ 6 | 最终成品（排版后）| 确认发布 |

## 🔄 完整工作流程

### Phase 1：素材整理（智能跳过）

接收用户输入的素材后，先判断是否需要整理。

#### 1.1 自动判断是否已整理

判断标准：
```
已整理的特征（满足2个以上 → 跳过整理）：
  ✅ 有清晰的标题层级结构（H1/H2/H3）
  ✅ 段落分明，逻辑连贯
  ✅ 没有大量口语化的"嗯""啊""然后然后"
  ✅ 没有明显的错别字和语病
  ✅ 内容有主题归类

未整理的特征（满足2个以上 → 需要整理）：
  ❌ 大段口语化文字，没有分段
  ❌ 大量语气词和重复表达
  ❌ 没有标题结构
  ❌ 逻辑跳跃，话题混杂
  ❌ 明显的语音转文字错误
```

#### 1.2 执行整理（如需要）

调用「录音稿整理」skill 的处理流程：
1. 全文通读，理解内容和主题
2. 修正错别字、语法错误
3. 梳理主要脉络，提取核心主题
4. 按标题层级重新组织结构
5. 输出整理后的文档

**模式分流：**
- 🚀 自动模式：自动判断 + 自动整理（如需要），直接进入 Phase 2
- 🔧 交互模式：展示判断结果，⏸️ 等用户确认是否需要整理；整理完后 ⏸️ 等用户确认整理结果

#### 1.3 素材池建立

无论是否需要整理，都在此步建立「素材池」——从录音稿原文中提取所有可用素材：

```
素材池（按类型分类）：
  📊 数据素材：具体数字、百分比、金额、时间等
  📖 案例素材：真实故事、客户案例、个人经历
  💡 观点素材：独到见解、反常识判断、趋势预测
  🔧 方法素材：可复制的步骤、框架、工具
  💬 金句素材：精彩表述、可传播的句子
```

> ⚠️ 这个素材池是本 skill 的核心差异点：文案生成时优先从这里取素材，而不是只从个人自传里找。录音稿本身就是最好的素材来源。

### Phase 2：提炼选题

调用「录音稿提炼选题专家」skill 的处理流程。

**必读知识库**（并行读取）：
- `02.内容创作系统/🔥04.复盘与方法论/13大爆款元素.md`
- `02.内容创作系统/🔧05.用户画像/我的用户画像.md`

执行步骤：
1. 深度分析整理后的文档，逐段标记关键知识点
2. 识别可独立成篇的内容单元
3. 基于13大爆款元素包装选题（10-20个）
4. 结合用户画像验证精准度
5. 按爆款概率排序，推荐 TOP 5
6. 自动添加到灵感点子表

**输出格式（每个选题）：**
```
选题：[具体选题]
爆款元素：[主要] + [次要]
内容类型：教知识/聊观点/讲故事/晒过程
目标用户：[具体用户群体]
素材池匹配：[标注该选题可用的素材池素材]
爆款概率：0%-100%
```

**模式分流：**
- 🚀 自动模式：自动选择爆款概率最高的 TOP 1 选题，直接进入 Phase 3
- 🔧 交互模式：⏸️ 展示 TOP 5 选题，等待用户选择

---

### Phase 3：类型判断 + 路由

基于选定的选题，判断内容类型并路由到对应的文案 skill。

#### 3.1 内容类型判断

```
选题中有可复制的方法/步骤/教程？
  ├─ 是 → 「教知识」
  └─ 否 → 选题中有明确的立场/判断/观点？
           ├─ 是 → 「聊观点」
           └─ 否 → 选题中有完整的故事线？
                    ├─ 是 → 「讲故事」
                    └─ 否 → 「晒过程」
```

#### 3.2 路由目标

| 内容类型 | 调用 Skill | 传入参数 |
|---------|-----------|---------|
| 教知识 | 「教知识文案」(jiaozhishi wenan) | 选题 + 素材池 + 录音稿原文 |
| 聊观点 | 「聊观点文案」 | 选题 + 素材池 + 录音稿原文 |
| 讲故事 | 「讲故事文案」(jiangushi wenan) | 选题 + 素材池 + 录音稿原文 |
| 晒过程 | 「公众号爆款生产」 | 选题 + 素材池 + 录音稿原文 |

**模式分流：**
- 🚀 自动模式：自动判断类型，直接路由，进入 Phase 4
- 🔧 交互模式：⏸️ 展示类型判断结果和理由，等待用户确认或修改

### Phase 4：文案生成

**必读知识库**（并行读取）：
- `02.内容创作系统/🔧06.我的档案/我的个人上下文/风格萃取/直播口语风格萃取.md` ⚠️ 必读（先读取，用口语节奏打底）
- `02.内容创作系统/🔧06.我的档案/我的个人上下文/公众号文案风格萃取.md` ⚠️ 必读（再读取，做书面化微调）
- `02.内容创作系统/🔧06.我的档案/AI创作规范.md`
- `02.内容创作系统/🔥00.素材库/文案结构/_框架使用说明书.md`
- 按内容类型读取对应的开篇模板库

#### 4.1 素材优先级（核心差异点）

文案生成时，素材来源按以下优先级：

```
优先级1：录音稿素材池（最高优先）
  → 数据素材：录音稿中提到的具体数字、案例数据
  → 案例素材：录音稿中的真实故事、客户案例
  → 观点素材：录音稿中的独到见解
  → 方法素材：录音稿中的可复制步骤
  → 金句素材：录音稿中的精彩表述

优先级2：个人自传 + 社群总结（补充）
  → 当录音稿素材不够时，从个人自传提取相关经历
  → 从社群总结提取专业观点补充论证

优先级3：合理推理（兜底）
  → 以上都不够时，基于已有素材合理推理
```

#### 4.2 调用对应文案 skill

根据 Phase 3 的路由结果，调用对应的文案 skill 生成完整文案。

调用时传入额外参数：
- `素材池`：Phase 1 建立的素材池，作为首选素材来源
- `录音稿原文`：整理后的完整文档，供文案 skill 随时引用
- `选题`：Phase 2 选定的选题

**风格约束**（所有类型通用）：
- 必须使用用户的口吻（参照公众号文案风格萃取）
- 高频口语词：那、就、其实、所以、你会发现、呢、然后
- 短段落原则：每段不超过3-4行
- 禁用AI味词汇：综上所述、建议您、首先其次最后
- 数字具体化：优先使用录音稿中的真实数字

**模式分流：**
- 🚀 自动模式：⏸️ 输出完整文案（含选题摘要+素材来源标注），等待用户确认。这是自动模式唯一的内容确认点。
- 🔧 交互模式：⏸️ 输出完整文案，等待用户确认。

## ⚠️ 核心原则

### 素材优先级

```
录音稿原文素材 > 个人自传/社群总结 > 合理推理
```

录音稿本身就是最好的素材来源——里面有真实的案例、数据、观点、方法论。文案生成时必须优先使用录音稿中的素材，而不是抛开录音稿从个人自传里找。

### 选题忠实度

- 选题必须来源于录音稿原文内容，不能凭空捏造
- 可以用爆款元素重新包装，但核心知识点必须来自原文
- 标注每个选题对应的录音稿原文段落

### 一稿多题

一份录音稿通常能提炼出 10-20 个选题。本次只选 1 个写成文案，其余选题自动存入灵感点子表，后续可以通过「灵感碎片转文案」继续使用。
