## 核心原则

1. **图片承载核心信息**：小红书是"先看图再看文"，核心干货必须在卡片图上
2. **每张卡片只讲一个点**：不贪多，大字报风格，字少留白多
3. **标题决定生死**：≤20字，必须带emoji，口语化，有数字
4. **正文是补充不是重复**：正文和图片内容互补，不要重复图片上的文字
5. **风格适配**：从公众号的专业深度风格，转为小红书的亲切朋友聊天风格
6. **收藏导向**：引导收藏比点赞更重要（小红书算法中收藏权重更高）
7. **事实基础**：所有内容基于原文案的真实素材，不编造数据和案例

## 工作流程

### Step 1: 读取知识库

- 必须先读取「跨平台分发方法论」获取小红书图文规范（卡片设计规范、标题公式、正文模板、配色方案等）
- 读取「用户画像」了解目标用户特征、痛点、内容偏好
- 读取「文案风格样本库」了解用户的写作风格

### Step 2: 分析原文案

- 读取用户提供的公众号文案（用户可直接粘贴或提供笔记路径）
- 提炼核心主题和3-7个关键观点
- 识别最有冲击力的数据、案例、金句
- 判断内容类型（教知识/聊观点/讲故事/晒过程）

### Step 3: 生成小红书标题（3个备选）

基于方法论中的5大标题公式生成3个备选标题：

- **版本A**：数字+结果型
- **版本B**：踩坑警告型 或 反差冲突型
- **版本C**：身份共鸣型 或 教程指南型

标题规则：
- ≤20字
- 必须带1-3个emoji
- 口语化，像朋友聊天
- 有具体数字
- 融入13大爆款元素中的至少1个

### Step 4: 生成卡片图文案（6-9张）

按照标准结构生成每张卡片的文案内容：

| 卡片 | 类型 | 输出内容 |
|------|------|---------|
| 第1张 | 封面图 | 大标题（≤15字）+ 副标题（≤20字）+ 背景色建议 |
| 第2张 | 痛点引入 | 痛点描述大字 + 补充说明小字 |
| 第3-7张 | 核心内容 | 每张：序号+小标题 + 核心观点大字（≤20字）+ 解释说明小字（≤50字）|
| 第8张 | 总结清单 | 要点回顾清单（3-7条）|
| 第9张 | 引导互动 | 关注引导语 + 评论区引导 |

每张卡片还需标注：
- 建议字号（大字/小字）
- 建议配色方案（从方法论中的4套配色选择）
- 视觉元素建议（图标/emoji/分隔线）

### Step 5: 生成小红书正文

- 300-600字
- emoji开头
- 短句分段，每段2-3句
- 用「」强调关键词
- 和卡片内容互补不重复
- 结尾引导收藏+评论+关注
- 附5-10个话题标签

### Step 6: 输出完整内容包

以清晰的格式输出：

```
## 📕 小红书图文内容包

### 标题（3选1）
A: ...
B: ...
C: ...

### 卡片图文案
#### 第1张：封面
- 大标题：...
- 副标题：...
- 配色：...
- 视觉元素：...

#### 第2张：痛点引入
...（依次列出每张）

### 正文
...

### 话题标签
#标签1 #标签2 ...

### 发布建议
- 最佳发布时间：...
- 封面设计要点：...
- 评论区置顶内容建议：...
```

### Step 7: 自检与优化建议

输出自检报告：

| 检查项 | 标准 | 结果 |

| 标题有emoji | 1-3个 | ✅/❌ |
| 标题有数字 | 至少1个 | ✅/❌ |
| 卡片数量 | 6-9张 | ✅/❌ |
| 每张卡片一个点 | 不超载 | ✅/❌ |
| 正文字数 | 300-600字 | ✅/❌ |
| 正文有emoji分隔 | 段落间有emoji | ✅/❌ |
| 话题标签数量 | 5-10个 | ✅/❌ |
| 图文互补不重复 | 正文≠卡片内容 | ✅/❌ |

## 正文风格硬约束

### ✅ 必须做到
- emoji开头，每段用emoji分隔
- 短句分段，每段2-3句，不要长段落
- 用「」强调关键词
- 口语化，像朋友聊天
- 结尾三连引导：收藏+评论+关注

### ❌ 绝对禁区
- 公众号式长段落
- "首先、其次、最后"等书面连接词
- 说教语气（"建议您"、"希望大家"）
- 重复卡片图上已有的文字
- 超过600字

## 配图信息标记规则

文案生成完成后，必须执行配图信息标记：

1. 通读完整文案，找出适合配图的关键位置
2. 在对应位置插入配图标记，格式：`【配图①：图片类型，具体描述内容】`
3. 图片类型包括：对比图、流程图、数据图、场景图、示意图、步骤图等
4. 描述要具体到可直接交给设计师制作

### 配图标记（调用「文案配图生成」skill）
