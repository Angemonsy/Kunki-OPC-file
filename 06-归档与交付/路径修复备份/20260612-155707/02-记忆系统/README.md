# 记忆系统｜唯一运行入口

> 本目录是整个 Obsidian 知识库唯一有效的 AI 记忆系统。更新时间：2026-06-08。

## 最高规则

- AI 只能从本目录读取和写入运行记忆。
- [[02.内容创作系统]]、Skills、AGENTS.md、CLAUDE.md 都只能调用本目录，不能再各自维护一套记忆。
- 旧目录、旧档案、旧对话、旧内容只作为历史证据；与本目录冲突时，以本目录为准。
- 用户最新明确口述 > [[01-记忆系统/当前唯一真相.md]] > [[01-记忆系统/当下每时每刻（持续更新）.md]] > [[01-记忆系统/长期记忆.md]] > 历史资料。

## 当前文件分工

| 文件/文件夹 | 用途 | 更新频率 |
|---|---|---|
| [[01-记忆系统/当前唯一真相.md]] | 当前身份、定位、战略、禁用旧表达，事实最高优先级 | 重大变化才改 |
| [[01-记忆系统/当下每时每刻（持续更新）.md]] | 最新思考、动态、状态、近期任务，AI 每次启动优先看 | 高频更新 |
| [[01-记忆系统/长期记忆.md]] | 稳定用户画像、长期偏好、长期方法论、反复验证的规则 | 低频更新 |
| [[01-记忆系统/AI协作偏好.md]] | AI 说话方式、协作边界、输出偏好 | 用户确认后更新 |
| [[01-记忆系统/每日输入与复盘]] | 每天输入、碎片、日报、复盘、原始材料 | 每日更新 |
| [[01-记忆系统/归档]] | 合并前旧记忆、旧对话、历史证据 | 只读归档 |

## 写入规则

- 最新状态、最新想法、短期任务：写入 [[01-记忆系统/当下每时每刻（持续更新）.md]]。
- 稳定身份、业务、产品、目标用户：写入 [[01-记忆系统/长期记忆.md]]，必要时同步 [[01-记忆系统/当前唯一真相.md]]。
- 每日记录、输入、复盘、灵感碎片：写入 [[01-记忆系统/每日输入与复盘]]。
- 不再向 `02.内容创作系统/🛠️10.记忆系统/` 写入任何运行记忆。
