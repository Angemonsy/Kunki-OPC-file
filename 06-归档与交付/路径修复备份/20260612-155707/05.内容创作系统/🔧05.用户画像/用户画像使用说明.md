# 用户画像使用说明

> 用户画像是整个内容创作系统的基础,所有创作决策都要基于用户画像来判断

## 快速使用指南

### 创作前必查清单

**1. 选题阶段**(查看[[02.内容创作系统/🔧05.用户画像/我的用户画像#核心痛点]])
- [ ] 这个选题解决了哪个用户痛点?
- [ ] 这个选题适合哪类用户?(意向/意识/潜在)
- [ ] 预期互动数据如何?(查看"内容偏好"按互动率排序)

**2. 框架选择**(查看[[02.内容创作系统/🔧05.用户画像/我的用户画像#平台习惯]])
- [ ] 用户在哪个平台?(公众号/小红书/抖音/视频号)
- [ ] 用户需要什么内容类型?(工作流演示/工具推荐/工具演示/案例拆解)
- [ ] 预期数据表现?(查看"内容匹配策略"数据)

**3. 文案撰写**(查看[[02.内容创作系统/🔧05.用户画像/我的用户画像#决策路径]])
- [ ] 开篇是否给出明确价值承诺?(真实数据)
- [ ] 是否降低门槛?(3分钟学会/手把手教学)
- [ ] 是否有真实数据验证?(10篇3爆/8篇4爆)
- [ ] 是否提供免费试用?(智能体免费领/工具免费用)

**4. 发布策略**(查看[[02.内容创作系统/🔧05.用户画像/我的用户画像#获客渠道]])
- [ ] 平台选择是否匹配用户习惯?
- [ ] 内容类型是否匹配平台特性?

## 用户画像的4个核心用途

### 用途1: 选题验证

**使用场景**: 当你有一个选题想法时,用用户画像验证是否值得做

**验证步骤**:
1. 打开[[02.内容创作系统/🔧05.用户画像/我的用户画像#核心痛点]],找到对应的痛点
2. 查看"你的爆款如何解决"部分,看是否有类似案例
3. 查看互动数据,评估爆款潜力

**案例**:
```
选题: "5个AI工具提升写作效率"
验证:
- 对应痛点: "不会用AI或AI味太重"(73.5%最大痛点)
- 类似案例: 案例1(5个AI工具)转发率14.3%,收藏率87.5%
- 结论: ✅ 值得做,属于工具推荐类,预期转发率高
```

---

### 用途2: 框架匹配

**使用场景**: 选题确定后,选择合适的文案框架

**匹配步骤**:
1. 查看[[02.内容创作系统/🔧05.用户画像/我的用户画像#内容偏好]],找到互动率最高的内容类型
2. 根据内容类型选择对应框架:
   - 工作流演示类 → [[02.内容创作系统/🔥00.素材库/文案结构/dontbesilent/dontbesilent-教知识·方法论拆解类框架|dontbesilent-教知识·方法论拆解类]]
   - 工具推荐类 → [[00.框架使用说明书#问题拆解型]]
   - 工具演示类 → [[00.框架使用说明书#成果揭秘型]]
   - 案例拆解类 → [[00.框架使用说明书#情节反转型]]

**数据参考**:
- 工作流演示类: 互动率20.1%(最高)
- 工具推荐类: 转发率14.3%(传播广)
- 工具演示类: 收藏率120%(用户粘性强)
- 案例拆解类: 转发>点赞(降低门槛)

---

### 用途3: 平台策略

**使用场景**: 决定在哪个平台发布,以及如何调整内容

**平台选择矩阵**:

| 平台 | 最佳内容类型 | 核心卖点 | 预期数据 |
|------|------------|---------|---------|
| **公众号** | 工作流演示类<br>工具推荐类 | "X篇Y爆"+完整流程+手把手教学 | 互动率20.1%<br>转发率14.3% |
| **小红书** | 工具推荐类<br>工具演示类 | 精选价值+免费诱饵+可视化 | 收藏率120%<br>收藏率87.5% |
| **视频号** | 工作流演示类<br>案例拆解类 | 挑战冲突+真实成果+我也能做 | 转发率6.6%<br>转发率4.8% |

**使用方法**:
1. 查看[[02.内容创作系统/🔧05.用户画像/我的用户画像#平台差异化策略]]
2. 根据内容类型选择最佳平台
3. 使用对应平台的核心卖点撰写文案

---

### 用途4: 数据复盘

**使用场景**: 内容发布后,用数据验证和优化用户画像

**复盘步骤**:
1. 记录实际数据(阅读/点赞/评论/转发/收藏)
2. 对比[[02.内容创作系统/🔧05.用户画像/我的用户画像#内容匹配策略]]中的预期数据
3. 分析差异原因:
   - 数据超预期 → 提取成功要素,更新用户画像
   - 数据低于预期 → 分析失败原因,调整策略
4. 更新[[用户画像更新记录]],记录优化方向

**案例**:
```
内容: "10个AI工具推荐"
预期: 工具推荐类,转发率14.3%,收藏率87.5%
实际: 转发率18.5%,收藏率95%
分析: 超预期,可能因为:
  - 工具数量从5个增加到10个(更丰富)
  - 每个工具都有真实使用截图(可信度高)
  - 提供了免费替代方案(降低门槛)
优化: 更新用户画像,强调"工具数量"和"免费替代"的重要性
```

## 用户画像更新机制

### 何时更新用户画像?

**触发条件**(满足任一即更新):
1. 单篇内容数据超预期2倍以上
2. 连续3篇内容数据低于预期
3. 发现新的用户痛点或行为特征
4. 平台算法或用户习惯发生重大变化

### 如何更新用户画像?

**更新流程**:
1. 在[[用户画像更新记录]]中记录更新原因和数据
2. 更新[[02.内容创作系统/🔧05.用户画像/我的用户画像]]对应部分
3. 在[[02.内容创作系统/🔥00.素材库/文案结构/_框架使用说明书|框架使用说明书]]中同步更新相关数据

**更新原则**:
- 数据驱动: 所有更新必须有真实数据支撑
- 持续验证: 新发现需要3次以上重复验证才写入
- 保留历史: 旧数据不删除,标注"已优化"并保留对比

## 常见问题

### Q1: 用户画像太复杂,每次都要全部看完吗?

**A**: 不需要。根据创作阶段查看对应部分:
- 选题阶段 → 只看"核心痛点"
- 框架选择 → 只看"内容偏好"
- 平台策略 → 只看"平台差异化策略"
- 数据复盘 → 只看"内容匹配策略"

### Q2: 用户画像和框架使用说明书有什么区别?

**A**:
- 用户画像: 回答"用户是谁""用户要什么"(WHO + WHAT)
- 框架使用说明书: 回答"怎么写""怎么做"(HOW)
- 关系: 用户画像指导框架选择,框架使用说明书指导具体创作

### Q3: 如何判断用户画像是否准确?

**A**: 看数据验证:
- 准确: 实际数据与预期数据误差<20%
- 需优化: 实际数据与预期数据误差20-50%
- 需重构: 实际数据与预期数据误差>50%
