## 🚀 快速操作

### 1. 发现新热点
```
1. 每日监控各平台热榜（微博、知乎、抖音）
2. 使用 /热点追踪 skill 自动分析赛道热点
3. 评估相关度、时效性、创作难度
```

### 2. 追热点创作
```
1. 使用 /热点分析 skill 深度分析
2. 确定内容角度（聊观点/教知识/晒过程）
3. 使用 /聊观点文案 或 /教知识文案 快速创作
4. 24-48小时内发布
```

### 3. 热点选题化
```
1. 发现好热点
2. 使用 /录音稿提炼选题专家 提炼选题角度
3. 添加到灵感点子表
```
