# AI创作规范

> ⭐ 必读：AI生成70% + 人工精修30%的质量标准

---

## 📋 核心原则

**AI的作用**：
- ✅ 快速生成结构化初稿
- ✅ 提供素材和思路
- ✅ 保持逻辑清晰

**AI的局限**：
- ❌ 无法100%模仿个人风格
- ❌ 缺乏真实情感温度
- ❌ 容易产生"AI味"

**人工精修的价值**：
- 注入个人风格和情感
- 打磨关键金句
- 去除AI味

---

## 🎯 AI生成初稿的质量标准

### 1. 结构完整性（必须达标）

**检查清单**：
- [ ] 开篇：是否抓住痛点/制造悬念？
- [ ] 主体：逻辑是否清晰？层次是否分明？
- [ ] 结尾：是否引导行动？

**不合格示例**：
```
开篇：今天我们来聊聊内容创作。（太平淡）
主体：内容创作很重要，需要选题、写文案、发布。（太笼统）
结尾：希望对你有帮助。（太敷衍）
```

**合格示例**：
```
开篇：很多人做自媒体失败的原因，99%是因为没有选题。（痛点直击）
主体：我把选题拆解成3个步骤...（结构清晰）
结尾：现在就打开你的笔记本，按照这3个步骤试一次。（引导行动）
```

---

### 2. 内容准确性（必须达标）

**检查清单**：
- [ ] 数据是否真实？（禁止编造数据）
- [ ] 案例是否真实？（禁止编造案例）
- [ ] 方法是否可行？（禁止纸上谈兵）

**重要提醒**：
- ⚠️ 如果系统还没测试，不要编造测试数据
- ⚠️ 如果没有真实案例，用"假设"或"理论上"来表达
- ⚠️ 如果方法未验证，明确说明"这是设计思路，还未实测"

---

### 2.5 权威来源归属（必须达标）

> **全局规则**：所有文案skill（公众号爆款生产、录音稿转文案、灵感碎片转文案、热点文案生成、爆款拆解改写、对话转文案、社群精华转文案等）在生成文案时，均须遵守此规则。

**规则**：文案中引用任何外部研究、报告、数据、权威观点时，**必须标注到可追溯的程度**。

| 引用类型 | 必须标注 | 示例 |
|----------|---------|------|
| 学术研究/报告 | 论文名+发表机构+年份 | "哈佛商业评论2025年发表的《AI Is Making Work More Intense》指出..." |
| 新闻事件 | 事件名+时间+来源 | "据36氪2026年3月报道..." |
| 数据/统计 | 数据来源+时间 | "根据Statista 2025年数据..." |
| 专家/名人观点 | 人名+身份+出处 | "Y Combinator创始人Paul Graham在《How to Do Great Work》中提到..." |

**为什么这条规则重要**：
- 防止被指责抄袭：标注来源后，即使别人用了同一篇研究，你的文案有明确出处，不构成抄袭
- 增加权威感：标注出处让读者觉得你做了功课，不是随口一说
- 可追溯性：读者想深入了解时能找到原始来源

**踩坑教训**：不标注来源时，你和另一个博主引用同一篇研究、得出类似结论，写出来的段落会高度相似，容易被指责抄袭。标注来源后，你可以说"我们引用了同一篇公开研究，但分析和案例完全不同"。

---

### 3. 信息密度（建议达标）

**检查清单**：
- [ ] 每段是否有实质内容？（避免废话）
- [ ] 是否有具体案例/数据支撑？（避免空洞）
- [ ] 是否有可操作的建议？（避免泛泛而谈）

**不合格示例**：
```
选题很重要。好的选题能帮你获得更多流量。所以一定要重视选题。
（3句话说了同一件事，信息密度为0）
```

**合格示例**：
```
选题决定了80%的成败。我用13大爆款元素评分，80分以上才做，爆款率从20%提升到60%。
（1句话包含：数据、方法、结果）
```

## ✍️ 人工精修的30%要做什么

### 1. 去除AI味（必做）

**AI味的特征**：
- 太正式、太官方
- 用词太书面化
- 句式太工整
- 缺乏情感温度

**去除方法**：

| AI生成 | 人工精修 |
|--------|----------|
| "这个方法非常有效" | "你会发现，这个方法真的管用" |
| "建议您尝试" | "你可以试试" |
| "通过数据分析发现" | "我发现" |
| "综上所述" | "所以" |
| "首先...其次...最后..." | "第一个...第二个...第三个..." |

**口语化词汇表**（优先使用）：
- 那、就、其实、你会发现、所以
- 真的、确实、特别、非常、超级
- 说白了、简单来说、换句话说
- 比如说、举个例子、打个比方

---

### 2. 注入个人风格（必做）

**参考**：[[02.内容创作系统/🔧06.我的档案/我的个人上下文/风格萃取/我的文案风格样本库.md|我的文案风格样本库]]

**个人风格特征**：
- 口语化、真诚、实战派
- 常用词汇："那"、"就"、"其实"、"你会发现"、"所以"
- 句式偏好：长短句结合、追问式论证
- 开篇习惯：直击痛点或金句开场
- 结尾习惯：引导行动+社群导流

**注入方法**：
1. 读一遍AI生成的初稿
2. 用自己的话重新说一遍关键句子
3. 保留AI的结构，替换成自己的表达

---

### 3. 打磨关键金句（建议做）

**什么是关键金句**：
- 开篇第一句（决定用户是否继续看）
- 每个段落的第一句（决定用户是否跳过）
- 结尾最后一句（决定用户是否行动）

**打磨标准**：
- 简短有力（不超过20字）
- 易于传播（用户愿意转发）
- 有记忆点（用户看完能记住）

**打磨技巧**：
- 用数字：80%的成败、3个步骤、5分钟
- 用对比：从靠灵感到靠系统、从碰运气到可复制
- 用反问：你有没有遇到过这种情况？
- 用金句：选题不对，后面再努力也白搭

---

### 4. 调整情感温度（建议做）

**AI生成的内容通常偏冷**，需要加入：
- 共鸣点：让用户感觉"这说的就是我"
- 鼓励语：让用户感觉"我也能做到"
- 真诚感：让用户感觉"这是真心话"

**调整方法**：

| 冷冰冰 | 有温度 |
|--------|--------|
| "这个方法适用于所有人" | "如果你也遇到这个问题，可以试试这个方法" |
| "按照步骤操作即可" | "别担心，我手把手教你" |
| "希望对你有帮助" | "如果这篇文章帮到了你，欢迎来交流" |

---

## 🚫 避免的AI生成陷阱

### 陷阱1：过度使用排比句

**AI喜欢这样写**：
```
这个系统有三个特点：
第一个特点是数据驱动，第二个特点是持续学习，第三个特点是闭环反馈。
```

**应该这样写**：
```
这个系统有三个特点：
- 数据驱动：每个选题都要评分
- 持续学习：每个爆款都要复盘
- 闭环反馈：数据反馈到系统里
```

---

### 陷阱2：过度使用"首先...其次...最后..."

**AI喜欢这样写**：
```
首先，我们要明确目标。其次，我们要制定计划。最后，我们要执行落地。
```

**应该这样写**：
```
第一步，明确目标。第二步，制定计划。第三步，执行落地。
```

---

### 陷阱3：过度使用"综上所述"

**AI喜欢这样写**：
```
综上所述，这个方法非常有效。
```

**应该这样写**：
```
所以，这个方法真的管用。
```

---

### 陷阱4：过度使用"建议您"

**AI喜欢这样写**：
```
建议您尝试这个方法。
```

**应该这样写**：
```
你可以试试这个方法。
```

## 💡 实战案例

### 案例1：开篇优化

**AI生成**：
```
今天我们来聊聊如何搭建内容创作系统。
```

**人工精修**：
```
很多人做自媒体失败的原因，99%是因为没有选题，更新太慢，以及没有办法持续出爆款。
```

**优化点**：
- 去掉"今天我们来聊聊"（太AI）
- 改为痛点直击式开篇
- 用"99%"制造数据冲击

---

### 案例2：主体优化

**AI生成**：
```
这个系统有四个核心特点。第一个特点是数据驱动，每个选题都要经过评分。第二个特点是持续学习，每个爆款都要复盘。第三个特点是闭环反馈，数据会反馈到系统里。第四个特点是风险控制，发布前会检测敏感词。
```

**人工精修**：
```
你会发现，这个系统有四个核心特点：

**第一个特点：数据驱动**
每个选题都要经过13大爆款元素的评分，80分以上才进入创作流程。不是拍脑袋，而是用数据说话。

**第二个特点：持续学习**
每个爆款都会被复盘分析，提取成选题模板、开篇模板、文案框架，归档到模板库。下次创作的时候，直接调用这些验证过的模板。

**第三个特点：闭环反馈**
发布后的数据会反馈到系统里，告诉你哪些选题爆了，哪些开篇效果好，哪些结构用户喜欢。系统会根据这些数据，自动优化推荐逻辑。

**第四个特点：风险控制**
发布前会自动检测敏感词，覆盖小红书、抖音、视频号、公众号的平台规则，给出替换建议。避免违规被封。
```

**优化点**：
- 加入"你会发现"（个人风格）
- 每个特点单独成段（提升可读性）
- 每个特点都有具体说明（提升信息密度）
- 用"不是拍脑袋，而是用数据说话"（增加对比）

---

### 案例3：结尾优化

**AI生成**：
```
希望这篇文章对你有帮助。
```

**人工精修**：
```
希望这篇文章能给你一些启发。

如果你也在搭建自己的系统，欢迎来交流。另外我也做了一个AI+自媒体的社群，群里面我会分享很多内部的工作流和方法论，如果你有兴趣的话，可以加入到我的社群。
```

**优化点**：
- "希望对你有帮助"改为"希望能给你一些启发"（更真诚）
- 增加社群导流（引导行动）
- 用"如果你有兴趣的话"（降低压迫感）

## 🎯 质量对标机制（v1.1新增）

> 核心理念：每篇文案生成后，必须与同类型的历史高质量文章进行对标，确保输出质量不低于已有水平。

### 1. 对标流程（文案生成后、排版前执行）

```
文案初稿生成
    ↓
判断文案类型（聊观点/教知识/讲故事/晒过程）
    ↓
从成品库/发布文案中找到同类型的高质量文章作为对标样本
    ↓
逐维度对比（开篇/论证/案例/语感/结尾）
    ↓
输出对标报告，标注差距项
    ↓
针对差距项修改后，进入排版
```

### 2. 对标样本库

| 文案类型 | 对标样本 | 核心优点 |
|---------|---------|---------|
| 聊观点·趋势预判 | [[02.内容创作系统/🔥02.发布文案/2026年/2026年2月21日-为什么我有40个AI智能体却不做全自动化内容.md]] | 真实场景开篇、内心独白、"主厨vs自动炒菜机"比喻、高案例密度 |
| 教知识·工具教程 | （待补充：下次产出高质量教知识文章后归档） | — |
| 讲故事·个人经历 | （待补充） | — |
| 晒过程·实战复盘 | （待补充） | — |

**维护规则：**
- 每次产出用户认可的高质量文章，归档到对应类型的对标样本
- 每个类型保留1-3篇对标样本，优胜劣汰
- 对标样本必须是用户明确认可的文章（不是AI自认为好的）

### 3. 对标维度与评分

| 维度 | 权重 | 评分标准 | 对标样本参考 |
|------|------|---------|------------|
| 开篇真实感 | 25% | 是否有真实场景/个人经历？是否3秒内抓住注意力？ | "我前两天真的认真想过这件事" |
| 论证深度 | 20% | 是否有内心思考过程？逻辑链是否完整？ | "想了一个晚上→技术可行→但反而想明白了另一件事" |
| 案例密度 | 20% | 每500字是否有具体案例/数据？案例是否真实？ | 2023年ChatGPT经历、11个步骤、20个框架、DeepSeek课程 |
| 语感自然度 | 20% | 读起来像真人说话吗？口语词使用是否自然？ | "你猜怎么着""说到底""拼的就是" |
| 结尾力度 | 15% | 是否有力收束？引流是否自然？ | 反问收尾+"拼的就是你喂给AI的东西" |

**评分规则：**
- 每个维度0-10分
- 加权总分 ≥ 7分 → 通过
- 加权总分 5-7分 → 修改差距项后重新评分
- 加权总分 < 5分 → 必须重写

### 4. 对标报告输出格式

```
📊 质量对标报告

🔖 对标样本：[样本文章名]
📝 当前文案：[当前文章名]

| 维度 | 对标样本表现 | 当前文案表现 | 得分 | 差距分析 |
|------|------------|------------|------|---------|
| 开篇真实感 | ... | ... | X/10 | ... |
| 论证深度 | ... | ... | X/10 | ... |
| 案例密度 | ... | ... | X/10 | ... |
| 语感自然度 | ... | ... | X/10 | ... |
| 结尾力度 | ... | ... | X/10 | ... |

📈 加权总分：X.X / 10
✅ 判定：通过 / 需修改 / 需重写

🔧 修改建议：
1. [具体修改建议]
2. [具体修改建议]
```
