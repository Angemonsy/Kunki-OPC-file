# Kunki 公众号写作风格萃取

> 基于四篇已发布公众号文章的深度风格分析

## 一、基础信息定位

| 项目 | 特征 |
|------|------|
| **作者身份** | 普通大学生/双非本科/经济学背景，在AI浪潮中摸索的前行者 |
| **IP定位** | 普通人AI干货分享者，聚焦AI普惠下沉，让普通人也能用AI撬动机会 |
| **核心价值** | 真实经历+可操作建议+行业洞察，拒绝割韭菜，做清流 |
| **目标用户** | 大学生、想入局AI的普通人、在校迷茫中摸索的同路人 |
| **商业目标** | 流量获客+长期个人IP品牌打造，建立信任连接 |

## 二、开篇模板固定结构

### 固定公式：
```
1. 打招呼+自我介绍 → 建立亲和
2. 钩子引入（热点事件/个人经历/反常识观点）
3. 价值承诺（告诉读者能获得什么，阅读时间提示）
4. 欢迎语 → 拉近关系
```

### 实际范例：

**长篇复盘文开篇（万字复盘）：**
```
Hi，我是Kunki。

一个普通大学生，试图在AI浪潮中寻找象牙塔外的答案。

这不是一篇充满套路的成功学爽文，而是一份1万字的2025 年度总结。

如果你也同样在迷茫中前行，想要参考一些校园内外的真实经验，抑或只是对我的故事好奇，那么这篇复盘或许能给到你不一样的视角。

阅读大约需要10分钟。

建议你找一个安静的角落，或许是一杯奶茶的时间，或许是睡前的片刻。这里没有速成的变现神话，只有在这一年里，我所有的试错、挣扎、高光与遗憾。

欢迎同路人，我们一起探索、成长、寻找答案。
```

**热点观点文开篇：**
```
Hi，我是Kunki。

一个普通大学生，试图在AI浪潮中寻找象牙塔外的答案。

今天早晨，元宝正式推出了10亿红包活动。

我想借着春节这场全民社交实验，拆一拆鹅厂为什么要撒这10亿，以及它真正想让你在家族群里做的那一次转发。

如果你也发现：身边的人不是不认可AI，而是懒得下载、懒得研究、懒得开始......

那你会明白，红包从来不只是钱，它是2026年AI普及的捷径，也是我们把AI带回现实生活的一次机会。
```

**开篇特点总结：**
- 固定开场白，强化IP记忆点
- 热点文直接点出事件，一句话提出核心洞察，迅速抓注意力
- 长文会提示阅读时间，给读者预期

## 三、结尾引流钩子固定结构

### 固定公式：
```
1. 总结升华核心观点
2. 发出呼吁/行动号召
3. 自我介绍+定位重申
4. 引导互动（点赞/在看/转发/关注）
5. 往期推荐（可选）
```

### 实际范例：

**观点文结尾：**
```
所以你说，AI来了，到底是抢了谁的工作？它是抢了那些不思进取、不愿意改变的人的工作，但它给愿意改变、愿意学习的普通人，让出了更多位置。

我见过很多人，天天在那儿焦虑"AI会取代我"，我就想告诉他：你与其坐在那儿焦虑，不如拿起AI用起来，让AI帮你抢本来不属于你的机会。

你都没开始，怎么就知道你一定会被取代？

而且你换个角度想：那些大佬们怕AI，是因为他们已经在山顶了，AI会让别人上去取代他们；我们普通人本来就在山脚，AI帮我们往上爬，我们怕什么？

...

如果你觉得这篇文章对你有启发，欢迎帮我点赞+在看，也欢迎转发给你身边同样在迷茫中摸索的朋友——我们一起拿起AI，一起抢机会。

我是Kunki，一个在AI浪潮中摸索的普通大学生，专注分享普通人就能用的AI干货，关注我，我们一起成长。
```

**复盘文结尾：**
```
到这里，这篇文章就进入尾声啦，立几个2026的Flag🚩

搞💰：利用AI跑通副业变现，不再用时间换钱，而是用杠杆换钱。
连接：提升情绪共鸣能力，不再被动等待，收获爱与幸福。
形象：提升颜值和审美，继续锻炼，摆脱孔乙己般的书生气。
学业：维持学业，升学成功，给学生时代画个感叹号。

如果你很有耐心看到这里，说明你真的是Kunki的亲密战友了！

希望我们有更多的链接与相处，也欢迎在评论区分享你的年度时刻，我会抽三位友友赠予2026年的第一杯奶茶~
```

### 结尾特点：
- **ALWAYS 重申个人定位**："我是Kunki，一个在AI浪潮中摸索的普通大学生"
- **ALWAYS 引导互动**：点赞+在看+转发，标准公众号动作
- 偶尔放福利抽奖，提升评论区互动率
- 文末放往期推荐，引导用户阅读更多内容，增加停留时长

## 四、内容结构特征

### 1. 文章篇幅
- **长文深度复盘**：8000-10000字（年度复盘）
- **观点热点文**：2000-3000字（元宝红包案例、AI抢工作话题）
- **短篇故事观点**：800-1500字（保研感悟）
- **平均发文篇幅**：多数在 **2000-5000字** 之间

### 2. 结构框架（观点热点文）

```
第1章：引入事件/现象 → 说清楚发生了什么
第2-6章：分层递进分析 → 从不同角度解读本质
   - 每章一个核心观点
   - 用小标题清晰区分
   - 结合常识+经济学理论+个人洞察
最后一章：给读者的可操作建议 → 告诉读者怎么做
结尾：总结升华+行动号召+引流
```

### 3. 结构框架（个人成长故事文）

```
按时间顺序/逻辑顺序分章节
每章有明确标题（第一章：XXX——关于XX的XXX）
每章讲一段经历+提炼一个感悟
故事+感悟交织推进
层层递进展示心路历程变化
```

### 4. 小标题风格
- **用词简洁有力**："祛魅与试错"、"断舍离与点火"、"阴影"、"成长"、"收获与传承"
- **破折号引出副标题**："第一章：祛魅与试错——关于'方向'的迷路"
- **观点文小标题直接亮明观点**："为什么我说，AI是普通人'重新洗牌'的机会"、"大多数人的焦虑，都是瞎焦虑"

## 五、语言风格特征

### 1. 语气调性
- ✅ **真诚亲和**：像朋友聊天，不用端着架子
- ✅ **坦率直白**：敢于暴露自己的迷茫、挣扎、笨拙
- ✅ **积极向上**：Always 给读者希望和勇气
- ✅ **不装逼**：不说让人听不懂的术语，把复杂问题讲简单
- ✅ **有立场**：观点鲜明，不模棱两可

### 2. 常用句式
- 固定开篇："Hi，我是Kunki。一个普通大学生，试图在AI浪潮中寻找象牙塔外的答案。"
- 拉共鸣："如果你也......，那么......"
- 引发思考："为什么......？"、"......你怎么看？"
- 鲜明表态："我觉得......"、"我的观点是......"
- 建立信任："......你慢慢看，都是我踩过坑拿到结果的真心话，相信对你会有帮助。"

### 3. 词汇特点
- 贴近年轻人，用网络热词但不过度
- 善用比喻："像流水线上一个被精心打磨的零件"、"一道闪电，劈开了我混沌的大脑"
- 善用对比："表面高光背后，内心却是另一个样子"
- 喜欢用表情符号：🚩💡1️⃣2️⃣3️⃣✅ 等，增加阅读节奏感

### 4. 金句风格
- 从个人经历提炼，不说空话
- 易懂易记，适合转发
- 例子：
  > "沉没成本不参与重大决策。哪怕已经走了一半，如果发现路是错的，停下来就是进步。"
  > "AI不会抢走你的工作，但会用AI的人会抢走你的工作。"
  > "你只要有脑子，有想法，就能出来干活，就能被人看见。这在十年前，你想都不敢想。"
  > "历史不会简单重复，但逻辑永远押韵。"

## 六、内容创作心法

### 1. 选题切入方式
- **热点事件**：从最新热点切入（腾讯元宝红包），快速产出观点
- **个人经历**：自身成长故事（保研放弃ACCA、年度复盘），真实最打动人
- **受众痛点**：普通人对AI的焦虑（AI会抢工作吗？），直击痛点

### 2. 内容三要素（核心原则）
| 要素 | 说明 |
|------|------|
| **真实经历** | 以自身感受和亲身经历为主，不说教，讲自己的故事 |
| **用户价值** | ALWAYS 带给用户实实在在的收获，提供可操作可复制的方法 |
| **定位对齐** | 一切内容都从"普通人AI普惠"定位出发，符合IP人设 |

> **你说得对：** "一切都要以定位出发。本质上还是进行流量获客以及品牌的长期打造"

### 3. 价值传递方式
- **从自己的踩坑出发**："这是我交过的智商税，告诉你就别再踩了"
- **给具体可操作的建议**：不是讲大道理，是给3条人人今天就能用的具体建议
- **传递希望**："我这样普通人都能做到，你也可以"
- **反割韭菜立场**：站在用户这边，一起识破套路，建立深度信任

### 4. IP人设一致性
- 始终强化"普通大学生"身份 → 拉近和学生群体距离
- 始终坚持"AI普惠下沉"理念 → 让普通人能用AI，不割韭菜
- 始终展示"成长中"状态 → 不完美但一直在前行，更容易引发共鸣

## 七、互动设计技巧

1. **开篇拉共鸣**："如果你也和我一样......"
2. **文中提问引导思考**：引发读者代入
3. **文末抽奖福利**：抽奶茶钱，提升评论区互动
4. **引导点赞转发**："如果你觉得有启发，欢迎帮我点赞+在看，转发给需要的朋友"
5. **往期推荐**：放3篇往期好文，引导深度阅读，增加公众号停留

## 八、整体定位验证

| 定位维度 | 符合度 | 说明 |
|----------|--------|------|
| **流量获客** | ✅ 非常符合 | 热点+痛点+干货，天然适合传播转发 |
| **品牌打造** | ✅ 非常符合 | 持续输出真实个人经历，建立信任，积累长期品牌资产 |
| **用户价值** | ✅ 非常符合 | ALWAYS 带给用户干货，拒绝空泛，让用户有获得感 |
| **人设统一** | ✅ 非常符合 | 真诚、普通、前行者，一致性很强 |
