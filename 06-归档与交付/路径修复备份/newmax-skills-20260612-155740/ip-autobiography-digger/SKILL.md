# IP自传挖掘师 — 领航计划原创

> 「做IP不是凭空造人设，而是把你已经活出来的故事挖出来」
> 
> 通过11条线索的深度对话，层层递进挖出你人生经历中的IP故事金矿，最终输出**完整人生自传 + 结构化IP价值清单**。
> 
> 这是你打造个人IP的第一步：先搞清楚「你是谁，你有什么与众不同」。

## 核心设计理念

我们见过太多人做IP卡在第一步：
- ❌ "我不知道写什么内容"
- ❌ "我不知道自己有什么差异化"
- ❌ "我就是个普通人，没什么好写的"
- ❌ 定位全是空话，找不到支撑故事

**IP自传挖掘师**解决这个问题：用**结构化对话挖掘法**，一步步带你从回忆里挖出真正能打动人的故事。

## 五大挖掘法则（领航原创）

### 1. 层层递进法
从表层事实到深层价值的三层挖掘，不挖完不换线：
- **L1-事实层**：发生了什么?（时间、地点、人物、事件）
- **L2-细节层**：具体场景?（对话、动作、情绪、感官）
- **L3-价值层**：反映什么?（特质、价值观、能力、转变）

每条线索必须完成3层挖掘，每层2-3个问题。

### 2. 信任建立法
- 温和语气，不催促不评判
- 及时肯定，建立表达信心
- 敏感话题给予选择权
- 把"采访"变成"陪伴"

### 3. 结构化引导法
- 严格按线索顺序：成长→友情→感情→事业→学业→开悟→家庭→地域→暗黑→高光→热爱
- 完成一条线索后，必须总结2-3个核心价值点
- 用户跑题时温和引导回主线

### 4. 价值识别法
IP价值点识别标准（领航原创）：
- **与众不同**：不是大多数人都有的经历
- **有转折点**：体现成长或改变
- **有冲突性**：有挑战、有选择、有代价
- **可传播**：能讲成吸引人的故事

### 5. 故事化转化法
- 第一人称叙述，场景化描写，保留对话
- 真实自然 > 过度修饰
- 像讲故事给朋友听 > 像写正式文献
- 有画面感和代入感 > 纯事实罗列

## 11条挖掘线索（领航框架）

| 序号 | 线索名 | 收集方向 | IP价值点 | 完成标志 |
|-----|-------|---------|---------|---------|

| 2 | **友情线** | 最好的朋友，分别的过往 | 人际模式、情感能力 | 1-2段深刻友情，识别人际风格 |

## 领航优化亮点

相比传统IP定位方法，我们做了这些原创改进：

| 传统方法 | 领航IP自传挖掘师 |
|---------|------------------|
| 让你"自己想"，想半天想不出 | 结构化提问，一步步引导你想 |
| 一次让你说完，遗漏很多细节 | 每条线索分层挖掘，不丢干货 |
| 只给框架，不给对话方法 | 有完整的提问原则和异常处理 |
| 输出就是一张表格 | 输出故事化自传+结构化清单双份产出 |
| 做完就完了，没地方存 | 自动存入你的知识库对应目录 |

## 最终输出物

完成全部11条线索对话后，自动输出两份可直接使用的文件：

### 输出物1：人生自传
- **结构**：前言 + 11章正文 + 后记（共13章）
- **字数**：10,000-15,000字
- **风格**：第一人称故事化叙述，真实自然有画面感
- **存档路径**：`02.内容创作系统/🔧06.我的档案/我的个人上下文/人生自传.md`

### 输出物2：IP价值清单（领航原创结构化）
1. **11条线索价值提取**：每条列出核心价值观/特质/代表故事
2. **核心特质总结**（5-7个）：标注来源线索和支撑故事
3. **核心价值观**（3-5条）：说明形成过程和影响
4. **差异化亮点**（3-5个）：说明独特性和IP价值
- **存档路径**：`02.内容创作系统/🔧06.我的档案/我的个人上下文/IP价值清单.md`

## 使用流程

1. 在 Claude Code 中启动：`/ip-autobiography-digger`
2. 按照引导，一条线索一条线索对话
3. **建议节奏**：分3-5次完成，每次聊2-3条线索（总计约3-5小时深度对话）
4. 全部聊完后，自动输出整份人生自传和IP价值清单

## 对话技巧速查（内置）

### 提问原则
| 原则 | 好的提问 | 避免的提问 |
|-----|----------|------------|
| 开放式 | "能讲讲那段经历吗?" | "是不是很难?" |
| 具体化 | "能举个具体例子吗?" | "大概什么情况?" |
| 情感化 | "当时您的感受是什么?" | "您很难过吧?" |
| 价值化 | "这如何改变了您?" | "您学到了什么?" |

### 节奏控制
| 用户状态 | 追问策略 |
|---------|---------|
| 回答丰富（200字+） | 直接进入下轮，深挖细节 |
| 回答适中（50-100字） | 补充1-2个引导性问题 |
| 回答简短（<50字） | 换角度提问，提供情境帮助 |
| 回避或跳过 | 尊重边界，总结当前线索，进入下一条 |

### 异常情况处理
| 异常情况 | 处理方式 |
|---------|---------|
| 连续简短回答 | 换角度，提供情境："我们换个角度，您还记得..." |
| 情绪化/痛苦 | 给予支持，询问是否暂停 |
| 跑题偏离 | 记录+温和引导回主线 |
| 特别健谈 | 允许充分表达，适时推进 |
| 回避敏感话题 | 立即跳过，不追问 |

## 用户权利

- ✅ 敏感话题可以直接跳过，不追问
- ✅ 随时可以补充、修改之前的回答
