### 考点2：第二章 — WTO的地位

**核心知识点**（来自PPT）：

1. **世界贸易组织具有独立国际法人资格**
  - 根据《马拉喀什建立世界贸易组织协定》成立
  - 是常设性、永久性国际组织
  - 可以独立缔约、提起诉讼、享受特权豁免
2. **特权与豁免**
  - 每一成员应给予WTO履行职能所必需的特权和豁免
  - WTO官员和成员方代表同样享有特权豁免
  - 标准与《专门机构特权及豁免公约》保持一致
  - 可订立总部协议，与其他国际组织密切合作

**总结**：WTO是具有独立国际法人地位的永久性常设国际组织。

### 考点3：第三章 — WTO的组织机构及其职能（重点：总理事会、部长级会议）

**核心组织机构**：


| 机构        | 地位            | 主要职能                                                                                                                            |
| --------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **部长级会议** | WTO**最高权力机构** | 立法权、最高决策权、机构设置权、人事权、对协定的解释权、对成员义务的豁免权、批准国家/地区加入WTO的权力                                                                           |
| **总理事会**  | 休会期间最高权力机构    | 1. 代行部长级会议职能 2. 负责筹备部长级会议 3. 在适当时候**作为争端解决机构开会行使职能** 4. 在适当时候**作为贸易政策审议机构开会行使职能** 5. 下设三个理事会：货物贸易、服务贸易、知识产权 6. 批准预算财务报告、对协定进行解释 |
| 争端解决机构    | 常设机构          | 负责管理争端解决规则和程序                                                                                                                   |
| 贸易政策审议机构  | 常设机构          | 负责定期审议各成员贸易政策                                                                                                                   |
| 分理事会      | 总理事会下属        | 货物贸易理事会、服务贸易理事会、知识产权理事会                                                                                                         |
| 各专门委员会    | 处理专门议题        | 贸易与发展委员会、贸易与环境委员会、国际收支限制委员会等                                                                                                    |
| 总干事与秘书处   | 日常办事机构        | 总干事是行政首脑，秘书处负责日常事务                                                                                                              |


**重点记忆**：总理事会在休会时代行部长级会议职能，并在适当时候分别承担**争端解决机构**和**贸易政策审议机构**的职能。

### 考点4：第四章第二节 — 贸易自由化原则

**核心知识点**：

1. **贸易自由化含义**
  - 在WTO框架下，指各成员方通过多边贸易谈判，实质性地削减、限制和取消一切妨碍和阻止国际贸易发展的各项关税和其他非关税贸易壁垒，不断扩大成员方之间的货物和服务贸易。
2. **实施要点**
  1. 以WTO共同规则为基础
  2. 以多边贸易谈判为主要手段
  3. 以争端解决机制为保障
  4. 以例外条款和贸易救济措施为辅助
  5. 以过渡期体现优惠和差别待遇
3. **具体体现**
  1. **关税减让**：承诺关税约束，关税限定在一定水平不能随意提高
  2. **减少非关税贸易壁垒**：制定专门协议规范非关税措施，减少贸易壁垒
  3. **扩大服务贸易市场准入**：分阶段开放服务业各领域

### 考点5：第五章第一节 — WTO投票表决机制

**核心规则**：

1. **协商一致原则**（默认规则）
  - 与会成员未正式提出反对即视为通过
  - 缺席、沉默、弃权不构成反对
2. **投票表决规则**（协商一致失败时使用）

| 规则类型       | 适用情形           | 所需多数                     |
| ---------- | -------------- | ------------------------ |
| 简单多数       | 一般事项           | >50%                     |
| 三分之二多数     | 修正案提请接受        | ≥2/3                     |
| 四分之三多数     | 条款解释、义务豁免等重大事项 | ≥3/4                     |
| 全体成员接受规则   | 修改基本原则         | 100%同意（实际上几乎不可能通过）       |
| **反向协商一致** | 争端解决机构决策       | 只要不是一致反对就通过（这是乌拉圭回合重大创新） |

**关键点**：反向协商一致主要应用于争端解决，只要不是所有成员都反对，决定就通过，这大大提高了争端解决效率。

### 考点6：第五章第二节 — 贸易政策审议机制

**核心知识点**：

1. **含义与目的**
  - WTO成员集体对各成员贸易政策定期进行全面审议
  - 目的：提高透明度，促使成员更好遵守规则，确保多边贸易体制平稳运行
2. **审议对象**
  - 全部贸易政策和措施，覆盖货物贸易、服务贸易、知识产权
  - 还需要对世界贸易环境发展变化进行年度评议
3. **审议周期**
  - 取决于成员在世界贸易中所占份额
  - 份额越大，审议越频繁（四大贸易体每2年审议一次）
4. **主要特点作用**
  - 是监督机制，以透明度为基础
  - 周期灵活，根据贸易份额确定
  - 提高透明度，增强可预见性和稳定性
  - 促进相互交流，督促成员履行义务

### 考点7：第六章 — 关贸总协定1994年条款修正

**核心知识点**：

GATT1994对GATT1947主要做了两项修正：

1. **性质定位修正**
  - GATT1947：单独的政府间行政协定，只"**临时适用**"
  - GATT1994：是世界贸易组织法律框架的组成部分，**不再是临时适用**
2. **具体条款修正**（六个谅解）
  1. 关于解释第2条第1款(b)项的谅解
  2. 第17条（国营贸易企业）条款的谅解
  3. 对有关国际收支条款的谅解
  4. 对解释第24条（适用的领土范围、边境贸易、关税同盟和自由贸易区）的谅解
  5. 对解释第28条（减让表）的谅解
  6. 关于豁免义务的解释

### 考点8：农业协议

**核心知识点**：

1. **产生背景**
  - 农产品贸易长期游离于GATT规则约束之外
  - 发达国家大量补贴导致生产过剩、价格扭曲
  - 乌拉圭回合最终达成《农业协议》
2. **主要内容**：

  **(1) 市场准入**
  - **关税化**：将非关税措施转化为等值关税
  - 关税减让和关税约束
  - 最低市场准入和现行市场准入
  - 关税配额管理
  - 特殊保障条款

  **(2) 国内支持政策分类**

| 政策类型 | 颜色 | 性质 | 说明 |
|----------|------|------|------|
| 绿箱政策 | 绿色 | 免予削减 | 政府服务计划，费用不转嫁给消费者，不具有价格支持作用 |
| 黄箱政策 | 黄色 | 需要削减 | 政府对农产品直接价格干预和补贴（种子、肥料、灌溉补贴等） |
| 蓝箱政策 | 蓝色 | 免予削减 | 按固定面积产量给予的休耕补贴等 |
| S&D政策 | - | 发展中国家特殊 | 发展中国家农业投资补贴、低收入地区投入补贴等免予削减 |

  **(3) 出口补贴**
  - 不禁止但要求逐步削减
  - 最不发达国家免除削减义务
  - 视出口实绩提供的补贴受削减承诺约束

### 考点9：争端解决机制

**核心特点**：

1. **继承GATT的特点**
  - 鼓励磋商调解解决
  - 以保证规则有效实施为优先目标
  - 禁止单方面报复
  - 给予发展中国家特殊差别待遇
2. **WTO新特点**
  - 规定了严格的时间限制（审理更快捷）
  - 实行**反向协商一致**决策（只要不一致反对就通过）
  - **允许交叉报复**（可在不同领域授权报复）
  - 设立了正式完善的争端解决机构

**基本程序**：

1. **磋商**（必经前置程序）
2. **专家组审理**（临时成立）
3. **上诉机构审理**（常设，最终机构）
4. **裁决的执行与监督**
5. 补偿
6. **报复**（授权后才能进行）

### 考点10：第九章第一节 — 反倾销协议

**核心知识点**：

- 反倾销是WTO允许的三种贸易救济措施之一，是目前各成员广泛使用的最主要贸易救济手段。

**实施反倾销措施的必备要件**：

1. **倾销的确定**：出口价格低于正常价值
  - 正常价值：通常采用出口国国内市场价格
  - 出口价格：实际支付给出口商的价格
  - 调整后比较确定倾销幅度
2. **损害的确定**：对进口国国内产业造成损害
  - **实质性损害**：已经发生实质损害
  - **实质性损害威胁**：即将发生实质损害
  - **实质性阻碍**：阻碍国内新产业建立
3. **因果关系**：损害必须是由倾销造成，而非其他因素导致

**反倾销基本程序**：

1. 国内产业申请立案（或主管机关自行发动）
2. 审查立案
3. 调查
4. 初裁
5. 终裁
6. 行政复审
7. 司法审查

**反倾销措施**：临时反倾销措施、价格承诺、征收反倾销税

### 考点11：非歧视待遇原则（第四章第一节）

**核心知识点**：

- 非歧视原则是WTO最基本原则，由**最惠国待遇**和**国民待遇**构成

**(1) 最惠国待遇**

- **含义**：一成员给予任何第三方的优惠，立即无条件给予所有其他成员
- **实施要点**：
  1. **自动性**：立即无条件给予
  2. **同一性**：受惠标的必须相同
  3. **相互性**：既是受惠方也是给惠方
  4. **普遍性**：适用于所有货物、服务、知识产权领域

**(2) 国民待遇**

- **含义**：对其他成员方的产品、服务、提供者，待遇不低于本国同类产品服务提供者
- **实施要点**：
  1. 使用范围存在差异
  2. 待遇只限于境内享受
  3. "不低于"是最低要求

**关系**：两者都是非歧视原则的构成，国民待遇也是最惠国待遇中"待遇"的一部分。

### 考点12：1947年关贸总协定成立背景

**核心知识点**：

1. **历史背景**：
  - 两次世界大战的教训（战争与贸易保护的关系）
  - 美国崛起，西欧衰落
  - 联合国建立运作
  - 多边贸易体制建立符合各国利益
2. **成立过程**：
  - 1944年布雷顿森林会议，决定建立IMF、世界银行和国际贸易组织
  - 1947年日内瓦第二次筹委会，23国进行关税谈判
  - 1948年哈瓦那会议通过《国际贸易组织宪章》（《哈瓦那宪章》）
  - 由于美国等国国会未批准，国际贸易组织未能成立
  - 关税谈判达成的协议形成了"临时适用"的1947年关贸总协定

### 考点13：第九章第二节 — 补贴与反补贴协议

**核心知识点**：

1. **补贴定义**：
  - 一成员政府或公共机构向企业提供财政资助，或价格收入支持
  - 目的：增加出口或减少进口，可能损害其他成员利益
2. **专向性**：补贴只给予特定企业/产业/地区，才受协议约束
3. **补贴分类**（交通灯体系）：

| 类型 | 俗称 | 性质 | 说明 |
|------|------|------|------|
| 禁止性补贴 | 红灯补贴 | 禁止使用 | **出口补贴**和**进口替代补贴** |
| 可诉补贴 | 黄灯补贴 | 允许但可申诉 | 如果造成对其他成员利益损害，可申诉并采取反制 |
| 不可诉补贴 | 绿灯补贴 | 不可申诉 | 一般不被反制，如研发补贴、贫困地区补贴、环保补贴 |

> 💡 **考试提示**：本分类为教材经典口径，考试按老师PPT讲授作答即可。现实中"不可诉补贴"条款已到期失效，WTO现行规则核心强调禁止性补贴和可诉补贴两类。

4. **反补贴措施**：
  - 国内产业申请立案调查
  - 确认补贴、损害、因果关系
  - 最终可以征收**反补贴税**或达成**价格承诺**

**反倾销与反补贴对比**：

- 微量标准不同
- 忽略不计标准不同
- 邀请磋商是反补贴发起方义务，反倾销无此要求
- 价格承诺方式有所不同

### 考点14：第六章第五节 — 关税减让

**核心知识点**：

1. **关税减让含义**（四层含义）
  1. 削减关税并约束减让后的税率
  2. 约束现行关税水平
  3. 上限约束，即将关税约束在高于现行税率的某一特定水平，各方的实施税率不能超出这一水平
  4. 约束低关税或零关税
2. **关税减让谈判基础**
  - 商品基础：各国海关进口税则
  - 税率基础：以上一轮谈判确定的约束税率作为起点
3. **关税减让谈判原则**
  - 互惠互利
  - 考虑对方需要
  - 对谈判情况保密
  - 按照最惠国待遇实施
4. **谈判类型**
  - 多边关税谈判
  - 加入WTO时的关税谈判
  - 修改撤回减让表的谈判

## 📝 第二部分：选择题考点整理（20分）

### 高频考点清单：

#### 1. WTO基本原则

- 非歧视待遇原则（最惠国+国民待遇）→ 核心基本原则
- 贸易自由化原则 → 关税减让、减少非关税壁垒
- 允许正当保护原则 → 发展中国家可更高保护
- 公平竞争原则 → 反对不正当贸易手段
- 特殊和差别待遇原则 → 给发展中国家优惠
- 透明度原则 → 公布贸易政策措施

#### 2. 争端解决机制

- 特点：反向协商一致、允许交叉报复、严格时限
- 基本程序：磋商→专家组→上诉机构→执行→报复
- 反向协商一致：只要不是全体一致反对，决定就通过

#### 3. 非歧视待遇原则

- 最惠国待遇是自动的、无条件的
- 国民待遇要求不低于本国同类产品服务待遇
- 两者区别：最惠国待遇是对不同国家产品平等，国民待遇是对进口品和国产品平等

#### 4. GATT成立背景

- 1947年日内瓦谈判，23个原始缔约方
- 源于布雷顿森林会议，本来要成立国际贸易组织，未果，GATT临时适用

#### 5. 乌拉圭回合

- 第八轮多边谈判，1986-1994
- 启动地点：乌拉圭埃斯特角城
- 主要成果：
  - 关税进一步减让
  - 将服务贸易首次纳入多边贸易体制
  - 建立了贸易政策审议机制和争端解决机制
  - 达成《建立世界贸易组织协定》，1995年1月1日WTO正式成立

#### 6. 关税减让谈判

- 含义见上面判断题考点14
- 基础：商品基础（海关税则）+ 税率基础（上一轮约束税率）
- 原则：互惠、考虑对方需要、保密、最惠国待遇实施

#### 7. WTO成立基础

- 乌拉圭回合谈判成果
- 1947年GATT为历史基础
- 1994年4月马拉喀什协定签署，1995年1月1日正式成立

### 专题一：反倾销协议考点整理

**核心问题**：实施反倾销措施的必备要件是什么？

**答题要点**（分三点）：

#### 1. **倾销的确定**

倾销定义：一国出口商以**低于正常价值**的价格，将产品出口到另一国市场的行为。

确定倾销需要三个步骤：

- **正常价值的确定**：通常采用出口国国内市场价格，也可采用第三国出口价格或结构价格
- **出口价格的确定**：实际支付或应当支付给出口商的价格
- **出口价格与正常价值比较**：调整后公平比较
- **倾销幅度确定**：计算倾销幅度 = (正常价值 - 出口价格)/出口价格 × 100%

#### 2. **损害的确定**

- **国内产业定义**：指进口方境内生产相同或类似产品的生产者全体，或总产量占国内总产量主要部分的生产者
- **损害存在的标准**三种情况：
  1. **实质性损害**：已经造成实质损害
  2. **实质性损害威胁**：即将发生实质损害
  3. **实质性阻碍**：阻碍国内新产业的建立

#### 3. **因果关系**

倾销与损害之间必须存在因果关系，即损害是由倾销造成的，而非其他因素造成。

---

**反倾销基本程序**（如果问题问到程序，按这个答）：

1. 提出申请（或主管机关自行发动）
2. 审查立案
3. 调查
4. 初裁
5. 终裁
6. 行政复审
7. 司法审查

**反倾销措施**：

1. 临时反倾销措施（关税、保证金等）
2. 价格承诺（出口商承诺提高价格）
3. 征收反倾销税（最终措施）

### 专题二：反补贴协议考点整理

**核心定义**：

- 补贴：政府或公共机构提供财政资助或价格支持，授予企业利益
- 专向性：只针对特定企业/产业，才受协议约束

**补贴三大类**（见前文判断题）：

- 红灯：禁止性 → 出口补贴、进口替代补贴
- 黄灯：可诉 → 允许但造成损害可申诉
- 绿灯：不可诉 → 研发、贫困地区、环保补贴，一般不能申诉

**反补贴措施**：

- 程序类似反倾销
- 最终措施：征收反补贴税或价格承诺

**反补贴与反倾销区别**：

1. 微量标准不同
2. 可忽略不计标准不同
3. 反补贴要求必须邀请磋商，反倾销无此义务
4. 价格承诺方式有所不同

### 专题三：WTO基本原则在贸易争端中的应用

**案例题如果问某措施违反什么原则，主要从这几个角度答**：

#### 1. **非歧视待遇原则**

- 是否违反最惠国待遇：对不同国家是否给与不同待遇
- 是否违反国民待遇：对进口产品待遇是否低于本国产品

#### 2. **关税保护原则**

- 是否不当使用非关税措施限制进口
- GATT/WTO原则上主张只用关税保护，禁止数量限制

#### 3. **公平竞争原则**

- 是否存在倾销、补贴等不公平竞争行为
- 政府是否不当干预造成扭曲

#### 4. **透明度原则**

- 是否及时公布相关法律法规和措施
- 是否通知WTO

### 论述题1：中国与WTO的关系

**答题要点**（从这几个方面展开，尽量多写）：

---

#### 一、中国加入WTO的历程

1. 复关谈判（1986-1995）：中国从恢复GATT缔约国地位开始谈判
2. 入世谈判（1995-2001）：WTO成立后转为入世谈判
3. 2001年12月11日，中国正式加入WTO，成为第143个成员

---

#### 二、中国加入WTO的权利

1. **享受多边无条件最惠国待遇**：中国产品在其他WTO成员享受平等关税待遇
2. **享受其他成员开放市场的利益**：中国产品更容易进入国际市场
3. **发展中国家特殊差别待遇**：作为发展中国家，享受过渡期等优惠安排
4. **利用争端解决机制公平解决贸易摩擦**：可以通过多边机制解决中美、中欧等贸易争端
5. **获得多边贸易体制话语权**：参与规则制定，维护中国和发展中国家利益

---

#### 三、中国加入WTO的义务

1. **给予其他成员最惠国待遇和国民待遇**
2. **削减关税，规范非关税措施**：中国入世后大幅降低关税，逐步取消非关税壁垒
3. **按照TRIPS协定规范知识产权保护**：完善了中国知识产权保护法律体系
4. **增加贸易政策透明度**：定期公布法律法规，通知WTO
5. **按比例缴纳WTO会费**

---

#### 四、加入WTO对中国的影响和意义

1. **促进了中国对外贸易高速增长**：中国成为世界第一货物贸易大国
2. **推动了中国经济体制改革**：促进社会主义市场经济体制完善
3. **加快了中国产业结构升级**：引入竞争，提高企业竞争力
4. **促进了就业和消费者福利**：消费者可以买到更多低价优质进口产品
5. **提升了中国的国际地位**：中国在多边贸易体制中发挥越来越重要作用
6. **带来的挑战**：一些竞争力弱的产业受到冲击，需要调整升级

---

#### 五、中国加入WTO后的发展与贡献

1. 中国认真履行入世承诺，得到国际社会认可
2. 中国积极参与WTO谈判，推动多边贸易体制发展
3. 在全球经济下行和贸易保护主义抬头背景下，中国坚定维护多边贸易体制
4. 中国提出更高水平对外开放，对标WTO高标准推进改革

---

**总结**：中国加入WTO是改革开放和经济全球化的重要里程碑，既促进了中国经济发展，也为世界经济增长作出了重大贡献。中国与WTO是互利共赢的关系。

#### 👉 可能考点一：试论世界贸易组织确立与发展的基础

**答题要点**：

**(一) 理论与政策基础**

1. 二战前国际贸易理论政策演变：
  - 重商主义 → 自由贸易 → 保护幼稚工业 → 超保护贸易
2. 二战后：贸易自由化 → 新贸易保护主义 → 贸易自由化深化
3. WTO贸易理论政策取向：**有条件的自由贸易**
  - 倡导自由贸易但不是无限自由贸易
  - 根据经济发展水平竞争力决定政策组合
4. 国际贸易理论政策演变规律：
  - 不存在完全自由或完全保护，只是程度不同
  - 经济发展水平阶段决定政策选择
  - 竞争力高低决定政策选择
  - 不同产业不同产品政策不同
  - 面向国内 vs 国际市场利益集团倾向不同
  - 自由贸易实行时间更长，促进作用更大，但要适度合理

**(二) 市场经济体制基础**

1. 市场经济体制基本特征：
  - 市场主体独立性
  - 市场关系平等性
  - 市场行为规范性
  - 市场活动竞争性
  - 市场过程趋利性
  - 市场环境开放性
  - 市场结果分化性
2. WTO与市场经济：
  - WTO基本原则来源于市场经济
  - 运行机制体现市场经济要求
  - 促进成员市场经济体制发展完善

**(三) 经济全球化**

1. 含义：以市场经济为基础，发达国家为主导，跨国公司为载体，信息技术为动力，实现全球资源配置，各国经济相互融合
2. 表现：贸易全球化、生产全球化、金融全球化、投资全球化、企业活动全球化、消费全球化、观念人才全球化
3. 经济全球化与可持续发展：
  - WTO将可持续发展正式纳入宗旨
  - 强调合理利用世界资源，保护环境

**(四) 协调国际贸易利益的现实需要**

- 需要多边机构协调各国贸易政策，解决贸易争端，促进国际贸易正常发展

#### 👉 可能考点二：试述1947年关贸总协定的八轮多边贸易谈判（乌拉圭回合成果）

**核心重点：乌拉圭回合主要成果**

1. **背景**：
  - 20世纪80年代资本主义经济滞胀，新贸易保护主义抬头
  - 原有GATT规则覆盖范围有限，需要拓展
2. **目标**：
  - 削减关税，改善市场准入
  - 完善多边贸易体制，扩大规则管辖范围
  - 强化适应能力
  - 促进国际合作，加强政策协调
3. **主要成果**：
  - **货物贸易**：进一步关税减让，完善规则
  - **服务贸易**：首次将服务贸易纳入多边贸易体制，达成GATS
  - **知识产权**：达成TRIPS协定，将与贸易有关的知识产权纳入管辖
  - **投资措施**：达成TRIMs协议
  - **制度建设**：建立贸易政策审议机制和争端解决机制
  - **组织机构**：达成《建立世界贸易组织协定》，正式成立WTO

---

#### 👉 可能考点三：试述世界贸易组织与1947年关贸总协定的联系与区别

**联系**：

1. 历史继承性：WTO继承GATT的历史
2. 组织机构：保留了GATT秘书处
3. 规则继承：GATT规则成为GATT1994，保留在WTO框架内
4. 运行机制：继承多边争端解决，主张多边方式解决争端

**区别**：

1. **法律地位不同**：WTO是具有独立国际法人资格的永久性国际组织，GATT是临时适用的政府间行政协定
2. **管辖范围不同**：WTO管辖货物贸易、服务贸易、知识产权，GATT只管辖货物贸易
3. **争端解决机制不同**：WTO反向协商一致，效率更高，GATT原来需要一致同意容易被阻挠
4. **义务不同**：WTO要求成员"一揽子"接受所有协定，GATT可以保留诸边性，选择参加
5. **成员范围更广**：WTO目前有166个成员（截至2025年，最新加入为东帝汶，2024年8月30日），比GATT更广泛。占全球贸易98%

---

#### 👉 可能考点四：WTO与主要国际组织的关系

**世界经济三大支柱**：WTO + IMF + 世界银行

- **与联合国关系**：不是联合国专门机构，只是正常合作协调
- **与IMF关系**：宗旨一致，相互合作，相互协商，交换信息，共同协调
- **与世界银行关系**：宗旨重合，合作协调
- **与联合国贸发会议**：合作，每半年开会，研究贸易与发展等问题
- **与区域贸易集团**：允许存在，但要符合WTO规则
- **与非政府组织**：合作，开放对话，非政府组织可以旁听部长级会议
