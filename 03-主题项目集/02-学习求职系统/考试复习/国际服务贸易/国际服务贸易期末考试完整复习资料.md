## 第一部分：关于服务

### 1. 服务的商品属性及其特性

#### 1.1 服务的商品属性

- 服务是**劳动产品**，具有**使用价值**和**价值**
- 服务作为商品，同样遵循**价值规律**
- 服务的价值由生产服务的**社会必要劳动时间**决定

#### 1.2 服务商品的四大特性


| 特性            | 含义                  |
| ------------- | ------------------- |
| **无形性**       | 服务在本质上是无形的，不能被触摸    |
| **生产与消费的同步性** | 服务的生产和消费通常同时进行      |
| **不可储存性**     | 服务无法储存起来供以后销售       |
| **异质性**       | 服务质量因提供者、时间、地点等因素而异 |


---

### 2. "服务"井喷为那般？——服务业快速发展的原因

#### 2.1 服务业井喷发展的主要原因

1. **生产力发展**：农业和工业劳动生产率提高，解放了大量劳动力，劳动力向服务业转移
2. **需求结构变化**：人均收入提高，人们对服务的需求增长**快于**实物商品
3. **专业化分工深化**：生产性服务业从制造业中独立分离出来，促进专业化提升效率
4. **城市化进程**：城市化促进了服务业的集聚和发展，大城市是服务业的主要载体
5. **消费结构升级**：居民消费从"物质消费"向"服务消费"转型，教育、医疗、旅游、文化等服务需求增长

#### 2.2 服务业发展的意义

- 吸纳大量就业（服务业是吸纳就业最多的产业）
- 推动经济持续增长
- 促进产业结构优化升级
- 提高人民生活质量

---

### 3. 制造业服务化

#### 3.1 定义

制造业企业从**以生产产品为中心**向**以提供服务为中心**转变，将服务作为增值竞争的重要手段

#### 3.2 主要表现阶段（按产业链位置）


| 阶段     | 主要服务形式        |
| ------ | ------------- |
| **售前** | 提供咨询、设计、定制服务  |
| **售中** | 提供融资、租赁、安装培训  |
| **售后** | 提供维修、保养、升级、回收 |


#### 3.3 驱动因素

1. 市场竞争加剧，产品同质化严重
2. 利润环节向服务转移，制造环节利润变薄
3. 信息技术发展降低了服务提供成本
4. 消费者需求从"买产品"向"买解决方案"转变

#### 3.4 经济效应

- 提升制造业附加值和利润率
- 增强企业市场竞争力
- 促进制造业与服务业融合发展

## 第三部分：关于国际服务贸易

### 4. 国际服务贸易四种模式（GATS分类）**【填空题必考！】**

根据WTO《服务贸易总协定》（GATS），国际服务贸易分为四种提供模式：


| 模式      | 中文名称      | 定义                               | 生产者移动？      | 消费者移动？ | 典型例子                           |
| ------- | --------- | -------------------------------- | ----------- | ------ | ------------------------------ |
| **模式一** | **跨境提供**  | 从一成员境内向任何其他成员境内提供服务              | 否           | 否      | 国际电话服务、跨境电商服务、通过互联网提供咨询服务      |
| **模式二** | **境外消费**  | 在一成员境内向任何其他成员的服务消费者提供服务          | 否           | 是      | 出境旅游、出国留学、外国游客在本国消费            |
| **模式三** | **商业存在**  | 一成员服务提供者通过在另一成员境内**设立商业机构**提供服务  | 是（通过投资设立机构） | 否      | 外国银行在本国开设分行、外资连锁超市、外资律所设立办公室   |
| **模式四** | **自然人流动** | 一成员服务提供者通过**自然人短期入境**在另一成员境内提供服务 | 是（自然人短期移动）  | 否      | 外国专家短期来华提供咨询、外籍艺人来华演出、外国教师短期讲学 |


#### 【重点辨析】🚩 商业存在 vs 自然人流动


| 区别维度   | 商业存在                     | 自然人流动                      |
| ------ | ------------------------ | -------------------------- |
| 是否设立机构 | 需要在东道国设立商业存在（公司/分行/分支机构） | 不设立长期机构，短期入境提供服务           |
| 时间长度   | 长期持续经营                   | 短期提供服务后离境                  |
| 性质     | 属于国际直接投资（FDI）            | 属于自然人临时移动                  |
| 例子     | 汇丰银行（英国）在中国开设分行→商业存在     | 英国银行派专家短期来华为中国客户提供咨询→自然人流动 |


**记忆口诀：**

- 都不动→跨境提供
- 消费者动→境外消费
- 机构动→商业存在
- 个人动→自然人流动

### 5. 国际服务贸易规则体系

#### 5.1 多边规则：WTO框架

- **《服务贸易总协定》（GATS）**：WTO框架下第一个多边国际服务贸易协定
- 基本原则：
  - 最惠国待遇（自动给予所有成员优惠）
  - 市场准入（按承诺开放市场）
  - 国民待遇（给予外国服务提供者不低于本国待遇）
  - 透明度（公开法律法规和政策）

#### 5.2 区域/双边规则

- RCEP：第八章专门规范服务贸易，附各国服务开放承诺表
- CP TPP、USMCA等自由贸易协定均包含服务贸易章节
- 双边自贸协定通常包含服务贸易开放承诺

#### 5.3 核心目标

- 逐步推进国际服务贸易自由化
- 扩大全球服务贸易规模
- 促进全球服务业发展

### 6. 数字贸易的内涵

#### 6.1 定义

基于数字技术进行的货物和服务交换，既包括数字化交付的服务，也包括通过数字平台完成的实物贸易

#### 6.2 主要类型

1. **数字化服务**：云计算、大数据服务、在线教育、数字内容、视频会议
2. **电子商务**：通过互联网平台买卖实物商品
3. **数字平台服务**：搜索引擎、社交媒体、共享经济平台

#### 6.3 与传统贸易的区别


| 特征   | 数字贸易                 | 传统贸易        |
| ---- | -------------------- | ----------- |
| 交付方式 | 可远程瞬时交付              | 需要物流运输      |
| 边际成本 | 接近于零（复制一份数字产品成本几乎为零） | 持续有物流和生产成本  |
| 关键要素 | 数据                   | 货物          |
| 监管难点 | 数据流动、税收征管、隐私保护更复杂    | 关税、海关监管相对成熟 |


#### 6.4 发展趋势

- 全球数字贸易增长速度**远超**传统货物贸易
- 数字贸易规则成为当前国际经贸谈判的焦点
- 各国对数据跨境流动、数字税等议题存在较大分歧

### 7. 服务外包的本质

#### 7.1 定义

企业将**非核心服务业务**发包给外部专业服务商完成，以降低成本、聚焦核心竞争力

#### 7.2 分类


| 分类      | 全称     | 内容                   |
| ------- | ------ | -------------------- |
| **ITO** | 信息技术外包 | IT系统开发、维护、数据中心运营     |
| **BPO** | 业务流程外包 | 人力资源管理、财务会计、客户服务呼叫中心 |
| **KPO** | 知识流程外包 | 研发、设计、数据分析等高知识含量业务   |


#### 7.3 国际服务外包（离岸外包）

- 发包方主要来自：美国、欧盟、日本等发达国家
- 接包方主要来自：印度、中国、菲律宾等发展中国家
- 驱动因素：劳动力成本国际差异+通信技术降低远距离协调成本

#### 7.4 对发展中国家的意义

- 创造大量就业机会
- 增加外汇收入
- 促进技术溢出和本土能力建设
- 推动本国服务业升级

## 第四部分：关于中国的国际服务贸易

### 8. 中国的国际服务贸易发展概况

#### 8.1 现状特征

1. **规模持续扩大**：中国已成为全球第二大服务贸易国
2. **长期保持逆差**：服务进口大于出口
  - 主要逆差领域：旅行、运输、知识产权使用费
  - 主要顺差领域：建筑服务、其他商业服务、加工服务
3. **结构变化**：传统服务（旅游、运输）占比下降，新兴数字服务占比上升

#### 8.2 发展趋势

- 服务出口竞争力逐步提升
- 高质量发展成为主题
- 更加注重扩大服务进口

## 第五部分：关于技术和知识产权贸易

### 13. 国际技术贸易

#### 13.1 定义

不同国家企业之间关于**技术使用权**的跨国转让交易

#### 13.2 主要交易标的

- 工业产权：专利权、商标权
- 专有技术（技术秘密/know-how）
- 版权
- 技术咨询与技术服务

#### 13.3 主要交易方式


| 方式         | 说明                      |
| ---------- | ----------------------- |
| **许可证贸易**  | 最主要方式，许可方授予被许可方技术使用权    |
| **特许经营**   | 品牌+技术+管理模式整体许可，如麦当劳、肯德基 |
| **合作生产**   | 技术转让与生产合作相结合            |
| **技术咨询服务** | 提供技术咨询、方案设计等服务          |


#### 13.4 特点

- 交易标的是**无形**的技术知识
- 通常只转让**使用权**，不转让所有权
- 交易过程复杂，谈判周期长
- 涉及知识产权保护问题

#### 13.5 对发展中国家的作用

- 获取国外先进技术
- 缩短自主研发周期
- 促进本国技术进步
- 提升产业技术水平

### 14. WTO《与贸易有关的知识产权协定》（TRIPS）

#### 14.1 概述

TRIPS是WTO框架下的国际知识产权协定，是当前国际上**最全面**的多边知识产权保护协定

#### 14.2 基本原则

1. **国民待遇**：给其他WTO成员国民不低于本国国民的保护
2. **最惠国待遇**：给任何一个成员的优惠自动给予所有成员
3. **平衡保护**：知识产权保护应当促进技术进步，增进社会福利

#### 14.3 保护范围

TRIPS要求保护以下七类知识产权：

1. 版权及相关权利
2. 商标
3. 地理标志
4. 工业设计
5. 专利
6. 集成电路布图设计
7. 未披露信息（商业秘密）

#### 14.4 最低保护期限

- 专利：至少**20年**
- 版权：至少作者终生加**50年**

#### 14.5 执法要求

- 要求各成员建立完整的知识产权执法程序
- 提供民事、行政、刑事三种救济途径
- 允许海关采取边境措施扣留侵权货物
