# 跨境电商Pre讲稿与期末复习资料_优化版（提取文本）

跨境电商课程项目讲稿与期末复习资料（优化版）
项目：汕尾梅陇珠宝供应链——925银饰/珍珠耳饰出口文莱｜版本：Presentation + Exam Review
一、先给组员文件做优化判断
组员文件的方向是对的：已经覆盖了商品、目的国、税费、原产地证、出口模式几个核心点，基本对应老师给出的“关税+境内税、区域贸易协定/海外仓、原产地证获取”重点。但原稿有三类需要修正或强化的地方：
税费口径要拆开：关税、境内税/消费税、协定税率不能混写。文莱官方口径中，珠宝及仿首饰进口关税为 Nil，消费税/Excise Duty 为15%；同时文莱不征收VAT或销售税。因此讲解时应说“文莱没有增值税，珠宝进口端重点是进口关税与消费税/Excise”。
RCEP与中国—东盟自贸协定不要混淆。项目更适合优先讲中国—东盟自贸协定/Form E，因为文莱属于东盟，且组员资料中也写到东盟协定税率为0%。如果引用RCEP税率，应以实际查询数据库为准，原稿中“RCEP 4%”与后文“RCEP 15%”存在不一致，应删除后文“RCEP 15%”表述。
原产地证部分不能只写流程截图，应讲清楚“为什么要办、办什么证、怎么申请、提交哪些资料、对项目有什么价值”。本项目应办理中国—东盟自贸区优惠原产地证书，即Form E，用来证明货物为中国原产，以便目的国进口清关时申请协定优惠税率。
最终建议：Presentation 以“项目逻辑”为主，讲清楚我们为什么选银饰/珍珠耳饰、为什么选文莱、税费怎么影响定价、为什么选9610，以及Form E怎么降低合规风险；期末复习版则按老师开放题目整理成可背诵的问答模板。
二、Presentation简略讲稿（适合上台讲PPT）
建议时长：4—6分钟。语速正常时约900—1200字。可以直接按下面讲。
1. 开场：项目定位
我们小组的跨境电商项目，选择的商品是925银饰和珍珠耳饰，主要对接汕尾梅陇珠宝供应链，出口目的国选择文莱。我们的项目逻辑不是单纯找一个便宜商品去卖，而是围绕“供应链优势、目标市场适配、税费成本、通关模式和原产地规则”来做综合判断。
2. 为什么选择925银饰和珍珠耳饰
首先，从供给端看，汕尾梅陇本身具有比较成熟的珠宝首饰产业基础，925银饰和珍珠耳饰的生产、设计、加工和配套都比较成熟，能够形成成本优势和款式更新优势。其次，从跨境电商属性看，这类商品具有体积小、重量轻、客单价相对较高、运输成本占比低、适合小包直邮的特点。对于中小卖家来说，它比大件商品更适合通过跨境电商零售模式试水。
同时，925银饰和珍珠耳饰的款式变化空间大，可以做轻奢、日常通勤、礼品、宗教文化适配等不同定位，比较适合在TikTok、Shopee、Instagram等内容电商和货架电商场景中展示。
3. 为什么选择文莱作为目的国
我们选择文莱，主要基于三个原因。第一，文莱人均收入较高，消费者有一定购买力，适合非黄金类饰品和轻奢饰品切入。第二，文莱属于东盟成员，和中国之间可以适用中国—东盟自贸协定，这为首饰产品争取优惠关税提供了制度基础。第三，文莱市场规模虽然不大，但竞争强度相对没有欧美市场那么激烈，也暂时没有像欧美那样对中国小包裹进行大规模政策收紧，因此适合中小卖家做“小市场切入、低库存测试、逐步复购”的模式。
4. 目的国税费：关税+境内税/消费税
在税费方面，需要区分关税和境内税。根据文莱公开税务与海关信息，文莱不征收VAT或销售税，因此我们不需要像进入欧盟、新加坡等市场一样重点考虑进口增值税或消费端GST。对于珠宝品类，文莱官方资料显示“Jewellery including imitation jewellery”的进口关税为Nil，但有15%的Excise Duty。换句话说，项目定价时不能只看“零关税”，还要把15%的消费税/货物税因素算进去。
如果我们能够通过中国—东盟自贸协定取得Form E原产地证，就可以在目的国清关时更有依据地申请协定优惠待遇。这里的关键不是单纯说“免税”，而是用原产地证证明货物符合协定原产资格，降低通关不确定性。
5. 出口模式：为什么选择9610
在9610、1210、9710和9810四种模式中，我们更倾向于选择9610。原因是我们的项目初期是B2C零售订单，商品是小体积、高货值、多款式，订单具有小批量、多批次、试错频繁的特点。9610也就是跨境贸易电子商务零售出口，适合境内企业通过电商平台把商品直接发给境外消费者，并采用“清单核放、汇总申报”的方式提高通关效率。
相比之下，1210更适合保税备货，通常用于跨境进口或特殊区域备货；9710更适合B2B直接出口；9810适合已经有稳定销量、需要提前备货到海外仓的企业。本项目初期市场验证还不充分，如果一开始就选择海外仓，会产生库存、仓储和滞销风险。所以，我们的策略是先用9610低成本测试市场，等订单稳定后，再评估是否通过9810或海外仓提升履约速度。
6. 原产地证：办什么、为什么、怎么用
本项目如果要享受中国—东盟自贸协定优惠，核心单证是中国—东盟自贸区优惠原产地证书Form E。它的作用是证明出口货物原产于中国，是进口国海关判断是否给予协定关税优惠的重要依据。
操作上，企业可以通过中国国际贸易“单一窗口”或“互联网+海关”等线上系统申报，选择对应的中国—东盟自贸协定证书类型，填写出口商、收货人、运输路线、发票、HS编码、货物描述、原产地标准等信息，提交后由海关或贸促会等签证机构审核。通过后再随商业发票、装箱单、提单或物流单据一起提供给进口方用于清关。
7. 结尾：项目总结
总的来说，我们项目的核心思路是：用汕尾梅陇珠宝供应链提供产品和成本基础，用文莱作为东盟小市场切入口，用9610模式降低前期履约和库存压力，再通过Form E原产地证和自贸协定降低关税与通关风险。这个方案的重点不是追求一开始就大规模铺货，而是先用轻资产、低库存、小包直邮的方式验证需求，再根据销量决定是否升级到海外仓或B2B模式。
三、期末复习版：开放题目答题模板
下面这一版更适合你自己复习。考试如果围绕小组项目出开放题，可以按“结论先行—项目依据—课程知识点—风险/优化”四步写。
题目1：选择什么商品出口？为什么？
参考答案：我们小组选择出口925银饰和珍珠耳饰。原因主要有四点。第一，供应链端具有优势，项目可以对接汕尾梅陇珠宝供应链，当地珠宝首饰加工产业较成熟，具备成本、款式、加工和小批量供货优势。第二，产品适合跨境电商，925银饰和珍珠耳饰体积小、重量轻、客单价相对较高，运输成本占比低，适合小包直邮。第三，产品具有内容营销空间，饰品类商品依赖视觉展示，可以通过短视频、图文种草和直播展示款式、佩戴效果与礼品属性。第四，该品类适合中小卖家轻资产试错，不需要大件仓储和复杂售后，能够通过多SKU、小批量方式测试市场。
答题关键词：供应链成熟；轻小件；高货值；多SKU；小包直邮；内容电商；低库存试错。
题目2：选择哪个国家作为出口目的国？为什么？
参考答案：我们选择文莱作为出口目的国。第一，文莱人均收入较高，消费者具备一定购买力，适合轻奢饰品、银饰、珍珠耳饰等非黄金类饰品切入。第二，文莱属于东盟成员，中国与东盟之间存在自贸协定安排，出口企业可通过中国—东盟自贸区优惠原产地证书Form E申请协定优惠关税，从而降低进口端税费不确定性。第三，文莱市场规模较小，但竞争压力相对低于欧美成熟市场，也暂未出现欧美针对中国跨境小包裹的强烈政策收紧，因此适合中小卖家作为区域市场切入点。第四，文莱具有穆斯林文化背景，饰品设计可围绕日常、礼品、简洁、精致等方向做本地化适配。
答题关键词：高收入小市场；东盟成员；自贸协定；Form E；竞争较低；文化适配。
题目3：该地区针对小包裹现行关税、增值税、消费税规则怎样？
参考答案：对于文莱市场，需要分清关税、增值税和消费税/货物税。文莱不征收VAT或销售税，因此不存在类似欧盟VAT、新加坡GST那样的进口增值税负担。文莱进口税制主要看商品是否属于应税货物、适用的进口关税和Excise Duty。以珠宝类商品为例，文莱公开资料显示珠宝及仿首饰进口关税为Nil，但Excise Duty为15%。因此，本项目不能简单理解为“零税负”，而应在定价中考虑15%的消费税/货物税因素。
如果考试要求结合区域贸易协定，则可补充：文莱为东盟成员，中国出口至文莱的产品如符合中国—东盟自贸协定原产地规则，并能提供Form E原产地证，可申请协定税率优惠。实际清关时还需要结合HS编码、完税价格、物流方式和进口方申报材料判断。
题目4：若目的国近期小包关税政策有调整，变化是什么？对中小直邮卖家有什么影响？
参考答案：就我们选择的文莱而言，目前未查到类似美国取消低值包裹免税、欧盟拟取消150欧元以下小包免关税那种针对跨境小包的大规模收紧政策。因此，本项目面对的核心不是“小包免税政策取消”的冲击，而是要准确核算珠宝类商品的进口关税与Excise Duty，并保证单证合规。
但从全球趋势看，欧美等主要市场正在收紧低值小包政策，对中国直邮卖家的影响包括：第一，低价直邮优势下降，税费和清关成本上升；第二，平台和物流商需要承担更多合规申报责任；第三，卖家需要更重视HS编码、真实申报、原产地、完税价格和退货安排；第四，部分卖家会从纯直邮转向海外仓、本地履约或B2B批量出口。对我们项目而言，选择文莱和东盟小市场，可以在一定程度上避开欧美政策高压区，但仍必须做好税费核算和原产地证明。

题目6：我国跨境电子商务零售进口现行税收优惠政策是什么？
注意：这道题问的是“中国跨境电商零售进口”，不是我们项目的“出口文莱”。考试时要单独回答。
参考答案：我国跨境电子商务零售进口现行优惠政策主要包括：在规定限值以内的跨境电商零售进口商品，关税税率暂设为0%；进口环节增值税、消费税取消免征税额，暂按法定应纳税额的70%征收。现行额度方面，单次交易限值为人民币5000元，个人年度交易限值为人民币26000元。完税价格超过5000元单次交易限值但低于26000元年度交易限值，且订单下仅有一件商品的，可以通过跨境电商零售渠道进口，但应按照货物税率全额征收关税和进口环节增值税、消费税，并计入个人年度交易总额；超过年度限值的，一般按一般贸易管理。
答题关键词：限值内；关税暂设0%；增值税/消费税按70%；单次5000元；年度26000元；超限按规则全额征税或一般贸易。
题目7：区域贸易协定和原产地证在本项目中的作用是什么？
参考答案：区域贸易协定的核心作用是通过成员国之间的优惠关税安排降低贸易成本，但企业不能只因为目的国属于自贸协定成员就自动享受优惠税率，还必须证明产品符合原产地规则。本项目目的国文莱属于东盟成员，因此可以考虑适用中国—东盟自贸协定。为了享受优惠待遇，企业应申请中国—东盟自贸区优惠原产地证书Form E。
Form E的作用主要有三点：第一，作为进口国海关判定货物原产地和适用优惠关税的依据；第二，降低企业进口端税费成本和清关不确定性；第三，提高贸易合规性，避免因单证不齐导致补税、延误或无法享受优惠。申请时需要通过中国国际贸易“单一窗口”或相关系统填写出口商、进口商、货物描述、HS编码、发票、运输信息、原产地标准等，并随商业发票、装箱单、物流单据一起用于清关。
题目8：本项目是否需要海外仓？
参考答案：本项目初期不建议直接使用海外仓。原因是文莱市场规模较小，需求还需要验证，而925银饰和珍珠耳饰虽然体积小、适合备货，但款式多、流行变化快，若提前大量铺货到海外仓，可能出现库存积压和资金占用。更稳妥的方案是：第一阶段使用9610直邮模式，低库存测款；第二阶段根据订单数据筛选爆款；第三阶段如果复购稳定、订单密度上升，再考虑9810出口海外仓或区域海外仓，提高履约时效和用户体验。

结论：我们选择某商品/某国家/某模式。

2. 30秒口头总结
我们项目选择汕尾梅陇供应链下的925银饰和珍珠耳饰出口文莱。选择该品类，是因为它轻小、高货值、多款式，适合跨境电商小包直邮；选择文莱，是因为其人均收入较高、属于东盟成员、可通过中国—东盟自贸协定和Form E争取优惠待遇。税费方面，文莱不征收VAT或销售税，但珠宝类商品需要关注进口关税和15%的Excise Duty。出口模式上，我们优先选择9610，因为它适合B2C零售、小批量、多批次、低库存测款；等销量稳定后，再考虑9810海外仓。
