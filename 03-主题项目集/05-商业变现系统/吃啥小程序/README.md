# 「吃啥！」小程序 — 校园干饭决策工具

## 项目简介

「吃啥！」是一款解决大学生"选择困难症"的微信小程序，由 Kunki 和两位师弟合作开发。

**核心痛点**：大学生每天都会遇到难题 —— "今天到底吃什么？"，纠结半天谁也做不了决定。

**解决方案**：通过随机抽卡帮你做决定。选学校、选范围、排除不想吃的店，点一下抽卡，不知道吃什么就让命运告诉你。

## 产品设计

### IP 形象
设计了一只橘猫 IP 叫 **「干饭咪」**，希望它不只是一个冷冰冰的工具，更像一个每天饭点准时出现、陪你一起纠结、最后帮你拍板的校园干饭搭子。希望产品有陪伴感、有情绪、有记忆点。

### 功能模块

| 模块 | 功能说明 |
|------|----------|
| 🍜 **吃啥** | 随机抽一家餐饮店铺，食堂/外卖都支持 |
| 🧋 **喝啥** | 随机抽一杯具体饮品，蜜雪、喜茶、星巴克、奈雪等，支持按品牌筛选，复制商品名直接美团下单 |
