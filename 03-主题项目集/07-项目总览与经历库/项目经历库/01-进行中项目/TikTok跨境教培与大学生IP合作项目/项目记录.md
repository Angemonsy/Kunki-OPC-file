## 12. 核心共识（从沟通中提炼）

1. **产品认知**：新手做产品不需要一开始就做到完美，只要能解决用户当下痛点就是有价值的，完美主义会导致内耗，小步试错逐步迭代才是正确路径
2. **AI产品时效性**：AI时代工具迭代快，纯录播课程时效性差，推荐用可实时更新的飞书文档+直播结合的交付形式
3. **合作认知**：不要逼自己做六边形战士，找能力互补的同频伙伴一起干，比一个人单打独斗效率高很多，不容易钻牛角尖
4. **产品定位逻辑**：不要卖工具，要卖"用工具解决用户问题"，解决实际问题的产品才值钱，不容易被替代

## 13. 项目运作模式与分成机制

**整体流程：**
- 公开课获客 → 转化训练营 → 交付 → 复盘迭代
- 目标：6月10号前积累意向客户，目标拉满 **30-50人** 公开课
- 定位：轻交付，只给1-2个核心工作流，训练营定价99元

**公开课获客模式：**
- 私域拉人 + 两节公开课
- 交付押金99元，**课程到场听完并写完复盘可退还**
- 如果报名训练营，则押金不退还，直接抵扣学费
- 公开课讲师：对方讲IP定位，我讲AI技术赋能

**需要筹备的物料：**

**阶段一（公开课）：**
- [ ] 发售主海报（对方负责）
- [ ] 公开课PPT/教案讲义 + 自我介绍 + 讲稿（双方各自准备自己部分）
- [ ] 产品福利（咨询看账号名额、AI提示词等）
- [ ] 产品付款二维码 + 产品海报
- [ ] 产品转化话术

**阶段二（训练营交付，预计2-3天/2-3场）：**
- [ ] 理论+工作流现场实操直播授课（后期制作成回放），我负责AI部分屏幕共享演示操作
- [ ] 社群运营话术
- [ ] 复盘作业机制

**分成机制：**
- 销售（人头提成）：30%
