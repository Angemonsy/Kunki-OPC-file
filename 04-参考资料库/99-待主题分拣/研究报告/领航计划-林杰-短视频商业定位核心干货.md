## 一、核心认知：短视频获客 = 艺人公司

### 1.1 账号赚钱 ≠ 粉丝量

**核心结论：** 账号能不能赚钱，跟粉丝量没有一毛钱关系，只跟你的**商业定位**有关。

- 除非你靠接广告赚钱，否则粉丝量没用
- 有些大号粉丝特别多，但商业价值不高，广告费也很低
- 定位对了，小账号也能赚钱

### 1.2 短视频获客工业化流程

定位 → 账号装修 → AI内容系统 → 选题 → 脚本 → 拍摄 → AI剪辑 → 表现力调整 → 获客

**定位是总开关**，决定后面所有环节。

### 1.3 悖论：素人不要纠结定位

> 对于没有产品的素人小白来说，定位是一道紧箍咒，一旦纠结定位，你会发现你什么都干不了。

**核心建议：**
- 先干起来，边做边调整
- 先拍视频，把系统用起来，这才是最关键
- 听完课理解原理就行，不要卡住纠结
- 账号做起来之后，再来校正定位

## 二、本质区别：线下营销 vs 线上短视频营销

### 2.1 线下营销本质（C→D点）

- 用户已经有需求才会上门
- 大家产品服务差不多，最后卷价格战
- 很多老板把线下逻辑搬到线上：默认刷视频的人已经有需求

### 2.2 短视频营销本质（A→B→C→D）

- **90%的人刷短视频是无聊消遣，没有任何需求**，都在A点和B点
- 核心不是展示产品，而是**先激发兴趣，激发需求**
- 完成A→B的转化，让用户停下来听你说话，再建立信任，最后成交

### 2.3 常见误区

全账号都是CD点内容（纯产品介绍）→ 营销味太重，用户信任度低 → 很难成交。

**正确做法：** 先讲故事→建立信任→激发需求→带出产品。就像安顿护心手表那个案例：

1. 讲3亿负债东山再起的故事（A→B，抓住注意力）
2. 讲如何研发产品（建立信任）
3. 讲已经救了3万多人（证明效果）
4. 最后带出产品（C→D成交）

## 三、商业定位五大步骤（四步法+避坑）

```
定赛道 → 定产品 → 定用户 → 定内容方向 → 定人设
```

> 为什么把人设放最后？因为人设是做出来的，不是规划出来的，先干起来最重要。

### 3.1 四大核心原则

1. **少即是多**：聚焦细分赛道，不要贪多
2. **内容产品强关联**：内容围绕产品转
3. **定位动态变化**：先干起来，边走边调
4. **变现导向**：一切都是为了提高准客户含量（精准客资/总观看量）

**准客户含量公式：**
```
准客户含量 = 目标客户数 ÷ 总观看数
```
精准流量远大于泛流量，我们最终是为了成交。

---

## 四、第一步：向内求 → 找到细分赛道

### 4.1 三圈交集法

找 **擅长** ∩ **喜欢** ∩ **值得做（能赚钱）** 的交集

- 如果找不到交集，**优先选你擅长的**
- 喜欢这件事是需要正反馈的，不能赚钱你很难一直喜欢

### 4.2 怎么判断自己擅长什么？

- 过去经常在哪些事情上面成功？
- 别人经常在哪些方面夸奖你？
- 哪些人经常来请教你？
- 哪个方向你学起来比别人更快？

## 五、第二步：向外看 → 分析赛道竞品

### 5.1 判断标准

1. **看同行**：有没有中小玩家赚到钱？随便找20个，都能赚到钱，你去做自然也能赚到钱；如果只有头部赚钱，慎入。
2. **看市场**：选市场大、增速快的赛道，水大才好养鱼。

### 5.2 产品定价重构五步法（定价定江山）

1. **竞品摸底**：了解对手定价
2. **问题诊断**：发现自己定价尴尬问题
3. **差异化挖掘**：从用户/产品/服务三个维度找差异
4. **产品重构**：拆分不同价格带产品
5. **价值包装**：讲清楚差异化结果

### 5.3 定价案例：知识付费

- 大IP卖6800，普遍流通货卖999，你原来定3980 → 尴尬！
  - 高不成低不就，用户会比价：为什么不买999？为什么不买6800？
- 差异化挖掘：发现来找你的最多的是**有手艺有产品的老板，想快速起号接单**，这波人效果最好
- 差异化：
  - 用户差异化：只服务"有手艺想接单"的这群人
  - 效果差异化：80%第一个月接到单，送一对一诊断，给出现成变现路径
- 产品重构：拆分出两个产品
  - 基础版：999（低门槛留人）
  - 高端版：5980（包结果，服务差异化）
- 结果：价差6倍，用户从"拒绝"变成"选择"，转化率提升

### 5.4 定价案例：实体私教

- 头部卖6000，普通卖1500，你定4999 → 尴尬
- 差异化挖掘：发现**产后宝妈**来的最多，最迫切，最容易出效果
- 差异化：只做产后宝妈，用户细分，差异化
- 产品重构：基础入门 + 高端一对一专属方案
- 结果：避开价格战，转化率提升

### 5.5 核心思维：避竞争不如差异化

> 创业最聪明的方式不是参与竞争，而是**避开竞争**。找到细分人群，做出差异化。

## 六、第三步：定位万能公式 → 用户→内容→人设

### 6.1 用户画像

- **调研付费用户**：他们为什么愿意为你付费？解决什么需求？为什么掏钱？
- **谁掏钱谁就是你的目标客户**（这个很反常识但很重要）
  - 例子：卖小学AI培训课 → 掏钱的是家长，不是小孩 → 目标客户是家长
  - 例子：律师给被告打官司 → 掏钱的是家属 → 目标客户是家属

### 6.2 用户四种心理状态（A/B/C/D）

| 状态 | 用户心理 | 内容应对 |
|------|---------|---------|
| A点 | "跟我有什么关系？" → 一秒划走 | 开头必须抓注意力 |
| B点 | 多看几秒 → 痛点激发 | 痛点型内容 |
| C点 | 已经有需求，对比选择 | 专业信任内容 |
| D点 |  ready to buy → 准备购买 | 直接成交广告 |

### 6.3 内容方向两个维度

**维度一：按目的分**（对应A/B/C/D）

- **拉新/泛话题**：扩大流量圈子，打A点
- **建立信任/痛点型**：让人相信你能解决问题，打B点
- **促成交/成交型**：增强下单信心，打C点
- **通知型/广告**：老客户通知新产品，打D点

**维度二：按表达方式分**

- **聊观点**：表达态度看法
- **晒过程**：真实记录，vlog
- **教知识**：干货方法
- **讲故事**：共鸣，建立信任

**交叉组合**：目的 × 表达方式 = 你的内容选题

例子：目的是建立信任（打B点） + 表达方式是讲故事 → 讲学员一个月接到第一单的故事

### 6.4 人设五种类型（成本由高到低）

1. **崇拜者**（最高级，客单价最高）
2. **陪伴者**
3. **搞笑者**
4. **教练/导师**
5. **反差者**

**核心建议：**
- 最低成本做人设：你本来是什么样就是什么样，拿起手机就能拍，不要搞道具特效
- 人设不是定出来的，是慢慢做出来的
- 超级符号：视觉锤（发型/服装/道具）+ 语言钉（金句口头禅）+ 价值观（最高级）
- **克制就是态度**：到一定阶段，知道不发什么比发什么更重要
- **反差公式**：行业定位 + 反差性格 = 强记忆点，例如：物流老板 + 有良心 = 记忆点

## 七、第四步：定位避坑

1. **商业访谈类不要做**：成本极高，要求高，产出低
2. **低价社群不要做**：99块钱服务一年，违背商业逻辑，很难持续运营，不如直接卖智能体

### 10.3 A/B/C/D理论对你内容创作的启示

你的账号大部分内容就是打**A→B→C**，完全正确：

**关键提醒**：不要全账号都是硬广，会降低信任度。保持"内容80%，成交20%"的比例就好。

继续强化这个差异化就好，不需要变。
