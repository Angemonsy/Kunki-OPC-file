# Social Transcriber Skill — 短视频一键转逐字稿

> 一句话：把抖音或小红书链接丢给 Codex 或 Claude Code，自动下载视频、提取音频、生成字幕和逐字稿。

## 发布信息

- 发布日期：2026年5月25日
- 定位：Claude Code / Codex Skill
- 场景：中文短视频内容提取、爆款分析、对标研究

## 核心工作流

1. **输入**：用户提供抖音 / 小红书视频链接
2. **自动下载**：爬取下载视频文件到本地
3. **音频提取**：从视频中分离出音频轨道
4. **语音转录**：AI语音识别生成字幕
5. **输出**：产出 `.srt` 字幕文件 + `.md` 整理好的逐字稿

## 适用场景

- ✅ 爆款短视频拆解分析
- ✅ 对标博主内容批量研究
- ✅ 公开课/讲座视频文字化
- ✅ 观点型视频干货提取
- ✅ 金句文案素材积累

## 与领航内容创作系统协同

```
用户丢链接 → Social Transcriber → 逐字稿 → 
  ├─→ 爆款拆解改写 (现有Skill)
  ├─→ 录音稿提炼选题专家 (现有Skill)
  ├─→ 爆款复盘分析 (现有工作流)
  └─→ 存入爆款案例库
```

## 优势对比

| 方式 | 时间 | 自动化 | 适合场景 |
|------|------|--------|---------|
| 手动下载+转写 | 10-15分钟 | ❌ | 偶尔一次 |
| 第三方在线工具 | 3-5分钟 | ⚠️ 需要手动步骤 | 中等频率 |
| Social Transcriber | 1-2分钟 | ✅ 全流程全自动 | 高频爆款研究 |

## 笔记

实用性很强，对于需要频繁从中文短视频平台获取内容做分析的场景，省去了大量手动转录的麻烦。整个流程全自动，输出结构化本地文件，方便后续AI分析处理。
