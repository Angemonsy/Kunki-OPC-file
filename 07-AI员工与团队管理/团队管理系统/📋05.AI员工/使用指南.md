# AI员工使用指南

> 10个Claude Code窗口 = 8个AI员工 + 2个备用
> 核心动作：开窗口打 `/启动 XX`，关窗口它自动存记忆

---

## 窗口一览

| 窗口   | 命名      | 干什么                      | 频率  |
| ---- | ------- | ------------------------ | --- |
| 1    | 🐱 叮当猫  | 总管+记忆+战略+日常对话            | 每天  |
| 2    | ✍️ 内容工厂 | 选题→公众号→短视频→各类文案          | 每天  |
| 3    | 📢 营销获客 | 发布分发+引流钩子+转化+朋友圈         | 每天  |
| 4    | 📚 产品交付 | 课程+录课+手册+交付物+直播+社群       | 每天  |
| 5    | 📊 数据参谋 | 数据采集+复盘+热点+对标+PLAYBOOK   | 每周  |
| 6    | 👥 团队管家 | 招聘+方案+薪资+考核+管理           | 每周  |
| 7    | 🔧 系统研发 | OpenClaw+bot+Agent+插件+代码 | 需要时 |
| 8-10 | 备用      | 新业务线/临时项目                | 待定  |

## 每天怎么用

### 早上开工

打开 **窗口1 叮当猫**（自动跑启动协议）
- 告诉你本周进度、草稿箱/待发布状态
- 扫公告板，看其他员工有没有传话
- 建议你今天该干啥

### 上午写内容

切到 **窗口2**，说 `/启动 内容工厂`
- 它自动读完PLAYBOOK、风格偏好、选题库、上次记忆
- 你直接说"帮我写篇文案"就开干，不用@任何文件
- 写完自动存草稿箱
- 结束时自动更新记忆 + 往公告板通知营销获客

### 写完发布

切到 **窗口3**，说 `/启动 营销获客`
- 它扫公告板，主动告诉你"有一篇新文案可以发了"
- 帮你分发到各平台、转小红书图文、写朋友圈文案

### 下午产品/交付

切到 **窗口4**，说 `/启动 产品交付`
- 处理课程内容、交付物、直播稿、社群内容
- 交付执行员工入职后配合他的工作出物料和SOP

### 每周固定

- **窗口5 数据参谋**：看数据、做复盘、更新PLAYBOOK，结论通知内容工厂
- **窗口6 团队管家**：看周报、算提成、处理招聘

### 需要时才开

- **窗口7 系统研发**：改代码、调bot的时候

## 上下文断了怎么办

对话太长token爆了 / 隔了几天再用，直接说：

```
/启动 内容工厂
```

3秒恢复：
1. 角色卡 → 知道自己是谁
2. 记忆文件 → 知道上次做到哪
3. 必读文件 → 恢复完整上下文
4. 公告板 → 看有没有新消息

## 信息怎么在员工之间流转

```
内容工厂写完文案
  → 公告板写"@营销获客 新文案可发"
     → 营销获客启动时看到，主动说"有篇文案可以发了"

数据参谋发现爆款规律
  → 公告板写"@内容工厂 建议多写XX类"
     → 内容工厂启动时看到，调整选题方向

任何员工有重要发现
  → 公告板写"@叮当猫 建议更新PLAYBOOK/MEMORY"
     → 叮当猫早上扫到，决定是否写入全局记忆
```

叮当猫每天早上扫公告板 → 处理完的移到"已处理"区

## 记忆系统（三文件结构）

每个AI员工在 `📋05.AI员工/记忆/{角色名}/` 下有3个文件：

| 文件 | 干什么 | 谁来更新 | 频率 |
|------|--------|---------|------|
| **ROLE.md** | 角色定义：职责、行为准则、知识文档路径 | 你/叮当猫 | 角色调整时 |
| **MEMORY.md** | 经验记忆：踩坑记录、偏好、规律沉淀 | AI员工自己 | 有新经验时追加 |
| **STATUS.md** | 当前状态：进行中事务、待办、最近动作 | AI员工自己 | 每次对话结束必更新 |

### 启动时自动读取

```
你说"团队管家"
  → skill识别角色名
    → 自动读取 记忆/团队管家/ROLE.md
    → 自动读取 记忆/团队管家/MEMORY.md
    → 自动读取 记忆/团队管家/STATUS.md
      → AI知道自己是谁、有什么经验、上次做到哪了
```

### 结束时自动写回

```
你说"先这样" / 对话结束
  → AI自动更新 STATUS.md（本次做了什么、新待办）
  → 有新经验 → 追加 MEMORY.md
  → 有跨窗口信息 → 写公告板
```

### 记忆层级

| 层级 | 谁能写 | 存什么 |
|------|--------|--------|
| 公司级（叮当猫的MEMORY.md等） | 只有叮当猫 | 老板身份、偏好、战略、全局记忆 |
| 岗位级（各员工三文件） | 对应员工 | 角色定义 + 工作经验 + 当前状态 |
| 传话（公告板） | 所有员工 | 跨窗口信息传递 |

### 记忆维护

- **STATUS.md**：每月初旧记录移到 `归档/`，只保留最近30天
- **MEMORY.md**：长期保留，验证过的经验不清理
- **ROLE.md**：基本不动，除非角色职责调整

## 核心就两个动作

1. **开窗口时**：打一句 `/启动 XX`
2. **对话结束时**：它自动存记忆 + 写公告板

其他的不用管，系统自己跑。

## 你只需要记住的事

| 动作 | 你要做的 | AI自动做的 |
|------|---------|-----------|
| 开工 | 说角色名（如"团队管家"） | 读角色卡+记忆三文件+必读文件+公告板 |
| 干活 | 正常聊天布置任务 | 正常执行 |
| 收工 | 说"先这样"或关窗口 | 更新STATUS.md + 追加MEMORY.md + 写公告板 |
| 断了 | 重新说角色名 | 3秒恢复，无缝接上 |

**一句话：说名字开工，说完事收工，记忆全自动。**
