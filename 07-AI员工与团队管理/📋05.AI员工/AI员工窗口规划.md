# AI员工窗口规划

> 用途：10个Claude Code对话窗口 = 10个AI员工，专职专责，像团队一样分工
> 当前使用：8个活窗口 + 2个备用
> 最后更新：2026-04-01（v2：加入团队管家+角色卡+记忆+公告板体系）

---

## 总览

| 窗口   | 命名      | 一句话定位                          | 使用频率 |
| ---- | ------- | ------------------------------ | ---- |
| 1    | 🐱 叮当猫  | 总管：记忆+日常对话+战略决策                | 每天   |
| 2    | ✍️ 内容工厂 | 全部内容创作：选题→公众号→短视频→各类文案         | 每天   |
| 3    | 📢 营销获客 | 获客全链路：发布分发+引流钩子+各平台转化+销售话术     | 每天   |
| 4    | 📚 产品交付 | 产品全生命周期：课程+录课+手册+交付物+直播+社群     | 每天   |
| 5    | 📊 数据参谋 | 数据闭环：采集+复盘+热点研究+对标+PLAYBOOK    | 每周   |
| 6    | 👥 团队管家 | 团队管理：招聘+方案+薪资+考核+管理            | 每周   |
| 7    | 🔧 系统研发 | 技术全部：OpenClaw+bot+Agent+插件+自动化 | 需要时  |
| 8-10 | 备用      | 新业务线/临时大项目/员工专用/测试            | 待定   |

## 分工边界（防止搞混）

| 容易混的 | 怎么分 |
|---------|--------|
| 内容工厂 vs 营销获客 | 内容工厂只管"生产内容"，营销获客只管"发出去+让人买" |
| 内容工厂 vs 产品交付 | 内容工厂是公域内容（公众号/短视频），产品交付是付费产品（课程/交付物/直播） |
| 营销获客 vs 产品交付 | 营销获客管"还没付钱的人"，产品交付管"已经付钱的人" |
| 数据参谋 vs 内容工厂 | 数据参谋只看数据和出结论，不写文案。结论反馈给内容工厂执行 |
| 叮当猫 vs 团队管家 | 叮当猫管战略决策和日常对话，团队管家管具体的招聘/薪资/考核/管人执行 |
| 叮当猫 vs 其他所有 | 叮当猫是调度中心+公告板处理者，不干具体活 |

## 每日打开顺序

```
早上开工 → 🐱 叮当猫（状态同步，今天干啥）
上午核心 → ✍️ 内容工厂（选题→写文案→转短视频脚本）
写完之后 → 📢 营销获客（发布+分发+做引流素材+朋友圈）
下午产品 → 📚 产品交付（课程内容+交付物+配合交付执行员工）
每周定期 → 📊 数据参谋（看数据+复盘+出优化建议）
需要时开 → 🔧 系统研发（写代码改系统的时候）
```

---

## 客户旅程全覆盖

```
陌生人看到你 → ✍️ 内容工厂（生产内容吸引他）
     ↓
想了解更多 → 📢 营销获客（引流钩子+私信接待+朋友圈种草）
     ↓
付费购买 → 📚 产品交付（课程+交付物+社群+教练）
     ↓
想升单 → 📢 营销获客（升单话术+客户见证）+ 📚 产品交付（高端交付）
     ↓
数据回流 → 📊 数据参谋（复盘+优化→反馈给内容工厂）
```

## 各窗口详细说明

### 窗口1：🐱 叮当猫（总管）

**定位**：调度中心+公告板处理者，管战略决策和日常对话

**对应业务清单**：战略大脑

**职责范围**：
- 记忆系统（启动协议、状态同步、周文件管理）
- 日常对话、问答、闲聊
- 战略决策（定价、合作、方向）
- 财务回顾（月度经营复盘）
- 商务合作评估
- 风险雷达监控
- 公告板处理（扫描其他员工的传话，分发或处理）

**核心skills**：
- 月度经营复盘
- dbs系列诊断工具
- 资产负债分析
- 每日工作规划助手

**注意**：团队管理的具体执行（招聘/方案/薪资/考核）已移至👥团队管家窗口

---

### 窗口2：✍️ 内容工厂

**定位**：全部内容创作，从选题到成稿

**对应业务清单**：内容创作与流量（8项）

**职责范围**：
- 选题生成、验证、评分
- 公众号爆款文案生产（所有文案类型）
- 短视频口播脚本
- 长文转短视频
- 录音稿/灵感碎片/用户提问/社群精华→文案
- 爆款拆解改写、衍生系列
- 标题生成
- 对标账号内容分析

**核心skills**：
- 选题系列：选题生成、选题验证评分、选题匹配爆款模板、爆款内容选题策划师
- 文案生产：公众号爆款生产、教知识文案、讲故事文案、聊观点文案、录音稿转文案、灵感碎片转文案、用户提问转文案、社群精华转文案、对话转文案、实战复盘转内容
- 衍生：爆款拆解改写、爆款衍生系列
- 辅助：标题生成、标签生成、文案配图生成、敏感词检测、外部素材分析
- 短视频：干货浓缩短视频、短视频引流文案、长文转短视频文案

**产出物**：公众号文案（存到草稿箱）、短视频脚本、选题清单

---

### 窗口3：📢 营销获客

**定位**：内容出来后，发出去+让人买

**对应业务清单**：引流与转化（7项）

**职责范围**：
- 多平台发布与分发（公众号/小红书/抖音/推特）
- 引流钩子制作与投放
- 朋友圈文案
- 销售话术设计
- 客户见证/好评文案
- 私域转化策略
- 升单话术
- 各平台内容格式转化（长文→小红书图文、推特串等）

**核心skills**：
- 发布分发：一键分发、微信公众号发布、小红书发布、小红书图文、抖音发布、推特内容转换、公众号排版、公众号一键发布
- 转化：营销转化专家、引流课设计、客户见证转化文案、产品推广文案、结尾钩子生成
- 朋友圈：朋友圈文案生成
- 直播转化：私域直播系统

**产出物**：各平台发布内容、引流钩子、销售话术、朋友圈文案

---

### 窗口4：📚 产品交付

**定位**：付费产品的全生命周期，从做产品到服务客户

**对应业务清单**：99体验营(5项) + 领航计划(14项) + 999课程(8项) + 12000代搭建(5项) + 59800 B端定制(3项) = 35项

**职责范围**：
- 课程大纲设计与迭代
- 录课脚本撰写
- 学习手册/交付物制作
- 直播文稿（开营/答疑/结营）
- 社群内容生成（防群凉）
- 教练管理物料
- 交付SOP打磨
- 学员案例收集整理
- 合同模板生成

**核心skills**：
- 直播：直播文稿生成、直播复盘
- 社群：社群内容生成
- SOP：SOP文档收纳整理、SOP文档MCP适配
- PPT：PPT大纲生成
- 录音稿：录音稿整理

**产出物**：课程大纲、录课脚本、学习手册、直播稿、交付物包、SOP文档

**注意**：交付执行员工入职后，这个窗口会高频使用，配合他做交付相关的物料和SOP

---

### 窗口5：📊 数据参谋

**定位**：看数据、出结论、优化方法论

**对应业务清单**：数据采集 + 内容复盘相关

**职责范围**：
- 各平台数据采集与汇总
- 单篇内容复盘（归因分析）
- 爆款案例库更新
- PLAYBOOK方法论更新
- 热点采集与趋势研究
- 对标账号分析
- 选题库数据验证
- A/B测试结果分析

**核心skills**：
- 数据：数据采集、内容复盘、爆款复盘分析
- 研究：热点采集助手、热点分析、趋势分析
- 对标：小红书账号分析、X平台研究分析、TikTok研究分析、公众号标题采集、网红发现与评估

**产出物**：数据报告、复盘结论、PLAYBOOK更新建议、对标分析报告

**闭环**：数据参谋的结论 → 反馈给内容工厂优化下一篇

## 角色卡与记忆体系

### 文件结构

```
02.领域/1.团队管理/AI员工/
├── 角色卡/                    ← 每个员工的身份+必读文件+工作边界+可用skills
│   ├── 内容工厂.md
│   ├── 营销获客.md
│   ├── 产品交付.md
│   ├── 数据参谋.md
│   ├── 团队管家.md
│   └── 系统研发.md
├── 记忆/                      ← 每个员工的独立记忆（上次做了什么/当前进度）
│   ├── 内容工厂-记忆.md
│   ├── 营销获客-记忆.md
│   ├── 产品交付-记忆.md
│   ├── 数据参谋-记忆.md
│   ├── 团队管家-记忆.md
│   ├── 系统研发-记忆.md
│   └── 归档/                  ← 每月归档旧记忆
└── 公告板.md                   ← 员工之间的传话板
```

### 启动方式

每个窗口新对话时，说 `/启动 角色名` 或直接说"你是XX"，AI自动：
1. 读取角色卡（知道自己是谁）
2. 读取启动必读文件（加载上下文）
3. 读取记忆文件（知道上次做到哪）
4. 扫描公告板（有没有其他员工的传话）
5. 汇报就绪

### 记忆层级

| 层级 | 文件 | 谁能写 | 内容 |
|------|------|--------|------|
| 公司级（全局） | MEMORY.md / USER.md / PREFERENCE.md 等 | 只有叮当猫 | 老板的身份、偏好、战略、全局记忆 |
| 岗位级（窗口） | AI员工/记忆/xxx-记忆.md | 对应员工 | 该窗口的工作历史、进度、反馈 |
| 传话（跨窗口） | AI员工/公告板.md | 所有员工可写 | 跨窗口的信息传递、洞察上报 |

### 收尾协议（每个员工通用）

每次对话结束前：
1. 更新自己的记忆文件
2. 有跨窗口价值的信息写入公告板
3. 重要发现标记 `→ @叮当猫` 上报

### 记忆维护

- **月度归档**：每月初将上月记忆移到 `归档/` 目录，只保留最近30天
- **长期经验沉淀**：经过验证的经验写入角色卡的"长期经验"区块，不随归档丢失

---

## 调整规则

1. **每季度回顾一次**：业务变了，窗口分工跟着调
2. **新业务线 > 3个tasks时**：从备用窗口开一个新的
3. **某窗口长期不用**：考虑合并到相近窗口，释放出来
4. **某窗口太重**：考虑拆分，从备用窗口分一个出来
5. **角色卡更新**：业务清单变化时，同步更新对应角色卡的职责和必读文件
