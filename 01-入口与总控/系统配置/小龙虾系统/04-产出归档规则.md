# 小龙虾产出归档规则

> 更新时间：2026-05-24

## 一、核心原则

小龙虾所有产出统一进入：

```text
C-记忆核心/02-每日输入/lobster_input/
```

这个目录是远程 AI 员工产出的本地镜像区、复盘区和素材池。

## 二、目录结构

```text
C-记忆核心/02-每日输入/lobster_input/
├── 01-xuange-选哥/
├── 02-contenthelper-内容助手/
├── 03-cuihuo-催活助手/
├── 04-gzhmonitor-公众号监控助手/
├── 05-xuedadazi-学习搭子/
├── 06-sucai-素材整理大师/
├── 07-fupange-复盘哥/
├── 08-yasige-雅思哥/
├── 09-zongkongxia-总控虾/
└── _README.md
```

## 三、普通智能体产出路径

```text
C-记忆核心/02-每日输入/lobster_input/[智能体目录]/YYYY-MM-DD/[文件名].md
```

## 四、总控日报路径

```text
C-记忆核心/02-每日输入/lobster_input/09-zongkongxia-总控虾/YYYY-MM-DD-小龙虾每日总控日报.md
```

## 五、归档与正式沉淀的区别

`lobster_input` 是每日产出区，不等于最终资产区。

后续由林总或 Main Agent 二次确认后，再把高价值内容迁移或整理到：

```text
C-记忆核心/04-迭代记忆/
C-记忆核心/03-经验沉淀/
D-内容创作/08-草稿库/
E-产出交付/03-数据反馈/
E-产出交付/05-合作管理/
```

## 六、未发布草稿规则

未发布的文章、短视频、口播稿、初稿，不能放入：

```text
E-产出交付/01-已发文案/
```

只能放入：

```text
D-内容创作/08-草稿库/
C-记忆核心/02-每日输入/lobster_input/02-contenthelper-内容助手/
```

只有明确已发布、有平台、发布时间、链接或数据反馈时，才允许进入已发文案目录。

## 七、状态字段

每个产出文件必须标注：

```text
状态：待林总确认 / 可执行 / 已归档 / 需二次加工 / 已回流 GitHub
```

## 八、产出文件头模板

```markdown
# 标题

- 日期：YYYY-MM-DD
- 智能体：中文名 / agent_id
- 任务来源：林总指令 / 定时任务 / 飞书输入 / GitHub任务
- 输入来源：读取了哪些关键文件或链接
- 输出类型：选题 / 初稿 / 素材 / 复盘 / 学习记录 / 日报 / 其他
- 状态：待林总确认

---
```

## 九、回流后报告

每次小龙虾 push 后，必须向林总报告：

```text
本次新增/更新文件：
- 路径1
- 路径2

本次 Git commit：
- commit hash / commit message

需要林总确认：
- 事项1
```
