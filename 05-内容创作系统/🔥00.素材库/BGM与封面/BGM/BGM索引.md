# BGM 库

将 `.mp3` 文件放入本文件夹，并在下方表格登记信息。
Video Forge 生成视频时，会根据 Gemini 分析出的文案情绪，自动匹配最合适的 BGM。

## 使用说明

1. 把 BGM 文件（mp3）放到本文件夹下（`11.素材库/BGM/`）
2. 在下方表格添加一行，填写文件名、情绪类型、节奏、备注
3. 生成视频时 pipeline 会自动读取此表，匹配最佳 BGM

## 情绪类型参考

| 类型         | 说明     | 适用场景      |
| ---------- | ------ | --------- |
| neutral    | 平稳、通用  | 日常分享、教程   |
| excited    | 激昂、振奋  | 重大发布、成就展示 |
| serious    | 严肃、深沉  | 行业分析、深度思考 |
| humorous   | 轻松、幽默  | 吐槽、趣味内容   |
| dramatic   | 戏剧性、感动 | 故事、转折     |
| calm       | 舒缓、安静  | 复盘、反思     |
| inspiring  | 鼓舞、自信  | 方法论、干货    |
| mysterious | 悬疑、好奇  | 揭秘、探索     |
|            |        |           |
