## 一、核心选题公式

选题模型： `热点事件/新奇概念 + 全民好奇心 + 通俗解读承诺`

公式分两个子类型：

子类型A——热点解读型： `热门AI事件 + "一条视频搞清楚" + 全解承诺`

|变量|可选值示例|
|---|---|
|热门事件|DeepSeek爆火 / GPT诞生700天 / 国产模型霸榜 / AI视频登顶|
|解读承诺|一条视频搞清楚 / 一条全解 / 全面超越|

子类型B——趣味项目型： `AI做了个[有趣的东西] + 大众好奇的问题`

|变量|可选值示例|
|---|---|
|趣味项目|花钱模拟器 / 复刻5000年春节 / AI主播你听不出来 / Agent接管你的家|
|大众好奇|5000亿能买什么 / 古人怎么过年 / AI能替代真人吗|

底层驱动力： 好奇心（"我也想知道"）+ 社交货币（"看完可以跟人聊"）+ 民族自豪（国产AI话题）
