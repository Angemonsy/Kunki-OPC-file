## 🎯 完整操作流程（共7步）

### **第一步：热点追踪 - 找到爆款选题**

#### 操作步骤：

1. 在对话框输入：`@热点追踪` （注意要输入@符号）
2. 按回车发送"开始"指令
3. 等待系统自动从今日热榜网站抓取最新热点

#### 系统会问你：

**"请提供你的行业赛道和信息"**

👉 **你要这样回答**：
```
我是科技赛道
```
或者
```
我是教育赛道
```
或者
```
我是美妆赛道
```
（根据你自己的领域填写）

#### 你会得到什么：

- 系统会推荐10个热点选题
- 每个选题都有专业评分（基于13大爆款元素）
- 比如：华为量子计算、马斯克预测AGI等

#### 选择一个你感兴趣的选题，记下来！

---

### **第二步：热点分析 - 生成15000字深度报告**

#### 操作步骤：

1. 在对话框输入：`@热点分析`
2. 告诉系统你选择的选题

👉 **示例输入**：
```
@热点分析 马斯克预测2026年实现AGI
```

#### 系统会自动完成3个阶段：

**阶段1：结论和建议**
- 这个选题值不值得做？
- 理由是什么？
- 有什么潜在风险？

**阶段2：文案框架**
- 自动匹配最合适的爆款框架（比如"未来预言型"）
- 给出详细的文案大纲
- 提供差异化角度建议
- 明确目标受众和建议时长

**阶段3：素材收集**
- 自动收集相关素材
- 输出完整的深度研究报告

⏰ **等待时间**：约2-3分钟，系统会自动完成

---

### **第三步：文案生成 - 人机共创写文案**

#### 操作步骤：

1. 在对话框输入：`@视频文案生成`
2. 告诉系统："报告已经生成了，帮我写一篇文案"

#### 系统会问你3个问题：

**问题1：希望生成的视频文案时长？**
👉 回答示例：
```
5-6分钟
```

**问题2：分发的平台？**
👉 回答示例：
```
公众号和视频号
```

**问题3：预期用户的行为？**
👉 回答示例：
```
点赞和转发
```

#### 接下来系统会做什么：

1. 生成20个选题方向
2. 推荐一个首选选题（并告诉你推荐理由）
3. 等你确认选题
4. 生成5-6分钟文案的框架
5. 等你确认框架
6. 直接生成完整文案

**💡 为什么要你确认？**
因为人机共创才是正确的道路！你的审美和判断是AI无法取代的，也是你的护城河。

#### 你会得到什么：

- 完整的文案（包括开头钩子、分点展开、结尾升华）
- 系统评分（从结构、内容、表达三个层面）
- 平均分数

---

### **第四步：事实核查 - 避免AI幻觉**

#### 操作步骤：

1. 在对话框输入：`@事实核查`
2. 系统会自动核查刚才生成的文案

#### 你会得到什么：

- 一份事实核查说明报告
- 核查优化后的完整文案版本

**✅ 到这一步，文案创作就完成了！**

---

### **第五步：公众号排版 - 一键美化**

#### 操作步骤：

1. 在对话框输入：`@排版优化`
2. 告诉系统："对文章进行排版"

#### 你会得到什么：

- 排版后的文章（自动生成）
- 可以直接下载
- 可以复制到公众号文章编辑器

**📱 如果要拍摄短视频**：把文案放进提词器直接开拍就行！

---

### **第六步：标题生成 - 吸引眼球**

#### 操作步骤：

1. 在对话框输入：`@爆款标题`
2. 系统会自动生成标题

#### 你会得到什么：

- 20个爆款标题
- 根据各平台特性推荐一个最佳标题
- 每个标题都符合13大爆款元素

---

### **第七步：标签生成 - 提高曝光**

#### 操作步骤：

1. 在对话框输入：`@标签`
2. 系统会自动生成标签

#### 你会得到什么：

- 符合内容的标签列表
- 可以直接使用

---

## ✅ 完成！你的爆款内容已经准备好了

### 整个流程你得到了：

1. ✅ 经过验证的热点选题
2. ✅ 15000字深度分析报告
3. ✅ 完整的文案（已事实核查）
4. ✅ 精美的排版
5. ✅ 20个爆款标题
6. ✅ 配套的标签

### 接下来只需要：

- 公众号发布：复制排版好的文章 → 粘贴到公众号编辑器 → 选择标题 → 发布
- 短视频发布：文案放进提词器 → 开拍 → 剪辑 → 发布

## 🎓 常见问题解答

### Q1: 我不会操作怎么办？
**A**: 只需要会打字和复制粘贴！按照步骤一步一步来，每次只需要@对应的技能，然后回答系统的问题就可以了。

### Q2: 整个流程需要多久？
**A**: 熟练后10分钟就能完成一篇可以直接发布的文案。

### Q3: 为什么要确认选题和框架？
**A**: 人机共创才是正确的道路！你的审美和判断是AI无法取代的，也是你作为内容创作者的护城河。

### Q4: 如果系统生成的内容不满意怎么办？
**A**: 可以要求系统重新生成，或者在确认框架时选择其他方向。

### Q5: 我需要准备什么技能包？
**A**: 需要先安装以下Skills：
- @热点追踪
- @热点分析
- @视频文案生成
- @事实核查
- @排版优化
- @爆款标题
- @标签

（联系老师获取这些技能包）
