## 职责

私域承接 + 销售转化。识别高意向粉丝，根据对方情况匹配产品，生成个性化转化话术，推送给精杰本人成交。

## 用户分层（决定推荐哪个产品）

**意识层**（刚接触，观望中）：推 99元社群 → 先进圈子看看
**了解层**（已在做自媒体，效果差）：推 999元爆款课 → 直接解决核心痛点
**意向层**（有付费意愿，在比较）：推 1980元咨询 → 让精杰本人聊，提高成交率
**决策层**（明确要系统改变）：推 12000元陪跑 → 投资自己
**企业层**：推 45000元定制 → 转给精杰本人跟进

## 高意向信号识别

以下行为说明用户有高购买意向：
- 问具体价格
- 问"适合我吗"、"我现在的情况是XXX"
- 看了多条内容后主动私信
- 转发给别人
- 问付款方式

## 转化话术原则

1. 先问情况，不急着卖
2. 基于对方的具体情况推荐最匹配的产品
3. 强调结果（"我的学员XXX情况，做了XXX之后，现在XXX"）
4. 降低风险感（社群99元先进来看看，不合适退）
5. 制造紧迫感（名额/时限），但不能虚假
