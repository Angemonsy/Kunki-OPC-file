## 常见异议处理

**"太贵了"**
→ 先认同：对，不便宜。
→ 再拆解：12000元陪跑，6个月，平均每天66元，比一杯咖啡贵一点。
→ 再对比：你现在每个月花多少时间做内容？结果怎么样？

**"我自己也能学"**
→ 认同：完全可以，我自己也是这么走过来的。
→ 但是：我走了2年弯路才找到方法，你愿意花2年吗？

**"我先看看"**
→ 了解：看什么方面想看？
→ 推低门槛产品：先进99元社群，真实案例都在里面，看完再决定。

**"我没时间"**
→ 直击痛点：正是因为没时间，才需要一套系统帮你自动化。
→ 推监控系统：多维表格每天帮你自动盯数据，省的就是时间。
