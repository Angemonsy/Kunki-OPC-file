# 【SOP】公众号数据采集全流程

> 通过 Playwright MCP 控制浏览器登录公众号后台采集数据，写入数据监控中心。
> 本流程已于 2026-02-28 完整跑通验证。

---

## 一、环境准备（一次性）

### 1.1 安装 Playwright MCP

在系统终端（不是Claude Code内部）运行：

```bash
claude mcp add playwright npx @playwright/mcp@latest
```

提示 `Added stdio MCP server playwright` 即成功。

> ⚠️ 必须在外部终端运行，不能在Claude Code会话内部执行（会报嵌套错误）

**重启 Claude Code** 使 MCP 生效。

---

### 1.2 获取公众号 AppID + AppSecret（一次性）

**目的**：为 DataSync 插件提供 API 凭证，实现后续自动化拉取。

**步骤：**

1. MCP 导航到 `https://developers.weixin.qq.com/platform/`
   - **等待条件**：页面出现「登录」按钮或已登录状态的头像
2. 点击右上角「登录」按钮
   - **等待条件**：出现微信扫码二维码弹窗

⏸️ **MCP 暂停点**：此步骤需要用户手动操作 — **微信扫码登录**，扫码并选择公众号账号，完成后告知 Claude「登录好了」

3. 登录后 MCP 点击左侧或顶部「公众号」入口（页面显示公众号数量）
   - **等待条件**：进入公众号管理页面，URL 包含 `/mp/`
   - **成功判断**：页面显示公众号名称和 AppID
4. MCP 读取「基础信息」页面中的 **AppID**（`wx` 开头字符串）并记录
5. 点击 AppSecret 旁的「启用」按钮（若已启用则点「重置」）
   - **等待条件**：出现微信扫码授权二维码弹窗

⏸️ **MCP 暂停点**：此步骤需要用户手动操作 — **管理员微信扫码授权生成 AppSecret**，扫码完成后告知 Claude「可以了」

6. MCP 读取页面上显示的 AppSecret 字符串并记录
   - **成功判断**：读取到一串32位字母数字字符串
7. 点击「完成」

> ⚠️ AppSecret **只显示一次**，点完成后永久隐藏，必须立刻保存
> ⚠️ 如果之前已启用过，需点「重置」重新生成（旧的立即失效）

### 1.3 配置 API IP 白名单（一次性）

**目的**：不配置会报 error 40164，导致无法调用 access_token。

**步骤：**

1. MCP 导航到 `https://myip.la`
   - **等待条件**：页面加载完成，出现 IP 地址数字
   - **成功判断**：页面正中显示形如 `x.x.x.x` 的公网 IP，MCP 读取并记录该 IP
2. MCP 导航回开发者平台基础信息页 `https://developers.weixin.qq.com/console/product/mp`（选择对应公众号 → 基础信息）
3. 找到「API IP白名单」一行，点「设置名单」链接
   - **等待条件**：弹出「设置 API IP 白名单」对话框，包含多行文本输入框
4. MCP 在文本框中填入第1步记录的公网 IP
5. 点「确定」按钮
   - **等待条件**：弹出二维码授权窗口

⏸️ **MCP 暂停点**：此步骤需要用户手动操作 — **管理员微信扫码授权设置 IP 白名单**，扫码完成后告知 Claude「可以了」

6. **成功判断**：「API IP白名单」行由「设置名单」变为显示具体 IP 地址（如 `38.98.189.211 编辑`）

> ⚠️ 家庭宽带 IP 会变动，如果某天 API 突然报 40164，重新查 IP 更新白名单即可

---

## 二、DataSync 插件配置（一次性）

1. Obsidian → 设置 → 社区插件 → DataSync 📊 → 设置
2. 填入：
   - **AppID**：从上一步获取
   - **AppSecret**：从上一步获取
3. 点「测试」按钮 → 出现 `✅ 公众号 API 连接成功` 即配置完成
4. 可选：开启「每日自动同步」，设置触发时间（建议9:00）

## 三、用 Playwright MCP 采集数据（日常执行）

> 适用场景：DataSync插件API权限不足时，手动用浏览器采集首页数据

### 3.1 打开公众号后台

告诉 Claude：「用 Playwright 打开公众号后台采集数据」

MCP 执行：导航到 `https://mp.weixin.qq.com`
- **等待条件**：页面出现微信扫码登录二维码（含「请使用微信扫描二维码登录」文字）

### 3.2 扫码登录

⏸️ **MCP 暂停点**：此步骤需要用户手动操作 — **微信扫码并选择公众号账号登录**，完成后告知 Claude「登录好了」

- **成功判断**：页面跳转，URL 变为 `https://mp.weixin.qq.com/cgi-bin/...`，顶部显示公众号名称

### 3.3 采集首页数据

MCP 在登录后的首页滚动查看页面，定位「近期发表」（或「内容与互动」）区域，该区域为文章列表卡片，每篇文章卡片包含：
- 文章标题
- 阅读数（眼睛图标旁）
- 点赞数（大拇指图标旁）
- 收藏数（五角星图标旁）
- 转发数 / 分享数

MCP 通过 `browser_snapshot` 读取页面无障碍树，或通过截图识别卡片数据，逐篇记录所有可见文章的完整数据。

- **成功判断**：至少读取到 1 篇文章的标题 + 阅读数，其余字段按实际显示读取（部分旧文章可能只有阅读数）

### 3.4 数据写入

Claude 将采集到的数据计算互动率/收藏率后，写入：

```
02.领域/0.内容创作系统/🔥03.数据反馈/📊 数据监控中心.md
```

## 四、互动率计算公式

| 指标 | 公式 | 爆款标准 |
|------|------|---------|
| 互动率 | (点赞+收藏+转发) / 阅读数 | >5% |
| 收藏率 | 收藏 / 点赞 | >50% |
| 讨论度 | 评论 / 点赞 | >10% |
| 传播力 | 转发 / 点赞 | >10% |

> 公众号后台无曝光量数据，用阅读数代替曝光量计算互动率

## 五、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 导航到公众号报404 | token过期 | 重新导航到 `https://mp.weixin.qq.com` |
| AppSecret只显示一次看漏了 | 点了完成 | 回到开发者平台重置AppSecret（旧的失效） |
| `claude mcp add` 报错嵌套 | 在Claude Code内部运行 | 开新的系统终端窗口运行 |
| 数据分析接口无权限 | 个人号不是认证服务号 | 用Playwright浏览器采集代替API |
| 公众号后台被claude-in-chrome拦截 | 安全白名单限制 | 改用Playwright MCP（无域名限制）|
