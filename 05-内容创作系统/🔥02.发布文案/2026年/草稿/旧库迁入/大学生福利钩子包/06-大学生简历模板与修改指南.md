# 大学生简历模板与修改指南

> 适用人群：找实习、参加商赛、申请项目、保研面试的大学生。

---

## 一、简历核心原则

| 原则 | 说明 |
|---|---|
| 一页纸 | 学生简历优先控制在一页 |
| 结果导向 | 不写“参与了”，写“完成了什么结果” |
| 数据化 | 能写人数、金额、增长、排名就写 |
| 匹配岗位 | 不同岗位用不同版本 |
| 少写空话 | 不写“认真负责、沟通能力强”这种无证据表达 |

---

## 二、简历结构模板

```text
姓名｜电话｜邮箱｜微信｜学校｜专业｜年级

教育背景
- 广东外语外贸大学 国际经济与贸易 本科
- GPA/排名：如适合岗位或升学申请可写
- 相关课程：按岗位选择，不要堆太多

实习/项目经历
项目名称｜角色｜时间
- 背景：项目要解决什么问题
- 行动：你具体做了什么
- 结果：带来什么数据/产出/成果

竞赛/校园经历
- 竞赛名称、奖项、负责内容、结果

技能证书
- 英语、办公软件、数据分析、AI工具等

个人作品/链接
- 公众号/视频号/作品集/知识库/项目链接
```

---

## 三、经历改写公式

推荐公式：

> 动词 + 工作内容 + 方法/工具 + 结果数据

例子：

- 普通写法：参与社团活动策划。
- 优化写法：负责XX社团活动策划与执行，完成活动流程设计、推文撰写和现场统筹，最终吸引200+同学报名，现场到场率约80%。

---

## 四、AI修改简历提示词

```text
请你作为一名大学生求职简历顾问，帮我修改下面这段经历。要求：
1. 用STAR法则重写；
2. 尽量数据化；
3. 语言适合简历，不要太口语；
4. 给我3个不同版本：保守版、结果导向版、面试突出版。

经历如下：
【粘贴经历】
```

---

## 五、常见错误

| 错误 | 修改方向 |
|---|---|
| 写太多课程 | 只写和岗位相关的课程 |
| 经历没有结果 | 加数据、作品、产出 |
| 所有岗位一份简历 | 每个方向单独调整关键词 |
| 自我评价空泛 | 用项目经历证明能力 |
| 排版花哨 | 简洁清晰优先 |
