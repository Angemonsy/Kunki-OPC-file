# AI期末复习提示词合集

> 用途：帮助大学生用AI快速整理课程资料、生成复习框架、模拟题、背诵清单和考前速记。  
> 使用方法：把课程PPT、老师重点、课本目录、往年题粘贴给AI，再套用下面提示词。

---

## 一、课程框架整理

```text
你现在是我的大学期末复习助教。我会给你一门课的课程资料，请你帮我整理成适合期末复习的知识框架。

要求：
1. 按章节整理；
2. 标出每章核心概念；
3. 标出可能考选择/判断/简答/论述的内容；
4. 用表格输出；
5. 最后给我一份考前复习优先级清单。

课程资料如下：
【粘贴资料】
```

---

## 二、老师划重点转背诵清单

```text
以下是老师期末划的重点，请你帮我整理成背诵清单。

要求：
1. 分成“必背”“重点理解”“选择题熟悉”三类；
2. 每个知识点给出简洁解释；
3. 对可能出简答题的内容，给我3-5句标准答案；
4. 对可能出论述题的内容，给我答题框架。

老师重点如下：
【粘贴重点】
```

---

## 三、生成模拟试卷

```text
请你根据下面的课程重点，帮我生成一套大学期末模拟试卷。

要求：
1. 题型包括选择题、判断题、名词解释、简答题、论述题；
2. 难度贴近普通大学期末考试；
3. 题目不要太偏；
4. 每道题后附参考答案；
5. 最后总结本套题考查的核心知识点。

课程重点如下：
【粘贴资料】
```

---

## 四、考前一页纸速记

```text
请你把下面这门课的复习资料压缩成“考前一页纸速记版”。

要求：
1. 只保留最高频、最可能考的内容；
2. 用标题+关键词+极简解释；
3. 适合考前30分钟快速浏览；
4. 按重要程度排序；
5. 不要写太长。

资料如下：
【粘贴资料】
```

## 五、简答题标准答案生成

```text
请你根据下面的知识点，生成适合大学期末考试的简答题答案。

要求：
1. 每个答案控制在150-250字；
2. 结构清晰，有分点；
3. 语言不要太AI，要像学生考试能写出来的答案；
4. 每个答案都给出关键词，方便背诵。

知识点如下：
【粘贴知识点】
```

## 六、论述题万能框架

```text
请你针对下面这个论述题，帮我生成一个期末考试可用的答题框架。

要求：
1. 先解释概念；
2. 再分析原因/机制；
3. 再结合例子；
4. 最后总结意义或启示；
5. 输出“框架版”和“完整答案版”。

题目：
【粘贴题目】
```

## 七、错题分析

```text
我做错了下面这道题，请你帮我分析。

要求：
1. 正确答案是什么；
2. 为什么正确；
3. 我可能为什么会选错；
4. 这道题背后的知识点是什么；
5. 下次遇到类似题怎么判断。

题目和我的答案如下：
【粘贴题目】
```

## 八、AI使用注意事项

| 风险 | 解决办法 |
|---|---|
| AI编造知识点 | 一定用老师PPT/课本/课堂重点校验 |
| 答案太像AI | 让AI改成“大学生考试语言” |
| 内容太长背不完 | 要求AI压缩成关键词和框架 |
| 不知道重点 | 先输入老师划重点，而不是让AI凭空猜 |

一句话：AI负责提效，你负责判断。
