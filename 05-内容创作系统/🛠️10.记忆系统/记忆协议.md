# 记忆系统协议

> Memory Work 四层记忆架构的完整实现。

---

## 四层记忆架构

```
+-----------------------------------------------------+
|  Layer 0 - 持久记忆（我是谁）                         |
|  -> 个人自传、IP定位、用户画像、风格萃取                |
|  -> 更新频率：极低，身份级变化才更新                    |
+-----------------------------------------------------+
|  Layer 1 - 工作记忆（我现在在做什么）                  |
|  -> 当下状态 + 周工作区                               |
|  -> 更新频率：每次对话 / 每周                          |
+-----------------------------------------------------+
|  Layer 2 - 动态记忆（跨周保留的洞见）                  |
|  -> 偏好、决策逻辑、方法论心得                         |
|  -> 更新频率：跨周保留，有生命周期，会衰减              |
|  -> 文件：MEMORY.md 动态记忆区块                       |
+-----------------------------------------------------+
|  Layer 3 - 程序性记忆（情境->行动模式）                |
|  -> 可复现的协作模式，情境触发自动执行                  |
|  -> 更新频率：确认后不衰减                             |
|  -> 文件：MEMORY.md 程序性记忆区块                     |
+-----------------------------------------------------+

    <-> AI观察笔记（动态记忆的毕业终点，稳定特征存放处）
    <-> MEMORY_LOG（记忆操作审计日志）
```

## 文件清单

| 文件 | 层级 | 说明 |
|------|------|------|
| SOUL.md | 人格定义 | AI的性格、沟通风格、行为准则 |
| USER.md | Layer 0 | 用户是谁、做什么、面向谁 |
| MEMORY.md | Layer 2+3 | 动态记忆 + 程序性记忆 |
| AI观察笔记.md | AI认知 | AI对用户的长期观察 |
| PREFERENCE.md | 内容偏好 | 选题/标题/风格的偏好飞轮 |
| INVENTORY.md | 资产清单 | 用户拥有的产品、工具、系统 |
| MEMORY_LOG.md | 审计日志 | 每次记忆操作的记录 |
| 周工作区/YYYY-WXX.md | Layer 1 | 每周一个文件，追踪任务和进展 |

## 惊奇度驱动（记忆触发核心标准）

**什么值得记** — 评估用户输入与已有记忆的偏离程度：

- **高惊奇 -> 值得记录**：修正既有认知、填补空白、稳定模式浮现（2次以上）
- **低惊奇 -> 不记录**：印证已有记忆、一次性处理、纯事务进展

**观察粒度**：关注行为背后一致的内因，记"为什么这么做"而非"做了什么"。

## 记忆生命周期

### 写入
- AI观察到高惊奇度信号 -> 直接写入对应文件 -> 追加 MEMORY_LOG -> 对话末尾简短通知
- 所有层级均可直接写入，无需事前确认
- 唯一例外：SOUL.md（人格定义）修改前需用户确认
- 通知格式：`[记忆] 文件名 操作：内容摘要`

### 衰减（仅 Layer 2 动态记忆）
- 4周未被调用 -> 强度降一级（三星 -> 二星 -> 一星 -> 空星）
- 降至空星 -> 周复盘时建议清理或归档
- 程序性记忆（Layer 3）不衰减

### 强度升级
- 一星 -> 二星：第二次在不同场景中被验证
- 二星 -> 三星：第三次验证，且跨周出现

### 毕业（Layer 2 -> AI观察笔记）
- 条件：三星 + 周复盘确认 + 属于稳定特征
- 操作：写入 AI观察笔记，原条目标注 graduated

### 冲突解决
- 新观察 vs 旧记忆 -> 以新为准，标注变更原因
- 用户纠正 -> 立即更新，标注"用户校准"

## 周节奏

```
周一 --> 读取上周 -> 创建新周 -> 迁移待办 -> 询问计划
周中 --> 正常协作 -> 惊奇度后台检测 -> 持续更新工作记忆
周五 --> 展示周报 -> 衰减检查 -> 毕业检查 -> 记忆校准 -> 归档
```

## 启动检查清单

AI每次启动时执行：
- [ ] 读取核心记忆文件（SOUL + USER + MEMORY）
- [ ] 读取工作记忆（当下状态）
- [ ] 检查周文件是否存在，不存在则创建新周 + 归档旧周
- [ ] 主动汇报当前状态
- [ ] 其他文件按需加载（涉及时才读）
