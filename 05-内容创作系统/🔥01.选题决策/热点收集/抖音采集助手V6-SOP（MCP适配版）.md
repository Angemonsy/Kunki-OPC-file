### 采集功能1：博主主页采集

**适用场景**：采集某个抖音博主主页的作品数据

**两种采集模式**：
| 模式 | 适用场景 |
|------|---------|
| 模式0 | 采集博主主页全部/大量作品（20条以上选这种） |
| 模式1 | 只采集博主最近更新的作品（20条以内选这种） |

**MCP操作**：
1. ✅ 导航到智能体页面
2. ✅ 点击对话区域的【博主主页采集】按钮

**参考截图**：
![[920ea0457961aa4f8fe511f25c0ea117_MD5.jpg]]
![[226f3879eb90c4d24f72cdc5b1a6d716_MD5.jpg]]

3. ✅ 识别参数填写表单，按以下规则填写：

**参数说明**：

| 参数 | 填写说明 | 是否必填 |
|------|---------|---------|
| 博主主页链接 | 进入抖音博主主页，复制浏览器地址栏链接 | ✅ 必填 |
| 采集模式 | 默认模式0；只要最近几条选模式1 | ✅ 必填 |
| Cursor | 模式0时使用，首次采集留空；续采时填上次返回的游标值 | 续采时填 |
| 采集作品数量 | 仅模式1时有效，填想采集的条数（如10） | 模式1时填 |

**博主主页链接获取方法**：

**参考截图**：
![[5b8fd7a78e04a097b8a5590541afc279_MD5.jpg]]

4. ✅ 填写完成后点击发送
5. ✅ 等待采集完成
   - **等待提示**：显示「正在调用」属于正常状态，可切换其他页面，但不要关闭智能体标签页
   - **成功判断**：智能体回复「已成功调用完成采集」，并附上表格链接
6. ✅ 点击返回的表格链接查看采集结果，或直接去飞书表格查看
7. **回写游标**：从智能体返回结果中找到 `cursor` 值，自动更新到 `02.热点收集/抖音coze工作流.md` 对应博主的游标字段，供下次续采使用

**分批续采（Cursor使用方式）**：
- 第一次采集完后，智能体会返回一个 `cursor` 值
- 下次想从上次位置继续采集（如第101条开始），将该 cursor 值填入 Cursor 字段即可

## 常见问题排查

| 问题现象 | 解决方案 |
|---------|---------|
| 采集失败/无数据 | 检查飞书表格字段是否被删除或改名 |
| 表格链接录入后无效 | 确认录入的是自己创建的表格链接，而非模板链接 |
| 资源点不足 | 参考：https://my.feishu.cn/wiki/KAbXw8JIpi7G5pkFY7Nc221XnLf?from=from_copylink |
| 喜欢列表采集失败 | 检查博主喜欢列表是否设置为公开 |
| 激活码无效 | 确认激活码是否已绑定其他扣子账号 |
