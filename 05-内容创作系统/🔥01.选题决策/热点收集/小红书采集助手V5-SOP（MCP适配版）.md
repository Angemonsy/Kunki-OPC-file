## 常见问题快速排查

| 问题现象 | 原因 | 解决方案 |
|---------|------|---------|
| 提示"cookie失效" | 小红书登录态过期 | 重新获取Cookie（步骤3.1-3.2） |
| 采集结果返回"FieldNameNotFound" | 表格字段被删改 | 重建表格或检查字段是否被改名/删除 |
| 采集结果返回"Forbidden" | 飞书授权失效 | 重新执行步骤5授权流程 |
| 仿写内容为空 | 模型账号未关联或额度耗尽 | 检查7.1配置，或按教程充值 |
| 口播文案不出现 | 阿里云额度用完 | 登录阿里云充值并开启余额权限 |
| 总是提示cookie失效 | 被平台反爬检测 | 切换备用线路采集；降低采集频率 |

## Cookie失效处理流程（日常维护）

当采集提示Cookie失效时：

```
发现Cookie失效
    ↓
打开小红书网页端（www.xiaohongshu.com）
    ↓
确认已登录账号
    ↓
使用插件重新获取Cookie
    ↓
回到扣子智能体 → 更多 → 录入cookie
    ↓
粘贴新Cookie → 发送
    ↓
确认"保存成功" → 重新执行采集
```
