# 候选选题推荐 - 2026年07月04日

> 基于林总540学生法则与AI商业IP定位筛选。核心定位：用AI系统化解决具体场景问题，帮助年轻向上普通人拿结果。内容链路：具体场景 → AI系统/工作流 → 拿到结果 → 沉淀复用 → 产品/服务承接。

---

## 📋 候选选题清单

### 选题1：Claude Sonnet 5发布，最强Agentic Sonnet来了，大学生怎么用？
- **内容主线**：AI工具更新 → 实操指南
- **推荐指数**：⭐⭐⭐⭐⭐
- **核心亮点**：6月30日刚发布，时效性强；Sonnet 5能自主规划、用浏览器和终端，agentic能力接近旗舰级但价格更低；免费用户也能用。可以结合大学生实际场景（写论文、做项目、搭系统）给实操建议。
- **目标受众**：想用AI提升效率的大学生、年轻职场人
- **内容类型**：教知识文案

### 选题2：GPT-5.6被美国政府限制发布，AI竞赛变成政治竞赛？
- **内容主线**：行业趋势 → 观点分析
- **推荐指数**：⭐⭐⭐⭐
- **核心亮点**：GPT-5.6 Sol测试分数刷新纪录但无法直接使用，Anthropic Fable 5被商务部一纸信函下线。AI模型发布开始由政府拍板而非企业决定。这个事件折射的信号值得深度解读，但注意不涉及敏感政治立场，聚焦"对普通用户意味着什么"。
- **目标受众**：关注AI行业动向的年轻人
- **内容类型**：聊观点文案

### 选题3：2026是Agent爆发年，但80%的人用错了方向
- **内容主线**：AI方法论 → 认知纠偏
- **推荐指数**：⭐⭐⭐⭐⭐
- **核心亮点**：80%组织已从Agent部署看到经济回报，但实验与生产之间有40%失败率。大多数人的问题不是"不会用AI"，而是"没有把AI嵌入工作流"。可以结合自己用Claude Code/Claudian搭知识库、建内容生产线的真实经验，讲清楚Agent正确用法。
- **目标受众**：已经开始用AI但没拿到结果的人
- **内容类型**：教知识文案 / 聊观点文案

### 选题4：一人公司不是噱头，我用自己的AI系统跑通了最小闭环
- **内容主线**：AI一人公司 → 实战复盘
- **推荐指数**：⭐⭐⭐⭐⭐
- **核心亮点**：36.3%新公司由一人创办，Dario Amodei预测2026年出现一人独角兽。但SoloNest数据显示仅20%稳定赚到钱。结合自己用AI系统（知识库+内容生产线+Skill+AI员工）跑通副业的真实经历，讲清楚"一人公司"的真相：不是一个人干所有事，而是一个人+一组AI Agent。避免极端表达。
- **目标受众**：想用AI启动副业/小闭环的年轻人
- **内容类型**：讲故事文案 / 实战复盘转内容

### 选题5：大学生"AI+信息素养"大赛报名了，零报名费还能加保研分
- **内容主线**：大学生竞赛 → 信息差传递
- **推荐指数**：⭐⭐⭐⭐
- **核心亮点**：7月3日刚开始报名，时效性强；全程零报名费，校赛省赛全国联赛层层闯关，奖品证书保研履历评优加分都有。作为专业第一+国奖+竞赛金奖选手，这个信息差值得传递。可以顺便分享AI竞赛备赛方法论。
- **目标受众**：大学生（尤其想保研/加分的）
- **内容类型**：教知识文案

### 选题6：OpenClaw"养龙虾"热潮退烧，真正留下来的用法是什么？
- **内容主线**：AI工具评测 → 去伪存真
- **推荐指数**：⭐⭐⭐⭐
- **核心亮点**：龙虾从全民狂热到"卸虾"服务兴起，工信部发风险预警，多券商禁止使用。但深度使用者给出"革命性"评价的比例是仅听说者的4.2倍。可以冷静分析：龙虾到底值不值得普通人投入时间？什么场景真正有用？什么坑必须避？
- **目标受众**：对OpenClaw好奇但还没上手的普通人
- **内容类型**：聊观点文案 / 教知识文案

### 选题7：WAIC 2026下周到上海，首设OPC一人公司展区，释放了什么信号？
- **内容主线**：行业大会 → 趋势解读
- **推荐指数**：⭐⭐⭐
- **核心亮点**：7月17-20日上海举办，1100家企业参展，首设OPC专属展示区。国家级AI大会首次把"一人公司"放进主展区，信号意义很强。可以提前做一篇预览+解读，帮读者抓住关键信息。
- **目标受众**：关注AI行业趋势的年轻人
- **内容类型**：聊观点文案

### 选题8：MCP协议成了AI Agent的"USB接口"，普通人也需要懂一点
- **内容主线**：技术科普 → 实用认知
- **推荐指数**：⭐⭐⭐⭐
- **核心亮点**：MCP（模型上下文协议）从Anthropic提案变成行业标准，Google I/O也推WebMCP。对普通人来说，理解MCP就像理解USB接口，不需要会造但需要知道"什么东西能插上去"。可以类比讲清楚，降低技术门槛。
- **目标受众**：对AI工具有好奇心的小白
- **内容类型**：教知识文案

### 选题9：Vibe Coding时代，不会写代码的人开始"聊"出产品了
- **内容主线**：AI编程 → 趋势+实操
- **推荐指数**：⭐⭐⭐
- **核心亮点**：Vibe Coding入选柯林斯年度词汇，从"敲代码"到"聊代码"。腾讯90%工程师用AI编码。但研究显示实际任务耗时可能反增19%。结合自己用Claude Code搭知识库系统的真实体验，讲清楚Vibe Coding的正确打开方式。
- **目标受众**：想用AI做产品但不会写代码的年轻人
- **内容类型**：教知识文案

### 选题10：你的AI工具月费超过40美元了吗？2026最优AI工具组合方案
- **内容主线**：AI工具 → 省钱攻略
- **推荐指数**：⭐⭐⭐
- **核心亮点**：行业数据显示每月20美元成为专业版通用标准，精明买家选2-5款工具组合而非单一平台。可以结合自己实际在用的工具（Claude/Claudian/Obsidian/飞书等），给一套适合大学生/年轻职场人的最优工具组合方案。
- **目标受众**：预算有限但想用好AI的年轻人
- **内容类型**：教知识文案

## 🏆 Top 3 首推选题及推荐理由

### 🥇 Top 1：选题4 - 一人公司不是噱头，我用自己的AI系统跑通了最小闭环

**推荐理由**：
- 与540核心定位完全吻合：用AI系统化解决场景问题，拿结果，沉淀复用
- 有真实经历背书（知识库+内容生产线+Skill系统+AI员工），不是空谈
- 市场热度高（OPC是2026现象级话题），但有独特视角：不是追热点，而是用自己跑通的案例去伪存真
- 能同时触达内容号受众（大学生想用AI做副业）和商业号受众（AI工具/系统变现）
- 避免了"一人公司"话题的常见坑：不吹"10亿独角兽"，不说"读大学没用"，而是讲真实的最小闭环

### 🥈 Top 2：选题1 - Claude Sonnet 5发布，最强Agentic Sonnet来了，大学生怎么用？

**推荐理由**：
- 时效性极强（6月30日刚发布），趁热度窗口期发
- Sonnet 5的agentic能力跃升对普通用户意义大：能自主规划、用浏览器和终端
- 作为重度Claude用户（Claudian+Claude Code），有第一手使用体验可分享
- 大学生场景切入（写论文/做项目/搭系统）与540定位高度匹配
- 免费用户也能用，降低门槛，适合广传播

### 🥉 Top 3：选题3 - 2026是Agent爆发年，但80%的人用错了方向

**推荐理由**：
- 数据扎实（Anthropic 500+企业调研、80%已见经济回报、40%实验到生产失败率）
- 有认知纠偏价值：大多数人的问题不是"不会用AI"而是"没嵌入工作流"
- 能自然带出自己的AI系统实践（知识库+内容生产线作为"正确用法"的案例）
- 适合作为教知识+聊观点混合型内容，既有判断又有方法
- 标题自带冲突感（"爆发年"vs"用错方向"），有点击欲
