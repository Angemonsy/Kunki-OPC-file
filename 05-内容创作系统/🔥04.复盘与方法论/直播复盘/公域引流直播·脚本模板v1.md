# 公域引流直播·脚本模板v1

> **定位**：公域平台（视频号/抖音）引流直播，目标是拉新+筛选+收诚意金，不是直接卖课
> **与v2脚本的区别**：v2是私域卖课（15分钟循环+预录），本模板是公域引流（内容分享+即时演示+诚意金筛选）
> **首次验证**：2026-04-03 视频号直播，转化效果不错
> **方法论依据**：[[03.参考资料库/04.学习资料/直播录播课/]] 8篇直播实战课
> **参考话术库**：[[02.领域/0.内容创作系统/🔥04.复盘与方法论/直播复盘/直播可复用话术库]]

## 核心逻辑

### 转化路径

```
曝光进入 → 停留（内容吸引） → 做数据（互动参与） → 做成交（诚意金）
```
> 来源：直播认知篇"四步用户路径"

### 成交四部曲（贯穿全场，不是只在最后）

| 步骤 | 含义 | 在脚本中的位置 |
|------|------|--------------|
| ① 你有需求 | 挖痛点，让观众意识到自己的问题 | 开场+每轮演示前 |
| ② 需求能被解决 | 演示证明这套系统能解决问题 | 核心演示+互动演示 |
| ③ 我最适合帮你解决 | 人设背书+学员案例+帮观众做事 | 自我介绍+案例+互动演示 |
| ④ 你必须现在解决 | 趋势窗口+限时限量+从众 | 紧迫感+转化环节 |

> 来源：成交篇"直播间成交的四部曲"

### 四大成交原理（每轮至少用1个）

| 原理 | 具体动作 |
|------|---------|
| **权威性** | 自我介绍数据（30万粉丝、100个万粉学员）、引用黄仁勋/哈佛研究 |
| **稀缺性** | 限时（直播间专属）、限量（X个名额）、面试筛选 |
| **社会认同** | 实时播报下单人数、学员案例、"已经有XX人在学了" |
| **互惠** | 福袋抽奖、免费帮观众做定位、送资料包 |

> 来源：成交篇"直播间疯狂爆单的四大技巧"（《影响力》）

### 三角色意识

主播在直播中同时扮演三个角色，不能只当老师：

| 角色 | 职责 | 常见失误 |
|------|------|---------|
| **老师** | 讲干货、做演示、给价值 | 只讲不卖，全程当免费课 |
| **主持人** | 控节奏、拉互动、暖场 | 不引导互动，冷场 |
| **销售员** | 挖痛点、塑品、逼单 | 不好意思卖，转化放最后才提 |

> 来源：主播素养篇"同时承担老师、主持人、销售员三大角色"

### 与私域卖课直播的本质区别

- 私域：观众已经认识你，重点是塑品+逼单
- 公域：观众不认识你，重点是展示能力+建立信任+低门槛筛选
- 公域直播的产品应该是**引流课/诚意金**（低价），不是直接卖高客单

> 来源：进阶篇"公域低价课+私域中高客单价打法"

### 产品设计

- 前端：诚意金（99元），降低决策门槛
- 筛选：诚意金不等于入学，需面试，制造稀缺感
- 后端：正式产品价格（根据实际产品调整）
- 退出机制：面试不通过可退，降低观众心理负担

- [ ] 社群通知（开播前1小时）

> 来源：认知篇"靠私域启动"、流程篇"预热引流"

## 直播结构总览（90-120分钟）

| 阶段 | 时间 | 内容 | 四部曲 | 四原理 |
|------|------|------|--------|--------|
| 开场 | 0:00-0:10 | 自我介绍+痛点互动+主题预告+福袋 | ①挖需求 | 权威+互惠 |
| 趋势铺垫 | 0:10-0:20 | 行业判断+三大趋势+权威背书 | ①加深需求 | 权威 |
| 演示1 | 0:20-0:40 | 全流程自动化演示+选题互动 | ②能解决 | — |
| 首轮种草 | 0:40-0:45 | 效率对比+价格锚定+学员案例 | ③我最适合 | 社会认同 |
| 演示2-3 | 0:45-1:00 | 定时推送+AI人格互动 | ②能解决 | — |
| 互动演示 | 1:00-1:15 | 帮观众做定位/选题+福袋 | ②③组合拳 | 互惠+社会认同 |
| 故事+紧迫感 | 1:15-1:25 | 个人故事+趋势窗口+学员案例 | ④必须现在 | 稀缺 |
| 转化收尾 | 1:25-1:35 | 产品介绍+上架+催单+答疑 | ④逼单 | 稀缺+从众 |

> **核心变化**（vs旧版）：成交四部曲贯穿全场，不是最后才卖。"首轮种草"在第40分钟就开始铺垫产品。

### 15分钟循环节奏（底层逻辑）

虽然公域直播不像私域那样严格15分钟一轮卖课，但底层节奏是一样的：

```
每15分钟 = 一个完整单元
├── 10分钟干货/演示（老师角色）
├── 2分钟互动（主持人角色）
└── 3分钟种草/卖课（销售员角色）
```

> 来源：主播素养篇"15分钟一轮循环"、在线人数锯齿状曲线

公域直播的区别是：前3轮的"种草"可以很软（"这个能力在课程第X节教"），后3轮逐渐加硬（限时限量逼单）。

## 详细脚本

### 一、开场（0:00-0:10）

**目标：** 留住前30秒进来的人 + 建立权威 + 挖第一刀痛点 + 发福袋拉互动

#### [0:00] 技术确认+开场互动

```
"朋友们，大家能看到我的屏幕吗？能的话扣个1。"
（等10秒确认）
```

#### [0:01] 自我介绍（必须有，每场必说）

```
"刚进来的朋友们，我是XX，
一个非程序员出身的AI一人公司实践者。
我用AI搭了14个AI员工，帮我自动写文章、做视频、发内容。
全网30万AI粉丝，带出过100个万粉AI博主。
今天在直播间现场演示，怎么用AI搭建属于你自己的一人公司。
觉得有用的点左上角关注，直播间不迷路。"
```

> 来源：主播素养篇"让用户觉得你配讲这个课"。自我介绍要包含：你是谁+你做到了什么+今天讲什么+引导关注

#### [0:03] 痛点互动（成交四部曲第①步：你有需求）

```
"在开始之前，先问一下——
有多少朋友是一个人做自媒体的？
从选题、写稿、配图到剪视频，全是一个人干，
做出来的内容还没什么数据？
有的话评论区扣个'累'字，我看看有多少人。"

（等10秒看评论区）

"我看到很多人扣'累'了。你们的感受我太懂了，
问题不是你不够努力，是你在用一个人的精力干一个团队的活。
今天我给你看，一个人怎么干一个团队的活。"
```

> 来源：成交篇"向下制造痛点"、主播素养篇"直击痛点场景代入"

#### [0:05] 主题预告+福袋（互惠原理）

```
"好，今天我们的主题叫做【__主题名__】。
我会给大家展示【__X个玩法/场景__】，全部现场演示，不放录播。
想听的扣个1，互动越多，待会干货越多。

另外，小助理先挂一个福袋，大家去抽奖。
今天直播间全程有福袋，互动的朋友都有机会中奖。"
```

> 来源：成交篇"互惠原理——福袋"。福袋在开场就发，拉住第一波人

#### [0:08] 需求摸底（了解观众构成）

```
"我想问一下，直播间的朋友们，
你们现在有用过【__工具名__】的吗？
用过的扣个66，没有用过的扣个88。
我先看一下大家情况，然后决定怎么着重去讲。"
```

**要点：**
- 摸底互动有两个作用：①了解观众水平调整内容深度 ②拉互动数据给算法
- 开场10分钟内必须完成：自我介绍+痛点互动+福袋+需求摸底

---

### 二、趋势铺垫（0:10-0:20）

**目标：** 让观众觉得"这个事很重要，我必须关注"（成交四部曲第①步加深）

**结构：为什么这个东西会火 → 权威背书 → 三大趋势 → 和你有什么关系**

#### [0:10] 降维解释

```
"我先给大家讲一下，为什么【__工具/趋势__】会火。
是真的突然AI变得这么牛了吗？不是的。
AI大模型一直很牛，只不过大家一直没有机会去接触。
【__工具名__】火的原因是什么？
是因为你第一次能够在微信、在飞书里面，
直接和AI聊天，让它帮你干活。
这才是它真正爆火的原因。"
```

#### [0:13] 权威背书（权威性原理）

```
"而且昨天【__权威人物：如黄仁勋__】说了什么？
他说AI智能体就是AI时代的操作系统，
就像今天我们电脑的Windows和苹果系统一样。
这个我是非常认可的。"
```

> 来源：成交篇"借助别人的权威性"

#### [0:15] 三大趋势

```
"一旦这种AI员工爆发，会出现三个趋势，
而且这三个趋势，是能够直接帮你赚到钱的——

第一个：【__趋势1：如AI一人公司__】
（一句话解释）

第二个：【__趋势2：如AI大佬/战略顾问__】
（一句话解释）

第三个：【__趋势3：如AI员工团队__】
（一句话解释）

我今天这三件事全部给大家讲清楚。
想听的扣个【__关键词：如'AI一人公司'__】。"
```

#### [0:18] 重复自我介绍（简短版，给新观众）

```
"刚进来的朋友，我是XX，今天在现场演示AI一人公司。
点左上角关注，后面全是干货演示，别错过。"
```

> 来源：主播素养篇"每30分钟讲一次自我介绍"。公域流量持续进人，新观众不知道你是谁

---

### 三、核心演示（0:20-0:40）

**目标：** 让观众亲眼看到系统能力（成交四部曲第②步：你的需求能被解决）

#### 演示1：全流程自动化（约15分钟）

**最震撼的演示放第一个。** 展示从输入一句话到完整产出的全流程。

```
"好，我现在给大家看一下我的AI系统是怎么干活的。
大家看一下我公司有多少个AI员工——14个。
从管家到选题到写手到编辑，全是AI。

我只需要给管家发一句话——"

（现场操作，边等边讲解每个步骤）
```

**边等AI响应边讲解（不要冷场）：**

```
"大家看，它自动帮我做了什么？
第一步：出选题，给了3个方向
第二步：自主选择最优选题，并说明为什么选这个
第三步：写手开始写文案
第四步：编辑优化+出5个标题
第五步：转为小红书图文+朋友圈文案

全程我没有说第二句话。这就是一人公司的意思。"
```

**插入互动点（主持人角色）：**
- 出选题时："这三个选题让你们选，你们会选哪个？选1的扣1，选2的扣2，选3的扣3"
- AI选完后："和你们选的一样吗？它为什么选这个？因为反常识观点、争议性、容易引爆评论区"
- 看开头时："你们觉得这个开头写得怎么样？觉得能爆的扣1，不能的扣2"
- 看结尾时："这句金句写得怎么样？很多人正常是想不到的，也写不出来"

**演示结束后，插入一句软种草（销售员角色）：**

```
"这就是我的AI一人公司。
有人问这个怎么学——别急，先看完今天的演示，
待会我告诉大家怎么跟着我学。
现在先继续看更多玩法。"
```

> 这句话的作用：提前告知"后面有卖课"，降低观众被突然推销的抗拒感

---

### 四、首轮种草（0:40-0:45）

**目标：** 第一次正式提到产品（成交四部曲第③步：我最适合帮你解决）

> **关键变化**：旧版脚本最后才卖。方法论明确说"成交四部曲要贯穿全场"。首轮种草在第40分钟，不用硬逼单，只是让观众知道有这个东西。

```
"刚才大家看到了，一句话就出一篇完整文案。
以前这个流程要2小时，现在10分钟搞定。

算一笔账：每天省2小时，一个月省60小时。
你的时间值多少钱？
哪怕按50块一小时算，一个月省3000块。

这套能力，我有一套系统的学习方案，
想了解的待会听我讲。
但现在不着急，先继续看下一个演示。"
```

**学员案例（社会认同原理，首次出场）：**

```
"顺便说一下，已经有学员通过这套方法，
发了一篇十万加阅读量的爆款公众号文章。
（展示截图）

还有学员用一键生成的短视频，
做到了4.7万播放量。
（展示截图）

这些都是真实数据，不是我编的。"
```

> 来源：成交篇"社会认同原理——营造热销氛围"

### 五、演示2-3（0:45-1:00）

#### 演示2：定时推送/自动巡检（约5分钟）

**展示系统不是一次性的，而是持续运转的。**

```
"除此之外，我每天早上9点，
我的选题策划师会自动给我推送一份AI热点资讯。
大家看，这是昨天早上推的——
（展示截图/消息记录）

它告诉我热度多少、有什么爆款元素、
我应该从哪个角度切入。
我只需要回复一个数字，它就直接开始帮我写文章。"
```

#### 演示3：AI人格互动——叮当猫（约10分钟）

**这是建立情感连接的关键环节。** 让观众看到AI不只是工具，而是有"性格"的搭档。

```
"我现在跟他聊个天，你们看看他了不了解我。"

（现场发消息："在你眼里，我是一个怎么样的人？"）
（等回复，展示结果）

"看到没有？他说我【__复述AI的评价__】。
他说我是行动力超强的实战派，但偶尔需要被拽一把。
这些都是他记住的，他对我的记忆和理解。"
```

**追加痛点场景（成交四部曲第①步再次挖痛）：**

```
"我跟他说一个很多人都有的问题——
我现在很焦虑，AI发展太快了，
用了AI之后反而变得更忙了，怎么办？

直播间有没有同感的？有的扣个1。"

（等AI回复，展示结果）

"看到没有？他不是给你一堆空话。
他知道我现在忙什么，问题出在哪里，
然后给我具体的建议——砍掉90%的工具研究，
执行层全部甩给AI，你只做三件事：
选题判断、内容终审、商业决策。"
```

**[0:55] 重复自我介绍（简短版）+ 引导关注**

```
"刚进来的朋友，我是XX，正在现场演示AI一人公司系统。
前面已经演示了一键出文章、每日热点推送、AI搭档互动。
接下来是最炸的环节——我现场帮直播间的朋友做定位分析。
点左上角关注，别错过。"
```

### 六、互动演示——帮观众解决问题（1:00-1:15）

**目标：** 让观众从"看别人用"变成"帮我用"（成交四部曲②③组合拳）

**这是本模板的杀手锏环节。**

> 原理：当AI帮一个观众出了完整定位报告，其他观众产生两个反应：①"我也想要"（需求被激活）②"这个老师的AI真的能帮我"（信任建立）。这同时完成了四部曲的②和③。

#### [1:00] 征集互动+发福袋（第二次互惠）

```
"好，现在我让AI来帮你们做一个定位分析。
谁想做？在评论区给出你的情况——
你是干什么的？卖什么产品？面向什么人群？
我抽一个人，让AI现场帮你出报告。

另外小助理再挂一个福袋，大家去抽奖。
互动越多，中奖概率越大。"

（等30秒-1分钟收集评论）

"好，我选这位朋友——他是做【__赛道__】的，卖【__产品__】。
我现在把信息发给AI，大家看他怎么做。"

（现场发消息，等结果，边等边和观众聊天）
```

**等结果时穿插的内容（避免冷场）：**

可以聊：你为什么做这个系统（童年故事），或者回答评论区其他问题。

#### [1:08] 展示结果+逐条讲解

```
"大家集中注意力，看一下这份定位分析报告——
第一部分：赛道分析，规模多大、用户有什么痛点
第二部分：爆款元素分析，做什么内容容易火
第三部分：三套定位方案，各自优缺点
第四部分：行动清单，从第一条视频开始怎么做

大家觉得这份报告怎么样？专业的扣一波666。"
```

**帮完后接软种草：**

```
"我只给了一句话描述，它就出了这么完整的报告。
你们想一下，如果你有这么一个AI搭档，
每天帮你做选题、写文案、做定位，
你的内容产出效率会提升多少倍？

想拥有这套系统的朋友，后面我告诉你们怎么学。"
```

**注意事项：**
- 最多帮1-2个人，不要帮太多，留出"我也想要"的欲望
- 选的人要有代表性（观众群体中的典型画像）
- 如果AI出报告太慢，中间穿插讲童年故事/个人经历

### 七、个人故事+紧迫感（1:15-1:25）

**目标：** 建立人格信任 + 制造时间窗口紧迫感（成交四部曲第④步：你必须现在解决）

#### [1:15] 个人故事（3-5分钟）

**讲一个和今天主题相关的真实故事，建立情感连接。**

```
"大家知道我为什么要做这件事吗？

我小时候家里不是很有钱，
一个星期5块零花钱，我全部买了哆啦A梦漫画。
黑白的，不断地看，基本上所有的动漫书我全部看完了。

2023年我在国企工作，接触到AI的时候，
我第一个感觉就是——这不就是哆啦A梦的雏形吗？
于是我直接离职，成为AI博主。
很多人觉得我疯了，但我就是预测到了今天。

然后今年春节，OpenClaw爆火，
我发现——我真的可以做出属于我的哆啦A梦了。
一个能从口袋里掏出各种技能来帮我解决问题的搭档。
我只需要告诉它我要干什么就行了。

这就是我做这件事的初心。"
```

> 来源：成交篇"权威性原理——展示自己的权威性"。故事是最好的权威背书，比直接说数据更打动人。

#### [1:18] 趋势窗口+紧迫感

```
"我给大家分析一下，为什么2026年必须抓住这波机会。

AI在给大家一个幻觉——普通人也能轻松创业成功。
这确实是事实，我社区里有非常多普通人拿到结果了。
但这个时间窗口只在2023年到2026年。

过了今年，大量有资源、有资金、有创业经验的人涌进来，
你就知道了——贫富分化，富人越富，中产消失。

而且AI之后还有风口吗？
有一天当我们不再需要上班的时候，还有风口可以追吗？
可能没有了。

所以2026年最重要的事是什么？
找到一个靠谱的社群，一起学习，快速抹平信息差，
线下找到合作伙伴，在今年拿到结果。"
```

#### [1:22] 学员案例加强（社会认同，第二次出场）

```
"我们社区已经有非常多人拿到结果了。
（展示案例截图/数据截图）

不管是挂链接直接带货，还是上直播间带货，
都有人通过这套方法实际赚到了钱。
这些都是真实的数据。"

**[1:24] 重复自我介绍（最后一次简短版）**

### 八、产品介绍+转化（1:25-1:35）

**目标：** 清晰介绍产品 → 塑品 → 上架 → 催单 → 收尾

#### [1:25] 塑品——你加入后会经历什么（搭桥环节）

> **关键补充**：旧版缺这一步，从演示直接跳到卖。观众知道你的AI很厉害，但"我加入后具体怎么学会"这个桥没搭好。

```
"好，现在总结一下今天你们看到了什么：
一键出文章、AI热点推送、叮当猫搭档、现场做定位分析。

这些东西，我会在【__时间__】带大家一起搭起来。

加入之后你会经历什么？

第一：跟着我搭好你自己的AI系统
（从装工具到配好AI，让AI认识你、了解你的业务）

第二：学会用AI做内容
（选题、写文案、做视频、多平台分发，全链路打通）

第三：加入学习社群
（一群人一起学，遇到问题随时问，不怕学不会）

第四：线下聚会
（全国【__X__】个城市都有，找到一起干事的人）

而且你加入之后不只是学我一个人的课——
（展示其他行动营/课程列表）
这些全部免费学习，一年时间内全部开放。"
```

#### [1:28] 价格锚定+消除顾虑

```
"很多人问这个要多少钱。
我先说一下——你去外面找人帮你做一份定位报告，
少则几百，多则几千。
你请一个兼职帮你写文案，一篇200-500，一个月至少2000。
我教你的是一套系统，学会了一辈子用。

然后犹豫的原因无非三个：

第一，怕学不会——不需要编程基础，跟着操作就行。
学不会的在群里问，有人帮你解决。

第二，怕没时间——正因为没时间，你才需要AI帮你省时间。

第三，觉得贵——你先交一个诚意金就行，
正式加入之前我们会面试评估，不合适全额退。"
```

> 来源：成交篇"价格锚定"、v2脚本"消除顾虑三板斧"

#### [1:30] 产品上架

```
"好，现在我上架产品。先说清楚——

这是一个【__金额：如99元__】的诚意金。
不是你想加入就能加入，我们会对你进行面试。
面试通过后，诚意金直接抵扣正式费用，

## 已验证有效的要素（来自4/3直播）

### ✅ 高效要素（必须保留）

1. **即时演示 > 预录视频**：公域直播观众要看"真的"，现场操作可信度远高于预录
2. **帮观众做事**：抽一个观众现场出定位报告，其他人的"我也想要"欲望直接拉满
3. **AI人格展示**：让AI评价你、给你建议、吐槽你，比展示功能更有温度
4. **选题互动猜谜**：让观众猜AI会选哪个选题，然后揭晓+讲原因，参与感+学到东西
5. **童年故事锚点**：哆啦A梦不只是人设，是真实的情感连接
6. **诚意金+面试筛选**：降低决策门槛的同时保持稀缺感
7. **趋势窗口论**："2026是最后窗口"的判断比任何逼单话术都有效

### ⚠️ 已修正的问题（对照方法论校准）
