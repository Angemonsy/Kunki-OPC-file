# 直播贴片文案（121构图）

> 适用于：AI一人公司·现场搭建 直播
> 构图规则：上1/4主题 + 中2/4主播出镜 + 下1/4营销
> OBS分辨率基准：1920×1080（竖屏直播则为1080×1920）

---

## 贴片1：主题贴片（上部1/4区域）

### 文案内容

- **主标题**：AI一人公司·现场搭建
- **副标题**：非程序员｜14个AI员工｜一人=一个团队

### 布局建议

- 主标题居中偏左，占据上部区域60%宽度
- 副标题紧贴主标题下方，居中
- 整体距顶部留20px安全边距
- 主标题字号：48px 粗体（OBS中对应约72pt）
- 副标题字号：24px 常规（OBS中对应约36pt）
- 字间距：主标题2px，副标题1px

### 配色建议

- 背景：半透明深色遮罩 `rgba(0, 0, 0, 0.55)` — 保证文字可读又不完全挡镜头
- 主标题颜色：`#FFFFFF`（纯白）
- 副标题颜色：`#E0E0E0`（浅灰，拉开层级）
- 「AI一人公司」四字可单独用品牌强调色 `#FFD700`（金色）突出

### 设计风格

- 简洁科技感，无多余装饰
- 可在主标题左侧加一个小图标（机器人或公司logo），尺寸不超过40×40px
- 底部加一条1px的 `#FFD700` 分隔线，与中部区域区隔

### OBS使用说明

- **图层名称**：`贴片-主题`
- **图层类型**：图片源（PNG，透明底）
- **尺寸**：1920×270px（上部1/4）
- **位置**：X=0, Y=0
- **图层顺序**：在摄像头图层之上，在人物介绍贴片之上
- **透明度**：100%（遮罩已内置在PNG中）

## 贴片2：人物介绍贴片（中部区域）

### 文案内容

- **主文案**：XX（填你自己的名字）
- **身份标签**：非程序员·14个AI员工
- **补充信息**：AI一人公司实践者

### 布局建议

- 位于画面左下角或右下角（不挡脸部），垂直居中偏下
- 采用L型角标设计：竖条色块 + 横向文字
- 主文案「你的名字」字号：36px 粗体
- 身份标签字号：20px 常规
- 补充信息字号：16px 常规
- 整体宽度不超过画面的35%

### 配色建议

- 竖条色块：`#FFD700`（金色），宽度4px，高度覆盖全部文字行
- 背景：`rgba(0, 0, 0, 0.60)` 圆角矩形（圆角8px）
- 主文案颜色：`#FFFFFF`
- 身份标签颜色：`#FFD700`
- 补充信息颜色：`#CCCCCC`

### 设计风格

- 新闻访谈式角标，专业但不呆板
- 竖条金色线 + 黑底白字，辨识度高
- 不要加头像或照片，保持简洁

### OBS使用说明

- **图层名称**：`贴片-人物介绍`
- **图层类型**：图片源（PNG，透明底）
- **尺寸**：约600×120px
- **位置**：X=40, Y=480（左下角标位置，根据实际出镜调整避免挡脸）
- **图层顺序**：在摄像头图层之上，在主题贴片之下
- **透明度**：100%
- **备注**：如果主播走位较多，可将此贴片固定在画面左下或右下角

## 贴片3：营销贴片（下部1/4区域）

### 文案内容

- **价格展示**：~~原价1980~~ → **直播间专属 ¥999**
- **行动号召（CTA）**：👇 点击下方购物袋 立即抢购
- **引导文案**：约17个skills | 知识库模板 | 学员社群 | 一年更新 | 下播恢复原价

### 布局建议

- 分两行：
  - 第一行（核心）：价格信息居中，原价用删除线+小字，现价用大号加粗
  - 第二行（引导）：CTA + 引导文案居中
- 原价字号：20px 删除线
- 现价字号：56px 粗体（视觉最大元素）
- CTA字号：22px 粗体
- 引导文案字号：16px 常规
- 「¥999」左侧可加闪动箭头或购物袋icon

### 配色建议

- 背景：`rgba(220, 38, 38, 0.85)`（红色遮罩，营造促销紧迫感）
- 原价颜色：`#FFB3B3`（浅红，弱化）+ 删除线
- 现价颜色：`#FFFFFF`（纯白大字）
- 现价数字可加 `2px #FFD700` 描边，增强醒目度
- CTA颜色：`#FFD700`（金色，跳出红底）
- 引导文案颜色：`#FFFFFF`
- 底部可加一条呼吸灯动画的金色线条（如使用视频源）

### 设计风格

- 电商促销风格，红底白字金色点缀
- 价格对比必须醒目（原价小+删除线，现价大+加粗）
- 保持信息密度适中，观众3秒内能看完

### OBS使用说明

- **图层名称**：`贴片-营销`
- **图层类型**：图片源（PNG，透明底）；如需动画效果可用媒体源（带呼吸灯的MP4/WebM）
- **尺寸**：1920×270px（下部1/4）
- **位置**：X=0, Y=810
- **图层顺序**：最上层（在所有贴片和摄像头之上）
- **透明度**：100%
- **备注**：卖课环节可设为常驻显示；干货演示环节可降低至60%透明度或暂时隐藏，用快捷键切换（建议绑定F1显示/隐藏）

## 制作备忘

1. 三张贴片均导出为**透明底PNG**，分辨率与OBS画布一致（1920×1080）
2. 用Figma/Canva制作均可，确保导出时背景透明
3. 营销贴片如需动画（价格闪烁、箭头跳动），导出为WebM视频源
4. 所有文字确保在手机端直播预览中仍可读（测试小屏可读性）
5. 金色统一用 `#FFD700`，作为品牌色贯穿三张贴片
