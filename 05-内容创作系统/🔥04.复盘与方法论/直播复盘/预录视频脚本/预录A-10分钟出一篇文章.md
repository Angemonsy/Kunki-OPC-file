# 预录A：10分钟出一篇文章（2-3分钟精华版）

## 录制目标

让观众亲眼看到：从一句指令到公众号草稿箱里躺着一篇排好版的文章，全程10分钟。精华版压缩到2-3分钟，保留每个关键节点的"结果画面"，中间等待全部剪掉。

**最终时长：** 2分30秒左右

---

## 录制前准备

### 软件环境
- [ ] Obsidian 打开，Claudian插件就绪，对话窗口清空历史（干净界面）
- [ ] 浏览器登录好微信公众号后台，保持在后台首页
- [ ] OBS录屏准备好，录制区域全屏1920×1080
- [ ] 鼠标指针放大（Windows设置→辅助功能→鼠标指针→大号）

### 内容准备
- [ ] 确保知识库中有最新的爆款元素评分模板和文案框架
- [ ] 提前跑一次完整流程，确认AI能顺利走完全链路（热点→选题→写作→标题→排版→敏感词→发布）
- [ ] 如果某个环节容易卡，提前调试好prompt
- [ ] 准备一个"安全选题"作为备选——万一热点追踪结果不理想，手动选一个好的继续

### 画面准备
- [ ] 关闭所有通知（微信、QQ、系统通知全关）
- [ ] 桌面壁纸用纯色或简洁背景
- [ ] Obsidian主题用深色模式（录屏更清晰）
- [ ] 字体大小调到16px以上，确保录屏后文字可读

---

## 逐步操作流程

### 第1步：发出指令（录制起点）
- 点击Claudian对话窗口
- 输入：`帮我追踪最近3天的热点，用13大爆款元素评分，推荐TOP3选题`
- 按回车发送
- **画面停留3秒**，让观众看清指令内容

### 第2步：热点追踪+选题推荐
- AI开始联网搜索热点
- 等待AI返回热点列表和评分结果
- **关键画面**：TOP3选题列表出现，每个选题有评分和爆款元素标注
- 鼠标慢慢划过选题列表，停留2秒

### 第3步：选题确认
- 输入：`用第1个选题，帮我写一篇文章`（或者AI自动推荐最高分的）
- AI自动判断适合的文案类型（教知识/聊观点/讲故事）
- **关键画面**：AI回复"这个选题适合用XX框架来写"

### 第4步：文案生成
- AI开始自动生成文案（开头→正文→结尾）
- 等待完整文案输出
- **关键画面**：完整文案出现在对话窗口中，滚动展示全文
- 鼠标从上往下慢慢滚动，让观众看到文案结构

### 第5步：标题生成
- AI自动生成10个备选标题
- **关键画面**：10个标题列表，有评分或推荐标记
- 鼠标指向得分最高的标题，停留2秒

### 第6步：排版优化
- AI自动执行排版（加粗、分段、emoji等）
- **关键画面**：排版前后对比（如果有的话），或排版完成的最终效果

### 第7步：敏感词检测
- AI自动对四个平台做敏感词检查
- **关键画面**：检测结果——"四个平台均通过"或检测报告

### 第8步：一键发布到公众号草稿箱
- AI执行发布操作
- **关键画面**：发布成功的提示

### 第9步：验证结果（录制终点）
- 切换到浏览器，打开公众号后台
- 进入草稿箱
- **关键画面**：草稿箱里出现刚才的文章，标题、封面、正文都在
- 点击进去预览，滚动展示完整文章
- **画面停留5秒**，给观众足够时间消化

## 剪辑要点

| 环节 | 处理方式 | 保留时长 |
|------|---------|---------|
| 发出指令 | 原速保留 | 5秒 |
| AI搜索热点（等待） | **剪掉或2倍速** | 3秒 |
| 热点结果展示 | 原速，鼠标慢划 | 10秒 |
| 选题确认 | 原速 | 5秒 |
| AI写文案（等待） | **剪掉，跳到结果** | 0秒 |
| 文案滚动展示 | 原速慢滚 | 15秒 |
| 标题列表 | 原速 | 8秒 |
| 排版+敏感词 | 2倍速 | 5秒 |
| 发布操作 | 原速 | 5秒 |
| 公众号草稿箱验证 | 原速，**放慢到0.8倍** | 15秒 |

**总计约：2分30秒**

### 剪辑注意事项
- 每次"等待AI"的画面用**淡入淡出过渡**，不要硬切，让观众感知到"这里有个等待被跳过了"
- 文案滚动展示时，可以加一个半透明遮罩高亮关键段落
- 最后草稿箱验证画面是全片高潮，给足时间，不要赶
