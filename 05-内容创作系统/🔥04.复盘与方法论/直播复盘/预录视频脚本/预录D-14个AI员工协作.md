# 预录D：14个AI员工协作（1分钟精华版）

## 录制目标

让观众感受到：你不用开电脑，手机上发一句话，AI员工就自动干活。14个AI员工在云端7×24小时待命。节奏要快，信息密度要高——1分钟讲清楚"指挥团队干活"的感觉。

**最终时长：** 1分钟

---

## 录制前准备

### 软件环境
- [ ] 电脑端Telegram打开（比手机录屏更清晰），登录好账号
- [ ] 14个AI员工bot全部在线（OpenClaw框架运行正常）
- [ ] 至少确认以下bot可正常响应：选题官、写作官、管家bot
- [ ] OBS录屏准备好，1920×1080
- [ ] 不录声音（直播时边放边讲）

### 内容准备
- [ ] 提前测试：给选题官发"帮我看今天有什么热点"，确认能正常回复
- [ ] 提前测试：给写作官发写作指令，确认能正常回复
- [ ] 如果有管家bot协调多bot的场景，提前测试一遍
- [ ] 准备好要发送的指令文本，录制时直接粘贴（减少打字时间）

### 画面准备
- [ ] Telegram界面字体大小调大，确保录屏后可读
- [ ] 关闭所有通知
- [ ] Telegram聊天列表展示多个AI员工bot（让观众看到"14个"的阵容感）
- [ ] 每个bot的头像和名称清晰可见

---

## 逐步操作流程

### 第1步：展示AI员工列表（录制起点）
- 画面：Telegram聊天列表，显示多个AI员工bot
- 快速滚动一下列表，让观众感受到"这里有十几个bot"
- **停留3秒**

### 第2步：给选题官发消息
- 点击"选题官"对话
- 输入：`帮我看今天有什么热点`
- 发送
- 等待选题官回复热点推荐
- **关键画面**：选题官回复的热点列表（带评分）

### 第3步：给写作官发消息
- 切到"写作官"对话
- 输入：`用第1个选题写一篇教知识类文章`
- 发送
- 等待写作官回复确认或开始输出
- **关键画面**：写作官回复"收到，开始写作"或输出文案片段

### 第4步：展示多bot协作（如有）
- 如果管家bot会自动协调——展示管家bot通知其他bot的画面
- 或者快速切换几个bot的对话，展示不同bot各司其职
- **关键画面**：多个对话窗口中不同bot在工作

### 第5步：回到聊天列表（录制终点）
- 切回聊天列表总览
- 能看到多个bot都有新消息（小红点/未读标记）
- **停留3秒**，表达"它们在后台各干各的"

## 剪辑要点

| 环节 | 处理方式 | 保留时长 |
|------|---------|---------|
| AI员工列表展示 | 原速 | 5秒 |
| 给选题官发消息 | 原速 | 5秒 |
| 选题官回复（等待） | **剪掉等待，跳到结果** | 0秒 |
| 选题官回复内容 | 原速 | 8秒 |
| 给写作官发消息 | 原速 | 5秒 |
| 写作官回复（等待） | **剪掉等待，跳到结果** | 0秒 |
| 写作官回复内容 | 原速 | 8秒 |
| 多bot/列表总览 | 原速 | 5秒 |

**总计约：1分钟**（需要严格控制）

### 剪辑注意事项
- **1分钟很短，每一秒都要有信息量**，没有"空镜"时间
- AI回复的等待时间全部剪掉，硬切到结果
- 聊天列表的滚动要快但不能糊，让观众感受到"很多bot"
- 如果写作官回复内容很长，只展示开头几行就切走，不要等它写完
