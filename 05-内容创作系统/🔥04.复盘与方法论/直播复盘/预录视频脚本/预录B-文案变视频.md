# 预录B：文案变视频（2分钟精华版）

## 录制目标

让观众看到：一篇文案粘进去，AI自动拆场景、生成克隆声音、加字幕、渲染出片。重点让观众**听到克隆声音**，这是全片最大卖点。

**最终时长：** 2分钟

---

## 录制前准备

### 软件环境
- [ ] VideoForge 打开并登录，界面干净（关掉之前的项目）
- [ ] 声音克隆模型已训练好，确认能正常调用
- [ ] 准备好一篇已生成的文案（最好用预录A中生成的那篇，前后呼应）
- [ ] OBS录屏准备好，1920×1080
- [ ] **系统声音录制打开**（这个视频需要录声音！克隆语音是卖点）

### 内容准备
- [ ] 文案已复制到剪贴板，随时可粘贴
- [ ] 提前跑一次完整流程，确认渲染不报错
- [ ] 确认克隆声音质量OK（清晰、自然、像本人）
- [ ] 准备一段成片，万一录制时渲染失败可以用备选

### 画面准备
- [ ] 关闭所有通知
- [ ] VideoForge界面字体清晰可读
- [ ] 鼠标指针放大

---

## 逐步操作流程

### 第1步：展示文案来源（录制起点）
- 打开Obsidian或文本编辑器，展示刚才生成的文案
- 全选文案，Ctrl+C复制
- **画面停留2秒**，让观众看到"这就是刚才AI写的那篇"

### 第2步：粘贴到VideoForge
- 切换到VideoForge界面
- 点击"新建项目"或"导入文案"
- Ctrl+V粘贴文案
- **画面停留2秒**，展示文案已粘贴到位

### 第3步：触发视频生成
- 点击"生成视频"（或对应按钮）
- AI开始拆解文案为场景分镜

### 第4步：场景拆解
- **关键画面**：AI把文案拆成多个场景片段，每个片段有对应画面描述
- 鼠标滑过场景列表，展示拆解结果

### 第5步：AI语音生成
- 展示声音克隆设置界面（选择你自己的声音模型）
- 触发语音生成
- **关键画面**：语音波形生成过程

### 第6步：字幕自动生成
- AI根据语音自动生成字幕
- **关键画面**：字幕轨道出现在时间线上

### 第7步：渲染
- 点击渲染/导出
- 等待渲染完成（这里快进）

### 第8步：播放成片（录制高潮）
- 渲染完成，点击播放
- **完整播放15-20秒成片**
- **确保系统声音在录！观众必须听到克隆声音**
- **画面停留到播放结束**

## 剪辑要点

| 环节 | 处理方式 | 保留时长 |
|------|---------|---------|
| 展示文案+复制 | 原速 | 5秒 |
| 粘贴到VideoForge | 原速 | 5秒 |
| 触发生成 | 原速 | 3秒 |
| 场景拆解结果 | 原速展示 | 10秒 |
| 语音生成过程 | 原速/略快进 | 8秒 |
| 字幕生成 | 2倍速 | 3秒 |
| 渲染等待 | **快进到完成** | 3秒 |
| **播放成片** | **原速，完整保留** | **20秒** |

**总计约：2分钟**

### 剪辑注意事项
- **成片播放部分绝对不能剪！** 这是全片核心，声音效果要完整呈现
- 渲染快进时加一个"⏩ 快进中"的小标注
- 声音克隆设置界面可以短暂放大展示你自己声音模型的选择
