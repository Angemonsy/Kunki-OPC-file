# 预录C：MCP浏览器自动化（2分钟精华版）

## 录制目标

让观众看到：AI像一个真人一样操控浏览器——自动打开网页、自动点击、自动输入、自动采集。视觉冲击力要拉满，这是"AI替你干活"最直观的展示。

**最终时长：** 2分钟

---

## 录制前准备

### 软件环境
- [ ] Chrome浏览器打开，Claude in Chrome插件（MCP）已安装并就绪
- [ ] Claudian对话窗口打开（通过Claudian触发MCP任务）
- [ ] 准备一个演示效果好的任务（见下方任务选择）
- [ ] OBS录屏准备好，1920×1080
- [ ] 不录声音（直播时边放边讲）

### 任务选择（选一个视觉效果最好的）

**推荐方案A：关键词爆款采集**
- 指令："帮我在视频号搜索关键词'AI赚钱'，采集前10个爆款视频的标题和点赞数"
- 效果：浏览器自动打开视频号、自动搜索、自动滚动、自动记录数据
- 优势：操作步骤多，视觉冲击强

**备选方案B：公众号数据采集**
- 指令："帮我打开公众号后台，采集最近10篇文章的阅读数据"
- 效果：自动登录后台、自动翻页、自动记录
- 优势：和内容创作场景关联度高

**备选方案C：小红书内容采集**
- 指令："帮我在小红书搜索'一人公司'，采集前5篇笔记的标题和互动数据"
- 效果：自动打开小红书、搜索、滚动、记录

### 录制前测试
- [ ] 提前跑一遍选定的任务，确认MCP能顺利执行完
- [ ] 确认不会遇到验证码/登录弹窗等意外（提前登录好）
- [ ] 确认网速稳定，页面加载不卡

### 画面准备
- [ ] 关闭所有通知
- [ ] 浏览器只保留一个空白标签页（干净起点）
- [ ] 鼠标指针放大
- [ ] 浏览器全屏或最大化

---

## 逐步操作流程

### 第1步：展示空白浏览器（录制起点）
- 画面：一个干净的Chrome浏览器空白页
- **停留2秒**，让观众看到"现在什么都没有"

### 第2步：发出指令
- 切到Claudian对话窗口
- 输入MCP任务指令（如：`帮我在视频号搜索关键词"AI赚钱"，采集前10个爆款视频的标题和点赞数`）
- 按回车发送
- **停留2秒**

### 第3步：AI接管浏览器
- 浏览器自动打开目标网站
- **关键画面**：地址栏自动输入URL，页面自动加载
- 观众能看到"没有人在操作，浏览器自己动了"

### 第4步：自动搜索
- AI自动在搜索框输入关键词
- 自动点击搜索按钮
- **关键画面**：搜索框里文字"自己出现"，搜索结果加载

### 第5步：自动滚动+采集
- AI自动滚动页面，逐条查看搜索结果
- 自动记录标题、数据等信息
- **关键画面**：页面在自动滚动，鼠标自动移动和点击
- 这一步视觉冲击最强，**尽量完整保留**

### 第6步：展示采集结果（录制终点）
- 切回Claudian对话窗口
- AI回复采集结果：一个整理好的数据表格
- **关键画面**：结构化的数据（标题、点赞数、评论数等）
- **停留5秒**，让观众看清结果
