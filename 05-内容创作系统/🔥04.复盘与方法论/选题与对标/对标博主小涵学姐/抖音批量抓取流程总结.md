# 抖音批量抓取对标博主视频文字稿+数据统计 - 成功流程总结

## 🎯 目标
批量提取抖音对标博主所有公开视频的：
- 完整逐字稿（用于二创）
- 互动数据（点赞量，方便找到爆款）
- 自动排序，整理成可直接阅读的 Markdown 文档

---

## 🛠️ 完整自动化流程

### 步骤 1：浏览器打开博主主页
- 工具：`browser_open` 直接打开抖音分享的主页链接
- 作用：模拟真人浏览器访问，绕过抖音反爬，直接拿到完整 DOM

### 步骤 2：关闭登录弹窗
抖音网页版一打开就会弹出登录二维码弹窗挡住内容，需要点击关闭：
- 位置：弹窗**右上角灰色 ×**
- 校准坐标：**(756, 200)**（在 1920×1080 分辨率下精准命中）
- 工具：`browser_click(x=756, y=200)`
- 成功后整个主页内容完全可见

### 步骤 3：滚动加载所有视频
- 工具：`browser_scroll(direction="down", amount=2000)` 重复多次直到页面底部
- 作用：抖音网页版懒加载，只有滚动才会加载出更多视频和数据

### 步骤 4：JS 提取所有视频数据
执行 JavaScript 从 DOM 中直接提取结构化数据：
```javascript
Array.from(document.querySelectorAll('[data-e2e="user-post-item"]')).map(item => {
  const linkEl = item.querySelector('a');
  const statsEl = item.querySelector('[data-e2e="like-count"]');
  return {
    href: linkEl ? linkEl.href : null,
    title: item.querySelector('img')?.alt || '',
    diggCount: statsEl ? statsEl.textContent : ''
  }
})
```
- 提取到的数据：视频链接、标题、点赞量
- 零网络请求，直接从已加载的 DOM 拿，最快最稳定

### 步骤 5：按点赞量降序排序
拿到所有视频数据后，按点赞数从高到低排序，方便找到爆款

### 步骤 6：逐个提取文字稿
对每个视频链接：
1. **解析直链**：抓取抖音网页，从 `window._ROUTER_DATA` JSON 中提取无水印视频直链（不需要 cookie，反爬不拦截）
2. **下载视频**：requests 流式下载到系统 `/tmp/` 临时目录
3. **提取音频**：ffmpeg 转成 16kHz 单声道 WAV 格式（满足 ASR 输入要求）
4. **语音转录**：调用牛马AI本地运行的 **SenseVoice Small** 模型 API 识别文字
   - 全程本地计算，不需要 API 密钥，不花钱
   - 模型约 240MB，一次性下载后重复使用

### 步骤 7：自动清理临时文件
- 所有视频 `.mp4` 和音频 `.wav` 都放在系统 `/tmp/` 目录
- 提取完成后自动删除，不占用知识库空间，不挤爆内存

### 步骤 8：整合输出 Markdown 文档
输出包含：
- 爆款排行榜表格（排名+标题+点赞量）
- 每条视频完整文字稿
- 原视频链接

## 🔧 技术栈总结

| 环节 | 技术 | 优势 |
|------|------|------|
| 主页爬取 | 浏览器自动化 | 绕过反爬，DOM 直接可用 |
| 关闭弹窗 | 坐标点击 (756, 200) | 校准后一次性关闭 |
| 数据提取 | JS 从 DOM 提取 | 零请求，直接拿到结构化数据 |
| 视频下载 | 直链 requests 下载 | 利用抖音公开接口，无需破解 |
| 音频提取 | ffmpeg 转码 | 标准化输出，满足 ASR 要求 |
| 文字转录 | 本地 SenseVoice 模型 | 全程本地，不花钱，token 消耗≈0 |
| 存储清理 | `/tmp/` + 自动删除 | 不占知识库空间 |

---

## 🪙 Token 消耗
- **99% 的步骤不消耗 token**：浏览器操作、下载、转码、本地转录都是本地计算，不经过 Claude API
- **只有最后整合输出文档消耗 token**：就是输出文字稿本身，和正常聊天一样
- 整体 token 消耗≈正常聊一次天，非常经济

---

## ✅ 优势总结

1. **不封号**：浏览器模拟真人访问，不频繁批量请求，不会触发风控
2. **不花钱**：不需要第三方 API 密钥，所有计算本地完成
3. **省 token**：只有最终输出消耗 token，成本极低
4. **不占空间**：临时文件自动清理，知识库只存文字稿
5. **全自动**：给一个主页链接，输出就是整理好的 Markdown 文档，直接能用

---

## ⚠️ 注意事项

1. 抖音网页版不登录最多能看到 20 条左右视频，如果博主视频更多，需要登录后再爬
2. 网络不好时页面加载慢，可以适当等几秒再滚动/提取
3. 坐标 (756, 200) 是 1920×1080 分辨率校准的，如果分辨率不同需要微调
