## 当前最高效结构模板

### A. 清单式（收藏率最高，780%验证）
```
开篇：建立信任 + 价值预告 + 制造悬念
主体：X个工具/方法，每个统一模板（痛点→方案→场景→效果）
结尾：总结 + 行动引导
```
最佳数量：3/5/7个（奇数更好记）
**v2补充**：短篇幅（<1500字）+强实操+多截图=收藏率极高（780%），适合做引流型内容

### B. 流程演示式（互动率最高，26.4%验证）
```
开篇：痛点/冲突 + 震撼承诺 + 免费诱饵
主体：5-11步流程，每步配截图+操作指引+原理解释
升华：价值观输出（趋势判断）
结尾：多层次导流
```
关键：每步都配图、原理解释不能少、人机共创价值观
**v2补充**：用角色化拆解（给AI取岗位名）替代纯步骤编号，互动率从19.8%→26.4%

### C. 案例拆解式（互动质量均衡）
```
开篇：故事引入 + 数据震撼 + 门槛低
好奇：刁钻问题 + 分享预告
主体：4个核心方法，每个有反常识点
行动：3步开始，降低执行门槛
```
关键：数据要具体（不说"赚了很多"，说"月入12万"）

### D. 观点递进式（聊观点类专用，互动率21.6%验证）🆕
```
开篇：个人经历/焦虑 + 热点引入
第一段：经历铺垫（从60分到有灵魂的真实差距）
第二段：核心论点（比喻降维，如"秘书再能干没有大脑也白搭"）
第三段：趋势升华（什么会贬值 vs 什么不会贬值）
结尾：反问收束 + 导流
```
关键：必须绑定当下热点、必须有真实使用经历、比喻要一听就懂

## 选题决策规则（数据驱动）

**优先选**：
- 命中"工具演示+免费诱饵+时间震撼"组合的（历史最高转发率12.1%）
- 能做完整流程演示+角色化拆解的（互动率均值20%+）
- 有真实数据验证的（8篇4爆、月入12万等具体数字）
- **新增**：顶级热点+自己有真实使用经历→优先做观点类（互动率20%+潜力）

**谨慎选**：
- 纯观点无热点绑定、无真实经历背书的（仍然风险高）
- 追海外/国内用户无感知的热点
- step-by-step说明书式长教程（适合小红书不适合公众号）

**最佳发布时机**：
- 工具推荐类：年初（1-2月）用户规划期
- 热点蹭流量：热点发生48小时内 ⭐**权重提升**：案例7/8验证，卡准热点窗口对阅读量影响极大

**平台差异**：
- 公众号：工作流演示类表现最好（互动率26.4%），用户偏深度互动
- 视频号：挑战冲突+真实成果类最优（转发率6.6%），用户偏快速转发
- 小红书：收藏率为王，工具推荐类收藏率87.5%

**免费诱饵与转发率关系**（精化）：
- 有免费诱饵的案例转发率：12.1%、14.3%、6.6%、4.8%（均值9.5%）
- 无免费诱饵的案例转发率：0.7%、0.7%、1.2%（均值0.9%）
- **结论：免费诱饵是转发率>5%的几乎必要条件**（假设3已验证✅）
