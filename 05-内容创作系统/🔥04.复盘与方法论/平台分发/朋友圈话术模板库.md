# 朋友圈话术模板库

> 从爆款案例中提炼的可复用模板，按场景分类，越用越精准

## 使用说明

- 每个模板都来自真实验证过的爆款朋友圈
- 模板中 `{xxx}` 为需要替换的变量
- 优先使用⭐⭐⭐⭐以上评级的模板
- 新模板从「朋友圈爆款案例库」中提炼后添加到这里

## A. 干货分享模板

### 模板A1：故事→方法论（来源：成龙差异化样本）

```
{一个具体人物/事件的故事开头，直接进场景}

{故事展开，2-3段，有转折}

{一句话点题，连接到自己的领域}

给我在{领域}上，有{N}点启发：

1️⃣{启发1，一句话}

2️⃣{启发2，一句话}

3️⃣{启发3，一句话}

有启发的，点个赞吧。
```

**适用场景**：从别人的故事/案例中提炼方法论
**效果评级**：待验证

## B. 个人故事模板

### 模板B1：时间锚点→场景还原→信念宣言（来源：离职做AI样本）

```
{时间锚点，如"马上就是XX两整年了"}，还记得很清楚，

{场景还原，有具体地点和对话}

{对方的反应，真实不美化}

{自己当时的状态和想法}

{时间推移到现在}

{感悟，不说教，自然流出}

{信念宣言式结尾，一句话}
```

**适用场景**：人生节点回顾、重大决定、成长感悟
**效果评级**：待验证

## C. 日常生活模板

### 模板C1：对话引入→生活延伸→专业穿插→幽默收尾（来源：书店样本）

```
{朋友/同事的一句话或问题}

{你的回答，自然展开}

{从生活细节延伸到个人背景}

{自然过渡到专业思考，不硬转}

{轻松感悟，不沉重}

{幽默金句收尾，哈哈。}
```

**适用场景**：周末日常、旅行、吃饭、逛街等生活场景
**效果评级**：待验证
