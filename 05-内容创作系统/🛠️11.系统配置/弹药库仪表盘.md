# 🎯 内容弹药库仪表盘

> 所有文案的生产状态、类型分布、平台分发一目了然。
> 基于 [[frontmatter规范]] 中定义的统一字段。

---

## 📊 状态总览

```dataview
TABLE WITHOUT ID
  status as "状态",
  length(rows) as "数量",
  join(map(rows, (r) => "[[" + r.file.name + "]]"), ", ") as "文件"
FROM "02.领域/0.内容创作系统/🔥02.发布文案"
WHERE status
GROUP BY status
SORT choice(status = "草稿", 1, choice(status = "精修中", 2, choice(status = "待发布", 3, choice(status = "已发布", 4, 5)))) ASC
```

---

## 📝 待办弹药（草稿 + 精修中 + 待发布）

```dataview
TABLE
  title as "标题",
  type as "类型",
  status as "状态",
  created as "创建日期",
  viral_score as "爆款分"
FROM "02.领域/0.内容创作系统/🔥02.发布文案"
WHERE status = "草稿" OR status = "精修中" OR status = "待发布"
SORT created DESC
```

## 🔥 已发布弹药

```dataview
TABLE
  title as "标题",
  type as "类型",
  published_date as "发布日期",
  platforms as "平台",
  viral_score as "爆款分"
FROM "02.领域/0.内容创作系统/🔥02.发布文案"
WHERE status = "已发布"
SORT published_date DESC
LIMIT 20
```

## 📂 按类型分布


## 💡 使用说明

- **状态流转**：草稿 → 精修中 → 待发布 → 已发布 → 已归档
- **新文案**：所有skill自动存档时已注入统一frontmatter，无需手动填写
- **旧文案**：部分旧文案可能字段不全，表格中会显示为空值，不影响使用
- **更新频率**：Dataview实时查询，保存文件后自动刷新
- **完整规范**：[[frontmatter规范]]
