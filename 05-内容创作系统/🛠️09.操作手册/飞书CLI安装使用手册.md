# 飞书CLI安装使用手册

> 让AI直接操作你的飞书：发消息、建文档、填表格、派任务，全部在Obsidian里完成。
> 最后更新：2026-04-02

---

## 这是什么？

飞书CLI是飞书官方开源的命令行工具。装上之后，你的AI助手（叮当猫/Claude）就能直接帮你操作飞书，不用你手动切来切去。

**能做什么：**
- 发飞书消息（给个人、给群）
- 创建飞书文档（Obsidian里的markdown一键变飞书文档）
- 读写飞书表格（数据自动填进去）
- 创建/管理任务（派活、追进度）
- 查看日历日程
- 搜索聊天记录、知识库
- 操作多维表格、邮件、会议纪要等

**一句话总结：装完之后，你跟AI说人话，AI帮你操作飞书。**

---

## 前置条件

1. ✅ 已安装 Obsidian + Claudian 插件（或终端 Claude Code）
2. ✅ 已安装 Node.js（版本 18 或以上）
3. ✅ 有飞书账号

> **检查 Node.js 是否已安装**：让AI跑 `node -v`，能看到版本号就行。
> 没装的话，去 https://nodejs.org 下载安装，一路下一步。

---

## 第一步：安装飞书CLI（1分钟）

跟AI说：**"帮我安装飞书CLI"**

AI会执行：
```bash
npm install -g @larksuite/cli
```

安装完成后验证：
```bash
lark-cli --version
```

看到版本号（如 `lark-cli version 1.0.2`）就说明装好了。

---

## 第二步：创建飞书应用（2分钟）

跟AI说：**"帮我初始化飞书CLI配置"**

AI会执行：
```bash
lark-cli config init --new --brand feishu
```

这条命令会弹出一个链接，**你需要在浏览器里打开这个链接**。

打开后会看到「创建飞书 CLI 应用」页面：

1. 头像随便选一个
2. 名称保持默认「飞书 CLI」
3. 点击蓝色的 **「创建」** 按钮
4. 等进度条跑完，看到「创建成功」就行

> ⚠️ 这一步是在飞书开放平台上创建一个"应用"，相当于给AI一个操作飞书的身份。只需做一次。

---

## 第三步：用户登录授权（2分钟）

创建完应用后，还需要用你的飞书账号登录，这样AI才能以你的身份操作。

跟AI说：**"帮我登录飞书CLI"**

AI会执行：
```bash
lark-cli auth login --recommend --no-wait
```

这条命令会生成一个授权链接，**你需要在浏览器里打开这个链接**。

打开后会看到权限列表页面：

1. 勾选底部的「一并开通多维表格、日历、通讯录、文档、消息与群组、邮箱、电子表格、任务、视频会议的常用权限」
2. 点击蓝色的 **「开通并授权」** 按钮
3. 看到「开通并授权成功」

然后会跳转到一个用户授权页面：

4. 确认权限列表（会列出所有你授权AI使用的能力）
5. 点击蓝色的 **「授权」** 按钮
6. 看到「授权成功」

> ⚠️ 链接有效期10分钟，超时要重新生成。看到链接就马上点，不要拖。
> ⚠️ AI会在后台等你授权完成，你授权完了它会自动检测到。

---

## 第四步：验证是否成功（30秒）

跟AI说：**"检查飞书CLI状态"**

AI会执行：
```bash
lark-cli auth status
```

看到以下信息就说明完全成功：
- `identity: "user"` — 已登录用户身份
- `tokenStatus: "valid"` — token 有效
- `userName: "你的名字"` — 显示你的飞书名字

## 开始使用

安装完成后，你可以直接用自然语言跟AI说需求：

### 发消息

```
你说："给梓恺发个消息，今天SOP改完"
AI执行：lark-cli im +messages-send --as bot --text "今天SOP改完" --user-id ou_xxx
```

### 创建文档

```
你说："把这篇文案同步到飞书文档"
AI执行：lark-cli docs +create --title "文章标题" --markdown "文章内容"
```

### 写表格

```
你说："阅读数3500，点赞120，记到飞书表格里"
AI执行：lark-cli sheets +write --spreadsheet "表格ID" --data "3500,120"
```

### 创建任务

```
你说："给梓恺创建一个任务：本周五前完成SOP第3版"
AI执行：lark-cli task create --title "完成SOP第3版" --due "2026-04-04"
```

### 查日历

```
你说："看看我今天有什么日程"
AI执行：lark-cli calendar +agenda
```

### 搜聊天记录

```
你说："搜一下上周关于'课程定价'的聊天记录"
AI执行：lark-cli im +messages-search --query "课程定价" --start-time "上周一"
```

## 常见问题

### Q1：链接过期了怎么办？
重新让AI执行登录命令，会生成新链接。链接有效期10分钟。

### Q2：token过期了怎么办？
token有效期2小时，refresh token有效期7天。7天内AI会自动刷新，不用你管。超过7天没用，重新执行第三步登录就行。

### Q3：权限不够怎么办？
如果AI操作时提示权限不足，它会告诉你缺什么权限。你只需要让AI重新执行：
```bash
lark-cli auth login --scope "缺失的权限名"
```
然后在浏览器里授权就行。权限是累加的，不会覆盖之前的。

### Q4：能在手机上用吗？
飞书CLI是电脑端命令行工具，需要在电脑上使用。但操作结果会同步到飞书App，你在手机飞书上能看到。

### Q5：安全吗？
- 飞书CLI是飞书官方开源项目（MIT协议）
- 所有操作都需要你授权，AI不能做你没授权的事
- 写入/删除操作支持 `--dry-run` 预览，不会误操作
- 密钥存储在系统钥匙串中，不会明文暴露

### Q6：Windows/Mac/Linux 都能用吗？
都能用。飞书CLI基于Node.js，跨平台支持。

## 进阶：自动化场景

飞书CLI + Obsidian的组合可以实现很多自动化场景，以下是几个高价值的例子：

### 场景1：每天自动推任务到团队群
配合Windows计划任务，每天早上8:30自动把Obsidian里的当日任务推送到飞书群。

### 场景2：文案发布后数据自动回流
文章发布后，把阅读数、点赞数自动写入飞书表格，不用手动记录。

### 场景3：写完文案一键同步到飞书
在Obsidian写完Markdown文案，一条命令变成飞书文档，团队直接在飞书看。

### 场景4：客户交付进度自动追踪
把客户交付物变成飞书Task，自动提醒deadline，在飞书多维表格里看所有客户的进度。
