# 系统使用手册

> 超级内容创作系统 v2.0 完整使用指南

## 🎯 系统概述

超级内容创作系统是一个**自我进化的内容创作生态**,不是简单的线性工作流,而是通过数据反馈持续优化的智能系统。

---

## 🚀 快速开始

### 创作前(选题决策)
1. 打开 [[💡 灵感点子表]] 记录想法
2. 使用 `选题验证评分skill` 对选题打分
3. 80分以上选题 → 进入创作流程
4. 70-79分选题 → 存入 [[📋 选题备选库]]

### 创作中(开篇+结构+文案)
1. 从 [[📚 开篇模板库(总索引)]] 选择开篇模板
2. 从 [[02.领域/0.内容创作系统/🔥00.素材库/文案结构]] 选择对应的文案框架
3. 使用 `教知识文案skill` 或 `聊观点文案skill` 生成初稿
4. 使用 `文案敏感词检测skill` 检查违规

### 发布前(排版适配)
1. 使用 `公众号排版skill` 适配排版
2. 使用 `小红书图文skill` 转换小红书版本

### 发布后(数据复盘)
1. 在 [[02.领域/0.内容创作系统/🔥03.数据反馈/📊 数据监控中心]] 记录数据
2. 爆款内容 → 使用 `爆款复盘分析skill` 提取模板
3. 低互动内容 → 记录到 [[02.领域/0.内容创作系统/🔥03.数据反馈/❌ 失败案例库]]

## 🔄 完整创作流程

```
第1步: 选题决策
├─ 灵感记录 → 选题验证评分 → 80分以上进入创作
└─ 70-79分存入备选库,<70分归档

第2步: 调用上下文
└─ 确认个人风格、产品信息、AI创作规范

第3步: 开篇设计
└─ 从开篇模板库选择对应类型模板

第4步: 文案创作
├─ 匹配文案框架
├─ AI生成初稿
├─ 人工精修
└─ 敏感词检测

第5步: 平台适配
└─ 使用平台排版skill适配

第6步: 发布追踪
└─ 数据监控中心记录数据

第7步: 复盘进化
├─ 爆款 → 复盘分析 → 提取模板 → 更新库
└─ 失败 → 失败案例库 → 避免踩坑
```

---

## ⚠️ 注意事项

1. **选题必须验证**: 每个选题都用 `选题验证评分skill` 打分
2. **发布前必检测**: 每段文案都用 `文案敏感词检测skill` 审核
3. **爆款必复盘**: 每个爆款都用 `爆款复盘分析skill` 提取模板
4. **失败也记录**: 低互动内容记录到失败案例库

## 🆘 常见问题

### Q1: 选题评分不到80分怎么办?
- 查看优化建议,按建议修改选题
- 或存入备选库,等待灵感优化

### Q2: 找不到合适的开篇模板?
- 先看精选版661条模板
- 再看分类开篇库
- 最后看你的黄金开篇库

### Q3: 文案被检测出敏感词?
- 按照替换建议修改
- 再次检测直到通过

### Q4: 如何快速提升爆款率?
- 多复盘爆款,提取模板
- 记录失败案例,避免踩坑
- 持续优化选题验证标准
