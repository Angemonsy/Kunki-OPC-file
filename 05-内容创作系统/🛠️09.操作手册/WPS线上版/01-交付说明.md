## 二、完整安装流程（5步搞定）

### 第一步：运行一键安装脚本（5-10分钟）

- **Windows** → 双击 `一键安装.bat`
- **Mac** → 打开「终端」（启动台 → 搜索"终端" → 打开），运行 `chmod +x 一键安装.sh && ./一键安装.sh`

脚本会按顺序自动安装以下6样东西（已装过的自动跳过）：

| 序号  | 安装什么            | 干嘛用的                                               |
| --- | --------------- | -------------------------------------------------- |
| 1   | Obsidian        | 笔记软件，整套AI系统的载体                                     |
| 2   | Node.js         | 运行环境，Claude Code和插件都靠它                             |
| 3   | Claude Code CLI | 命令行AI工具，Claudian插件的底层引擎                            |
| 4   | Playwright MCP  | 浏览器自动化，让AI能控制Chrome帮你操作网页                          |
| 5   | 6个Obsidian插件    | 从安装包复制到Obsidian（Claudian、Nano Banana、Web Clipper等） |
| 6   | 知识库模板           | 从安装包导入Obsidian（文件夹结构 + 23个AI技能）                    |

> 脚本报错？别慌，打开对应的安装手册，手动一步步来也很简单：
> - Windows 用户 → 工具安装手册（Windows）
> - Mac 用户 → 工具安装手册（Mac）

---

### 第二步：启用插件（1分钟）

1. 打开 Obsidian
2. 左上角「设置」（齿轮图标）→ 左侧菜单找到「第三方插件」
3. 关闭「安全模式」（弹窗点确认）
4. 在「已安装插件」列表中，**逐个打开所有插件的开关**（Claudian、Nano Banana、Web Clipper、BRAT等）

---

### 第三步：配置API（这一步必须手动，脚本装不了）

装完工具后，需要给AI"接通大脑"——配置API Key。

#### Claudian插件（让AI能和你对话）— 二选一：

**方案A：Claude Max官方订阅（推荐，效果最好）**
- 费用：785元/月（闲鱼代充）
- 操作：
  1. 闲鱼搜索「Claude Max充值」购买，拿到账号密码
  2. 浏览器登录 claude.ai
  3. 登录 Claude Code（详细步骤见安装手册「方案A」章节，有7步图文教程）
  4. Claudian 不用填任何环境变量，自动识别

**方案B：第三方API（省钱试用）**
- 费用：20元起步，用多少充多少
- 操作：
  1. 打开 openclaw-api.com 注册账号
  2. 充值（支付宝/微信）
  3. 创建令牌，复制API Key
  4. 填入 Claudian 插件环境变量（详细步骤见安装手册「方案B」章节，有4步图文教程）

#### Nano Banana插件（让AI能生成手绘配图）：

1. 打开 cdn.12ai.org 注册账号
2. 充值10元（够用很久）
3. 创建令牌，复制API Key
4. 填入 Nano Banana 插件设置（详细步骤见安装手册「Nano Banana」章节）

> 详细的API配置步骤（带截图），请看本手册的第五章「API配置」部分。

---

### 第四步：验证 + 让AI搞定剩余配置（2分钟）

1. 打开 Obsidian 左侧的 Claudian 聊天面板
2. 输入：**「帮我安装」**
3. AI 会自动检查你的环境，搞定剩余配置

> 如果AI能正常回复，说明API配置成功了！

---

### 第五步：填写个人信息 + 开始用（5分钟）

AI 需要认识你，才能写出像你的内容：

1. 在 Claudian 聊天框说：**「帮我填个人信息」**
2. AI 会一步步问你问题（你是做什么的？面向什么人群？你的风格偏好？）
3. 全程像聊天一样，5分钟搞定

填完后，试试说：**「帮我写篇公众号爆款」**

AI 能识别并启动对应技能，就全部OK了！
