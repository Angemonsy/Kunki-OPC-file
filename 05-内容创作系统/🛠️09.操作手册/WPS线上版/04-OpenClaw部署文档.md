# 【学员版】OpenClaw 云端 AI 团队部署指南

> 预计时间：45-60 分钟 | 难度：★★★☆☆ | 需要：信用卡（约 60 元/月）

---

## 一、先搞清楚：OpenClaw 是什么，为什么要装

**一句话：OpenClaw 是你的云端 AI 员工，24小时在线，你不开电脑它照样干活。**

本地的 Claude（Claudian）很好用，但有个致命缺陷——你关电脑它就停了。

OpenClaw 装在云服务器上，连接到飞书或 Telegram，你随时用手机发消息就能让 AI 帮你工作。出差、睡觉、开车——它一直在。

**学员版 AI 团队配置（5个角色）：**

| 角色                | 功能              |
| ----------------- | --------------- |
| 🧑‍💼 管家（steward） | 协调其他 bot，回答综合问题 |
| 🔍 情报员（scout）     | 搜索热点、分析行业动态     |
| ✍️ 写手（writer）     | 起草文案、标题、开篇      |
| 📊 分析师（analyst）   | 数据解读、账号分析       |
| 🎯 助教（ta）         | 回答课程问题、辅导学员     |

## 二、第一步：购买云服务器

### 推荐配置

**腾讯云轻量应用服务器**（推荐新手首选）

- 配置：**2核 4G 内存 80G 硬盘**
- 价格：约 **60-80 元/月**（经常有活动更便宜）
- 地区：选**上海**或**广州**（国内访问快）

> ⚠️ 不要选香港或海外节点，访问飞书会有延迟

### 购买步骤

1. 打开 [腾讯云官网](https://cloud.tencent.com/) → 登录账号
2. 点击顶部「产品」→「计算」→「轻量应用服务器」
3. 点击「立即选购」
4. 配置选择：
   - 镜像：选 **「应用镜像」**
   - 搜索并选择 **「OpenClaw」**（一键模板）
   - 套餐：2核4G，带宽 4Mbps 以上
5. 购买时长：建议先买 **1个月** 试用
6. 完成支付

> 💡 没有「OpenClaw」应用镜像？选「系统镜像」→ Ubuntu 22.04，后面手动安装（稍复杂，本文档以应用镜像为主）

---

## 三、第二步：开放防火墙端口

服务器买好后，OpenClaw 的控制面板需要开放端口才能访问。

1. 进入腾讯云控制台 → 轻量应用服务器 → 找到你的服务器
2. 点击服务器名称进入详情页
3. 点击上方「防火墙」标签
4. 点击「添加规则」，填写：
   - 应用类型：自定义
   - 协议：TCP
   - 端口：**18789**
   - 来源：所有 IP（0.0.0.0/0）
5. 点击确认保存

> ✅ 成功标志：规则列表里出现 18789 端口

---

## 四、第三步：进入 OpenClaw 控制面板

1. 回到服务器详情页，记下你的**公网 IP 地址**（类似 `43.xxx.xxx.xxx`）
2. 打开浏览器，访问：`http://你的IP:18789`
3. 第一次访问需要设置管理员账号密码（自己设，记住）
4. 登录成功后你会看到 OpenClaw 控制台

## 五、第四步：配置 AI 模型

OpenClaw 需要连接 AI 服务商，才能让 bot 有「大脑」。

### 推荐方案：DeepSeek（性价比最高）

DeepSeek 新用户注册送 **500万 token** 免费额度，够用好几个月。

#### 获取 DeepSeek API Key

1. 打开 [platform.deepseek.com](https://platform.deepseek.com/)
2. 注册账号（用手机号即可）
3. 进入「API Keys」→ 点击「创建 API Key」
4. 复制生成的 Key（只显示一次，复制保存好）

#### 在 OpenClaw 添加模型

1. 进入 OpenClaw 控制台 → 左侧「模型」→「添加模型」
2. 填写：
   - 模型名称：`deepseek-chat`（随便起）
   - 类型：选 `OpenAI 兼容`
   - API 地址：`https://api.deepseek.com/v1`
   - API Key：粘贴刚才复制的 Key
3. 点击「测试连接」→ 看到绿色✅ 表示成功
4. 保存

> 💡 也可以用 Claude API（效果更好但要梯子）、混元（腾讯官方）、MiniMax 等，配置方式类似

## 六、第五步：配置通信渠道（飞书/Telegram 二选一）

这步决定你用什么 App 跟 AI 员工对话。

**推荐选飞书**（国内访问稳定，适合大多数人）

### 方案 A：飞书渠道（推荐）

#### 步骤 1：创建飞书机器人

1. 打开 [开放平台.feishu.cn](https://open.feishu.cn/)
2. 登录飞书账号
3. 点击「创建应用」→ 选「自建应用」
4. 填写应用名称（如：AI写手）和描述，上传图标（随意）
5. 进入应用详情 → 「凭证与基础信息」
6. 记下 **App ID** 和 **App Secret**（后面要用）

#### 步骤 2：添加机器人能力

1. 在应用详情页 → 左侧「添加应用能力」
2. 勾选「机器人」→ 确认

#### 步骤 3：配置消息事件

1. 左侧「事件订阅」
2. 请求地址填：`http://你的IP:18789/飞书/`
   （具体格式在 OpenClaw 控制台 → 渠道 → 飞书 里查看）
3. 勾选事件：`接收消息`（im.message.receive_v1）
4. 保存

#### 步骤 4：在 OpenClaw 添加飞书渠道

1. OpenClaw 控制台 → 「渠道」→「添加渠道」→ 选「飞书」
2. 填入 App ID、App Secret
3. 选择刚才配置的模型（deepseek-chat）
4. 保存

#### 步骤 5：发布应用并测试

1. 回到飞书开放平台 → 「版本管理与发布」→ 申请发布
2. 发布后，在飞书里搜索你的机器人名称
3. 发一条测试消息，如果收到回复 ✅ 配置成功

---

### 方案 B：Telegram 渠道（适合已有 Telegram 的用户）

> 注意：需要能访问 Telegram（需要梯子）

#### 步骤 1：创建 Telegram Bot

1. 打开 Telegram → 搜索 `@BotFather`
2. 发送 `/newbot`
3. 按提示输入 Bot 名称和用户名
4. 复制生成的 **Token**（格式：`123456789:ABCdef...`）

#### 步骤 2：在 OpenClaw 添加 Telegram 渠道

1. OpenClaw 控制台 → 「渠道」→「添加渠道」→ 选「Telegram」
2. 填入 Bot Token
3. 选择模型
4. 保存，OpenClaw 会自动设置 Webhook

#### 步骤 3：测试

1. 在 Telegram 搜索你的 Bot 用户名
2. 发送 `/start`，收到回复 ✅ 成功

## 七、第六步：初始化 AI 团队（一键脚本）

这步用脚本给你的 5 个 AI 员工写入「灵魂」——让它们知道自己是谁、该干什么。

### 使用 OrcaTerm 执行脚本

OrcaTerm 是 OpenClaw 内置的网页版终端，不需要安装任何软件。

1. OpenClaw 控制台 → 左侧「终端」或「OrcaTerm」
2. 点击进入，会看到命令行界面
3. 复制下面的脚本，**全选**粘贴到终端，回车执行

```bash
#!/bin/bash
# AI 内容创作团队 - 学员版初始化脚本
# 执行方式：复制全部，粘贴到 OrcaTerm，回车

BASE="/root/.openclaw"

echo "========================================="
echo "  AI 内容创作团队 初始化"
echo "========================================="

# 创建 workspace 目录
echo "[1/3] 创建工作目录..."
for agent in steward scout writer analyst ta; do
  mkdir -p "$BASE/workspace-$agent/memory"
done
echo "✅ 目录就绪"

# 写入用户信息（你需要修改这里）
echo "[2/3] 写入用户信息..."

cat > /tmp/user_info.md << 'USER_EOF'
# USER.md - 关于你的用户

- **姓名：** [在这里填你的名字]
- **称呼：** [你希望 AI 怎么叫你]
- **时区：** Asia/Shanghai (UTC+8)
- **身份：** [你的身份，如：内容创作者、自媒体博主]

## 我在做什么

- [填写你的主要业务方向]
- [你运营的平台]
- [你的目标受众]

## 我的偏好

- 简洁直接，不要废话
- 给结果，不给过程
USER_EOF

for agent in steward scout writer analyst ta; do
  cp /tmp/user_info.md "$BASE/workspace-$agent/USER.md"
done
echo "✅ 用户信息已写入"

# 写入各角色身份
echo "[3/3] 写入角色身份..."

# 管家
cat > "$BASE/workspace-steward/SOUL.md" << 'EOF'
你是团队管家，负责协调和综合回答。

## 核心职责
- 理解用户的综合需求，给出全局性建议
- 协调其他 bot 的工作
- 当用户不确定找谁时，由你来接单并分发

## 行为风格
- 简洁专业，一句话说清楚
- 主动建议下一步行动
- 用户说"安排一下"你就知道该协调了
EOF

# 情报员
cat > "$BASE/workspace-scout/SOUL.md" << 'EOF'
你是内容情报员，专门搜集和分析信息。

## 核心职责
- 搜索最新热点、行业动态、竞品动向
- 分析某个话题的爆款潜力
- 找到可以蹭热点的内容切入角度

## 行为风格
- 先给结论，再给依据
- 数据要标注来源或时间
- 直接说"这个值得写/不值得写"
EOF

# 写手
cat > "$BASE/workspace-writer/SOUL.md" << 'EOF'
你是内容写手，专门负责文案创作。

## 核心职责
- 根据选题生成文案草稿（开篇/正文/结尾）
- 生成爆款标题备选
- 优化和润色文案

## 行为风格
- 口语化，不用 AI 腔
- 禁用：综上所述、值得注意的是、不难发现
- 每段不超过 4 行
- 直接输出内容，不要解释"我会帮你..."
EOF

# 分析师
cat > "$BASE/workspace-analyst/SOUL.md" << 'EOF'
你是数据分析师，负责解读数据和账号分析。

## 核心职责
- 解读内容数据（阅读量、互动率、涨粉量）
- 分析对标账号的内容策略
- 给出数据驱动的改进建议

## 行为风格
- 用数字说话
- 给出明确的优先级建议
- "下一步该做什么"永远是结论的最后一句
EOF

# 助教
cat > "$BASE/workspace-ta/SOUL.md" << 'EOF'
你是课程助教，负责解答学员问题。

## 核心职责
- 解答 AI 工具使用问题
- 解答内容创作方法论问题
- 引导学员找到解决方案，而不是直接给答案

## 行为风格
- 耐心，不厌烦重复问题
- 用举例子的方式解释抽象概念
- 引导思考：先问"你现在遇到的具体问题是？"
EOF

echo "✅ 角色身份写入完成"
echo ""
echo "========================================="
echo "  初始化完成！"
echo "  5个 AI 员工已就位：管家/情报员/写手/分析师/助教"
echo "  ⚠️  记得去修改 USER.md 里的用户信息！"
echo "========================================="
```

> ⚠️ 执行完后，记得去修改脚本里 USER.md 的内容，填入你自己的真实信息

### 修改 USER.md 的方法

执行完脚本后，在 OrcaTerm 里运行：

```bash
nano /root/.openclaw/workspace-steward/USER.md
```

修改好后按 `Ctrl+X` → `Y` → `Enter` 保存。

然后把改好的文件复制给其他 bot：
```bash
for agent in scout writer analyst ta; do
  cp /root/.openclaw/workspace-steward/USER.md /root/.openclaw/workspace-$agent/USER.md
done
```

## 九、常见问题

**Q：bot 不回复怎么办？**

按顺序检查：
1. 服务器是否在运行（腾讯云控制台查看状态）
2. 18789 端口是否开放（防火墙规则）
3. 模型 API Key 是否有效（OpenClaw → 模型 → 测试连接）
4. 飞书应用是否已发布（开放平台 → 版本管理）

**Q：API 费用怎么控制？**

DeepSeek 新用户有 500万 token 免费额度，日常使用完全够。付费后：
- deepseek-chat 约 ¥1/百万 token（输入）
- 每天正常用，一个月费用 < 10 元

**Q：服务器费用怎么算？**

腾讯云轻量 2核4G 正常价约 96元/月，经常有活动。
新用户首购可以低至 60元/月。

**Q：能不能用免费的 API？**

可以试试 Groq（免费，但有速率限制）或 Cloudflare AI（免费额度）。
但稳定性不如 DeepSeek 付费，建议先用 DeepSeek。

**Q：手机上能用吗？**

可以。飞书有手机 App，Telegram 也有。装好后直接和 bot 对话，体验和 PC 一样。
