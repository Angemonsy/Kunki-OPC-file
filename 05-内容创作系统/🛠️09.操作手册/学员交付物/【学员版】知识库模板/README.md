# 内容创作系统·知识库模板

欢迎使用这套内容创作知识库。这是一套为 AI 辅助内容创作设计的 Obsidian 系统，配合 Claudian 插件使用效果最佳。

---

## 这套系统能帮你做什么

- 用 AI 快速产出公众号/视频号/小红书文案
- 管理你的选题、开篇模板、文案框架
- 追踪每篇内容的数据，沉淀爆款规律
- 让 AI 记住你的风格、你的用户、你的产品

---

## 文件夹说明

| 文件夹 | 用途 |
|--------|------|
| `01.用户画像/` | 描述你的目标用户，AI 据此写出更精准的内容 |
| `02.文案结构/` | 存放你的 Skills 框架文件（从压缩包解压后复制进来） |
| `03.选题决策/` | 爆款选题表、选题备选库、灵感点子表 |
| `04.我的上下文/` | 你的个人信息、产品介绍、钩子话术——AI 的「记忆库」 |
| `05.开篇模板/` | 积累你实测有效的开篇，复用率极高 |
| `07.发布文案/` | 所有文案按年份归档，分草稿/待发布/已发布 |
| `08.数据反馈/` | 记录每篇内容的数据，用数据驱动选题 |
| `09.经验沉淀/` | 爆款方法论、平台规律、复盘沉淀 |

---

## 快速启动 3 步

**第一步：填写你的上下文**
打开 `04.我的上下文/个人自传.md`，把你的背景、专业领域、产品信息填进去。这是 AI 了解你的基础。

**第二步：描述你的用户**
打开 `01.用户画像/我的用户画像.md`，填写你的目标读者是谁、他们的痛点是什么。

**第三步：开始创作**
在 Claudian 插件里喊一声「帮我写一篇教知识类文章，选题是……」，AI 会自动读取你的上下文，按你的风格输出。

---

## Skills 框架安装

1. 收到 Skills 压缩包后解压
2. 将所有 `.md` 文件复制到你 Obsidian 库的 `.claude/skills/` 文件夹
3. 重启 Claudian 插件，输入 `/` 就能看到所有可用的 Skills

详细安装步骤见《工具安装手册》。
