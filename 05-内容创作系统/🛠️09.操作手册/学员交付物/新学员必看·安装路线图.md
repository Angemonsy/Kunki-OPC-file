# **阶段三：运行一键安装脚本**

- **Windows** → 双击 `一键安装.bat`

具体教程看文档：

![[06.附件/图片/9b5b3567def701502b92730e6153f757_MD5.jpg]]

- **Mac** → 打开终端（启动台→搜索"终端"），先进入安装包文件夹，再运行：
```
cd ~/Downloads/999课程安装包
chmod +x 一键安装.sh && ./一键安装.sh
```
> ⚠️ 如果你把安装包解压到了其他位置，把 `~/Downloads/999课程安装包` 换成你的实际路径

脚本会**按顺序自动安装6样东西**：

|   |   |   |
|---|---|---|
|**序号**|**安装什么**|**干嘛用的**|
|1|**Obsidian**|笔记软件，整套系统的载体|
|2|**Node.js**|运行环境，Claude Code和插件都靠它|
|3|**Claude Code CLI**|命令行AI工具，Claudian插件的底层引擎|
|4|**Playwright MCP**|浏览器自动化，让AI能控制Chrome帮你操作网页|
|5|**6个Obsidian插件**|从安装包的plugins/复制到Obsidian插件目录|
|6|**知识库模板**|从安装包的vault/导入Obsidian，含文件夹结构+23个AI技能|

![[06.附件/图片/d9cf551ce677a22a6a5978a55af4e83b_MD5.jpg]]

已装过的会自动跳过，全程约5-10分钟。

> 脚本失败？打开安装手册（[Windows](https://www.kdocs.cn/l/cdafluFig62Q) / [Mac](https://www.kdocs.cn/l/chlLaiiKZDlo)），手动一步步来也很简单。

# **阶段四：手动配置API（脚本装不了这个，必须手动）**

打开Obsidian → 左下角⚙️设置 → 第三方插件 → 关闭安全模式（弹窗点确认）→ 在「已安装插件」列表逐个打开所有插件的开关 → 然后配API：

**Claudian插件（让AI能和你对话）— 二选一：**

**方案A：Claude Max官方订阅（推荐，效果最好）**
- 费用：¥785/月（闲鱼代充）
- 购买：闲鱼搜「Claude Max充值」，或直接点 → [闲鱼链接](https://m.tb.cn/h.idJgFWj?tk=lzJ6UvfqU0q)
- 操作：闲鱼买Max → 登录Claude Code → Claudian不用填任何变量
- 详细步骤：打开 [Windows手册](https://www.kdocs.cn/l/cdafluFig62Q) / [Mac手册](https://www.kdocs.cn/l/chlLaiiKZDlo) →找到「二、安装Claudian插件」→「五）配置Claudian」→「方案A」第3-9步

**方案B：第三方API（省钱试用）**
- 费用：¥20起步，用多少充多少
- 操作：[openclaw-api.com](https://openclaw-api.com) 注册 → 充值 → 创建令牌 → 填入Claudian环境变量
- 详细步骤：打开 [Windows手册](https://www.kdocs.cn/l/cdafluFig62Q) / [Mac手册](https://www.kdocs.cn/l/chlLaiiKZDlo) →找到「二、安装Claudian插件」→「五）配置Claudian」→「方案B」第10-30步

> 💡 不知道选哪个？预算充足选A，先省钱试试选B，随时可以切换。

---

**Nano Banana插件（让AI能生成手绘配图）：**
- 费用：¥10（够用很久）
- 操作：[cdn.12ai.org](https://cdn.12ai.org) 注册 → 充值¥10 → 创建令牌 → 填入插件设置
- 详细步骤：打开 [Windows手册](https://www.kdocs.cn/l/cdafluFig62Q) / [Mac手册](https://www.kdocs.cn/l/chlLaiiKZDlo) →找到「三、安装Nano Banana插件」→「三）配置API Key」第1-17步

# **阶段五：验证 + 开始用**

3. 说 **「帮我写篇公众号爆款」** → AI启动技能，开始创作 🎉
