# Skill 总览与分类

> 这是知识库里全部 Skill 的说明书。每个 Skill = 一个能直接调用的 AI 能力。
> 用法：跟 AI 说一句对应的话（或目标），AI 会自动调用匹配的 Skill。不用记命令，描述你想干什么就行。
> 共 **182** 个 Skill，按"内容生产全流程 + 辅助 + 进阶"分为 8 大部分、20 个类别。

---
