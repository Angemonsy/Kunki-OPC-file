> 每条含：**功能** + **什么时候用/触发词** + 注意事项。共 140+ 个，分 8 大部分、20 个类别。

## 第一部分 · 内容创作主线（从 0 到发布）

### 1. 选题（决定写什么）

#### 选题生成

从零生成多个选题方案。适用于用户还没有选题方向、需要批量选题灵感的场景。
触发场景：当用户说"给我一些选题""帮我想选题""不知道写什么""生成选题"时自动调用。
关键词：生成选题、想选题、选题灵感、不知道写什么、给我选题

⚠️ 不触发场景（由其他skill处理）：
- 用户已有选题想深度分析能不能做 → 爆款内容选题策划师
- 用户已有选题想打分/排优先级 → 选题验证评分
- 用户需要标题 → 标题生成
- 用户需要写文案 → 对应文案类skill

#### 选题验证评分

纯评分工具：对已有选题进行13大爆款元素量化打分，输出分数和优先级排序。不做深度分析、不输出文案框架。适用于用户有1个或多个选题，想快速知道"几分""能不能爆""先发哪个"的场景。
触发场景：当用户说"帮我打个分""这个选题几分""能不能爆""先发哪个""选题排序"时自动调用。
关键词：打分、评分、几分、能不能爆、先发哪个、选题排序、优先级

⚠️ 不触发场景（由其他skill处理）：
- 用户需要深度分析+文案框架 → 爆款内容选题策划师
- 用户需要从零生成选题 → 选题生成
- 用户需要生成标题 → 标题生成

#### 爆款内容选题策划师

对用户已有的一个选题进行深度分析：联网搜索信息、匹配爆款元素、推荐脚本方向、输出文案框架。适用于用户已经有选题想法，想知道"这个能不能做、怎么做"的场景。
触发场景：当用户说"帮我分析这个选题""这个话题能不能做""这个选题怎么切入""帮我策划一下"时自动调用。
关键词：分析选题、策划选题、选题怎么做、能不能做、怎么切入

⚠️ 不触发场景（由其他skill处理）：
- 用户还没有选题、需要从零生成 → 选题生成
- 用户只需要打分/排优先级、不需要文案框架 → 选题验证评分
- 用户只需要追热点 → 热点追踪
- 用户需要写文案 → 对应文案类skill

#### 选题匹配爆款模板

从对标账号分析的筛选版中，自动匹配最佳爆款案例，提取文案类型、开篇方式、文案结构，提供可直接套用的市场验证模板。

触发场景：当用户提供选题后，需要找到经过市场验证的爆款模板、文案结构、开篇方式时自动调用。

关键词：选题匹配、爆款模板、对标分析、文案结构、开篇方式、市场验证、套用模板、匹配文案、验证数据、怎么写

快速启动：用户说"这个选题帮我匹配爆款模板"或"根据对标账号分析给我文案结构"或提供选题后问"怎么写"即可启动。

#### 痛点选题公式

用《领航计划》第八章的核心选题公式，帮学员批量产痛点选题：固定一个用户，把场景和人际关系一个个代进去，套出一串"刷到就停下来"的痛点选题，直接吐成"用户 × 场景 × 关系 × 痛点"的表格。解决"不知道写什么选题"的根本问题。

触发场景：当学员说"帮我套痛点选题""我是做XX的，给我想选题""用选题公式帮我出选题""我的用户是XX，痛点选题有哪些"时自动调用。

关键词：痛点选题、选题公式、用户场景关系、套选题、戳痛点、负面情绪选题、我这行写什么、痛点公式、批量选题

快速启动：学员报上自己的用户/赛道，说"帮我套痛点选题"即可启动。

⚠️ 不触发场景（由其他skill处理）：
- 想要通用、不限方法的选题灵感 → 选题生成
- 已有一个选题、想分析能不能做 → 爆款内容选题策划师
- 想给选题打分排优先级 → 选题验证评分
- 想要喂采集系统的搜索关键词 → 采集关键词生成

#### 录音稿提炼选题专家

从整理好的录音稿、PDF文档、课程笔记中深度提炼爆款选题，基于13大爆款元素和用户画像生成精准选题，自动添加到灵感点子表，并提供TOP 5优先级推荐和归档建议。

触发场景：当用户需要从录音稿、整理好的文档、课程笔记、PDF文件中提炼选题时自动调用。

关键词：提炼选题、录音稿选题、从文档提炼、选题挖掘、爆款选题、灵感提取、选题生成、PDF分析、课程笔记提炼

快速启动：用户说"从这个文档提炼选题"或"帮我挖掘这份录音稿的选题"或"分析这个PDF的选题"即可启动。

⚠️ 不触发场景（由其他skill处理）：
- 用户的录音稿还没整理、需要先结构化 → 录音稿整理
- 用户想直接从录音稿出公众号文章、不只是选题 → 录音稿转文案
- 用户没有文档素材、想从零生成选题 → 选题生成

#### 采集关键词生成

输入一个核心词、赛道或一个选题想法，自动按"核心词+维度词组合法"和"命题三步法"批量生成一组可直接喂给采集系统（视频号/抖音/小红书）的搜索关键词，解决"采集系统很自动，但不知道该搜什么词"的问题。

触发场景：用户说"生成采集关键词""我要采素材搜什么词""帮我想搜索关键词""这个赛道搜什么""把这个想法变成关键词""喂给采集系统的词"时自动调用。

关键词：采集关键词、搜索关键词、采集搜什么、关键词生成、找素材关键词、采集词、对标关键词、喂采集系统、关键词组合

快速启动：用户给一个核心词或赛道（如"AI做图""减肥""亲子教育"）或一个选题想法，说"生成采集关键词"即可启动。

### 2. 文案创作 · 按内容类型

#### 教知识文案

帮你做出真正有获得感、用户愿意收藏转发的知识内容。

#### 聊观点文案

基于实战验证的观点型文案创作方法,帮你做出立场鲜明、论证有力、引发共鸣的观点内容

#### 讲故事文案

帮你把真实经历变成打动人心的故事内容，让用户在别人的故事里看到自己的影子。

#### 产品推广文案

基于经纬「晒过程·客户见证/产品推广型」框架 + ABCD用户心理模型，将产品信息和真实素材（直播稿/学员反馈/实战数据）转化为高转化的产品推广文案。
核心方法论：A→B危机预警开头 + B→C困境转折（方案登场） + C→D结果展示 + 转化钩子收尾。
与「客户见证转化文案」的区别：客户见证以客户故事为主角，产品推广以产品/服务本身为主角。

触发关键词：产品推广、产品文案、推广文案、卖课文案、卖货文案、产品介绍文案、功能介绍

⚠️ 不触发场景（由其他skill处理）：
- 用户有客户反馈/案例想写见证型文案 → 客户见证转化文案
- 用户有碎片想法想写文案（不是产品推广） → 灵感碎片转文案
- 用户想写观点型/知识型/故事型文案 → 聊观点文案/教知识文案/讲故事文案
- 用户有录音稿想转文案 → 录音稿转文案
- 用户想从实战过程写教程型文章 → 实战复盘转内容
- 用户想拆解别人的爆款来改写 → 爆款拆解改写

#### 客户见证转化文案

将真实客户反馈、对话截图、案例描述转化为高转化率的客户见证文案。
目标不是阅读量，而是私聊咨询/加微信/付费转化。
基于「晒过程·客户见证/产品推广型」四段式框架（困境→转折→方法→结果）。

触发关键词：客户见证、客户案例、客户反馈转文案、见证文案、转化文案、客户故事

⚠️ 不触发场景（由其他skill处理）：
- 用户有碎片想法想写文案（不是客户案例） → 灵感碎片转文案
- 用户想写产品介绍/功能说明型文案 → 产品推广文案
- 用户有录音稿想转文案 → 录音稿转文案
- 用户想拆解别人的爆款来改写 → 爆款拆解改写
- 用户想从实战过程写教程型文章 → 实战复盘转内容
- 用户想写观点型/知识型/故事型文案（非转化导向） → 聊观点文案/教知识文案/讲故事文案

### 3. 文案创作 · 按素材来源（编排器）

#### 灵感碎片转文案

接收用户的碎片化想法、经历、观察、对话记录等原始文字，自动判断内容类型（教知识/聊观点/讲故事/晒过程），然后串联完整的公众号爆款生产流水线：类型判断 → 文案生成 → 标题生成 → 排版优化 → 敏感词检测 → 存档反馈。

本质是一个智能路由器 + 流水线调度器：碎片输入 → 类型判断 → 调用对应文案 skill → 补充下游环节。

触发场景：当用户有一段想法或经历想变成公众号文章，但不确定该用什么类型和框架时调用。

关键词：灵感、碎片、想法变文章、随手记、我有个想法、帮我写成文章、这段话能写成文章吗

快速启动：用户直接粘贴一段文字，或说"我有个想法，帮我写成公众号文章"即可启动。

⚠️ 不触发场景（由其他skill处理）：
- 素材是AI对话记录 → 对话转文案
- 素材是粉丝私信/评论区问题 → 用户提问转文案
- 素材是社群聊天记录 → 社群精华转文案
- 素材是录音稿/课程笔记 → 录音稿转文案
- 素材是别人的爆款文案想拆解 → 爆款拆解改写
- 素材是自己的爆款想衍生 → 爆款衍生系列
- 素材是外部热点链接 → 公众号爆款生产
- 用户有热点想写视频文案 → 热点文案生成

#### 对话转文案

将用户与AI的对话记录（讨论、问答、头脑风暴等）转化为公众号爆款文章。核心逻辑：从对话中提炼核心观点和素材 → 选择最佳文案路径和框架 → 生成文案 → 串联下游流水线（标题→排版→敏感词检测→存档）。

触发场景：当用户和AI聊完一个话题后，想把对话内容变成一篇公众号文章时调用。

关键词：对话转文章、聊天变文章、把我们聊的写成文章、讨论转文案、对话变内容、刚才聊的能写篇文章吗

快速启动：用户说"把我们刚才聊的写成一篇文章"或"这段对话帮我变成公众号文章"即可启动。

⚠️ 不触发场景（由其他skill处理）：
- 素材是单段碎片想法（不是多轮对话） → 灵感碎片转文案
- 素材是自己的实战过程想写方法论 → 实战复盘转内容
- 素材是社群聊天记录（不是用户与AI的对话） → 社群精华转文案
- 素材是粉丝私信/评论问题 → 用户提问转文案
- 素材是录音稿/课程笔记 → 录音稿转文案

#### 录音稿转文案

从录音稿、课程笔记、PDF文档出发，自动串联整理→提炼选题→选择选题→判断类型→文案生成→下游流水线的完整流程。本质是一个编排器，把现有的录音稿整理、选题提炼、文案生成等skill串成一条完整的生产线。

触发场景：当用户有录音稿、课程笔记、PDF文档，想从中提炼选题并生成公众号文章时调用。

关键词：录音稿转文章、课程笔记变文章、从录音稿写文章、录音稿生成文案、课程内容转文章、PDF转文章

快速启动：用户说"把这个录音稿变成公众号文章"或"从这份课程笔记写一篇文章"即可启动。

⚠️ 不触发场景（由其他skill处理）：
- 用户只想整理录音稿、不需要写文案 → 录音稿整理
- 用户只想从文档提炼选题、不需要写文案 → 录音稿提炼选题专家
- 用户有碎片想法想写文案（不是录音稿） → 灵感碎片转文案
- 用户有热点想写视频文案 → 热点文案生成

#### 用户提问转文案

从用户私信、评论区问题、社群提问出发，将真实用户问题转化为公众号爆款文章。核心逻辑：用户问题天然自带"痛点钩子"，直接用问题做开篇，回答问题做正文，是最高效的选题来源。

本质是一个编排器skill，把问题解析→选题包装→类型路由→文案生成→下游流水线串成一条完整的生产线。

触发场景：当用户有粉丝提问、评论区问题、私信截图、社群提问，想从中写一篇公众号文章时调用。

关键词：粉丝问题、评论区、私信、用户提问、有人问我、粉丝问了、回答问题写文章、问题变文章

快速启动：用户说"有粉丝问了这个问题，帮我写成文章"或粘贴问题内容即可启动。

⚠️ 不触发场景（由其他skill处理）：
- 素材是自己的碎片想法（不是粉丝提问） → 灵感碎片转文案
- 素材是社群多人讨论（不是单个提问） → 社群精华转文案
- 素材是AI对话记录 → 对话转文案
- 素材是录音稿/课程笔记 → 录音稿转文案

#### 社群精华转文案

从社群聊天记录、讨论精华、群内热议话题出发，提炼选题并生成公众号爆款文章。核心逻辑：社群讨论天然具备多视角碰撞、真实案例密集、争议性强的特点，是高质量素材的富矿。

本质是一个编排器skill，把社群内容清洗→选题提炼→类型路由→文案生成→下游流水线串成一条完整的生产线。

触发场景：当用户有社群聊天记录、群讨论截图、社群精华内容，想从中提炼选题并生成公众号文章时调用。

关键词：社群讨论、群聊记录、社群精华、群里聊的、社群内容、群讨论变文章、社群转文章

快速启动：用户说"群里刚聊了一个话题，帮我写成文章"或粘贴社群讨论内容即可启动。

⚠️ 不触发场景（由其他skill处理）：
- 素材是单个粉丝提问（不是多人讨论） → 用户提问转文案
- 素材是自己的碎片想法 → 灵感碎片转文案
- 素材是AI对话记录 → 对话转文案
- 素材是录音稿/课程笔记 → 录音稿转文案

#### 实战复盘转内容

将自己的AI实战过程（如用AI协作写文章、搭建工作流、解决问题等）转化为一篇可教、可复制的公众号爆款文章。

核心逻辑：实战过程回溯 → 方法论提炼 → 选题包装 → 文案生成 → 发布

与「公众号爆款生产」的区别：素材来源不是外部热点，而是自己刚完成的实战过程。

触发场景：当用户完成了一次AI实战（写文章、搭工作流、用工具解决问题等），想把这个过程变成一篇可教的公众号文章时调用。

关键词：实战复盘、过程变文章、方法论拆解、晒过程、实战转内容、把过程写成文章

快速启动：用户说"把刚才的过程写成一篇文章"或"把这个方法论变成公众号文章"即可启动。

⚠️ 不触发场景（由其他skill处理）：
- 素材是AI对话记录（不是实战过程） → 对话转文案
- 素材是碎片想法（不是完整实战经历） → 灵感碎片转文案
- 素材是外部热点链接 → 公众号爆款生产
- 素材是录音稿/课程笔记 → 录音稿转文案

#### 爆款拆解改写

输入别人的爆款文案全文，自动深度拆解结构→提炼可复用骨架→选择改写策略→替换素材生成自己的文案。核心价值：保留经过市场验证的开篇和结构，换上你自己的经历和素材。

触发场景：当用户粘贴别人的爆款文案，想要拆解学习并改写成自己的内容时自动调用。

关键词：拆解、改写、仿写、爆款拆解、拆解改写、学习这篇、照着写、模仿、换皮、借鉴结构

快速启动：用户粘贴一段爆款文案，或说"帮我拆解这篇爆款并改写"即可启动。

⚠️ 不触发场景（由其他skill处理）：
- 素材是自己的爆款想衍生续集/换角度 → 爆款衍生系列
- 用户只想复盘爆款数据、不需要改写 → 内容复盘
- 素材是自己的碎片想法 → 灵感碎片转文案
