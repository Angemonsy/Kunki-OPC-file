# 小红书卡片生成器 V13 - 分析报告

## 现状评估

V13 已经是一个**功能完整的生产可用工具**：

### ✅ 已实现功能

- [x] 多卡片（多页）批量生成，支持增删
- [x] 双模式设计：内容编辑模式 + 排版微调模式
- [x] Sortable.js 拖拽排序块级元素
- [x] 滑块精调：字体大小、上下边距、X/Y位置微调
- [x] 富文本：加粗 + 高亮
- [x] html-to-image 一键导出 3x 高清 JPG
- [x] 默认尺寸 375×500px，符合小红书比例

### 核心优势

- **纯HTML+JS**：零依赖，打开浏览器就能用
- **原生渲染**：导出结果和屏幕看到的一致
- **box-decoration-break** 正确处理换行高亮，解决了截图关键问题
- **用户体验好**：双模式分离逻辑清晰，不会误操作

---

## 优化方向建议

按优先级排序：

### 🔴 P0 核心体验优化（改动小，收益大）

### 1. 预设模板系统

**现状**：新建页面只有固定模板，用户需要从头删改

**优化方案**：
- 点击「加一页」弹出模板选择
- 预设常见场景模板：

| 模板 | 适用场景 | 结构 |
|------|---------|------|
| 封面模板 | 系列开篇 | 大标题 + 标签 + 副标题 + 简介 |
| 干货问答 | 问题解答 | 问题标题 + 多个要点列表 |
| 知识点卡 | 单个知识点 | 标题 + 多个内容块 |
| 金句卡片 | 观点金句 | 大字居中 + 留白 |

**收益**：用户不用从零开始搭建，点一下就有结构，效率提升N倍

---

### 2. 主题风格切换

**现状**：固定紫渐变顶边 + 白色背景

**优化方案**：
- 增加「主题」按钮，下拉选择预设：
  - 默认紫（现有）
  - 极简白：无边框纯色背景
  - 莫兰迪：莫兰迪色系顶边
  - 渐变彩：多色渐变
  - 深色模式：深色背景浅色文字
- 支持自定义背景色

**收益**：适配不同内容风格，视觉多样性提升

---

### 3. 一键复制整页HTML

**现状**：只能导出图片，无法保存可编辑源

**优化方案**：
- 增加「复制HTML」按钮，把当前卡片HTML复制到剪贴板
- 增加「粘贴HTML」按钮，粘贴后恢复编辑
- 做好的卡片可以存档，下次继续编辑

**收益**：解决存档问题，方便复用和分享

---

### 🟡 P1 功能扩展

### 4. 新增块类型

支持更多内容样式：
- 分割线（虚线/实线）
- 引用块（左边框+浅灰背景）
- 代码块（等宽字体+灰色背景）
- 图片块（插入URL显示图片）

### 5. 卡片尺寸切换

- 默认：375×500（正方形）
- 选项：375×800（长图）
- 选项：1080×1080（方封面）

### 6. 本地自动保存

- 所有卡片数据存在 localStorage
- 刷新页面不丢失，下次打开继续编辑

---

### 🔵 P2 细节优化

### 7. 快捷键支持

- `Ctrl+N` → 新建页面
- `Ctrl+E` → 导出图片
- 提升键盘党效率

### 8. 操作撤回

简单操作支持撤销后退

---

## 迭代建议

**优先做P0三个功能**：
1. 预设模板 → 提升创建效率
2. 主题切换 → 提升视觉多样性
3. HTML复制 → 解决存档需求

这三个需求加起来代码改动不大，但用户体验提升非常明显。

做完P0再看反馈决定是否继续P1/P2。
