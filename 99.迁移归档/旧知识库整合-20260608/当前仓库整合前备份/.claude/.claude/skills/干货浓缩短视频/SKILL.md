# 干货浓缩短视频

> 一篇2000字的干货文章，浓缩成60秒，一个点打透

## 🎯 功能概述

将公众号干货文章（通常1500-3000字）浓缩为**一条独立完整的短视频口播稿**（60秒以内，≤250字）。

核心逻辑：**一篇文章只挑一个点，打透它**。不是缩写全文，是从中提炼出一个最有冲击力、最反常识、最有画面感的知识点，用短视频的节奏讲清楚。

```
公众号长文 → 扫描提炼候选点 → 选最强的1个 → 匹配脚本结构 → 从开篇库选开篇 → 生成口播稿 → 自检 → 画面标记 → 存档
```

## 📥 输入参数

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `源文案` | ✅ 是 | 公众号文章路径或全文 | - |
| `指定角度` | ❌ 否 | 用户指定要讲哪个点 | 自动选最强点 |
| `时长目标` | ❌ 否 | 30秒/45秒/60秒 | 60秒 |
| `平台` | ❌ 否 | 视频号/抖音/小红书 | 视频号 |

## 🔄 完整工作流程

### Step 1：扫描文章，提炼候选点

读取源文案，从中扫描出**3-5个可以独立成立的知识点**。

每个候选点需要满足：
- 能用一句话说清楚（≤20字）
- 脱离原文上下文也能理解
- 有冲击力（反常识/有画面感/有数据/有对比）

**候选点筛选三问**（每个点必须通过）：
1. 这个点30秒内能讲清楚吗？→ 不能就太复杂，不适合短视频
2. 观众看完能记住什么？→ 必须有一个明确的记忆锚点
3. 脱离原文能独立成立吗？→ 需要太多背景知识的点不选

输出候选点列表，每个标注：
- 点的一句话描述
- 内容类型判定（教知识/聊观点/讲故事/晒过程）
- 冲击力类型（反常识/数据冲击/画面感/痛点共鸣/实操干货）
- 推荐指数（★1-5）

**如果用户指定了角度，跳过候选筛选，直接用用户指定的点。**

**展示格式**：
```
从这篇文章里提炼了X个可以做短视频的点：

① {点描述}（{内容类型}·{冲击力类型}）★★★★★ ← 推荐
② {点描述}（{内容类型}·{冲击力类型}）★★★★
③ {点描述}（{内容类型}·{冲击力类型}）★★★

用第①个还是换一个？
```

**等待用户确认后再进行下一步。**

### Step 2：匹配脚本结构

根据选定的点的**内容类型**，匹配最适合的短视频脚本结构。

#### 短视频适配的4种核心结构（从教知识/聊观点/讲故事/晒过程四大框架中精简）

**结构A：解题型**（适配「教知识」类选点）
```
🪝 钩子：痛点/困境场景（3-5秒）
📌 核心方法：一个解法讲清楚（20-35秒）
🎯 效果对比：之前vs之后（10-15秒）
💎 金句收尾（5秒）
```
开篇公式优先级：痛点连击 > 反直觉发现 > 成果前置

**结构B：认知颠覆型**（适配「聊观点」类选点）
```
🪝 钩子：反常识观点直接抛出（3-5秒）
📌 论证：一个角度打透（正面论据or反面拆解）（20-35秒）
🎯 案例/数据验证（10-15秒）
💎 金句升华（5秒）
```
开篇公式优先级：否定句式 > 制造对立 > 颠覆认知

**结构C：过程展示型**（适配「晒过程」类选点）
```
🪝 钩子：成果前置，先展示结果（3-5秒）
📌 关键步骤：最核心的1-2步怎么做（20-35秒）
🎯 踩坑/意外：过程中的转折点（10-15秒）
💎 一句话总结（5秒）
```
开篇公式优先级：成果前置 > 数量限定 > 时间效率

**结构D：故事浓缩型**（适配「讲故事」类选点）
```
🪝 钩子：冲突/悬念场景（3-5秒）
📌 转折：关键转变是什么（15-25秒）
🎯 结果+感悟（10-15秒）
💎 升华金句（5秒）
```
开篇公式优先级：场景还原 > 制造悬念 > 情绪共鸣

**输出格式**：
```
选定的点：{点描述}
内容类型：{教知识/聊观点/讲故事/晒过程}
推荐结构：{结构A/B/C/D}（{结构名}）

段落组合：🪝 → 📌 → 🎯 → 💎
各段时长分配：{具体秒数}
总字数控制：≤{字数}字
```

**不需要等待用户确认，直接进入Step 2.5。**

### Step 3：生成口播稿（核心步骤）

#### 3.1 创作前必读知识库

**必须在写脚本前自动读取以下文件**，不需要用户提醒：
1. `02.内容创作系统/🔧06.我的档案/我的个人上下文/风格萃取/直播口语风格萃取.md` → 口语节奏、句式、语气词打底
2. `02.内容创作系统/🔧06.我的档案/我的个人上下文/风格萃取/我的文案风格萃取.md` → 掌握语言风格
3. `02.内容创作系统/🔧06.我的档案/我的个人上下文/风格萃取/公众号文案风格萃取.md` → 掌握段落节奏

#### 3.2 口播稿生成

使用Step 2.5用户选定的开篇公式作为开头，按Step 2选定的结构生成口播稿。

**字数控制**（铁律）：
- 30秒 → 总字数 ≤ 120字
- 45秒 → 总字数 ≤ 180字
- 60秒 → 总字数 ≤ 250字

**语言规则**（基于风格萃取文档）：
1. 全程口语化，像跟朋友聊天
2. 短句为主，每句不超过15字
3. 词汇选择：精准的日常词汇，避免儿化音
4. 语气处理：可用"啊"表达语气，不用"吧"和"呢"
5. 人称使用：用"我们"而非"咱们"
6. 过渡语：用"那么""所以""为什么会这样呢"等自然过渡，不用"首先其次最后"
7. 情感浓度：克制但有力度，洞察而非煽情
8. 用省略号`...`标记停顿节奏
9. 用【重音】标记需要加重语气的词
10. 禁用AI词汇："综上所述""建议您""非常有效""值得注意的是"

**一个点铁律**：整个脚本只讲一个点。如果发现自己在塞第二个点，立刻删掉。

#### 3.4 金句设计

结尾金句从以下公式中选择或改编：

**对仗式**（S级爆款最爱）：「XX的时代结束了，YY的时代开始了」
**定义式**：「说白了就是用系统代替自律」
**让步转折式**：「AI可能不会XX，但它确实能YY」

金句自检四问：
1. 脱离上下文能理解吗？
2. 15-40字以内？
3. 有恍然大悟感吗？
4. 想截图分享吗？

### Step 4：自检（必做，不可跳过）

#### 4.1 AI味强制自检

**读取知识库**：`02.内容创作系统/🔧06.我的档案/AI创作规范.md`

逐项检查以下6项，每项标注✅或❌：

```
□ 开篇真实性：是否用钩子/痛点开场？（禁止"有个朋友问我"式虚构）
□ 口语高频词：是否使用了"那/就/其实/你会发现/所以"等口语词？
□ AI禁用词：是否避免了"综上所述/建议您/首先其次最后/非常有效"？
□ 比喻质量：比喻是否具体生动？（"超级能干的秘书" > "强大的引擎"）
□ 段落节奏：长短句是否交替？
□ 念出来测试：大声念一遍，嘴上顺不顺？
```

**判定规则**：
- 6项全部✅ → 通过
- 4-5项✅ → 修改不达标项
- ≤3项✅ → 必须重写

#### 4.2 风格对标检查

将口播稿与风格萃取文档逐项对比：

| 风格维度 | 标准 | 是否达标 |
|---------|------|---------|
| 词汇选择 | 精准日常词汇，无儿化音 | ✅/❌ |
| 句式结构 | 短句为主，长句精准展开 | ✅/❌ |
| 语气处理 | 用"啊"，不用"吧""呢" | ✅/❌ |
| 过渡语 | 口播式自然过渡 | ✅/❌ |
| 情感浓度 | 克制但有力度 | ✅/❌ |
| 整体语感 | 读起来像真人说话 | ✅/❌ |

#### 4.3 内容层自检

- 一个点铁律：是否只讲了一个点？
- 字数铁律：是否在目标字数范围内？
- 独立完整：脱离原文能理解吗？
- 前3秒：开头是钩子还是铺垫？
- 干货感：观众看完能记住/学到什么？
- 金句：结尾有记忆点吗？

#### 4.4 输出自检报告

```
## 口播稿自检报告

### AI味检查（6项）
- 开篇真实性：✅
- 口语高频词：✅
- AI禁用词：✅
- 比喻质量：✅
- 段落节奏：✅
- 念出来顺口：✅

### 风格对标（6项）
- 词汇/句式/语气/过渡/情感/语感：✅

### 内容检查
- 一个点：✅ 只讲了"{点描述}"
- 字数：✅ {实际字数}字（目标≤{目标字数}字）
- 独立完整：✅
- 前3秒钩子：✅ 使用了{开篇公式}
- 金句：✅ "{金句内容}"

### 结论：✅ 通过 / ❌ 需优化{具体项}
```

**自检不通过的项目，直接修改后重新输出口播稿，不需要用户参与。**

### Step 5：画面指引（与口播稿分离）

**重要：口播稿正文必须是纯文字，不插入任何emoji画面标记。画面指引单独用表格列在口播稿下方。**

画面指引表格格式：
```
| 时间 | 口播内容 | 画面 |
|------|---------|------|
| 0-5秒 | {开头几个字}... | 口播出镜 |
| 5-20秒 | {内容摘要}... | 口播出镜 |
| 20-30秒 | {内容摘要}... | 切屏录：{展示什么} |
| ... | ... | ... |
```

画面类型：
- **口播出镜**：默认画面，真人对镜头说话
- **切屏录**：切到手机/电脑屏幕录制，展示操作、界面、效果
- **文字卡片压屏**：在口播画面上叠加文字卡片（数据、对比、金句）
- **图片素材**：插入截图、示意图等

标记规则：
- 短视频需要**2-4个画面切换点**
- 优先在"展示操作/数据/对比"的位置切画面
- 口播稿和画面指引之间用 `---` 分隔

## ⚠️ 重要规则

1. **一个点铁律**：整个脚本只讲一个点，讲透它。不要试图塞两个点
2. **字数铁律**：严格控制在目标时长对应的字数范围内，宁短勿长
3. **独立完整**：观众不需要去看原文，这条视频本身就是完整的内容
4. **前3秒定生死**：开头必须是钩子，不要铺垫
5. **不需要引流**：结尾是金句升华，不是"去公众号看完整版"
6. **口语化**：念出来要自然，不像在读稿
7. **风格一致**：必须读取风格萃取文档后再写，保持用户说话习惯
8. **自检必做**：AI味检查+风格对标+内容检查三项全部通过才算完成

## 🔁 复用逻辑

用户说"再来一条"或"换个角度"时，回到Step 1的候选列表，排除已经用过的点，推荐下一个。
