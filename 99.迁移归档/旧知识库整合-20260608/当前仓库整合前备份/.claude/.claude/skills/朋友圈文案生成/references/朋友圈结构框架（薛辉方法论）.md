# 朋友圈文案结构框架

> 骨架来自薛辉166篇朋友圈的方法论萃取，皮肤用用户自己的风格。

---

## 一、6种结构模式（按使用频率排序）

### 模式1：真实事件 → 情绪释放 → 规律提炼（最高频）
- 先讲一件真实发生的事
- 让情绪先出来（愤怒/好笑/感慨/意外）
- 从事件中提炼一个可复用的规律或观点
- 读者跟着情绪走，接受观点时零抵抗

### 模式2：现象切入 → 拆解分析 → 反常识结论
- 抛出一个日常现象或热门话题
- 逐步拆解背后逻辑
- 给出反直觉的结论，制造认知冲击

### 模式3：知识框架型（编号列点）
- 直接给方法论框架
- 用1/2/3/4编号拆解
- 每个点：名称 + 解释 + 例子
- 适合干货类内容

### 模式4：数据/案例堆叠 → 个人判断
- 密集堆叠数据、案例、事实
- 形成信息量冲击
- 最后给出个人判断或行动结论

### 模式5：生活碎碎念 → 意外升华
- 轻松随意的生活流水账开头
- 中途突然转向深刻的人生观察
- 形成情绪落差，让人记住

### 模式6：故事沉浸叙述 → 现实映射
- 用画面感讲述一个故事（历史/他人/自己）
- 结尾拉回现实，与当下处境形成映射

## 二、8种开头钩子

| # | 类型 | 写法 | 示例句式 |
|---|------|------|---------|
| 1 | 反常识标题式 | 第一句就是反直觉判断 | "胖子比瘦子更适合做抖音" |
| 2 | 事件现场还原 | 直接把人拉进场景 | "前天刷朋友圈，发现有一个人复制我的朋友圈" |
| 3 | 对话直接引入 | 用真实对话开场 | "他跟我说：哥，我被辞退了" |
| 4 | 数字冲击 | 用具体数字制造好奇 | "3分钟卖了20万台" |
| 5 | 自问自答 | 抛出问题立刻回答 | "人活着是为了什么？是为了体验情绪" |
| 6 | 时间锚点 | 用时间制造代入感 | "三十三岁那年，刘禹锡穿着紫袍" |
| 7 | 情绪爆发式 | 直接释放情绪 | "哈哈哈哈哈哈哈哈" |
| 8 | 清单预告式 | 预告要讲几个点 | "说几个感受：1.xxx 2.xxx" |

## 三、5种收尾模式

| # | 类型 | 写法 | 示例 |
|---|------|------|------|
| 1 | 强观点收尾 | 一句话下判断，不解释 | "越是爱占小便宜的人越爱道德绑架" |
| 2 | 对仗金句 | 两句对仗，朗朗上口 | "消极浅试出谬论，积极深研得真知" |
| 3 | 自嘲/幽默收尾 | 主动降格，打破说教感 | "纯属写文案哈哈哈，改天反着写一篇" |
| 4 | 行动号召 | 引导下一步 | "下一个选题有了：《xxx》" |
| 5 | 留白式 | 不给结论，让读者自己想 | "窒息…" |

## 四、5大核心技巧

### 1. 对话还原法
把真实对话原文搬进来，不转述。读者看到原话会自动代入判断，比你说"这个人很无耻"有力十倍。

### 2. 身份降格 + 自我解构
每次输出强观点后，加一句自我调侃或质疑。主动把自己说低，反而让读者觉得真实可信。这是能持续输出强观点却不让人反感的核心机制。

### 3. 数字具象化
任何数字都转化成读者熟悉的参照物。不说"销量很高"，说"相当于1秒钟卖1111台，而我当年一个月才卖22台"。

### 4. 括号旁白
在正文中插入括号，像跟读者咬耳朵说悄悄话。制造亲密感和幽默感。
示例："凭良心赚钱，靠本事吃饭（哈哈哈哈哈）"

### 5. 跨界类比
用完全不相关的领域解释本领域。让专业知识变得人人可懂。
示例："豆包的思考过程像公务员，DS的思考过程像服务员"

## 五、金句句式模板（从166篇中提取）

| 句式 | 示例 |
|------|------|
| 越是X的人越Y | "越是爱占小便宜的人越爱道德绑架" |
| X不是X，而是Y | "穷人缺的从来都不是钱，而是体面" |
| 四字对仗 | "消极浅试出谬论，积极深研得真知" |
| 反转式 | "智者不入爱河，其实人人皆是智者，只要Ta不入爱河" |
| 类比降维 | "再贵的爱马仕，也不如我孩子实验中学的成绩单" |
| 否定+肯定 | "不要鹤立鸡群，要离开那群鸡" |
| 三段递进 | "面对复杂，保持欢喜" |

## 六、使用指南

生成朋友圈文案时：
1. 先选一种结构模式（根据素材类型选）
2. 选一种开头钩子（根据话题选）
3. 用核心技巧填充中间（对话还原、数字具象化等）
4. 选一种收尾模式
5. 最后用用户自己的语言风格重写（参考《朋友圈文案风格萃取》）

**关键原则：骨架用薛辉的，语言用用户的。**
