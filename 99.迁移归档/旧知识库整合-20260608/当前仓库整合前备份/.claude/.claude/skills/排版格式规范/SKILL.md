# 排版格式规范

## 标题层级编号规则

| 层级 | Markdown | 编号格式 | 示例 |
|------|----------|----------|------|
| 一级标题 | `#` | 一、二、三、 | `# 一、下载安装包` |
| 二级标题 | `##` | 一）二）三） | `## 一）运行安装脚本` |
| 三级标题 | `###` | 1、2、3、 | `### 1、打开Obsidian` |
| 四级标题 | `####` | 1）2）3） | `#### 1）选择路径` |

## 执行规则

1. 每个层级的编号在其父级下独立计数，进入新的父级后重新从头编号
2. 一级和二级都用中文数字（一二三四五六七八九十），三级和四级用阿拉伯数字
3. 一级用顿号「、」，二级用右括号「）」，三级用顿号「、」，四级用右括号「）」
4. 一级vs二级通过「、」vs「）」区分；三级vs四级也通过「、」vs「）」区分
4. 如果标题本身不需要编号（如文章开头的引言段落），不强加编号
5. 正文中的列表项（如"第一种""第一条"）不受此规则影响，保持原样

## 操作流程

1. 读取目标文件全文
2. 识别所有 `#` `##` `###` `####` 标题行
3. 按层级关系重新编号
4. 用 Edit 工具逐一替换，不改动正文内容
