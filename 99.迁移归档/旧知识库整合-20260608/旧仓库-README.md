# 林kunki个人知识库使用说明
## 🎯 一句话简介
这是林kunki的一人公司全链路运营知识库，所有和540法则、IP运营、内容创作、产品相关的资料都在这里。
## 📂 文件夹结构（找东西直接对照）
| 文件夹 | 内容 | 什么时候找 |
|--------|------|------------|
| 🟢 A-系统基座 | 飞书同步脚本、工具配置 | 几乎不用找，我来维护 |
| 🟡 B-参考资料 | 外部课程笔记、行业报告、学习资料 | 找之前存的课程、外部资料 |
| 🔵 C-记忆核心 | 540方法论、IP定位、决策记录、过往经验 | 找我们一起确定的定位、规则、决策 |
| 🏭 D-内容创作 | 文案素材、选题库、产品资料、保研资料、词库 | 找写文案的素材、产品介绍、资料 |
| 🟣 E-产出交付 | 已发布的文案、数据反馈、合作记录、客户资料 | 找已经发过的内容、历史数据 |
