## 🔧 使用方法（无需完整克隆）

### 方法一：GitHub API 直接读取单个文件（推荐）

对于任意文件路径 `path/to/file.md`，可以直接获取原始内容：

```
https://raw.githubusercontent.com/Angemonsy/Kunki-OPC-file/main/path/to/file.md
```

示例：
- 读取 `CLAUDE.md`: `https://raw.githubusercontent.com/Angemonsy/Kunki-OPC-file/main/CLAUDE.md`
- 读取 `C-记忆核心/01-个人上下文/A02-USER.md`: `https://raw.githubusercontent.com/Angemonsy/Kunki-OPC-file/main/C-记忆核心/01-个人上下文/A02-USER.md`

然后用 `x-reader-url` 读取这个 URL 即可。

### 方法二：稀疏克隆（只拿最新内容，小体积）

如果需要多个文件，使用稀疏克隆减少下载量：

```bash
git clone --depth=1 https://github.com/Angemonsy/Kunki-OPC-file.git
```

`--depth=1` 只拉取最新一次提交，体积小很多。

## ⚠️ 规则

1. **优先读最新**：永远读取 main 分支最新内容，因为每日同步推送
2. **只拿需要的**：不要完整克隆，用 API 读取单个文件节省流量
3. **遵循结构**：五大板块结构固定，按图索骥找文件
4. **记忆优先**：个人上下文和经验沉淀是核心，这是林总的独家资产
5. **更新同步**：如果本地有旧版本，重新读取 main 分支获取最新
