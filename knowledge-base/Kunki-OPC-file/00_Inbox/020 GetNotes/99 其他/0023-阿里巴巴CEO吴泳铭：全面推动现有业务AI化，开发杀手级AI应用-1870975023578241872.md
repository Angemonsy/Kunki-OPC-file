# 阿里巴巴CEO吴泳铭：全面推动现有业务AI化，开发杀手级AI应用

## 🧠 摘要
阿里巴巴CEO吴泳铭近日表示，公司现有业务将全面实现AI化，展现了阿里巴巴在人工智能领域的战略布局和技术实力。与此同时，知情人士透露，阿里巴巴正在开发一系列AI原生应用，其中一些可能会在今年内推出。这些应用有望基于成熟的AI技术，成为下一个“杀手级”产品。

据悉，阿里巴巴的目标是打造一个甚至比抖音更受欢迎的AI应用，这一突破性产品可能很快就会问世。这表明阿里巴巴不仅致力于优化现有业务，还在积极探索全新的AI驱动型产品，以进一步巩固其在科技领域的领先地位。
