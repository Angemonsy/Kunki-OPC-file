#### 录音总结
本次AI行业分享会中，前互联网创业者、AI投资人李立克分享了大模型时代AI改造全行业的机遇，结合自身投资与创业案例分析了中国AI产业的优势，随后听众提问互动，最后邀请于学AI创始人关一进行分享。

**开场嘉宾介绍与讲者自我介绍**
* **开场介绍**：本次分享活动主题为AI自动重塑改造一切，由主持人开场介绍浙大博士AI创新中心主任李立克进行分享。
* **讲者从业背景**：李立克2000年进入互联网行业，2008年开始做互联网网站，曾创办公司后出售给腾讯，移动互联网时代持续创业，近三年转向AI投资，累计投资超过60家AI创业公司。

**大模型开源对AI创业的推动作用**
* **开源浪潮的影响**：半年前Llama系列模型开源后，催生了中国第一波大模型创业公司，包括数础等一批项目均基于Llama生态发展。
* **历史对比**：本次开源浪潮和20年前中国互联网软件开源浪潮非常相似，每次开源都会带来行业全新的发展机遇。

**中国AI产业的核心优势**
* **制造与工程能力**：中国拥有全球门类最齐全的制造业，工程能力全球顶级，同时芯片和模型领域的科研创新能力追赶速度极快。
* **成本优势**：中国模型训练的边际成本远低于海外，同样质量的模型训练成本提升带来的边际价值极低，在全球市场具备价格竞争力。

**超算经济的发展机遇**
* **超算经济增长背景**：Google Cloud带动了超算经济的指数级增长，互联网公司降价推动，温文在港股市值已经超过3000-4000亿港币，市场普遍看好超算经济的变现前景。
* **中国能源优势**：中国新疆、西部等区域有大量低价冗余电力，可以满足大模型训练的高电力消耗需求，这是中国发展AI超算的独特优势。

**AI投资项目的增长案例**
* **超算服务公司增长**：李立克投资的一家专注大模型训练增长的超算服务公司，去年4月注册成立，到年底年收入已经突破1亿元，今年预计可实现2-3亿元收入，从零到一增长速度极快。
* **出海AI团队案例**：李立克半年前参与成立的专业AI技术团队，目前业务已经覆盖数十个国家，提供百兆级AI推理服务。

**AI重塑传统行业的商业案例**
* **特斯拉案例分析**：马斯克计划将特斯拉转型为智能出行服务公司，通过AI自动驾驶，单台车每月可以创造近2万元收入，两个月即可收回车辆成本，一年可创造24万元收入，价值比传统卖车模式提升三倍，支撑万亿市值设想。
* **拼多多电商案例分析**：拼多多用AI重构了整个零售供应链体系，直接对接生产厂家，去掉中间环节，效率比传统淘宝模式提升1/10，售价更低的同时依然能保持更高利润。

**AI创业的方向建议**
* **避免短期低价值项目**：短期靠AI批量写文章接广告可以解决个人温饱，但不适合有长期追求的创业者，这类项目没有长期价值。
* **坚持全流程改造**：AI创业应当用AI改造行业全流程，要么降低成本提高效率，要么创造全新的用户体验，要做独立的全闭环企业，不要做平台的附庸。

**AI产品的核心逻辑要求**
* **数据闭环要求**：好的AI产品需要形成数据自我反馈闭环，用户使用产生的数据反过来优化模型，模型优化后再提升用户体验，形成正向循环。
* **从小场景切入**：当前很多AI场景缺乏足够的用户操作数据，优先从小场景切入，构建持续的数据循环，更容易做出可用的AI产品。

**投资人开放合作邀约**
* **投资布局范围**：李立克团队在国内、硅谷、东京、悉尼、东南亚都有布局合作项目，同时拥有人民币和美元投资基金，对接国内招行等渠道加快投资流程。
* **合作条件**：只要是真正解决行业需求的AI项目，技术能力没有明显硬伤，都可以对接合作，李立克开放个人微信接受项目对接。
