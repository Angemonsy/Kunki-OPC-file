## 之前的QClaw，为什么我为什么用了一次就放弃了

最早打通微信和OpenClaw的是QClaw，当时还要邀请码限制，炒得挺火，邀请码在闲鱼都卖到200多一个。我当时也第一时间去测试了，说实话，体验真的挺一般的，我用了一次就不用了。

核心几个问题，其实原文其实说得很对：

**1️⃣ 默认模型是混元，真的不太好用，每次都要手动切，太麻烦了**
**2️⃣ 微信里面不支持markdown，长文章阅读体验真的很差，看个代码都看不清**
**3️⃣ 它是用服务号客服消息来打通信道，不能拉群，不能置顶，想用的时候找半天，用了几次就找不到了**

所以后来出了小程序版本，体验好了一点点，但还是要多跳一步，还是不舒服。在我这里，其实就被归类到"能用但不好用"的分类里了，我就没再用了。

其实这也不能怪QClaw，当时微信没开放接口，他们只能拧巴着这么做，产品体验上肯定会打折扣，这是没办法的事情。

但有意思的是什么呢？就算体验不好，还是有很多人抢着要，为什么？因为微信这个流量入口太香了啊！

我们每天打开微信的人都知道，**微信是真的国民APP，你一天打开多少次？如果你的AI能直接住在微信里，不用跳来跳去，那体验真的不一样，便捷性不知道高了一个量级。这就是为什么大家哪怕体验不好还抢着玩的原因——需求摆在这儿。**

## 官方插件来了，体验到底怎么样？我实测给你看

现在微信自己出手了，推出了官方的龙虾插件，目前还在灰度测试，我比较幸运，被灰度到了，装起来试试水。

安装其实挺简单的，如果你被灰度到了，直接在终端运行一句命令就行：
```plaintext
npx -y @tencent-weixin/openclaw-weixin-cli@latest install

```

然后会跳出一个二维码，你用微信扫一下，登录授权，就能装上了。装好之后，它会以一个微信联系人的形式出现在你的联系人列表里，还能置顶，这一点比QClaw好太多了——想用的时候直接点开就找得到，不用翻半天服务号消息。

但是说实话，目前版本体验也还有一些限制：

✅ **好的地方：**

- 直接住在微信里，联系人形式，能置顶，好找
- 打通了OpenClaw，你可以直接在微信里调用你的Agent
- 官方接口，稳定性有保障

❌ **还不够好的地方：**

- 目前还不支持拉进群，只能单聊能用
- 依然不支持markdown格式，长内容阅读体验还是一般
- 还在灰度，不是所有人都能用上

所以你得去微信设置-插件里看看你有没有被抽到

从我实测下来，官方开放了接口，这才是最大的意义——给了所有玩家一张入场券，接下来就是各个玩家上场打仗了。

所以真正的太子是谁？现在还不好说。

但不管太子是谁不重要，重要的是——**微信终于开放了接口，这个口子开了，这才是最大的消息。**

在此之前，想要打通微信和OpenClaw，大家都是扭扭捏捏，各种hack，各种变通，体验都不顺畅。现在官方开了正门，接下来就是各个玩家就可以堂堂正正进来打仗了。
