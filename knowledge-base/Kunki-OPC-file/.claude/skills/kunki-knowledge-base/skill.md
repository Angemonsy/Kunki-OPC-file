# kunki-knowledge-base Skill

> Kunki 一人公司系统 - GitHub/Obsidian 主库远程访问入口。让小龙虾 AI 无需完整克隆仓库，即可直接读取林总知识库最新内容；飞书只作为轻工作台，不再作为完整知识库主库。

## 🔐 仓库信息

**GitHub 地址**: https://github.com/Angemonsy/Kunki-OPC-file

**默认分支**: `main`

**原始内容前缀**: `https://raw.githubusercontent.com/Angemonsy/Kunki-OPC-file/main/`

## 🧭 系统架构原则（必须先理解）

1. **GitHub/Obsidian 是唯一主库**：所有长期记忆、SOP、内容资产、产出归档，以 GitHub `main` 分支和本地 Obsidian 知识库为准。
2. **飞书是轻工作台**：飞书只承担 A01、kunki输入、kunki输出、任务展示/协作入口，不再作为完整知识库主库。
3. **执行任务前先读GitHub**：小龙虾/AI员工不得只看飞书旧文档，必须先读取 GitHub 最新主库，再读取飞书任务输入。
4. **产出先回主库**：生成的长期有效内容，优先写入 GitHub 对应五大板块；飞书只留摘要、展示版或任务链接。

## 🔧 使用方法（无需完整克隆）

### 方法一：GitHub API 直接读取单个文件（推荐）

对于任意文件路径 `path/to/file.md`，可以直接获取原始内容：

```
https://raw.githubusercontent.com/Angemonsy/Kunki-OPC-file/main/path/to/file.md
```

示例：
- 读取 `CLAUDE.md`: `https://raw.githubusercontent.com/Angemonsy/Kunki-OPC-file/main/CLAUDE.md`
- 读取 `C-记忆核心/01-个人上下文/A02-USER.md`: `https://raw.githubusercontent.com/Angemonsy/Kunki-OPC-file/main/C-记忆核心/01-个人上下文/A02-USER.md`

然后用 `x-reader-url` 读取这个 URL 即可。

### 方法二：稀疏克隆（只拿最新内容，小体积）

如果需要多个文件，使用稀疏克隆减少下载量：

```bash
git clone --depth=1 https://github.com/Angemonsy/Kunki-OPC-file.git
```

`--depth=1` 只拉取最新一次提交，体积小很多。

## 🔄 双向操作：直接写回 GitHub（节省飞书 token）

### 场景
小龙虾在云服务器生成了文档/复盘/内容，可以**直接提交回GitHub**，林总本地电脑 `git pull` 就能拿到，不用走飞书同步，节省飞书 token。

### 写回位置规则

| 产出类型 | GitHub/Obsidian归档位置 | 飞书处理 |
|---|---|---|
| 每日思考/复盘 | `C-记忆核心/02-每日输入/` 或追加到 `C-记忆核心/01-个人上下文/A03-MEMORY.md` | kunki输出留摘要 |
| 内容草稿/发布稿 | `E-产出交付/01-已发文案/` | kunki输出留标题+路径 |
| 选题推荐 | `D-内容创作/02-选题决策/` | 飞书展示Top3 |
| 爆款方法论/经验沉淀 | `C-记忆核心/03-经验沉淀/` | 飞书留摘要 |
| 产品/商业方案 | `D-内容创作/06-产品管理/` 或 `E-产出交付/02-变现路径/` | 飞书留展示版 |
| 合作记录 | `E-产出交付/05-合作管理/` | 飞书留协作记录 |
| 临时文件 | `E-产出交付/06-临时文件/` | 非必要不写飞书 |

**原则**：长期有效内容必须进GitHub/Obsidian；飞书只放摘要、协作入口或任务展示。

### 操作步骤（小龙虾这边）

```bash
# 1. 如果已经稀疏克隆了仓库，直接pull最新
cd /path/to/Kunki-OPC-file
git pull origin main

# 2. 创建/修改文件（按知识库结构放对位置）
vim C-记忆核心/02-每日输入/YYYY-MM-DD.md
# 或者生成新的文案放到 E-产出交付/01-已发文案/

# 3. 提交并推回GitHub（优先添加具体文件，避免误提交缓存/敏感文件）
git add "具体文件路径.md"
git commit -m "[龙虾] 每日更新：YYYY-MM-DD 内容创作/复盘"
git push origin main
```

### 林总本地拿到更新：

```bash
# 本地执行，一键拉取
cd D:\ObsidianVaults\MyVault
git pull origin main
```

就好了！GitHub 当中间枢纽，比飞书省token多了。
