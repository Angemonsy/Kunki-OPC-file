# 每日AI热点定时任务SOP（AIHOT版 v3.0 · 2026-05-14更新）

## 触发机制

- 每日 **22:00** 自动触发执行（牛马AI定时任务）
- 数据源：AI HOT ([https://aihot.virxact.com](https://aihot.virxact.com)) API + 补充搜索符合定位的额外新闻
- 输出两份文档到本地 `**D-内容创作/08-待选选题/**` 文件夹（待选选题区）

---

## 执行流程（严格按顺序）

### Step 1：从AIHOT获取全量数据

- 获取 **四个板块** 数据：
  1. **AIHOT精选** → 最近24小时精选内容
  2. **AIHOT今日日报** → 已经分类好的完整日报（模型/产品/行业/论文/技巧）
  3. **AIHOT更新日志** → 网站最近功能更新
  4. **补充搜索** → 额外搜索符合540定位（大学生/保研/AI创业）的新闻

### Step 2：生成「每日AI资讯汇总」

- 整合AIHOT四个板块 + 补充搜索，总共 **10-15条** 足够
- 按板块清晰展示，每条带标题、简介、原文链接
- 文件命名：`每日AI资讯汇总 - YYYY年MM月DD日.md`
- 存放位置：`D-内容创作/08-待选选题/`

### Step 3：生成「候选选题推荐」

- 从今日资讯汇总中筛选出 **5-10个** 好选题
- 每个选题必须标注：
  - 适合林总哪条内容主线（大学结果/AI工具与系统/一人公司实践/成长实验）
  - 推荐指数（星级）
  - 核心亮点
- 最后给出 **Top 3首推**，说明推荐理由
- 文件命名：`候选选题推荐 - YYYY年MM月DD日.md`
- 存放位置：`D-内容创作/08-待选选题/`

### Step 4：林总540定位筛选原则（必须严格遵守）

#### ✅ 优先推荐选题（得分高）

1. **AI工具使用技巧** → 你自己在用，读者也需要，干货永久不过时
2. **Claude/OpenAI/Anthropic官方更新** → 你天天用，亲测就是独家内容
3. **AI一人公司/智能体开发相关** → 契合IP定位「AI时代一人公司实践者」
4. **大学生/保研/竞赛相关的AI话题** → 核心受众就是大学生，刚需
5. **行业趋势/政策风向** → 适合做认知分享

#### ❌ 谨慎排除/降低优先级

1. **敏感法律话题**（AI代写/AI违法案例等）→ 你正在保研，避嫌，尽量不碰
2. **纯资本八卦**（Altman被调查/估值融资这类）→ 流量但对你没背书增益
3. **太硬核的学术论文** → 除非和学生直接相关，否则不推荐
4. **极端言论话题** → 不碰，保护保研，用词保持「我个人体验」视角
5. **已经过时一周以上的旧闻** → 时效性优先

#### 🎯 红线不能碰（保护保研）

- ❌ 禁止：「考研保研都是坑」「读大学没用」这种极端言论
- ✅ 允许：「我个人为什么选择保研+AI双线推进」「我个人在象牙塔里遇到的困惑」
- ✅ 表达原则：用**个人体验视角**，承认多元选择，不极端化

### Step 5：保存输出（新结构）

- 两份文档都放在：`**D-内容创作/08-待选选题/**`
- 这个文件夹放：还没确认选题的每日资讯和候选推荐，等着林总选题
- 林总确认选题后，再生成文案，最终文案归档到 `E-产出交付/`
- 飞书同步：只同步核心记忆和每日输入，不再同步每日待选选题
