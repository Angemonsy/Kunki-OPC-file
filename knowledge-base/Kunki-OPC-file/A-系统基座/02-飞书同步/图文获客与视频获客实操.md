# ❤️

#### 3.1、获取公众号 appid 和 appsecret

打开微信开发者平台，官网地址：[https://developers.weixin.qq.com/platform/login](https://developers.weixin.qq.com/platform/login)

扫码登录进入主页，然后点击<text color="red">**我的业务-公众号**</text>

在这里你可以看到公众号对应的：​

• AppID

• AppSecret

把这两个值先保存好，后面要用。

# 👍

**注意 1：只有管理员才能拿到 AppSecret**

这一点很多新手会卡住。

• 管理员：可以查看或重置 AppSecret

• 运营者：通常没有这个权限

如果你是运营者登录，发现看不到 AppSecret，不要怀疑自己，权限不够是正常的。

这时候需要让公众号管理员来操作。

**注意 2：AppSecret 平台不会长期保存**

微信平台不会把旧的 AppSecret 一直展示给你。

所以：​

• 第一次拿到后，要自己保存好

• 如果忘了，就只能重置

#### 3.2、配置服务器 IP 白名单

# ⚽

**为什么要做这一步？**

因为你的 OpenClaw 是部署在腾讯云服务器上的。

后面它要替你把文章发送到公众号草稿箱，微信需要先确认：​

"是不是你允许的服务器在调用我？"​

所以，要把你的服务器公网 IP 加到公众号白名单里。

##### 3.2.1 第一步：找到你的服务器公网 IP

如果你用的是腾讯云轻量服务器，可以在腾讯云控制台里看到公网 IP。

记下这个 IP，后面要填到白名单里。

##### 3.2.2 第二步：把 IP 加到白名单

**方法一：在开发者平台里加白名单**

进入微信开发者平台对应页面后，找到：​

**API IP 白名单**

把你的服务器公网 IP 加进去即可

**方法二：在公众号安全中心里配置**

如果你只有运营者权限，也可以试试在公众号后台的安全中心里配置。

有些场景下，这条路更方便。

# ✏️

注意：配置完不要立刻重试

**白名单刚加上后，通常不会立刻生效。**

建议你等 10～15 分钟再试

这样 IP 白名单就设置好了，我们就可以进行下面的操作了

### Step 5：生成画面场景数据

基于时间戳生成场景数据。**关键**：先读一下你当前 Remotion 项目里 `src/data/` 目录下已有的场景数据文件，看它的字段名和数据结构，然后按相同格式生成新数据。如果项目里没有，就用下面的默认格式：

**关于 Emoji（重要）**：

- 每个场景都应该配一个与内容相关的 emoji，作为画面中的视觉装饰元素
- emoji 在视频中会被**放大到非常醒目的尺寸**（fontSize 400px，占画面宽度约 37%），居中显示在画面中央偏上的位置，带弹入动画
- 这不是小装饰，是视觉焦点——所以选 emoji 要选那种大号显示好看的、和内容强相关
- emoji 是纯 Unicode 字符，Remotion 的 Chrome headless 会用系统 emoji 字体渲染（所以 Step 1 必须确保装了 emoji 字体）​
- 在场景数据中用 `doodle` 字段存 emoji 字符

```plaintext
# 保存为 out/gen-scenes.py 并执行
import json

with open("out/timestamps.json") as f:
    timestamps = json.load(f)

FPS = 30

# 深色配色轮换
COLORS = [
    {"bg": "#111318", "accent": "#00FF88"},
    {"bg": "#0D1117", "accent": "#58A6FF"},
    {"bg": "#1A0A2E", "accent": "#BD93F9"},
    {"bg": "#0F0F0F", "accent": "#FF6B6B"},
    {"bg": "#111318", "accent": "#FFD93D"},
]

# 为每个场景选一个跟内容相关的 emoji
# 这里用通用池轮换，实际生成时你应该根据每个场景的文字内容选更贴切的 emoji
EMOJI_POOL = ['🔥', '💡', '🚀', '🤖', '💰', '🎯', '⚡', '🧠', '📱', '✨',
              '💪', '🔧', '📊', '🎬', '🌟', '😱', '👀', '🎵', '📦', '🏆']

scenes = []
i = 0
scene_idx = 0
while i < len(timestamps):
    # 每3-5秒一个场景切换（约2-3句合并）​
    group = []
    group_start = timestamps[i]["start"]
    while i < len(timestamps) and (timestamps[i]["end"] - group_start) < 5.0:
        group.append(timestamps[i])
        i += 1
    if not group:
        group = [timestamps[i]]
        i += 1

    start_time = group[0]["start"]
    end_time = group[-1]["end"]
    full_text = "".join([t["text"] for t in group])
    color = COLORS[scene_idx % len(COLORS)]

    scenes.append({
        "id": f"scene-{scene_idx+1}",
        "startFrame": round(start_time * FPS),
        "endFrame": round(end_time * FPS),
        "text": full_text,
        "doodle": EMOJI_POOL[scene_idx % len(EMOJI_POOL)],  # 大号 emoji 装饰
        "backgroundColor": color["bg"],
        "textColor": "#FFFFFF",
        "accentColor": color["accent"],
    })
```
