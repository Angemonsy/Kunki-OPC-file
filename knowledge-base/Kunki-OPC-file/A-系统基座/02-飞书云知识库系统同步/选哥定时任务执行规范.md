## 四、13大爆款元素评分标准（每个元素0-10分）

满分130分，换算为百分制：`得分 ÷ 130 × 100`，四舍五入取整。

### 【生存层 - 基础流量】


| 元素        | 0分      | 5分     | 8-10分                 |
| --------- | ------- | ------ | --------------------- |
| **成本元素**  | 完全不涉及利益 | 间接涉及   | 直接告诉读者"你能省XX/赚XX/快XX" |
| **最差元素**  | 纯正面无风险  | 提到注意事项 | 核心卖点就是"避免XX错误/损失"     |
| **荷尔蒙元素** | 纯信息无情绪  | 轻微共鸣   | 看完标题就想点/转/评           |


### 【发展层 - 精准触达】


| 元素          | 0分      | 5分      | 8-10分                        |
| ----------- | ------- | ------- | ---------------------------- |
| **人群元素**    | 和目标读者无关 | 泛人群相关   | 一看就是写给"不甘平庸的大学生/想靠AI拿结果的普通人" |
| **场景元素**    | 纯概念无场景  | 模糊场景    | 读者能立刻想到"我什么时候能用"             |
| **数据元素**    | 没有数据    | 有数据但不震撼 | 数字本身就是钩子                     |
| **对比/对立元素** | 平铺直叙无反差 | 轻微对比    | 反差本身就是核心吸引力                  |


### 【超越层 - 破圈潜力】


| 元素          | 0分      | 5分      | 8-10分            |
| ----------- | ------- | ------- | ---------------- |
| **反认知元素**   | 所有人都知道  | 有一点新鲜感  | 直接打破固有认知         |
| **怀旧元素**    | 完全不涉及   | -       | 能唤起集体记忆          |
| **猎奇/揭秘元素** | 公开信息无秘密 | -       | 让人觉得"这信息别的地方看不到" |
| **头牌元素**    | 无知名品牌   | 提到但不是核心 | 自带流量的名字是标题一部分    |
| **高维认知元素**  | 纯信息搬运   | 分析比较常规  | 看完让人觉得"看问题角度不一样" |
| **钩子问题元素**  | 无法提炼问题  | 能提问但不抓人 | 问题本身就让人停住想看答案    |


### 评分纪律

- 大部分选题应该在 **60-80分** 区间
- **90分以上**一周最多出现 2-3个，标准不能太松
- 完全不沾边必须给 **0分**，不给同情分
- **必须结合林总定位（大学生+AI+成长）**打分，不是泛泛打分
- 每个分数必须有一句话理由，不允许只写分数

## 五、选题优先级与言论红线（必须严格遵守）

### 选题优先级（按这个顺序选）

1. **S级（最高）**：540一人公司实践相关
  - 540践行感悟、一人公司搭建心路、大学生一边校内一边做副业、林总当前正在做的事（写书/保研/OpenClaw/内容创作）
2. **A级**：结合540定位的AI相关
  - AI提高学习/副业效率、可落地AI副业、工具实测避坑、内容创作提效
3. **B级**：热点结合
  - 最新AI热点结合540定位找切入，不追无关热点

### 🚫 言论红线（保护保研，绝对不能碰）


| ✅ 允许                    | ❌ 禁止                |
| ----------------------- | ------------------- |
| 分享「我个人为什么选择保研+AI双线推进」   | 不说「考研保研都是坑，别去」      |
| 讲「我个人在象牙塔里遇到的困惑和思考」     | 不说「象牙塔没用，读大学没用」     |
| 讲「我尝试了这条路，感觉适合我，分享给你参考」 | 不说「所有人都应该出来做副业，别读书」 |
| 温和表达个人观点，承认多元选择         | 极端化、一棒子打死、人身攻击      |


**表达原则**：用「我个人体验」「我觉得」「对我来讲」个人视角，不极端化，承认多元选择。
