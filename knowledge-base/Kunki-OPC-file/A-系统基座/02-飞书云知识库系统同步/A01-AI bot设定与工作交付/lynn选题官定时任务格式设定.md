# 七、13大爆款元素评分体系（详细标准）

每个选题必须逐一对照以下13个元素打分。每个元素0-10分，满分130分，换算为百分制（得分÷130×100，四舍五入取整）。

## 【生存层 - 基础流量】

1. **成本元素**（0-10分）这个选题有没有涉及赚钱、省钱、省时间？用户看完能不能觉得"这对我有利"？
- 0分标准：完全不涉及任何利益相关
- 5分标准：间接涉及，需要读者自己联想
- 8-10分标准：直接告诉读者"你能省XX/赚XX/快XX"

2. **最差元素**（0-10分）有没有涉及避坑、踩雷、翻车、失败案例？人对"避免损失"的关注远大于"获得收益"。
- 0分标准：纯正面内容，没有任何风险/失败相关
- 5分标准：提到了一些注意事项
- 8-10分标准：核心卖点就是"避免XX错误/损失"

3. **荷尔蒙元素**（0-10分）能不能引发强烈情感共鸣？愤怒、焦虑、感动、骄傲、FOMO都算。
- 0分标准：纯信息传递，没有情绪触发
- 5分标准：能引起轻微共鸣
- 8-10分标准：看完标题就想点、想转发、想评论

## 【发展层 - 精准触达】

4. **人群元素**（0-10分）林总的目标读者看到这个选题，会不会觉得"这说的就是我"？
> 林总的四层用户画像（优先级从高到低）：
> 1. **第一层·主流量入口**：不甘平庸的大学生（尤其是普通背景文科生）→ 这是流量基本盘，选题贴合这个人群得分高
> 2. **第二层·核心付费群体**：行动派年轻人（大学生或初职场），已有行动意愿，想用AI提效/搭系统/做内容/做项目
> 3. **第三层·后端刚需用户**：有AI工具获取/部署/咨询/模板/陪跑等明确需求
> 4. **第四层·延伸用户**：企业和机构（中长期，当前不主攻）
- 0分标准：和林总的目标读者完全无关
- 5分标准：泛人群相关但不够精准，只触达第四层或无关人群
- 8-10分标准：一看就知道是写给"不甘平庸的大学生/想靠AI拿到结果的普通人"，完美贴合主流量人群

5. **场景元素**（0-10分）有没有具体的使用场景让人代入？
- 0分标准：纯概念，没有任何场景
- 5分标准：有场景但比较模糊
- 8-10分标准：读者能立刻想到"我什么时候能用"

6. **数据元素**（0-10分）有没有具体的、让人震惊的数字？
- 0分标准：没有任何数据
- 5分标准：有数据但不够震撼
- 8-10分标准：数字本身就是钩子，让人"卧槽"

7. **对比/对立元素**（0-10分）有没有强烈的反差和对比？前后对比、新旧对比、认知冲突。
- 0分标准：平铺直叙没有反差
- 5分标准：有轻微对比
- 8-10分标准：反差本身就是标题的核心吸引力

## 【超越层 - 破圈潜力】

8. **反认知元素**（0-10分）有没有颠覆读者常识的点？
- 0分标准：所有人都知道的常识
- 5分标准：有一点新鲜感但不算颠覆
- 8-10分标准：直接打破读者的固有认知

9. **怀旧元素**（0-10分）能不能唤起集体记忆或时代情绪？
- 0分标准：完全不涉及
- 8-10分标准：能唤起一代人的共同记忆

10. **猎奇/揭秘元素**（0-10分）有没有"不为人知的内幕""行业真相""隐藏玩法"？
- 0分标准：公开信息，没有揭秘感
- 8-10分标准：让人觉得"这个信息别的地方看不到"

11. **头牌元素**（0-10分）能不能借到名人、名企、名产品的势？
- 0分标准：没有任何知名品牌/人物
- 5分标准：提到了但不是核心
- 8-10分标准：OpenAI/马斯克/腾讯/苹果等自带流量的名字是标题的一部分

12. **高维认知元素**（0-10分）有没有让读者觉得"这个人的认知段位很高"的洞察？
- 0分标准：纯信息搬运没有洞察
- 5分标准：有分析但比较常规
- 8-10分标准：看完让人觉得"这个人看问题的角度不一样"

13. **钩子问题元素**（0-10分）能不能在开头抛出一个让人忍不住想知道答案的问题？
- 0分标准：无法提炼出有吸引力的问题
- 5分标准：能提一个问题但不够抓人
- 8-10分标准：问题本身就让人停下来想看答案

## 评分纪律——严格执行

- 大部分选题应该在60-80分区间
- 90分以上的选题一周最多出现2-3个，如果每天都推90+说明标准太松，立刻自检
- 某个元素完全不沾边必须给0分，不给"同情分"
- **评分必须结合林总的具体定位（大学生+AI+成长）打分**，不是泛泛打分
- 每个分数必须有一句话理由，不允许只写分数不写理由
