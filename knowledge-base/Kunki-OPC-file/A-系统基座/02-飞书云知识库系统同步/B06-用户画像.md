# B06\-用户画像

# 目标客户画像 \- 奇绩怪谈AIQ

## 核心受众分层

### 第一层核心受众：迷茫的大学生（重点）

**人群画像**：

- **身份**：大一到大四本科生，研究生也有

- **痛点**：

    - 天天上课考试，但不知道学了到底能干什么，对未来迷茫

    - 看到AI浪潮来了，但不知道从哪下手，不敢轻易尝试

    - 身边同学都在卷保研/考研/考公，不知道有没有其他出路

    - 想做副业，但找不到靠谱门路，怕被割韭菜

- **特征**：

    - 愿意尝试新事物，对AI好奇

    - 没太多积蓄，对价格敏感，喜欢高性价比

    - 相信真实经历胜过专家说教

    - 渴望\&\#34;有人带\&\#34;，少走弯路

**需求**：

- 想知道**普通人怎么用AI提高效率**，无论是学业还是副业

- 想看到**真实的成长路径**，别人踩过什么坑，怎么成功的

- 想找到**低门槛入门AI副业**的方法

- 需要**可直接落地的SOP**，不是空泛的道理

---

### 第二层扩展受众：想做AI副业的普通人

**人群画像**：

- **身份**：职场新人、斜杠青年、想赚外快的上班族

- **痛点**：

    - 知道AI是趋势，但不知道从哪切入

    - 学了很多AI概念，但还是不会落地变现

    - 被割过韭菜，对\&\#34;AI副业课\&\#34;有戒心

- **特征**：

    - 已经工作，有一定购买力

    - 追求\&\#34;真东西\&\#34;，愿意为真正有用的经验付费

    - 喜欢看真实案例，不喜欢空谈理论

**需求**：

- 想知道**哪些AI副业真的能赚到钱**

- 想拿到**验证过的变现路径**，直接照着做

- 想找**同频交流的圈子**，一起进步

---

### 第三层潜在受众：对AI好奇的职场人士

**人群画像**：

- **身份**：各行各业职场人

- **痛点**：

    - AI发展太快，担心被淘汰

    - 不知道AI怎么用到自己工作里

    - 学习时间少，需要高效方法

- **需求**：

    - 想知道**AI怎么提高本职工作效率**

    - 想要**简洁易懂的AI入门**，不用学复杂技术

    - 想了解**AI对行业的影响**，提前准备

---

## 受众核心共性

1. **都是普通人**，不是大佬，没太多资源

2. **相信真实**，不相信\&\#34;一夜暴富\&\#34;神话

3. **愿意行动**，想真刀真枪干，不想只当观众

4. **渴望提升**，想抓住AI这波浪潮，改变自己现状

---

## 内容适配策略

针对大学生核心受众：

- 内容多结合**大学校园场景**：保研、论文、考试、找工作

- 价格策略：低价入门，让更多人敢尝试

- 人设：**学长带路**，不是老师说教，分享自己踩过的坑

针对副业人群：

- 内容多讲**真实变现案例**，拆解可复制路径

- 强调**最小成本试错**，不要一下子投入太多

---

## 内容红线（对用户）

- 不吹\&\#34;躺赚\&\#34;\&\#34;被动收入\&\#34;\&\#34;一夜暴富\&\#34;

- 不割韭菜，只卖自己验证过的经验

- 说实话，讲真话，错了就承认，不装大神
