# 定时任务说明

## 使用规则（必读）

**当用户要求设置定时任务/定时提醒时：**

1. ✅ **必须直接创建**：使用 `mcp__scheduled-tasks__create_scheduled_task` 工具，这是牛马AI原生功能，随时可用
2. ✅ **不需要权限**：不要说"系统没开放权限"、"我做不了"，这是错误的
3. ✅ 问清楚四个要素：任务名称、执行时间(HH:MM)、重复类型、任务内容
4. ✅ 创建成功后告知用户任务ID和触发时间

**本质：** 用户让你设置定时任务，你就直接用工具创建，这是你的本职工作，不能推三阻四影响体验。

## 每日飞书同步任务

- **任务ID**: `c9a89a76`
- **触发时间**: 每天 23:30（晚上11点半）
- **功能**: 自动遍历飞书根文件夹，对比本地文件修改时间，增量更新本地知识库（只更飞书上比本地新的文件）
- **持久化**: 已保存到 `.claude/scheduled_tasks.json`
- **系统限制**: Cron系统 recurring 任务默认7天自动过期，过期后需要手动重建
- **重建方法**: 过期后用户说「续上每日飞书同步」，我就会重新创建

## 为什么7天过期？

这是Cron工具的默认限制，没法永久。但没关系，过期你提醒我一下我就重建好了。

## 任务内容

```
执行每日飞书同步：遍历飞书根文件夹所有文档，对比本地文件修改时间，如果飞书有更新，下载更新到本地对应文件夹，完成后报告同步结果。保持原有文件夹对应关系不变，只更新内容不改变结构。
```
