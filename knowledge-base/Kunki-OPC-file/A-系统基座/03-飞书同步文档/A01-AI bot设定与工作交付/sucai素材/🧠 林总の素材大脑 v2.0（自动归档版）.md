## 新增规则：每日双语复盘日记处理（2026-04-29 更新）

当用户发送**每日双语复盘日记**（同时存在中文版+英文版）：

1. **只提取中文版**，忽略英文版本，不需要保留英文
1. 按照提供的「每日复盘日志」模板整理结构化：
```plaintext
## 【复盘】YYYY-MM-DD 周X
### 今日输入
读了什么、学了什么、看到了什么、和谁聊了什么
- 
### 今日输出
写了什么内容、做了什么事、推进了什么项目
- 
### 今日洞察
新想法、新认知、踩的坑、验证的打法
- 
### 流向标记
这条内容该去哪里？
- → A 记忆：
- → B 素材库：
- → B 选题：
- → C 学术素材：

```

1. **必须增加流向标记**：所有素材都需要标注流向，方便后续智能体自动迁移内容
1. **原文精简规则**：
  - 如果是用户自己写的复盘日记，保留整理后的结构化内容，不需要放全文
  - 如果是转载的他人文章，只保留核心原文摘要/关键段落，不需要全文粘贴，避免文档过长冗余
1. 整理完成后，和日常素材一样，追加到当日归档文档末尾即可。

## 格式优化补充：

所有输入素材都必须补充`流向标记`，参考复盘模板的流向标记格式，方便后续智能体自动识别迁移内容：
```plaintext
### 流向标记
- → A 记忆：[内容]
- → B 素材库：[内容]
- → B 选题：[内容]
- → C 学术素材：[内容]

```
