## 公众号文章原文

今天豆包收费上了微博热搜，点进去一看，果不其然评论区有些不悦的声音："和国外有这么多差距还敢收钱""用了大半年突然收费，难以接受"诸如此类的……

看完其实挺有感触的，说句实在话——我现在每个月花在AI上的钱大几百块，连续半年了。只要有最新的模型、最新的功能、最新的产品上线，我都是第一时间买，第一时间上手去试。

很多人说AI不是越来越便宜了吗？没错，基础款确实在降价，市面上也有很多免费的AI产品。但真正最强的那一档从来没便宜过，而且还在涨，疯狂涨，无敌涨。更快的推理、更长的上下文、更强的代码能力，每一项都要额外付费。越前沿的能力，成本越高。

这背后的逻辑是什么？能用上最强工具的那批人，效率在指数级拉开，而后面的人可能根本意识不到差距已经存在了。

但今天我想聊一个更根本的问题——大部分人对花钱用AI这件事，心态从一开始就搞反了。

你觉得买AI会员是在花钱。但本质上这是在投资——投资你自己的生产力。

做过生意的人都理解一个道理：只要回报大于投入，就应该持续投。投广告是这样，投AI也是这样。我用AI写论文、搭工作流、做内容、跑商业化项目，它帮我省下来的时间和赚回来的钱，早就把会员费翻了好几倍。只要这个投产比是正的，这笔钱就不该省。

再说句更直白的，现在绝大部分人每天刷好几个小时短视频，我之前也是这样，很容易陷入信息茧房。在这样的大环境下，如果你愿意花一点钱，让最聪明的AI来陪你思考、帮你干活、替你梳理信息——这件事带来的长期复利，远比你现在能感受到的要大得多。

一个100分的工具就摆在那里，你为了省一两百块跑去用一个60分的。你觉得你在省钱，但你真正亏掉的是你的时间成本和决策成本。

去杭州学习，听到了一个观点，现在看来非常之正确：再穷不能省 token，再穷不能省模型。

我知道大家可能预算有限，但在你能负担的范围内，永远去用你够得着的最好的那个工具，这一定是AI时代对你自己最大的尊重。
