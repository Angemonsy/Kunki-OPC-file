# AI选题调研智能体 - 自动化内容生产项目

## 项目目标

创建一个完整的自动化内容生产智能体，能够：
1. 根据林总的人设和商业定位，每日抓取AI相关热点
2. 自动生成匹配定位的选题推荐并评分
3. 调用现有生产线，自动产出公众号文章 + 短视频口播文案
4. 标注配图位置，调用截图工具自动截图并插入
5. 实现从热点到成品文案的全自动化

### ✅ 已具备的基础设施

- `web_search`：实时网络搜索，抓取热点
- `browser-use`：浏览器自动化，支持网页截图
- `x-reader-url`：提取网页正文内容
- 完整的知识库沉淀：13大爆款元素、标题公式、文案框架、风格萃取

## 言论红线规则（必须严格遵守）

保护保研是第一优先级：

- ✅ **允许**：分享「我个人为什么选择保研+AI双线推进」「我个人在象牙塔里遇到的困惑和思考」
- ❌ **禁止**：「考研保研都是坑」「象牙塔没用读大学没用」「所有人都出来做副业」
- ✅ **表达原则**：用「我个人体验」「我觉得」「对我来讲」个人视角，承认多元选择，不极端化

## 模式选择

**自动模式**（日常更新推荐）：
- 只在选题确认和最终成品两个节点暂停
- 效率优先，5-10分钟出一篇

**交互模式**（重点内容打磨）：
- 选题、框架、文案每步暂停让用户确认
- 适合重点爆款冲刺
