## 小红书卡片生成器分析

这是一个**纯HTML+JS的在线小红书卡片生成工具**，核心功能：
- 支持多卡片（多页）批量生成
- 两种编辑模式：内容编辑 + 排版微调
- 支持拖拽排序块
- 点击元素可微调位置、字体大小、边距
- 富文本工具栏支持加粗/高亮
- 使用 html-to-image 导出高清图片（3倍像素）
- 默认尺寸 375×500px，符合小红书竖图比例

已有的功能已经很完整：✅ 实时编辑 ✅ 可视化排版 ✅ 高清导出

## PPT作品分析与方法论沉淀

成功提取了林总的《世界经济课堂展示》PPT中的22张图片，完整品鉴后提炼出**「林总GPT全景生图PPT法」**：

### 核心发现

整张幻灯片（背景+文字意境）**全都是GPT生成**，只需要自己叠加文字卡片微调——这个思路太颠覆了！出来的效果是专业发布会级别，碾压传统模板。

### 四大黄金原则提炼

1. **主题意象化** — 一页一个核心意象，用画面讲故事
2. **浅底文字层** — 浅背景+半透明白卡片，保证可读性
3. **图文分层** — 背景负责意境，前景负责信息
4. **配色统一化** — 蓝金配方（#F8F5F0 + #165DFF + #D4AF37）贯穿全程，高级感拉满

### 五步SOP标准化

1. 内容定稿 → 2. 意象构思 → 3. GPT生图 → 4. 文字叠加 → 5. 微调对齐

### 扩展需求记录

用户提出：当已有论文图表/原生图片需要放入PPT时，如何整合？

**可行方案评估**：
- ✅ 方案一（最简单可用）：GPT生成整张背景意境图，手动把自己的图表放到前景半透明白卡片里 → 现在就能用
- ⭐ 方案四（全自动化）：Python+OpenCV自动合成 → 技术可行，但开发量大，待后续需求起来再做
