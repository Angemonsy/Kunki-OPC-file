# 每日AI热点任务 - 2026-05-08

## 项目目标
每日自动获取最新AI热点资讯，进行选题推荐和分析，支撑内容创作

## 当前状态
- ✅ AIHOT Skill 已成功安装配置
- ✅ API测试通过，可正常获取资讯
- ✅ 已融入每日选题流程，替换原有自动化爬取方案

## 流程变更（2026-05-08更新）

### 旧流程（已废弃）
1. Scout爬取IT之家AI频道 → 获取候选池
2. 人工筛选 → 生成AI社群日报
3. Editor评分 → 输出选题报告

### 新流程（AIHOT驱动）
1. **触发**：每日自动触发时，调用 `AIHOT` Skill获取最近24小时精选资讯
   - 用户说"今天AI圈有什么"/"最近AI热点" → 精选模式（最近24小时）
   - 用户说"AI日报"/"今日日报" → 完整日报模式
   - 用户说关键词 → 自动关键词搜索
2. **AI社群日报**：从AIHOT返回结果中挑选5条与普通人关系最大的新闻，按格式整理
3. **Editor选题分析**：基于全部资讯筛选≥5个候选选题，五维权重评分，输出Top3推荐
4. **输出**：两份飞书文档 + 本地知识库存档

## 优势
- 数据源更优质：AIHOT每日人工精选，质量比爬虫更高
- 操作更省心：一键获取，不用维护多个爬虫源
- 格式更规整：返回结构化数据，直接可用

## 触发机制
- 每日定时任务：cron 06:55 自动触发，使用AIHOT获取资讯
- 用户手动触发：用户发"今天AI圈有什么"自动调用AIHOT
