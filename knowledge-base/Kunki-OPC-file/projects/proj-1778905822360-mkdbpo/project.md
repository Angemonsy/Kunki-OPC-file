## 工作原则

- 飞书/本地知识库/neuDrive三端都要能找回关键战略信息。
- 不把540降级为纯副业赚钱号；赚钱切口服务于长期能力体系。
- 所有商业建议必须落到：人群、需求、产品、价格、交付、案例。
- 优先小规模MVP，不做重交付，不盲目all in任何合作。
- 商业兴奋不能挤掉IELTS 6.5。
- BNI/OPC资源合作必须先评估产品质量、成交案例、分成机制、交付流程、时间成本、长期IP匹配度。

## 风险提醒

1. 账号拆太多导致执行力崩。
2. 商业号变成广告号。
3. 内容号被商业号污染。
4. 为成交触碰灰色大学生需求，如论文代写、造假、违规搬运。
5. 把真实案例包装误解为虚假吹牛。
6. 商业资源兴奋挤压IELTS备考。
7. 线下资源合作筛选不足，导致时间被低质量项目吞噬。
