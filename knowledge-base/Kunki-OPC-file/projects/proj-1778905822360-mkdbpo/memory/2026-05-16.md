## 本轮新增判断：账号命名方向

用户提出“我是林kunki”更像长期个人昵称，但内容号和商业号可能需要体现行业场景，让陌生用户一眼知道账号做什么。

当前判断：
- “我是林kunki”适合作为长期母品牌/署名/口播自我介绍，不适合单独承担早期账号获客和用户理解任务。
- 现阶段账号昵称应采用“个人名 + 场景关键词”，兼顾长期个人品牌资产和短期场景识别。
- 内容号优先推荐：“林kunki｜大学生用AI”。它直接锚定人群和场景，承接540学生法则、AI小结果、学习提效、副业起步、真实成长故事。
- 商业号优先推荐：“林kunki｜AI工具商业化”；若想更口语、更强转化，可测试“林kunki｜AI工具变现局”。它承接AI工具、智能体、OPC超级个体、工具测评、分销和项目转介。
- 命名原则：不要过度文艺，不要过度概念化，也不要一上来太像割韭菜副业号；先让用户看懂，再逐步沉淀个人品牌。
