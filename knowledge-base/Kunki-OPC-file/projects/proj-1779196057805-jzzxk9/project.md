# 540学生 · 内容创作与一人公司长期项目

## 一、项目定位

这是一个**长期内容资产与个人 IP 飞轮项目**，不是单篇文案生产任务。

核心目标是围绕林总的「**540学生法则**」「**AI时代大学生一人公司**」「**AI工具与系统**」「**大学结果**」「**成长实验**」「**社交链接与销售**」等长期主题，持续沉淀选题、文案、发布记录、数据反馈、爆款复盘、用户评论、产品转化与个人故事素材。

项目服务于三个长期目标：

1. **个人 IP 建设**：把林总从"AI工具教程号"升级为"**05后大学生 AI 一人公司实践者** / 我是林kunki"。
2. **内容飞轮增长**：持续输出抖音、视频号、小红书、公众号等多平台内容，形成选题—创作—发布—反馈—复盘—再创作闭环。
3. **商业转化承接**：通过内容沉淀信任，导向资料包、咨询、陪跑、社群、合作分佣等产品与服务。

```
我是林kunki，05后大学生，正在边保研边做AI一人公司。
```

## 八、OPC资源的正确位置

OPC 资源不能直接前置成「我有资源，你来对接」，否则容易显得像中介、项目贩子或割韭菜。

**正确表达：**
> 我不是一上来卖项目，我是在记录一个大学生如何用 AI、内容和资源整合，搭建自己的一人公司系统。在这个过程中，我接触到了一些真实项目、真实资源、真实合作机会，也会把里面的判断、踩坑和路径分享出来。

OPC 应该被包装成「**商业判断力训练场**」，不是单纯资源分发。

**安全表达：**
> 我不推荐大家盲目冲项目，我更想记录自己如何判断一个项目值不值得做。

## 九、项目资产管理规则

### 9.1 内容状态分层

- **选题池**：想法、灵感、主题方向，尚未写成完整文案。
- **草稿库**：文章初稿、短视频脚本、待修改内容，统一归入 `D-内容创作/08-草稿库/`。
- **已发布文案**：只有实际发布后，才归入 `E-产出交付/01-已发文案/`。
- **数据反馈**：发布后的播放、点赞、评论、收藏、转发、关注、私信、转化情况，归入 `E-产出交付/03-数据反馈/`。
- **复盘沉淀**：爆款原因、失败原因、可复用结构、评论洞察，归入 `C-记忆核心/03-经验沉淀/` 或对应项目复盘文档。

### 9.2 已发与未发红线

未发布内容绝不放入已发文案目录。

只有当用户明确说明"已发布/已发出/发布完成"，或提供发布时间、发布平台、发布链接、数据反馈后，才视为已发布内容。

状态不明确时，一律按草稿处理。

## 十、长期工作流

### Step 1：收集输入
输入来源包括：
- 林总口述灵感
- 每日学习笔记
- 线下局复盘
- 热点链接
- 用户评论和私信
- 已发布内容数据
- AI工具实测结果

### Step 2：归入主题板块
每条输入归入对应母题：OPC / 540 / AI工具 / 大学结果 / 成长实验 / 社交链接与销售。

### Step 3：生成选题
每个主题长期维护选题池，按照流量价值、IP价值、商业价值、风险程度排序。

### Step 4：产出草稿
每个选题根据平台生成不同版本：
- 抖音/视频号口播
- 小红书图文
- 公众号长文
- 朋友圈/私域短文

### Step 5：发布与记录
发布后记录：平台、发布时间、标题、链接、封面、正文版本。

### Step 6：数据复盘
至少记录：播放/阅读、点赞、评论、收藏、转发、涨粉、私信、成交/咨询线索。

### Step 7：沉淀方法论
每条有效内容都要沉淀：
- 为什么有效/无效
- 哪个钩子有用
- 哪个观点引发评论
- 哪类用户被吸引
- 能否改写成下一条内容

**允许并推荐：**
- ✅ 「对我个人来讲」「我觉得」「以我的经验」
- ✅ 「我不是反对读书，而是反对只会读书」
- ✅ 「我想在大学期间提前完成社会化训练」
