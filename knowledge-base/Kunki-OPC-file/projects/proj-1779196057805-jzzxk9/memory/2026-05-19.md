## OPC内容判断

OPC不能直接讲成“一个人注册公司”或“AI帮普通人暴富”。在本项目中应定义为：
> 一个人用 AI、内容、产品、系统和外部协作网络，把自己的能力放大成一套可交付、可获客、可成交、可复利的小型商业系统。

核心立场：**AI放大的是已有业务、已有能力、已有需求，而不是凭空变出一个商业模式。** 没有真实需求、客户、产品、交付，AI只会放大自嗨。

## 项目结构确认

**结论：内容号和商业号不拆分成两个长期项目，统一放在当前项目管理。**

当前统一放在「540学生 · 内容创作与一人公司长期项目」下，OPC是核心专题：
- 内容号：做人设、讲认知、记录实践、建立信任（540学生法则全类目）
- 商业号：产品化承接需求、展示工具/资料/咨询/陪跑（在同一项目下作为子板块）
- OPC：作为贯穿内容号和商业号的商业化总框架，把AI工具、成长实验、540法则全部串起来

等商业号有稳定产品线、稳定成交、稳定数据后，再考虑拆分独立项目。
