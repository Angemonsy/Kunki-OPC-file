# 林总内容创作长期发展项目

## 1. 项目定位

这是一个长期内容资产与个人 IP 飞轮项目，不是单篇文案生产任务。

核心目标是围绕林总的「540学生法则」「OPC普通人的一人公司」「AI工具与系统」「大学结果」「成长实验」「社交链接与销售」等长期主题，持续沉淀选题、文案、发布记录、数据反馈、爆款复盘、用户评论、产品转化与个人故事素材。

项目服务于三个长期目标：

1. **个人 IP 建设**：把林总从“AI工具教程号”升级为“05后大学生 AI 一人公司实践者 / OPC林Kunki”。
2. **内容飞轮增长**：持续输出抖音、视频号、小红书、公众号等多平台内容，形成选题—创作—发布—反馈—复盘—再创作闭环。
3. **商业转化承接**：通过内容沉淀信任，导向资料包、咨询、陪跑、社群、合作分佣等产品与服务。

## 2. 核心内容母题

### 2.1 OPC / 一人公司系列

核心表达：用 AI 把自己经营成一家公司。

重点方向：
- 大学生为什么适合一人公司
- 普通人如何从内容、工具、服务、社群开始 OPC
- 一人公司不是单打独斗，而是前端信任 + 后端协作网络
- OPC 与 AI、供应链、知识付费、社群、个人 IP 的结合

### 2.2 540学生法则系列

核心表达：课内用 AI 高效拿结果，课外用 540 训练现实能力。

结构：
- 3个100：AI工具使用、目标推进、优质信息输入
- 4个60：健身、社交表达、内容输出、销售成交

重点方向：
- “锻炼被看见的能力”对应链接与销售板块
- 大学生不只要绩点，还要训练表达、链接、成交、交付
- 学校结果与真实世界能力并行推进

### 2.3 AI工具与系统系列

核心表达：AI不是聊天玩具，而是普通人的杠杆。

重点方向：
- AI工具真实使用案例
- AI工作流、智能体、知识库、自动化系统
- 大学生如何用 AI 提效学习、内容创作、项目交付
- AI一人公司系统搭建与迭代

### 2.4 大学结果系列

核心表达：课内用 AI 和系统方法拿关键结果。

重点方向：
- 保研 / 港科广 / IELTS / 论文 / 竞赛
- 如何用最低投入拿高价值学业结果
- 不反学校，不贬低象牙塔，而是讲“我如何在大学系统内外双线成长”

### 2.5 成长实验系列

核心表达：真实记录一个大学生从象牙塔走向市场的养成过程。

重点方向：
- 健身、形象、穿搭、皮肤、表达
- 社交破圈、线下局复盘、链接贵人
- 执行力、情绪管理、能量管理
- 生活号与工作号之间的人设协同

### 2.6 社交链接与销售系列

核心表达：被看见、被信任、被选择，是大学生必须训练的能力。

重点方向：
- “锻炼被看见的能力”后续延展
- 线下局、社交表达、私域连接
- 从内容获得信任，从信任走向咨询/产品/合作
- 销售不是割韭菜，而是识别需求、解决问题、完成交付闭环

## 3. 项目资产管理规则

### 3.1 内容状态分层

- **选题池**：想法、灵感、主题方向，尚未写成完整文案。
- **草稿库**：文章初稿、短视频脚本、待修改内容，统一归入 `D-内容创作/08-草稿库/`。
- **已发布文案**：只有实际发布后，才归入 `E-产出交付/01-已发文案/`。
- **数据反馈**：发布后的播放、点赞、评论、收藏、转发、关注、私信、转化情况，归入 `E-产出交付/03-数据反馈/`。
- **复盘沉淀**：爆款原因、失败原因、可复用结构、评论洞察，归入 `C-记忆核心/03-经验沉淀/` 或对应项目复盘文档。

### 3.2 已发与未发红线

未发布内容绝不放入已发文案目录。

只有当用户明确说明“已发布/已发出/发布完成”，或提供发布时间、发布平台、发布链接、数据反馈后，才视为已发布内容。

状态不明确时，一律按草稿处理。

## 4. 长期工作流

### Step 1：收集输入

输入来源包括：
- 林总口述灵感
- 每日学习笔记
- 线下局复盘
- 热点链接
- 用户评论和私信
- 已发布内容数据
- AI工具实测结果

### Step 2：归入主题板块

每条输入归入对应母题：OPC / 540 / AI工具 / 大学结果 / 成长实验 / 社交链接与销售。

### Step 3：生成选题

每个主题长期维护选题池，按照流量价值、IP价值、商业价值、风险程度排序。

### Step 4：产出草稿

每个选题根据平台生成不同版本：
- 抖音/视频号口播
- 小红书图文
- 公众号长文
- 朋友圈/私域短文

### Step 5：发布与记录

发布后记录：平台、发布时间、标题、链接、封面、正文版本。

### Step 6：数据复盘

至少记录：播放/阅读、点赞、评论、收藏、转发、涨粉、私信、成交/咨询线索。

### Step 7：沉淀方法论

每条有效内容都要沉淀：
- 为什么有效/无效
- 哪个钩子有用
- 哪个观点引发评论
- 哪类用户被吸引
- 能否改写成下一条内容

4. 建立多平台内容模板：抖音/视频号口播、小红书图文、公众号长文。
5. 建立发布数据记录表和每周复盘机制。

## 6. 长期原则

- 内容创作不是零散写稿，而是长期 IP 资产建设。
- 每条内容都要进入“选题—草稿—发布—数据—复盘—沉淀”的闭环。
- 流量型内容负责破圈，观点型内容负责建立立场，故事型内容负责建立信任，产品型内容负责转化。
- 保护保研/升学安全，表达可以有冲突，但不能贬低学校、专业、群体或制度。
- 始终保持真实：林总不是完美导师，而是一个正在用 AI 和 OPC 方法论真实往前冲的大学生实践者。
