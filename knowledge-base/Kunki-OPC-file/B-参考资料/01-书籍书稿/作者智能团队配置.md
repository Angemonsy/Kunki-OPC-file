## 一人AI公司智能体团队分工配置（用于《OpenClaw一人公司：AI自媒体运营实战手册》参考）

### 一、整体架构原则

基于OpenClaw搭建可扩展的一人AI公司，核心设计规则：

📌 **飞书云文档是唯一权威数据源**：所有智能体的人设、规则、配置全部存在飞书，本地OpenClaw云服务器仅作为执行环境和缓存

🔄 **双向同步机制**：Main Agent（总管）负责保证飞书文档和本地配置一致，用户修改任一位置都会同步更新

🧩 **独立隔离设计**：每个智能体独享独立工作区、内存、配置，互不干扰，方便迭代重构

⚙️ **OpenClaw原生能力复用**：定时任务、消息路由、权限管理全部使用OpenClaw原生能力，可维护性强

### 三、各智能体核心职责

#### 1. 选哥（xuanguan）- 选题官
- **核心工作**：AI自媒体内容赛道的热点挖掘、选题策划
- 每日自动爬取小红书、公众号、抖音热点榜，筛选符合「我是林kunki」定位的选题方向
- 结合公众号订阅的行业大号最新文章，提炼可创作的选题
- 每日早6:55主动推送当日5个候选选题给老板，供创作者选择
- 负责承接公众号监控推送的新文章，进行选题价值初判

#### 2. 内容助手（contenthelper）- 内容初稿生成
- **核心工作**：根据确定的选题，生成符合账号调性的初稿内容
- 按照飞书文档中预设的账号内容模板、语气、结构生成初稿
- 支持图文教程、行业观点两种不同内容类型的生成
- 初稿自动输出Markdown格式，方便后续编辑和排版

#### 3. 催活助手（cuihuo）- 任务扫描提醒
- **核心工作**：项目进度管理、待办事项提醒、规则更新同步
- 定期扫描飞书多维表格中的任务清单，提醒负责人逾期/即将到期的任务
- 记录用户的习惯偏好，当有规则更新时，自动同步飞书文档，保证权威数据源一致
- 统计各智能体的工作数据，定期输出运营报表

#### 4. 公众号监控助手（gzhmonitor）- 公众号文章监控
- **核心工作**：自动订阅抓取目标公众号的最新文章，推送给选题官
- 基于wechat-watch技能部署，每日10:00自动检查已订阅的5个行业头部公众号的新文章
- 自动抓取文章正文，推送给选题官进行价值判断，不漏掉任何行业热点
- 已订阅公众号：奇绩怪谈AIQ（现我是林kunki）、数字生命卡兹克、赛博禅心、甲木未来派、APPSO

#### 5. 学习搭子（xuedadazi）- 保研学习陪伴
- **核心工作**：服务老板P1优先级的保研冲刺需求
- 每日提醒学习进度，解答专业课、论文写作相关问题
- 督促英语、专业课复习，整理保研信息和通知
- 模拟面试，提供答题思路参考

#### 6. 素材整理大师（sucai）- 素材整理价值提炼
- **核心工作**：帮老板整理每日刷到的碎片化素材，提炼创作/副业价值
- 对老板发送的文章、视频、观点进行整理，分类存储到飞书素材库
- 从碎片化信息中提炼可用于创作的选题、观点、案例
- 给老板的AI副业项目提供方向参考和思路启发

### 五、给读者参考的最佳实践

1. **一定坚持飞书唯一权威**，避免本地配置和文档不一致，换设备、重新部署只需要重新拉取飞书文档即可
2. **花名单词全小写+无特殊符号**，方便配置OpenClaw路由，不容易出错
3. **新智能体创建全程手动修改配置比交互式创建更可靠**，不容易卡住，四个地方必须添加配置：`agents.list` / `channels.feishu.accounts` / `bindings` / `tools.agentToAgent.allow`
4. **定时任务全部用OpenClaw原生cron管理**，不要修改系统crontab，方便在OpenClaw后台统一管理
5. **每个智能体职责单一**，不要一个智能体做所有事情，方便迭代重构，重构某个智能体不会影响其他团队成员
