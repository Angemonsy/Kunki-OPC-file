当笔记软件遇上AI：Obsidian的独特定位\n\nObsidian，本质上是一款笔记软件。没错，就像你手机上的备忘录、电脑上的Word文档、或者你用过的小黑板一样，它最核心的功能就是——记笔记。\n\n但和传统的笔记软件不同的是，Obsidian不是一个孤立的文字编辑器。它更像是一个\"知识操作系统\"——你可以用它来记录想法、整理资料、关联信息、输出文章，而所有这些操作都在同一个地方完成，不需要你在十几个App之间来回切换。\n\n传统笔记软件的痛点是什么？你写了一篇读书笔记，存在备忘录里；你看到一个不错的案例，截图保存到了相册；你写了一篇公众号文章，存在Word文档里；你有一个灵感，随手记在了微信文件传输助手里。结果就是——你的内容散落在各个角落，要用的时候找不到，AI更不可能帮你调用这些分散的素材。\n\nObsidian解决了这个问题。它把所有内容集中在一个地方——一个叫\"知识库\"的文件夹里。你的读书笔记、你的灵感、你的案例素材、你的历史文章，全部在这里。而当你给AI下指令时，AI就能直接进入这个知识库，翻阅你所有的素材，然后基于这些真实的、属于你的信息来写作。\n\n在本教程的体系里，Obsidian不是单独存在的——它是整个AI内容生产系统的\"地基\"。你所有的笔记、素材、个人信息、写作风格、历史文章，都会存放在Obsidian构建的知识库里，而AI会直接从这个知识库中读取信息，帮你写出\"像你写的\"内容。\n\n换句话说，Obsidian是这个系统的\"壳\"，而知识库才是这个系统的\"核\"。\n\n## 1.2 知识库：不只是存笔记的地方，它是AI的\"大脑\"\n\n这是本章最重要的一句话，请你在心里默念三遍：\n\n**知识库不只是存笔记的地方，它是AI的\"大脑\"。**\n\n什么意思？让我们用一个场景来说明。\n\n假设你是一位做职场培训的自媒体人。你让AI帮你写一篇关于\"中年人如何应对职场焦虑\"的公众号文章。如果你只是打开一个聊天窗口，对AI说\"帮我写一篇关于职场焦虑的文章\"，AI会给你什么？一篇\"正确的废话\"——观点正确、语言流畅，但没有任何个人色彩，读者看了不会觉得\"这是他写的\"。\n\n但如果你在Obsidian里建了一个知识库，里面存了你过去5年的培训经历、你接触过的学员案例、你对行业的深度观察、你之前写过的文章风格……这时候AI再写同一篇文章，会发生什么？\n\nAI会自动读取你的个人信息——你的职业背景、你的受众画像；AI会自动读取你的写作风格——你习惯怎么开头、怎么转折、怎么结尾；AI会自动读取你的历史文章——你之前聊过哪些话题、用过哪些案例。然后，AI会基于这些真实的、属于你的素材，产出一篇\"像你写的\"文章。\n\n这就是知识库作为\"AI的大脑\"的真正含义：**AI写文章时，会自动读取你知识库里的个人信息、写作风格、历史文章，才能写出\"像你写的\"内容。**\n\n再举一个更具体的例子。知识库模板里，有一个文件叫\"个人自传(持续更新).md\"，还有一个叫\"社群总结(持续更新).md\"。当你把你的个人经历、你运营社群的经验和心得写进这些文件之后，AI在帮你写文章时，就能调取这些真实经历作为素材——你曾经帮助过什么样的人、你遇到过什么样的困难、你是怎么解决的。这些真实的个人故事，是AI凭空编不出来的，它们只存在于你的知识库里。\n\n可以想象一下这样的对比：同样一个写作任务，A同学的知识库里只有三五个文件，内容简略；B同学的知识库里有详细的个人自传、丰富的案例、多篇历史文章、清晰的开篇库和创作规范。AI帮B同学写的文章，一定会比帮A同学写的文章更有深度、更有个人风格、更有说服力。差距不在AI的能力，而在知识库的丰富程度。\n\n## 1.3 知识库内容越丰富，AI越懂你\n\n理解了知识库是AI的\"大脑\"之后，一个自然的推论就是：\n\n**知识库里的内容越丰富，AI能调用的素材就越多，产出质量就越高。**\n\n这就像一个厨师做菜。如果厨房里只有盐和酱油，那做出来的菜味道可想而知；但如果厨房里有几十种调料、新鲜的食材、各种烹饪工具，那厨师就能做出一桌满汉全席。\n\nAI也是一样。你的知识库就是AI的\"厨房\"，你往里面放的每一条内容，都是AI可以用来\"做菜\"的食材。\n\n具体来说，知识库里的哪些内容对AI最有价值？主要包括以下几类：\n\n**个人经历**：你的职业背景、人生故事、转折点。这些是AI帮你写出\"有人味儿\"的文章的核心素材。比如你是一个45岁经历裁员后重新出发的人，这种真实的个人经历一旦写入知识库，AI就能在写文章时自然地融入，而不是编造一个空洞的故事。你的个人经历会存放在\"个人自传(持续更新).md\"这个文件里。\n\n**客户案例**：你服务过的人、解决过的问题。这些案例是文章说服力的来源。当AI能读取到真实的客户故事时，写出来的文章就不再是泛泛而谈的理论，而是有血有肉的实战分享。你的客户案例可以写在\"社群总结(持续更新).md\"中，也可以单独建文件存放在\"03.参考资料库\"文件夹里。\n\n**行业观察**：你对所在行业的理解、趋势判断、独特观点。这些是文章差异化竞争力的来源。当AI能读取到你对行业的独到见解时，就能帮你把这些观点表达得更清晰、更有力量。行业观察可以存放在\"02.领域\"文件夹中。\n\n**写作风格**：你习惯的行文节奏、用词偏好、文章结构。AI读取到这些信息后，就能模仿你的风格写作，让读者觉得\"这确实是他写的\"。写作风格信息可以记录在\"04.我的上下文\"文件夹和\"AI创作规范.md\"中。\n\n**历史文章**：你之前写过的所有文章。AI可以从中学习你的写作模式，保持风格的一致性。历史文章可以存放在知识库的相应文件夹中，AI会在需要时自动读取。\n\n**开篇素材**：知识库模板提供了\"聊观点类开篇库.md\"和\"教知识类开篇库.md\"，这些是经过验证的文章开头模板。AI可以从中选取合适的开篇方式，让你的文章开头就抓住读者的注意力。\n\n这些素材，越丰富越好。你往知识库里积累的每一条内容，都在让AI变得更懂你。\n\n## 1.4 你往知识库里积累的每一条内容，都在让AI变得更懂你\n\n让我们把上一节的观点再推进一步。\n\n很多人在刚开始用知识库的时候会有一个困惑：\"我先往里面放什么？\"或者\"我写的东西不够好，要不要先放一放？\"\n\n答案是：**不要等，现在就开始积累。哪怕只是一句话的灵感、一段随意的观察、一个不成熟的想法，都值得写进知识库。**\n\n为什么？因为AI的学习是持续的、累积的。你今天写的一段个人经历，可能在这个星期帮AI写出了一篇好文章的开头；你下周补充的一个客户案例，可能让AI在下一篇稿子里多了一个有力的论据；你一个月后整理的行业观察，可能成为AI帮你写出的爆款文章的核心观点。\n\n每一条内容，都在让AI多了解你一点。每一次积累，都在提升AI产出内容的质量。\n\n举一个真实的场景：假设你今天在社群里看到一个提问，你花10分钟帮忙解答了。这个过程中，你可能会想到一些有价值的观点或方法。如果你把这10分钟的收获随手记到知识库的\"00.收件箱\"文件夹里（哪怕只是三五句话），下次AI帮你写相关主题的文章时，就能调取到这个真实的互动场景，让文章更有说服力。但如果你没有记下来，这个素材就消失了，AI也永远无法调用它。\n\n知识库模板为你提供了清晰的结构来组织这些内容。模板中包含的文件夹有：\n\n- **00.收件箱**——用来随手记录未分类的想法，什么都可以往里扔，不用纠结归类\n- **01.项目**——正在进行的项目，比如你正在写的一系列文章\n- **02.领域**——你关注的领域，比如职场发展、AI应用、个人成长等\n- **03.参考资料库**——收集的素材和资料，比如你看到的好文章、好的案例\n- **04.我的上下文**——你的个人背景、写作风格等信息，这是AI最常读取的文件夹\n- **05.插件**——插件相关文件\n- **06.附件**——图片、文件等附件\n- **07.产品管理**——产品相关管理文件\n\n这些文件夹的设计，就是为了让你有地方放每一条内容，而不会觉得\"无处安放\"。不知道放哪里的内容，就先扔进\"00.收件箱\"，等有时间再整理归类。\n\n同时，模板里还有几个基础文件，是你最先要关注和填写的：\n\n- **CLAUDE.md**——AI的核心配置文件，告诉AI你的基本设定，这是AI读取的第一个文件\n- **个人自传(持续更新).md**——你的个人经历和背景\n- **社群总结(持续更新).md**——你的运营经验和心得\n- **聊观点类开篇库.md**——观点类文章的开篇素材\n- **教知识类开篇库.md**——知识类文章的开篇素材\n- **AI创作规范.md**——AI创作的规范和标准\n\n这些文件就是AI最先读取的\"关于你的信息\"，也是你最先要填写的内容。你不需要在第一天就把所有内容都填满，但你需要在每一天都往里面添加一点东西。30天后回头看，你会惊讶于AI已经如此了解你。\n\n记住：**知识库不是一蹴而就的，它是一个持续积累、持续完善的过程。**\n\n## 1.5 使用的AI工具：Claudian\n\n在整个体系中，我们使用的AI工具是Claudian——一个Obsidian插件。统一使用Claude引擎，配置好之后所有对话、写作、记忆都在Claudian里完成。\n\n这意味着什么？意味着你不需要打开浏览器去访问某个AI网站，不需要在多个工具之间来回切换。你只需要打开Obsidian，在Claudian的对话窗口里和AI交流，AI就会直接读取你知识库里的内容，帮你写作、帮你选题、帮你起标题——一切都在Obsidian这一个地方完成。\n\nClaudian就像你的一个\"AI员工\"，它住在你知识库里面，随时待命。你给它下指令，它就去知识库里找素材、找风格、找历史，然后给你交付结果。\n\n值得注意的是，Claudian不在Obsidian的官方插件市场中，不能通过常规的\"社区插件浏览\"方式安装。需要通过自动化脚本安装或者BRAT插件来安装。如果你之后需要重新安装，可以通过BRAT插件（一个用于安装社区测试版插件的工具）或手动下载文件的方式来完成。\n\nClaudian的配置也很简单。安装完成后，你只需要在Obsidian设置→Claudian→Claude标签→自定义变量中配置三个环境变量：ANTHROPIC_API_KEY（你的API密钥）、ANTHROPIC_BASE_URL（API代理地址）、ANTHROPIC_MODEL（使用的AI模型）。这三个变量中，只有API Key需要你替换为自己有效的令牌，其余两个按照本教程的配置即可。\n\n## 1.6 本指南的学习路径概述\n\n这本指南将带你从零开始，一步步掌握Obsidian和AI内容生产的完整流程。整体学习路径如下：\n\n**第一阶段：安装与配置**\n\n这是本指南前5章的内容。你将学会如何准备安装环境、如何完成所有工具的安装和配置。到这个阶段结束时，你的电脑上将拥有一个完整可用的Obsidian +
