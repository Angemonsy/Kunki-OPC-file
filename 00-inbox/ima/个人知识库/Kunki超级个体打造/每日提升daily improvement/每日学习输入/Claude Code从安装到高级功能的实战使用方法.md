# Claude Code从安装到高级功能的实战使用方法

视频全面讲解了Claude Code从安装到高级功能的实战使用方法，覆盖基础交互、复杂任务处理、多模态与上下文管理、高级定制扩展等内容，具体如下：

* **环境搭建与安装**：在Claude Code官网复制安装命令，在终端粘贴完成安装，可通过Pro/Max会员订阅或API Key两种方式登录，也能使用国产模型驱动。
* **三种工作模式切换**：按Shift+Tab循环切换，默认模式操作前需确认最稳妥，自动模式自动执行编辑操作，规划模式仅讨论方案不修改文件。
* **终端命令执行**：输入叹号进入bash模式，可运行任意终端命令，用于打开文件、创建目录等操作。
* **规划模式使用**：适合复杂项目重构前的方案探讨，可在该模式下明确需求、修改计划后再执行开发。
* **权限跳过设置**：启动时添加--dangerously-skip-permissions参数，可跳过所有终端命令权限检测，提升效率但存在理论风险。
* **后台任务管理**：按Ctrl+B将服务放入后台，用/tasks命令查看后台任务，按K可结束任务，避免阻塞Claude Code。
* **代码版本回滚**：使用/rewind命令或按两下ESC进入回滚页面，可选择回滚代码与对话，仅能回滚自身写入的文件。
* **图片处理功能**：支持拖拽图片或Ctrl+V粘贴图片，可让Claude Code根据设计图图片修改代码。
* **MCP工具接入**：以Figma为例安装MCP Server，授权后可精准还原设计稿，获取组件间距、字体样式等细节。
* **历史会话恢复**：使用/resume命令恢复历史对话，启动时加-c参数可自动恢复上一次对话。
* **上下文管理**：/compact命令压缩上下文减少token消耗，/clear命令清空全部上下文，适配新任务。
* **项目记忆文件**：用/init命令生成CLAUDE.md，可自定义项目信息与要求，重启后自动加载生效。
* **Hook功能配置**：通过/hooks命令设置，可在工具使用前后执行指定逻辑，如代码自动格式化。
* **Agent Skill创建**：创建自定义skill文件，定义任务规则与格式，可自动或手动调用，简化重复任务。
* **SubAgent创建**：用/agent命令创建独立子智能体，拥有独立上下文与工具，适合代码审核等重型任务。
* **Skill与SubAgent区别**：Skill共享主上下文，适合轻量关联任务；SubAgent独立上下文，适合重型隔离任务。
* **Plugin插件使用**：通过/plugin管理插件，一键安装可集成Skill、SubAgent、Hook等全套能力，拓展Claude Code功能。
