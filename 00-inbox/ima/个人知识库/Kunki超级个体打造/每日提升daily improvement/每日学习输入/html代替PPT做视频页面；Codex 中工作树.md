# html代替PPT做视频页面；Codex 中工作树

​

视频讲述了作者用HTML替代PPT制作视频素材的方法与优势，具体如下：

* **创作痛点**：制作视频时，PPT排版、配图调整耗时久，AI生成PPT靠图片拼接，消耗大量token。
* **HTML替代PPT的发现**：B站技术视频的精致交互分镜实际由HTML制作，适合做视频分镜素材。
* **HTML优于PPT的核心原因**：一是基于代码文本生成，更省token；二是尺寸、颜色、位置精准，排版规范不跑偏，生成即成品。
* **AI生成HTML演示一**：用小米Mimo agent，简单提示词即可生成苹果风、黑色背景的小米Mimo大模型HTML介绍页，可自动替换logo，还能一键转可编辑PPT。
* **AI生成HTML演示二**：上传已有视频脚本，简单规定配色与风格，AI快速生成排版工整、元素齐全的HTML，全程不到2分钟。
* **新视频制作流程**：写脚本→AI生成HTML→截图/录屏做素材→按需转PPT存档，token消耗大减，质量更高。
* **核心观点**：AI降低HTML使用门槛，无需代码只需自然语言，是表达方式的进化，让工具回归辅助，表达成为核心。

视频讲述了Codex APP中工作树的概念、原理与完整实战操作流程，具体如下：

* **工作树核心概念**：工作树源自Git，可将同一仓库拆分为多个独立工作目录，托管不同分支并保留完整文件状态，并非简单复制文件。
* **工作树作用**：解决单目录切换分支被打断开发状态的问题，每个任务对应独立目录与分支，互不干扰。
* **派生创建工作树**：在Codex中通过斜杠点击派生，选择“派生到新工作树中继续”，可创建独立分支工作树，区分主树干与分支树干。
* **工作树目录特征**：分支工作树会生成新的working tree目录，由Git管理，修改内容不影响本地主树干代码。
* **多工作树独立开发**：可创建多个工作树并行开发不同功能，如分别修改UI为红色、紫色，运行后各自生效，主目录保持不变。
* **工作树合并到本地**：在满意的工作树创建新分支，点击移动到本地，可将分支功能合并到主树干，完成开发闭环。
* **Codex工作树本质**：Codex未新增底层逻辑，仅将Git工作树操作可视化，降低使用门槛。
