## 3D手办

Nano Banana 火出圈的 3D 手办，看下 Seedream 4.0 也表现非常好。

我丢给我的老母亲和橘子看，他们问，这是哪儿做的呀，你刚拍的吗？

哈哈哈，我滴个乖乖，这是 AI 生成的，算了，反正也解释不清。

```
提示词：
创作一款以图片中角色为原型的1/7比例商业化手办，风格与环境均需写实。

将手办摆放在电脑桌上，使用一个圆形的、没有任何文字的透明亚克力底座。在电脑屏幕上，显示该手办的ZBrush建模过程。电脑屏幕旁边，放置一个印有原画的万代（BANDAI）风格玩具包装盒。
```

要知道，在 Nano Banana 中可得一大串英文提示词才比较好的出这个效果，现在 Seedream 4.0 对中文理解很强，直接用中文描述，好爽啊！

## API 调用

目前可以直接在火山方舟平台上调用 Seedream 4.0，而且可以支持 4K 输出，

现在IPM限制是500，2毛/张。

对于个人开发者或者企业接入相当简单，文档在这：https://www.volcengine.com/docs/82379/1541523

先获取下 API Key

甚至可以直接在体验地址中右上角点击快速 API 接入：

第二步，直接用 Python 接入测试。

```
curl -X POST https://ark.cn-beijing.volces.com/api/v3/images/generations \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $ARK_API_KEY" \
  -d '{
    "model": "doubao-seedream-4-0-250828",
    "prompt": "生成3张女孩和奶牛玩偶在游乐园开心地坐过山车的图片，涵盖早晨、中午、晚上",
    "image": ["https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_imagesToimages_1.png", "https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_imagesToimages_2.png"],
    "sequential_image_generation": "auto",
    "sequential_image_generation_options": {
        "max_images": 3
    },
    "response_format": "url",
    "size": "2K",
    "stream": true,
    "watermark": true
}'
```

甚至，可以利用模板一键快速创建企业级应用，这里还可以创建 Coze 智能体应用。
