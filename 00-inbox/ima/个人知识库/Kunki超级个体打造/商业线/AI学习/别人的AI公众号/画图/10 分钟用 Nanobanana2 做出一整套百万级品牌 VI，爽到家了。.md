我首先给到 Lovart 如下的提示词，主要就是说明清楚我想要创建的品牌是什么，以及想要让 Lovart 做的事情。

```
从0开始帮我创建一个原创品牌，品牌名字叫做‘月蚀LUNAR’，是一款女性香水。
要求：
深度洞察目标用户画像和竞品分析
完整品牌故事 + 调性说明
全套VI系统（logo、包装、店招、APP图标）
首发产品3款渲染图
上市营销方案（小红书种草路径 + 抖音投放脚本 + 朋友圈裂变海报）
甚至帮我生成天猫/抖音店的装修图和首屏banner，确保主角/产品100%一致
```

Lovart 在得到指令之后，会一顿分析，然后给出我三个方案。

我觉得这个非常的人性化，Lovart 没有直接开始动手，而是和用户进行了一次很有必要的交互，来确保接下来的任务准确性。

这里我的选择是

```
使用方案A，该品牌的气质是神秘优雅型(月蚀的神秘感)
```

然后 Lovart 就立刻开始进行设计了，全程遇到生成图片的时候，都使用 Nanobanana2。

很快，我们就得到了一系列用于营销的材料

![[10-分钟用-Nanobanana2-做出一整套百万级品牌-VI，爽到家了。-b1faf54d.gif|图片]]

这个设计整体感觉真的好高级啊，是那种高贵的奢饰品的感觉。

下面我们继续让 Lovart 生成小红书、抖音和朋友圈素材

- 小红书： 使用产品渲染图制作种草笔记
- 抖音： 基于产品图制作投放脚本
- 朋友圈： 利用 Banner 图制作裂变海报

很快我们就得到各种优质的投放素材了

我这里直接选择方案 B，毕竟对于 Lovart 的视频能力，我也是非常信任的！

很快我们就得到了一个投放短视频了，还是非常精美的。
