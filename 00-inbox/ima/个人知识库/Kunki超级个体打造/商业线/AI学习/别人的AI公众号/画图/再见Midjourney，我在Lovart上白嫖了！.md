# 再见Midjourney，我在Lovart上白嫖了！

这是苍何的第 437 篇原创！

大家好，我是苍何。

标题你没看错，这篇文章也不是标题党。

说实话，我算不上 Midjourney 的重度用户。

倒不是不认可它的效果，恰恰相反，每次看到别人用 MJ 生成的图，我都很眼馋。

那无敌的质感和艺术表现力，确实很强。

![[再见Midjourney，我在Lovart上白嫖了！-ffcb8f34.webp|图片]]

但为什么我迟迟没把它当主力？原因很简单：贵，而且麻烦。

每个月几十美金的订阅费，而且还得特殊的网络环境，对于想把 AI 绘画当生产力工具的人来说，这个门槛和成本确实有点高。

所以我一直在等一个机会，等一个能让我用更舒服、更划算的方式用 Midjourney 的机会。

就在前几天，这个机会来了。

我一直在使用的 Lovart，放了个大招，也是我写下今天这个标题的底气所在：

**Lovart 正式接入了 Midjourney！**

更骚的操作是，Lovart 的 Basic 以上会员，可以在会员期内无限使用Midjourney，无需额外积分。

这不就等于，我用一个工具的钱，MJ 给白嫖了？

> PS：对了，之前苍何送了几个 Lovart 年度会员，其中中奖的小伙伴们都可以痛快去体验啦。

我第一时间就冲上去体验了一把，玩了很多 MJ 生图，不得不说，还是很牛逼的。

MJ 最牛逼的还得是风格化，可以通过 SREF code 来控制。我是直接在midlibrary.io 这个网站中寻找喜欢的风格。

然后在提示词后加上--sref + code 即可。

下面分享下我用 Lovart + MJ 设计的一些作品。

## 写在最后

这一套完整的品牌设计下来，我最大的感受已经不是白嫖了 MJ 的快乐，而是一种「我真的可以」的掌控感和成就感。

过去，我们沉迷于寻找最好的“点”，比如哪个模型出图最强。但 Lovart 让我明白，真正拉开差距的，是能将所有点连成线乃至面的工作流和 Agent。

Midjourney 的美学是顶级的点，但只有在 Lovart 这个超级画布里，它才能和 Nano Banana 的精准、Seedream 4 的中文文字、以及视频生成等无数个“点”无缝连接，最终形成一个完整的品牌设计方案的面。

它给我的不是又一个 AI 模型，而是一个满配的创意厨房。它真正把设计师的思考方式，融入到了产品流程和 Agent 里。

所以，当我喊出“再见 Midjourney”时，我告别的不是它的能力，而是那个孤立、昂贵、只能出图的时代。

**我拥抱的，是一个集大成、高效率、能完成整个项目的全新创作范式。**
