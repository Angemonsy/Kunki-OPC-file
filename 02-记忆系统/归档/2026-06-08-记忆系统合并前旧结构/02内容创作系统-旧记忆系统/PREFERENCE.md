## 四、飞轮逻辑

```
生成选题/标题时：
1. 过滤排除项 -> 命中排除项的方向直接剔除
2. 数据验证加权 -> 历史数据好的方向优先推荐
3. 黑洞区降权 -> 数据持续差的方向降低推荐频率
4. 输出推荐 -> 标注每个推荐命中了哪个数据验证项
```
