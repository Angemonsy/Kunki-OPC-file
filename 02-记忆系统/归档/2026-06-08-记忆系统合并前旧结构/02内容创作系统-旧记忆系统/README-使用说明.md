# 记忆系统 — 使用说明

> 让AI真正"记住你"的Obsidian记忆系统。
> 基于四层记忆架构，让每次AI对话都能延续上下文，越用越懂你。

---

## 这是什么

一套放在Obsidian知识库里的Markdown文件，配合 `CLAUDE.md`（Claude Code）或 `AGENTS.md`（Codex）指令，让能读写文件的AI具备跨对话记忆能力：

- **记住你是谁**（身份、业务、目标）
- **记住你在做什么**（本周任务、当前进展）
- **记住你的偏好**（喜欢什么风格、不要什么方向）
- **越用越准**（自动积累观察、衰减过时信息）

## 快速开始

### 第1步：把文件放进你的Obsidian库

把这个文件夹整体复制到你的Obsidian知识库中，建议路径：
```
你的知识库/记忆系统/
```

### 第2步：填写你的基本信息

按优先级依次填写：

1. **SOUL.md** — 给AI取个名字，定义性格和沟通风格（5分钟）
2. **USER.md** — 填写你的基本信息、业务、目标受众（10分钟）
3. **INVENTORY.md** — 列出你的产品/工具/系统（按需）

其他文件（MEMORY、AI观察笔记、PREFERENCE等）不用手动填，AI会在协作中自动积累。

### 第3步：配置 AI 项目说明文件

如果你用 Claude Code，在知识库根目录的 `CLAUDE.md` 中加入以下指令；如果你用 Codex，在 `AGENTS.md` 中加入同等指令（根据你的实际路径调整）：

```markdown
## 记忆系统

每次新对话的第一条回复前，必须执行：

1. 读取 `记忆系统/SOUL.md`（性格内核）
2. 读取 `记忆系统/USER.md`（用户档案）
3. 读取 `记忆系统/MEMORY.md`（长期记忆）
4. 检查周工作区文件是否存在，不存在则创建
5. 用搭档的语气简短汇报当前状态

### 记忆写入规则
- 发现高惊奇度信号 -> 直接写入对应文件，对话末尾通知
- 通知格式：[记忆] 文件名 操作：内容摘要
- SOUL.md是唯一需要事前确认的文件
- 有记忆操作时，结束前追加 MEMORY_LOG
```

### 第4步：开始对话

正常和AI对话即可。AI会：
- 每次开场先读取记忆文件，延续上下文
- 协作中发现值得记录的信息，自动写入
- 每周自动创建周工作区文件，归档上周

## 文件说明

| 文件 | 你需要做什么 | AI会做什么 |
|------|-------------|-----------|
| SOUL.md | 填写AI的性格定义 | 读取，不会擅自修改 |
| USER.md | 填写基本信息 | 持续补充和更新 |
| MEMORY.md | 不用管 | 自动积累偏好和行为模式 |
| AI观察笔记.md | 不用管 | 记录对你的长期观察 |
| PREFERENCE.md | 不用管 | 自动记录内容偏好 |
| INVENTORY.md | 初始填写 | 发现新产品时自动更新 |
| MEMORY_LOG.md | 不用管 | 自动记录操作日志 |
| 记忆协议.md | 了解机制即可 | 按协议执行 |
| 周工作区/ | 不用管 | 每周自动创建和归档 |

## 核心机制

### 惊奇度驱动
AI不会记录所有信息，只记录"高惊奇度"的：
- 修正了之前的认知
- 填补了知识空白
- 某个模式反复出现（2次以上）

### 记忆衰减
动态记忆有生命周期，4周没被用到会逐级衰减，最终清理。这保证记忆始终是"活"的，不会堆满过时信息。

### 毕业机制
反复验证的观察会从MEMORY.md"毕业"到AI观察笔记，成为稳定认知。

## 注意事项

- 这套系统需要配合 **Claude Code / Claudian**、**Codex** 或类似的能读写文件的AI工具使用
- 纯网页版 ChatGPT/Claude 通常无法完整使用（没有本地 vault 文件读写能力）
- 建议先用1-2周，让AI积累足够的记忆再评估效果
