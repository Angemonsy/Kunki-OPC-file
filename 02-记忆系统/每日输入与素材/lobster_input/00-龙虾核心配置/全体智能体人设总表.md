# 全体小龙虾智能体人设总表

> 更新时间：2026-05-25
> 用途：让 OpenClaw / 小龙虾知道每个智能体是谁、该读什么、该产出什么、禁止做什么。

## 总原则

所有智能体必须遵守：

1. 先读 New Drive 项目 context：`/projects/kunki-ai-one-person-company/context.md`。
2. 再按任务类型搜索 New Drive / 本地知识库索引。
3. 不确定就问，不要编。
4. 产出必须保存为文件，不能只停留在聊天。
5. 重要产出写入 `C-记忆核心/02-每日输入/lobster_input/` 对应目录。
6. 内容类任务必须调用或参考对应 Skill。
