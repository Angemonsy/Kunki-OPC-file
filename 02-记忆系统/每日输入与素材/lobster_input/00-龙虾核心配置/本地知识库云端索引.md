## 8. New Drive 只放什么

New Drive 不需要一次性塞入所有本地文件原文。

优先放：

1. 总上下文；
2. 本地知识库索引；
3. 小龙虾人设；
4. 内容助手工作流；
5. 高频 SOP；
6. 每日关键产出摘要。

如果任务需要完整文件，再根据索引从本地 / GitHub / New Drive 附件读取。
